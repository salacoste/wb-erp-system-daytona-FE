# Шаблоны писем: настройка почты и отправка из заказов

В SelSup доступна возможность создавать и использовать **шаблоны писем** для отправки клиентам, например, при работе с оптовыми заказами. Это позволяет ускорить коммуникацию и использовать единый формат писем.

## Где находятся шаблоны писем

Раздел **Настройки → [Шаблоны писем](https://selsup.ru/application/email-templates)**[.](https://selsup.ru/application/email-templates)

В этом разделе вы можете создавать, редактировать и удалять шаблоны, которые затем используются при отправке писем из оптовых заказов.

## Создание шаблона письма

1.Перейдите в раздел **Настройки → [Шаблоны писем](https://selsup.ru/application/email-templates)[.](https://selsup.ru/application/email-templates)**

2.Нажмите кнопку **Добавить шаблон письма**.

**Важно:** в SelSup можно создать только **один шаблон письма**.\
Если шаблон уже создан, для изменений используйте редактирование существующего шаблона вместо создания нового.

3.В открывшемся окне укажите:

- **Заголовок письма** — тема письма, которую увидит получатель;
- **Контент (текст) письма** — основной текст сообщения.

4.Нажмите **Сохранить**, чтобы сохранить шаблон.

После сохранения шаблон появится в списке доступных шаблонов.

## Редактирование и удаление шаблонов

Сохранённый шаблон можно:

- **изменить** — при необходимости обновить текст или заголовок;
- **удалить** — если шаблон больше не используется.

## Подключение почты (интеграция с почтовым сервисом)

Перед отправкой писем из SelSup необходимо настроить интеграцию с почтовым сервисом.

1\. Перейдите в **Настройки → [Интеграции](https://selsup.ru/application/integration/)**.\
Интеграция с почтовым сервисом находится во вкладках **«Все»** и **«Доп. функции для работы с заказами»**.

2\. Откройте интеграцию с почтовым сервисом и нажмите **Настроить**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/01/screenshot_137.png.webp)

3\. Заполните данные по подсказкам на странице интеграции и сохраните настройки.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/01/screenshot_138.png.webp)\
После успешной настройки отправка писем из заказов станет доступна.

Для отправки письма у покупателя/получателя должна быть указана электронная почта.

## Использование шаблонов писем в заказах (оптовых и розничных)

**Важно перед отправкой**

Убедитесь, что:

- настроена **интеграция с почтовым сервисом** (см. раздел выше);

- в заказе указана **электронная почта получателя**.

**Как отправить письмо по шаблону**

1.  Откройте нужный заказ:

    - **Оптовый:** **Заказы на отгрузку → [Оптовый заказ](https://selsup.ru/application/wholesale/?actual=true&ascending=false&limit=100&page=1&sortBy=CREATEDDATE&type=WHOLESALE)** → создайте новый заказ и **сохраните** его (или откройте уже созданный). Подробнее о работе с оптовыми заказами вы можете ознакомиться в соответствующей [статье](../optovye-zakazy/index.html).

    - **Розничный:** откройте **розничный** заказ или создайте новый и **сохраните** его. Как работать с розничными заказами рассказали в [статье.](../voprosy-po-rabote-s-roznichnymi-optovymi-zakazami-i-zakazami-iz-internet-magazinov-v-selsup/index.html)

2.  Нажмите кнопку с иконкой конверта — **«Отправить по почте»**.

3.  В открывшемся окне:

    - выберите один из ранее созданных **шаблонов писем**;

    - проверьте/укажите **email получателя** (если нужно).

4.  Нажмите **Отправить**.

## Рекомендации

- Используйте шаблоны для типовых писем, чтобы сократить время на подготовку сообщений.
- Проверяйте текст шаблона перед отправкой, если письмо содержит индивидуальные условия или комментарии.
- Создавайте отдельные шаблоны для разных типов оптовых клиентов при необходимости.
