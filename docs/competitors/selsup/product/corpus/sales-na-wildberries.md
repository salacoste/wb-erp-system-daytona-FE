# Где найти и скачать файл с акциями на Wildberries

### Как скачать файл для участия в акции в Wildberries

Зайдите в личный кабинет WB — Цены и скидки — [Календарь акций](https://seller.wildberries.ru/promo-calendar).\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/04/wb-flsshsh.png.webp)

 

Выберите акцию, которую хотите проанализировать, выгодно в ней участвовать или нет.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/04/vibor.png.webp)\
Скачайте файл с товарами, которые Wildberries предлагает включить в акцию, нажав "Перейти к товарам акции", затем в открывшемся окне нажмите "Сформировать", чтобы WB сформировал файл с товарами, затем "Скачать".\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/04/sformirovat.png.webp)
