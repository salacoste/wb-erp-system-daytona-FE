## Импорт товаров из Avito** через Excel-файл**

**Шаг 1.** Чтобы импортировать объявления через Excel, перейдите в личный кабинет Avito, раздел **«Автозагрузка».**\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/import-tovarov-failom.png.webp)\
**Шаг 2.** Нажмите кнопку **«Настройки».**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/09/nastrojki-avtozagruzki.png.webp)

**Шаг 3**. Нажмите кнопку **«Скачать файл с объявлениями».**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/09/skachat-fajl-s-obyavleniyami.png.webp)

**Шаг 4.** Отметьте галочками объявления, которые нужно выгрузить в Excel.\
Пропишите адрес вашей электронной почты, куда будет отправлен готовый файл, и нажмите **«Создать файл»**.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/fail.png.webp)\
После этого появится сообщение, что файл в процессе подготовки. Готовый файл с товарами будет отправлен на указанную вами электронную почту.\
**Шаг 5.** Откройте письмо и нажмите кнопку **«Скачать файл».**

 

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/09/skachat-fajl-iz-pochty.png.webp)

**Шаг 6.** Вернитесь в SelSup на вкладку [Товары - Импорт товаров](https://selsup.ru/application/productsImport/), выберете **Avito** и установите настройки импорта:

- выберите организацию, в которую импортируете товары;
- производителя, который будет указан у импортированных товаров (если производитель не нужен, можно не выбирать). **Выбор производителя обязателен, если для товара требуется маркировка.** Без указания производителя корректная передача данных для маркировки невозможна.

**Шаг 7.** Перетащите или выберите файл для загрузки.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_203.png.webp)

Все товары, которые вы выбрали для загрузки в файл Excel, импортируются в SelSup и появятся в разделе [Товары](https://selsup.ru/application/products).\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_36-4.png.webp)

После импорта таким способом в карточке товара будут заполнены все параметры: категория, модель, бренд, страна, название, цена со скидкой и другие. Все фотографии также перенесутся из Avito.

В разделе [«Импорт товаров»](https://selsup.ru/application/productsImport/) также можно посмотреть ошибки импорта, причины их возникновения и исправить.

Полную инструкцию о возможностях интеграции с Avito смотрите [здесь](../vozmozhnosti-integratsii-s-avito/index.html).
