# Excel-файл товаров в SelSup: создание карточек и массовые настройки

В этой статье расскажем, как использовать Excel-файл товаров в SelSup не только для создания карточек, но и для массовой настройки разных параметров товара.

## Как устроен Excel-файл товаров

Файл с товарами, можно скачать в разделе **[Товары](https://selsup.ru/application/products/?ascending=false&deleted=false&grouped=true&limit=500&page=1&sortBy=TOTALORDERS)** через кнопку **Экспорт. **

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/04/browser_p6ru136jtc.png.webp)

Или в разделе **Товары - Импорт товаров - [вкладка Массовое редактирование](https://selsup.ru/application/productsImport/)** через кнопку **Скачать Excel.**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/04/browser_qcnnkp9ghx.png.webp)

В Excel-файле колонки разделены по цветам.

**Оранжевые поля** — обязательные для заполнения.\
**Голубые поля** — общие параметры SelSup.\
Далее идут цветные блоки маркетплейсов:

- светло-голубые — параметры Ozon;
- розовые — параметры Wildberries;
- желтые — параметры Яндекс.Маркета;
- остальные блоки — параметры других маркетплейсов.

Главный принцип работы с файлом такой:\
если параметр одинаковый для всех маркетплейсов, его лучше заполнять **в общих параметрах SelSup**.

Например, если у товара одинаковые **бренд** и **описание** для всех маркетплейсов, достаточно заполнить их в параметрах SelSup. Дополнительно дублировать эти же значения в параметрах маркетплейсов не нужно.

## Создание и обновление карточек через Excel-файл

Excel-файл в SelSup можно использовать не только для массовой настройки параметров товаров, но и для создания и обновления карточек на маркетплейсах.

Если вам нужно:

- массово обновить параметры карточек на маркетплейсах через Excel, используйте отдельную инструкцию [**«Обновление параметров карточек товаров на маркетплейсе через Excel»**](../obnovlenie-parametrov-kartochek-tovarov-na-marketplejse-cherez-excel/index.html).
- массово создать или отредактировать карточки **Wildberries**, используйте статью [**«Массовое создание и редактирование карточек WB»**](../massovoe-sozdanie-i-redaktirovanie-kartochek-wb/index.html).
- массово создать или перенести карточки в **Ozon**, используйте статью [**«Массовое создание и перенос карточек товаров в OZON»**](../perenos-kartochek-tovarov-v-ozon/index.html).
- массово создать или перенести карточки в **Яндекс.Маркет**, используйте статью [**«Массовое создание и перенос товаров в Яндекс.Маркет»**](../perenos-kartochek-tovarov-v-ozon/index.html).
- создать или отредактировать карточки в **Честном знаке**, используйте статью [**«Создание и редактирование карточек в Честном знаке»**.](../sozdanie-i-redaktirovanie-kartochek-v-chestnom-znake/index.html)

## Столбцы сезонности

Столбцы **Начало первого сезона**, **Конец первого сезона** и аналогичные поля для других сезонов нужны для отчета **Рука на пульсе по-товарно**.

Именно из этих колонок в отчет будут подтягиваться сезонные данные по товару. Подробней об отчете в [статье](../ruka-na-pulse-po-tovarno/index.html).

Важно: функционал сезонности в этой части еще дорабатывается, поэтому при заполнении этих колонок стоит учитывать текущую логику работы отчета.

## Столбец Теги

Поле **Теги** используется для массового добавления и удаления тегов у товаров.

Через Excel-файл удобно:

- массово проставить теги;
- изменить существующие;
- удалить теги у группы товаров.

Это особенно удобно, если теги используются для фильтрации, аналитики, листа сборки или других сценариев внутри SelSup.

Подробнее о работе с тегами можно прочитать в [статье про теги в карточках товаров.](../tegi-v-kartochkah-tovarov-instruktsiya-po-ispolzovaniyu/index.html)

## Убрать с остатков

Столбцы **Убрать с остатков FBS**, **Убрать с остатков FBS WB**, **Убрать с остатков FBS Ozon**, **Убрать с остатков FBS Я.Маркет** и аналогичные используются для массового обнуления остатков.

## Коэффициент коррекции

Столбец **«Коэффициент коррекции»** используется при планировании поставок.

Сначала SelSup рассчитывает рекомендуемое количество товара к поставке по основной формуле планирования, и если для товара заполнен коэффициент коррекции, **полученное значение дополнительно умножается на этот коэффициент.**

Например, если по формуле получилось 10 штук, а коэффициент коррекции равен 2, то итоговое рекомендуемое количество к поставке составит 20 штук.

Такой коэффициент удобно использовать, если товар продаётся в особых объёмах или при расчёте поставки нужно учитывать дополнительную поправку.

## Коэффициент продаж, у.е.

Столбец **Коэффициент продаж, у.е.** нужен для учета продаж в **условных единицах**. Его заполняют, если товар продается в одной форме, а учитывать продажи нужно в другой, например в штуках внутри упаковки.

После заполнения коэффициента данные можно использовать в аналитике. Подробнее о работе этого столбца читайте в статье [**«Продажи в условных единицах (учёт по коэффициенту)»**.](../prodazhi-v-uslovnyh-edinitsah-uchyot-po-koeffitsientu/index.html)

## Количество штук в коробе

Столбец Количество штук в коробе используется для заполнения параметра кратности короба. Он показывает, сколько единиц товара помещается в один стандартный короб.

Важно: в SelSup этот параметр используется только для планирования поставок и помогает корректно рассчитывать упаковку.

Через Excel-файл можно массово заполнить или обновить это значение сразу для группы товаров, если нужно быстро подготовить данные для планирования поставок.

Подробнее о работе этого параметра читайте в статье [«Кратность коробов».](../kratnost-korobov/index.html)

## ID Ozon и WB

Столбцы **Карточка Wildberries** и **Карточка Ozon** являются информационными.

В них выгружаются идентификаторы карточек маркетплейсов:

- в столбец **Карточка Wildberries** — **ID Wildberries**;
- в столбец **Карточка Ozon** — **ID Ozon**.

Эти поля помогают понять, с какими карточками на маркетплейсах связан товар в SelSup. Они нужны в первую очередь для контроля данных в файле и проверки связей товара с карточками маркетплейсов.

Использовать эти столбцы как основные поля для ручного редактирования карточек не нужно.

## Столбцы Дубликат и Комплект

Столбцы **Дубликат** и **Комплект** являются **информационными**.

Они помогают понять текущее состояние карточки:

- является ли товар дубликатом;
- является ли товар комплектом.

Эти поля нужны в первую очередь для контроля данных в файле и проверки текущих настроек товара. Использовать их как основные поля для ручного изменения логики товара не нужно.

Для изменения типа товара используется поле **Вид товара**.

## Что важно учитывать перед импортом

Перед загрузкой файла обратно в SelSup важно помнить несколько правил:

- не меняйте названия колонок;
- не удаляйте служебные строки файла;
- одинаковые данные лучше заполнять в общих параметрах SelSup, а не дублировать в блоках маркетплейсов;
- перед массовыми изменениями лучше сначала проверить логику на нескольких товарах.

## Как импортировать отредактированный файл обратно в SelSup

После того как вы внесли изменения в Excel-файл, его нужно импортировать обратно в SelSup.

Для этого:

1.  Перейдите в раздел **Товары → Импорт товаров -** вкладка [**Массовое редактирование**.](https://selsup.ru/application/productsImport/import)
2.  В синее поле для загрузки файла перетащите отредактированный файл.

Перед загрузкой воспользуйтесь настройками:

- **Выберите организацию**, для которой добавляем товары.
- Включите тумблер **«Удалять значения параметров, где пустые ячейки»** — SelSup удалит параметры в карточке, если в импортируемом файле ячейки этих параметров пусты.
- Используйте тумблер **«Отправлять только новые карточки на маркетплейсы» -** на маркетплейсы будут отправлены только новые карточки из файла. Уже существующие карточки обновляться не будут
- Выберите **«Обновлять существующие товары по комбинации (артикул, цвет и размер)» - е**сли в SelSup уже есть товар с такой же комбинацией артикула, цвета и размера, SelSup обновит его данными из файла вместо создания новой карточки.

Если нужно сразу отправить данные на маркетплейс, то в поле **«Отправить карточки после импорта в»** выберите соответствующий МП.

## Итог

Excel-файл товаров в SelSup нужен не только для создания карточек.

Через него можно массово:

- редактировать общие параметры товаров;
- управлять параметрами маркетплейсов;
- назначать менеджеров;
- заполнять сезонность;
- добавлять теги;
- настраивать минимальные и максимальные остатки;
- обнулять остатки;
- менять вид товара;
- указывать количество штук в коробе для планирования поставок;
- просматривать служебные признаки, например дубликат или комплект.
