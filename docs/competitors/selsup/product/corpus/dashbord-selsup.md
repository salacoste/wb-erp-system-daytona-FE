# Дашборд SelSup

Дашборд даст наглядную информацию по продажам, заказам, прибыли и расходам. Вы сможете отслеживать динамику показателей по FBS и FBO, сравнивать данные по организациям и маркетплейсам, а также видеть товары с лучшими и худшими показателями за выбранный период.

В этой статье мы расскажем вам о характеристиках, преимуществах и выгоде Дашборда.

## Польза Дашборда

**Дашборд SelSup** — это инструмент для анализа ключевых показателей бизнеса.

На Дашборде можно отслеживать динамику продаж, заказов, выручки, прибыли, расходов, возвратов и маржинальности за выбранный период. Это помогает быстрее находить слабые места, сравнивать показатели и принимать решения на основе данных.

Дашборд показывает данные по FBS и FBO, организациям и маркетплейсам. Вы можете оценивать общую эффективность бизнеса, смотреть структуру расходов, анализировать топ и антитоп товаров, а также контролировать повторные продажи.

**Для внутренней работы с командой**

Дашборд будет полезен руководителям и аналитикам для подготовки визуальных отчётов, оценки динамики показателей и планирования дальнейших действий.

## Фильтры и настройки Дашборда

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/orwanqnsv4-1-scaled.png.webp)

В Дашборде можно смотреть данные по аккаунту за нужный период и дополнительно фильтровать их по организациям и маркетплейсам.

Отчёты формируются по календарным дням. Для выбора периода используйте быстрые фильтры: **Сегодня**, **Вчера**, **Неделя** или **Месяц**

Также можно выбрать произвольный период: нажмите на иконку календаря или укажите даты вручную в поле периода.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

### Фильтр по организациям

Фильтр **«Организация»** позволяет выбрать одну или несколько организаций для отображения данных.

- Если организация не выбрана, SelSup показывает суммарные данные по всем организациям аккаунта.
- Если выбрана одна организация, данные отображаются только по ней.
- Если выбрано две или более организации, данные отображаются суммарно по выбранным организациям, а ниже появляется блок **<a href="#split_by_organisations" id="#split_by_organisations" type="internal">«Разбивка по организациям»</a>**.
- В блоках **«Топ / Антитоп товаров»** при выборе нескольких организаций SelSup формирует общий рейтинг по выбранным организациям — без суммирования данных между ними.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

### Фильтр по маркетплейсам

Фильтр **«Маркетплейс»** позволяет посмотреть данные по одному или нескольким маркетплейсам.

- Если маркетплейс не выбран, данные отображаются сразу по всем маркетплейсам.
- Если выбран один маркетплейс, данные отображаются только по нему.
- Если выбрано два или более маркетплейса, SelSup показывает сумму данных по выбранным маркетплейсам.

### Разбивка аналитики по организациям

Если в фильтре дашборда выбрано сразу несколько организаций, SelSup показывает общие показатели по выбранным организациям и дополнительную таблицу с разбивкой по каждой организации.

Таблица появляется под основными блоками аналитики. В строках отображаются организации, а в колонках — основные финансовые показатели:

- **Выручка, руб.**
- **Валовая прибыль, руб.**
- **Маржинальность, %**
- **Чистая прибыль, руб.**
- **Выручка, шт.**
- **Расходы МП, руб.**
- **Итого к оплате по данным API, руб.**
- **Прочие расходы, руб.**
- **Налог, руб.**

Так можно быстро сравнить показатели между организациями и понять, какая организация приносит больше выручки и прибыли за выбранный период.

Если дополнительно выбран фильтр по маркетплейсу, например Wildberries, таблица покажет разбивку только по выбранному маркетплейсу и выбранным организациям.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/chrome_9afrqslhfg-scaled.png.webp)

**Важно:**

Небольшая разница в пределах нескольких рублей между общей суммой и суммой по организациям допустима.

Она может возникать из-за округления при расчёте показателей по дням, неделям или нескольким организациям.

## Заказы

Также вы можете анализировать данные по заказам на графике за выбранный период: **по количеству заказов, их типу** и **по их общей сумме в рублях**.

**Источник данных:** [Отчёт по заказам / Лента заказов](https://selsup.ru/application/allOrders).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/pvbder20ny-1024x682.png.webp)

На графике заказы распределяются по категориям в зависимости от типа отгрузки:

- **Заказы FBS** — заказы, отгруженные с вашего склада. Подробнее смотрите в разделе [«Преимущества работы с SelSup по FBS»](../preimushhestva-raboty-selsup-po-fbs/index.html).
- **Заказы FBO** — заказы, отгруженные со склада маркетплейса. Подробнее смотрите в разделе [«Вопросы и ответы по FBO»](../voprosy-i-otvety-po-fbo-wildberries/index.html).

- [**Розничные заказы**](../voprosy-po-rabote-s-roznichnymi-optovymi-zakazami-i-zakazami-iz-internet-magazinov-v-selsup/index.html) — заказы, отгруженные по схеме RealFBS. Подробнее о преимуществах работы с курьерской доставкой читайте в статье [«Для кого подойдет работа по DBS (RealFBS) через СДЭК»](../sdek/index.html).
- [**Оптовые заказы**](../optovye-zakazy/index.html) — заказы, которые также отгружаются по схеме RealFBS.
- **Все заказы** — все заказы за выбранный период без применения фильтров.

Если навести курсор на конкретный период, откроется разбивка заказов по каждому типу за выбранную дату.

## Выручка, чистая прибыль, маржинальность

В блоке **«Выручка, чистая прибыль, маржинальность»** отображается динамика ключевых финансовых показателей за выбранный период.

Данные можно смотреть в формате графика или таблицы. Это помогает быстро оценить, как меняются выручка, прибыль, себестоимость и маржинальность, а также сравнить показатели по дням.

**В графике** отображаются значения выручки, прибыли, чистой прибыли, себестоимости и маржинальности.

**В таблице** отражены те же данные в числовом формате.

**Источник данных:** [Отчёт о прибылях и убытках](https://selsup.ru/application/analytics/).

## Повторные продажи Ozon

В блоке **«Повторные продажи Ozon»** отображается, сколько покупателей вернулись за повторной покупкой в выбранный период.

Блок помогает оценить, какая часть покупателей совершает покупки повторно, а не ограничивается одним заказом.

Показатель повторных продаж отображается отдельно от уникальных покупателей, чтобы было проще анализировать лояльность клиентов и возврат покупателей к вашим товарам.

## Топ и антитоп товаров

В блоках **«Топ товаров»** и **«Антитоп товаров»** отображаются товары с лучшими и худшими результатами за выбранный период.

Блок помогает быстро понять, какие товары приносят больше всего прибыли, а какие снижают общий финансовый результат.

Это удобно для анализа ассортимента, планирования закупок, корректировки цен и поиска товаров, по которым нужно проверить расходы, себестоимость или участие в акциях.

Товары сортируются по показателю **«Валовая прибыль»**.

- **Топ товаров** — товары с максимальной валовой прибылью;
- **Антитоп товаров** — товары с минимальной валовой прибылью, включая отрицательные значения.

Чтобы товары было проще найти и проверить, в блоках отображаются:

- штрихкод товара;
- артикул товара;
- маленькое фото товара.

**Источник данных:** [Товарная аналитика](https://selsup.ru/application/productAnalytics/).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/2026.06.03_chrome_z99k-scaled.png.webp)

****Товары по нескольким организациям****

Если на дашборде выбрано несколько организаций, товары из всех выбранных организаций попадают в общий рейтинг. SelSup **не суммирует данные** между организациями, **а сравнивает позиции в одном общем списке.**

После этого в блок «Топ товаров» выводятся **5 товаров с лучшими показателями**, а в блок «Антитоп товаров» — **5 товаров с худшими.**

Поэтому часть товаров может не отображаться, даже если внутри отдельной организации они входили в топ или антитоп.

## Сотрудники

В блоке **Сотрудники** можно посмотреть статистику по работе сотрудников: сколько товаров они добавили в поставки, или сколько товаров собрали в заказах FBS.

Данные доступны в двух форматах: в виде графика и таблицы. Это позволяет быстро оценить нагрузку сотрудников по датам и сравнить показатели между пользователями.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

### Статистика по поставкам

В этом подразделе отображаются данные по товарам и поставкам, которые обрабатывали сотрудники. Статистику можно просматривать в формате графика или таблицы.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/clsaq9l74a-1024x806.png.webp)

В статистике по поставкам доступны следующие показатели:

- **Количество товаров, собранных в заказах FBS** — показывает, сколько товаров сотрудник собрал в заказах FBS за выбранный период.
- **Сумма цен товаров, собранных в заказах FBS** — показывает общую сумму розничных цен товаров, собранных сотрудником в заказах FBS.
- **Добавлено в поставку шт. товаров** — показывает количество товаров, которые сотрудник добавил в поставки по датам.
- **Розничная цена добавленных в поставку товаров** — показывает общую сумму розничных цен товаров, добавленных сотрудником в поставки.
- **Создано уникальных моделей без учета цвета и размера** — показывает количество созданных карточек только по моделям. Учет работ именно по модели товара позволяет ускорить некоторые работы, например, печать этикеток.
- **Создано товаров с учетом цвета и размера** — показывает количество всех созданных товаров с учетом цвета и размера.

### Статистика по выполненным работам

В этом подразделе можно посмотреть, сколько заданий выполнили сотрудники. Статистика помогает оценить нагрузку при работе со складскими задачами, сборкой и раскладкой товаров.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/qht2wwncdf-1024x811.png.webp)

Чтобы данные по заданиям корректно попадали в статистику, в карточке сотрудника должны быть заполнены роль, склад и организация.

Сами задания можно создавать в разделе [**Задания**](https://demo2.selsup.ru/application/persons/jobs). Подробнее о добавлении заданий для операторов читайте в [**инструкции**](../jobs/index.html).

Также для формирования задач сотрудникам можно использовать раздел [**Задачник**](https://selsup.ru/application/usersTasks/).

### Количество выполненных заданий по сборке и раскладке

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/chrome_2026.05.21_jtbnyz.png.webp)

Показатель отображает, сколько заданий по сборке и раскладке выполнил каждый сотрудник. Эти данные можно использовать для контроля выполнения складских операций и распределения нагрузки между сотрудниками.
