# Подключение и настройка расширения Selsup в МойСклад для работы с кодами маркировки

Только у **Selsup** есть полноценное решение для работы с маркировкой в связке с **МойСклад**.\
Что это даёт бизнесу:

- всё в одной системе — настройка интеграций, импорт товаров, создание и отправка карточек, получение и управление кодами;

- экономия времени — не нужно переключаться между сервисами, всё работает автоматически;

- минимум ошибок — правильная передача данных в «Честный знак» без ручного ввода;

- готовое решение для маркетплейсов и для собственного склада.

## Подключение решения

- Перейдите в раздел [**Решения**](https://online.moysklad.ru/app/) в МойСклад.
- В строке поиска введите **Selsup** или **Селсап**.
- Найдите решение и выберите тариф:
  - **Маркировка** (только работа с кодами для маркетплейсов).

  - **Карточка ЧЗ + Маркировка** (создание карточек + полная работа с кодами).
- Оплатите тариф — установка произойдёт автоматически.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/09/screenshot_143.png.webp)

- Нажмите **Перейти в решение.**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/09/screenshot_176.png.webp)

- **Новым пользователям:** Нажмите кнопку «Перейти в решение», после чего укажите свой e-mail для завершения регистрации.

- **Существующим пользователям:** Перейдите во вкладку «Вход», укажите свой e-mail и нажмите кнопку «Войти».

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/09/screenshot_177.png.webp)

## Настройка интеграции

- Перейдите в раздел **Настройки - Интеграции**.
- В списке найдите **МойСклад** → нажмите **Настроить**.
- Включите тумблер **Работа с сервисом МойСклад**.
- Настройте интеграцию согласно [подробной инструкции](../integratsiya-s-moj-sklad-2/index.html).
- Аналогично подключите **Честный знак** согласно [инструкции](../integratsiya-s-chestnym-znakom/index.html).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/09/screenshot_147.png.webp)

## Импорт товаров

- Перейдите в раздел **Товары → Импорт товаров**.
- Во вкладке **МойСклад** отметьте нужные настройки и запустите импорт.
- Подробно про импорт — [по ссылке.](../import-kartochek-s-moj-sklad/index.html)

Из Честного знака напрямую товары не импортируются, но вы можете связать их с товарами из Selsup. Подробности — <a href="../import-kartochek-iz-chestnogo-znaka/index.html" class="decorated-link" data-end="2049" data-start="2038" rel="noopener">здесь</a>.

## Отправка карточек в «Честный знак»

- После импорта товаров откройте нужную категорию в разделе **Товары - Категории.**
- Укажите **код ТНВЭД** в соответствующем поле (его можно найти по ключевым словам).
- Сохраните изменения.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/09/screenshot_149.png.webp)

- В разделе **Товары** откройте карточку товара, включите переключатель **Честный знак**.
- Заполните обязательные поля (отмечены значком).
- Нажмите **Сохранить** — карточка автоматически отправится в ЧЗ.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/09/screenshot_151.png.webp)

Как создать новую карточку из SelSup рассказали в отдельной [статье](../kartockka_tovara/index.html).

## Работа с кодами маркировки

В разделе **Маркировка** можно:

- вводить коды в оборот,

- возвращать и выводить из оборота,

- отслеживать статусы,

- работать с наборами, комплектами и агрегацией.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/09/screenshot_155.png.webp)

Больше информации по работе с маркировкой вы найдете в разделе помощи модуль [Маркировка](../../help_cat/markirovka/index.html).

С Selsup вы экономите время, избегаете ошибок и полностью контролируете процесс маркировки в «Честном знаке».\
Подключите решение уже сегодня — и все операции с маркировкой будут у вас «под одной кнопкой».
