# Работа с КГТ Ozon через Selsup

Для работы с крупногабаритными товарами необходимо создать отдельный склад КГТ с остатками по FBS. О том, как создать склад, указать связь и перенести остатки можете прочесть [здесь](../perenos-ostatkov/index.html). \
О особенностях КГТ можете прочесть [тут](https://seller-edu.ozon.ru/kgt/chto-takoe-kgt). \
\
Если Вы создадите один склад в Selsup, но укажете связи с обоими складами Озона: крупногабаритным и обычным — остатки будут передаваться на оба эти склада, но на одном из складов будут возникать ошибки, что склад не предназначен для крупногабаритного товара (если устанавливаете остатки товара не КГТ) и наоборот. Это не будет мешать работе, но в истории будут транслироваться ошибки. \
\
Для удобства вы можете проставить игнорируемые склады маркетплейса, например, у не крупногабаритных товаров. Для этого Вам необходимо перейти в Товары - выбрать нужную карточку и найти поле “Игнорировать склады FBS”. В этом поле укажите склад маркетплейса, на который вы не хотите передавать остаток и нажмите на Сохранить. \
\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/09/photo_2024-09-24_16-46-57.jpg.webp)\
\
Есть возможность сделать это массово с помощью Excel-файла. Для этого необходимо снова перейти в раздел [Товары](https://selsup.ru/application/products) и нажать на кнопку Экспорт.\
В скачанном файле, найдите столбец “Игнорировать склады FBS” и просто вставьте название игнорируемого склада у нужных вам товаров. \
\
Помимо этого, в скачанном Excel-файле есть столбец “Только склады FBS”. В это поле вы можете внести те склады, на которые нужно передавать остаток у товаров.\
\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/09/photo_2024-09-24_16-48-06.jpg.webp)\
\
После всех изменений, загрузите файл обратно через раздел [Товары - Импорт](https://selsup.ru/application/productsImport/).\
\
Таким образом, при одном созданном складе с двумя связями складов маркетплейсов, в истории остатков не будут возникать ошибки.
