# Rich-контент, как добавить

Rich-контент — это расширенное описание товара в карточке на маркетплейсе. С его помощью можно наглядно показать преимущества товара, добавить текст, изображения, видео, таблицы и списки.

Такой формат помогает сделать карточку товара более информативной и удобной для покупателя: вместо обычного текстового описания можно оформить описание с заголовками, иллюстрациями, характеристиками и дополнительными блоками.

В SelSup rich-контент можно редактировать и отправлять на маркетплейс **Ozon**.

## Как открыть редактор rich-контента

Чтобы добавить или отредактировать rich-контент:

1.  Перейдите в раздел [**Товары**](https://selsup.ru/application/products/?ascending=false&deleted=false&grouped=true&limit=50&page=1&sortBy=TOTALORDERS).
2.  Откройте нужную карточку товара.
3.  Перейдите на вкладку **Rich-контент**.
4.  Нажмите кнопку **Открыть в редакторе Rich**.

После этого в новой вкладке браузера откроется редактор рич-контента.

## Как работать в редакторе

В редакторе rich-контента есть несколько рабочих областей:

- слева отображаются доступные блоки;
- по центру расположен холст, на который добавляются блоки;
- справа отображаются настройки выбранного элемента.

Чтобы добавить блок, выберите его слева и перетащите на холст.

В редакторе доступны разные типы блоков:

- **Текст** — для добавления заголовка и описания;
- **Таблица** — для характеристик, параметров или сравнительной информации;
- **Видео** — для добавления видеоконтента;
- **Витрина** — для добавления изображений;
- **Список** — для оформления преимуществ или важных особенностей товара.

Блоки на холсте можно менять местами и редактировать.

Например, если нужно добавить текстовое описание, перетащите блок **Текст** на холст. В появившемся блоке можно указать заголовок и описание товара.

Для товара **держатель для телефона** можно добавить заголовок:

**Держатель для телефона**

И описание:

**Удобный держатель помогает зафиксировать телефон в нужном положении, чтобы смотреть видео, пользоваться навигатором или общаться по видеосвязи.**

## Настройки элементов

У каждого блока есть свои настройки. Они отображаются справа от холста, когда блок выбран.

С помощью настроек можно изменить внешний вид и расположение элемента: тему, отступы, выравнивание, размеры текста и другие параметры.

Используйте настройки, чтобы оформить rich-контент в едином стиле и сделать описание удобным для просмотра.

## Как сохранить rich-контент

После того как rich-контент заполнен, нажмите **Сохранить JSON**.

После сохранения в карточке товара автоматически заполнится параметр **Rich Content JSON**. В него будут переданы данные, которые вы добавили в редакторе.

После этого карточка товара отправится на маркетплейс Ozon. Rich-контент на маркетплейсе будет соответствовать тому, что было заполнено в редакторе SelSup.

Также при нажатии на кнопки **Сохранить JSON -**  JSON-файл с rich-контентом будет скачан на компьютер.

Если нужно удалить добавленные блоки, нажмите **Очистить**, затем сохраните изменения.

## Как отредактировать rich-контент

Если rich-контент уже был добавлен и его нужно изменить:

1.  Перейдите в раздел **Товары**.
2.  Откройте нужную карточку товара.
3.  Перейдите на вкладку **Rich-контент**.
4.  Нажмите **Открыть в редакторе Rich**.
5.  Внесите изменения в нужные блоки.
6.  Нажмите **Сохранить**.

После сохранения параметр **Rich Content JSON** в карточке обновится автоматически, а карточка будет отправлена на Ozon с изменённым rich-контентом.

Если после редактирования нужно полностью удалить добавленные блоки, используйте кнопку «Очистить», затем сохраните изменения.
