## Рекомендации перед началом сверки

Чтобы начать сверять аналитику с маркетплейсом Wildberries:\
1. Перейдите в раздел [Аналитика и финансы → P&L](https://selsup.ru/application/analytics/) или [Аналитика и финансы → Отчёты](https://selsup.ru/application/reports/), здесь собраны все основные аналитические данные, полученные из маркетплейсов по API;

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/screenshot_350.png.webp)

2\. Выберите для какой организации смотреть аналитику и за какой период;\
3. Выберите суммировать ли данные;\
4. Если сверяете аналитику с Wildberries, то в фильтрах также укажите этот маркетплейс.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/screenshot_14.png.webp)Когда все фильтры указаны нажмите "Применить фильтры", чтобы SelSup сформировал данные.

Просматривать аналитические данные в SelSup Вы можете как из интерфейса, так и в Excel - файле, при проведении сверки удобнее выгружать файл из SelSup и проводить сверку с ним. Чтобы скачать файл, нажмите кнопку "Скачать финансовый отчет" в разделе [Аналитика и финансы - P&L](https://selsup.ru/application/analytics/).\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/screenshot_236.png.webp)\
В случае с WB необязательно скачивать детализацию из ЛК в файле, достаточно сверить наш финансовый отчет с интерфейсом Wildberries.

**Важно:**

При сверке отчетов выбранный период в SelSup должен соответствовать периоду отчета на маркетплейсе.

------------------------------------------------------------------------

Также учитывайте тип детализации отчетов Wildberries [в настройках аналитики](../nastrojki-selsup/index.html).

- Если выбран вариант **«По неделям»**, сверяйте данные с еженедельными отчетами Wildberries.
- Если выбран вариант **«По дням»**, используйте ежедневные отчеты Wildberries за тот же период.

**Дальнейшая инструкция в статье описывает сверку на примере еженедельных отчетов.**

Подробнее о терминах и формулах, используемых в аналитических отчетах, рассказали в этой **[статье](../terminy-i-formuly-v-analitike/index.html)**.

## Таблица сверки показателей SelSup и Wildberries

Для сверки данных SelSup и Wildberries используйте таблицу ниже. Она поможет быстро понять, где смотреть показатель в SelSup и с каким отчетом или разделом Wildberries его сравнивать.

Для большинства показателей сверку нужно проводить с отчетом **«Финансовые отчеты → Отчеты реализации»**. Если для показателя используется другой источник, это указано отдельно в таблице.

**Цветовая маркировка:**

- **можно сверять с отчетами Wildberries**
- **рассчитывается по формуле в SelSup**
- **напрямую не сверяется с отчетами Wildberries**

| Показатель SelSup | С каким отчетом сравнивать | Что брать в отчете Wildberries |
|----|----|----|
| Выручка, руб. | Отчеты реализации (за 1 неделю 2 отчета) | Столбец «Вайлдберриз реализовал Товар (Пр)» |
| Выручка, шт. | Отчеты реализации | Столбец «Количество» по продажам в 2 отчетах, без возвратов |
| Продажи, руб. \| Excel-отчёт | Отчеты реализации | Столбец «ВБ реализовал» в 2 отчетах, только по документам с типом «Продажи» |
| Продажи, шт. \| Excel-отчёт | Отчеты реализации | Столбец «Количество» по продажам в 2 отчетах |
| Возвраты, руб. \| Excel-отчёт | Отчеты реализации | Столбец «ВБ реализовал», только по возвратам |
| Возвраты, шт. \| Excel-отчёт | Отчеты реализации | Столбец «Количество», только по возвратам |
| Комиссия | Отчеты реализации | Столбцы «ВБ реализовал» − «К перечислению пр.» с учетом вычета возвратов |
| Логистика | Отчеты реализации | Выбрать «Логистика» в столбце «Обоснование для оплаты», затем суммировать столбец «Услуги по доставке товара покупателю» в 2 отчетах |
| Реклама | Отчет «Реклама → WB Продвижение → Финансы» | Суммировать данные за период |
| Штрафы | Отчеты реализации | Столбцы «Виды логистики, штрафов и корректировок ВВ» и «Общая сумма штрафов» |
| Хранение | Отчеты реализации | Столбец «Хранение ВН» |
| СПП | Отчеты реализации | Столбцы «Цена розн. с уч. согл. ск.» − «ВБ реализовал», с учетом вычета возвратов |
| Себестоимость | Не сравнивается с отчетом WB → получается по формуле | Σ(количество продаж × (себестоимость + прочие расходы)) − Σ(количество возвратов × (себестоимость + прочие расходы)) |
| Чистая прибыль | Не сравнивается с отчетом WB → получается по формуле | Валовая прибыль − Прочие расходы − Налоги |
| Валовая прибыль | Не сравнивается с отчетом WB → получается по формуле | Итого к оплате по API − Себестоимость − Самовыкуп |
| Налоги | Не сравнивается с отчетом WB → получается по формуле | (Выручка × ставка налога из данных организации) / 100 |
| Маржинальность | Не сравнивается с отчетом WB → получается по формуле | (Валовая прибыль / Выручка) × 100 |
| Итого к оплате по данным API | Не сравнивается с отчетом WB | Нельзя сравнивать с метрикой «Итого к оплате» из личного кабинета WB |
| Услуги | Не сравнивается | Нельзя сравнивать |
| Другое | Не сравнивается | Нельзя сравнивать |
| Прочие удержания | Не сравнивается | Нельзя сравнивать |
| Сторно платная приемка | Отчеты реализации | Нельзя сравнивать |
| Сторно расходы | Отчеты реализации | Нельзя сравнивать |
| Заказы, шт. | Не сравнивается с отчетом по заказам | — |
| Заказы, руб. | Не сравнивается с отчетом по заказам | — |

## Сверка отчета из WB и SelSup

Проведем сверку для примера по отчетам из Wildberries и SelSup.

**Важно:** если у вас есть продажи на территории СНГ, для сверки нужно использовать оба отчета реализации Wildberries. В тех строках, где указано сравнение по 2 отчетам, суммируйте данные из обоих отчетов.

**Примечание:** в отдельных внутренних материалах второй отчет может называться отчетом по выкупам. Для сверки используйте оба документа, если они есть за выбранный период.

**\* Прочие удержания:** прямое сравнение может не сходиться, потому что через API Wildberries и в интерфейсе личного кабинета статьи удержаний отображаются по-разному.

Отчет для сверки с WB (в ЛК маркетплейса перейдите во вкладку Финансовые отчеты - Отчеты реализации):

Обратите внимание, что если у Вас есть продажи на территории СНГ, то отчета у Wildberries будет два. Тогда для сверки аналитика в SelSup нужно использовать их оба:

**Прочие удержания:**

Показатели по **удержаниям** и **расчёту к выплате** могут не сходиться при сверке с интерфейсом Wildberries. Мы **не сравниваем удержания напрямую**, потому что через **API WB** приходят **другие статьи/разделение удержаний**, чем отображается в личном кабинете WB. Поэтому корректное сопоставление этих сумм “один в один” с интерфейсом WB не всегда возможно.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/screenshot_32.png.webp)

Они так же отражены  в еженедельном отчёте Wilberries

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/screenshot_33.png.webp)
