## 1 способ - скопировать данные с существующей карточки

После того как вы выбрали категорию, SelSup предложит вам скопировать данные с существующей карточки товара. Если нажать на ссылку, ваша новая карточка заполнится автоматически.

Вы можете скопировать параметры из карточек, недавно созданных в этой категории, через блок **«Скопируйте параметры с карточки»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_123.png.webp)

Вы также можете использовать панель управления для копирования и вставки данных карточек: выберите карточку, с которой хотите копировать информацию и используйте кнопки:

1\. Скопировать данные карточки\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_124.png.webp)

2\. Вставить данные карточки в новую карточку:\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/dobavlenie.png.webp)

Также можно копировать карточки по размерам. Для этого скопируйте данные из существующей карточки в режиме редактирования товара и затем перейдите в новую запись **«Создать товар»**.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_126.png.webp)\
Фотографии не копируются при заполнении карточки.\

**Важно:** Если копировать упрощённую карточку в новую карточку с категорией, где включены тумблеры цвета и размера, после сохранения параметры могут задублироваться. Это связано с тем, что у карточек с размерами и цветами добавляются уровни параметров.

Вы можете удалить задублированные параметры нажатием на кнопку "Удаление дубликатов товаров" в карточке товара.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_130.png.webp)

Подробнее о работе уровней параметров можно прочитать в [статье.](../urovni-parametrov-kartochki/index.html)

## 2 способ - скопировать данные с карточки конкурента

Подробная инструкция - <a href="../kopirovanie-kartochek-konkurentov/index.html" style="font-weight: 400; font-size: 16px;">здесь.</a>

Для этого требуется:

1.  Установить расширение;
2.  Извлечь данные;
3.  Указать категорию товара в карточке;
4.  Вставить данные.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_127.png.webp)\
Переносятся все параметры, **включая фотографии. **Важно быть внимательным при использовании скопированных фотографий без изменений, так как маркетплейс может штрафовать за такие карточки.\

**Обратите внимание:**

Копирование нескольких цветов одновременно не поддерживается. При повторном копировании сохранится только последний добавленный цвет. Чтобы перенести несколько цветов, скопируйте их по отдельности и затем объедините карточки.

## 3 способ - добавить параметры для категории

Чтобы добавить параметры, перейдите в раздел [Товары - Категории](https://selsup.ru/application/categories/), найдите нужную и нажмите на нее, либо создайте новую.

Найдите поле **«Параметры»**. В него можно добавить параметры, одинаковые для всей категории товаров. Тогда их не нужно будет добавлять в отдельные карточки.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_128.png.webp)

Например, в поле можно выбрать **«Номер декларации соответствия»**, и задать ему значение чтобы не заполнять их в каждой карточке отдельно.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/chrome_69ieraqgvz-300x153.png.webp)\
Нажмите **Сохранить**, когда заполните все параметры.

Общие параметры для категории будут отображаться в новых карточках. Вам не придётся заполнять их заново.

## 4 способ - использовать правила

Создайте правила между параметрами с разных маркетплейсов. Это ускоряет процесс заполнения карточек товаров. Например, если вы продаете одежду — настройте связь параметров Wildberries и Ozon, и при заполнении определенного параметра Wildberries, SelSup автоматически будет заполнять нужное значение в связанном значении Ozon. Подробнее читайте <a href="../pravila-zapolneniya-kartochek/index.html" style="font-size: 16px;">здесь.</a>
