## Настройка поля «Артикул» при импорте товаров

Что-то сломалось, уже чиним Перезагрузите страницу или попробуйте позже

При импорте товаров из «МойСклад» в SelSup вы можете выбрать, какое поле из карточки товара будет использоваться как **Артикул**. Это удобно, если в МойCклад артикулы хранятся не в стандартных полях, а в дополнительном поле.

**Как настроить?**

**1.Выберите поле для артикула**

Перейдите в **Настройки → [Интеграции](https://selsup.ru/application/integration/moysklad) →** поле **«Выберите тип артикула»**.

Укажите один из вариантов:

- **Код МС как Артикул** — будет использоваться поле *«Код»* из «МойСклад».
- **Внешний код МС как Артикул** — возьмется значение из *«Внешнего кода»*.
- **Дополнительное поле** — потребуется вручную ввести название нужного поля из «МойСклад».

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_31-1.png.webp)

**2.Если, нужно добавить новое поле в «МойСклад»**

- В «МойСклад» откройте карточку товара и выберите **Настройки → Дополнительные поля → Добавить**.
- Задайте название поля (например, «Внутренний артикул») и сохраните.
- Заполните это поле для нужных товаров.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_33-2.png.webp)

После настройки SelSup будет подтягивать артикулы по выбранному правилу, что ускорит работу и исключит ошибки. Далее, переходите к импорту товаров по инструкции ниже.

## Импорт товаров из МойСклад

Чтобы перенести карточки товаров из МойСклад в Selsup, зайдите в раздел [**Товары - Импорт товаров** ](https://selsup.ru/application/productsImport/moySklad)- вкладка **МойСклад.**

Ознакомьтесь с настройками импорта и укажите необходимые. О каждой настройке подробнее расскажем ниже:

- **Автоматически импортировать товары ночью**\
  При включении тумблера SelSup будет автоматически загружать новые товары с маркетплейса и обновлять информацию по уже созданным товарам каждую ночь. Это позволяет поддерживать актуальные данные без ручной загрузки.
- **Изменить цены товаров в SelSup при импорте из МС в соответствии с их ценами в МС**\
  При включении тумблера SelSup будет при каждом импорте из МойСклад обновлять закупочную цену товара, используя актуальные данные из МойСклад.
- **Изменить типы товаров в SelSup при импорте из МС, в соответствии с их типами в МС**\
  Включение этого тумблера позволяет SelSup при импорте автоматически обновлять тип товара (товар или комплект), если он был изменён или задан в МойСклад.
- **Выбор производителя обязателен, если для товара требуется маркировка.** Без указания производителя корректная передача данных для маркировки невозможна.

Если включён тумблер Автоматически импортировать товары ночью, а также тумблеры Изменить цены товаров… и/или Изменить типы товаров…, то обновление цен и типов будет происходить совместно с ночным импортом.

Нажмите кнопку "**Импортировать товары сервиса МойСклад".**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_207.png.webp)

**Важно:** Если у вас несколько организаций, не нужно выбирать конкретную организацию. Перед импортом товаров нажмите кнопку **Для всех организаций**.

Результаты импорта отобразятся ниже. При возникновении ошибок они будут указаны в таблице **Ошибки импорта**, где вы сможете просмотреть причины ошибок и внести необходимые исправления.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_208.png.webp)

При импорте товаров из МойСклад в SelSup товар отображается как модель, а модификация — как размеры этого товара. Карточки связываются по штрихкоду, артикулу или коду товара, в зависимости от выбранной вами настройке в разделе интеграции, об этом подробней рассказали выше в [статье](index.html).

**![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/09/2023-04-24_10-26-07-300x129.png.webp)**

**![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/09/2023-04-24_10-28-47-300x101.png.webp)**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/09/2023-04-24_10-27-11-300x123.png.webp)

После импорта товаров в карточке товара в блоке модификаций поле **ID МойСклад** должно быть заполнено и совпадать с ID МойСклад в самом сервисе МойСклад. Если ID МойСклад не проставлен, значит связь карточки товара в SelSup и МойСклад не установлена.

## Создание и выгрузка карточек в МойСклад из SelSup

Если товар уже создан в SelSup, его можно выгрузить в МойСклад прямо из карточки товара. Также в SelSup можно создать новую карточку и сразу отправить ее в МойСклад. Для массовой выгрузки большого количества товаров используйте Excel.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

### Способы добавления товара

**Способ 1: Для уже существующего товара в Selsup**

Если товар уже создан в Selsup, но еще не выгружен в МойСклад:

1.  Откройте карточку нужного товара в Selsup.

2.  Активируйте **тумблер (переключатель) «МойСклад»**.

3.  Нажмите кнопку **«Сохранить»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/03/screenshot_1-2.png.webp)

**Способ 2: Создание нового товара с одновременной выгрузкой**

Чтобы создать товар с нуля и сразу отправить его в МойСклад:

1.  Перейдите в раздел **«[Товары](https://selsup.ru/application/products/?ascending=false&deleted=false&grouped=true&limit=50&page=1&sortBy=TOTALORDERS)»** и нажмите **«Создать товар»**.

2.  Заполните все необходимые поля (название, артикул, цена и т.д.).

3.  Сразу активируйте **переключатель «МойСклад»**.

4.  Нажмите **«Сохранить»**.

**Результат:**

- В МойСклад будет создана карточка товара.

- В карточке товара в Selsup появится **иконка «МС»**, подтверждающая синхронизацию.

- В системное поле запишется **ID (идентификатор) из МойСклад**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/03/screenshot_2.png.webp)

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

### Массовое создание и выгрузка карточек

Этот способ идеален для добавления большого количества товаров через Excel-файл.

1.  Перейдите в раздел **«Товары»** → **«Импорт товаров»** → [**«Массовое редактирование»**](https://selsup.ru/application/productsImport/).

2.  Скачайте файл с данными, нажав на кнопку **«Скачать Excel»** (формат XLSX).

3.  Отредактируйте файл при необходимости, оставьте только товары, которые нужно создать в МойСклад.

4.  Вернитесь в тот же раздел (**«Массовое редактирование»**) и загрузите заполненный файл.

5.  **Внимание! Это важный шаг.** В поле **«Отправить карточки после импорта в:»** обязательно выберите из списка **«МойСклад»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/03/screenshot_3.png.webp)

**Результат:**\
Система импортирует все товары из файла в Selsup и сразу же отправит их в МойСклад, создав там соответствующие карточки.

## Объединение товаров

**Импортированные товары можно объединять** вручную через функцию **Объединение карточек** или массово— через **Массовое объединение**. Подробнее об объединении товаров можно прочитать в этой **[статье.](../merge/index.html)**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/obedinenie.png.webp)

После успешного объединения в карточке товара появится ссылка на МойСклад, что будет означать, что связь установлена.

**![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_155.png.webp)**

## Как связать карточки в SelSup и МойСклад

Если карточки не связались после импорта, необходимо в карточке товара в SelSup в верхней панели инструментов нажать на кнопку **МойСклад** и в выпавшем меню нажать **Найти и связать карточки**.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/05/svyaz-ms.png.webp)

Чтобы удалить связь карточек, удалите ID МойСклад и сохраните карточку без отправки данных в МойСклад.
