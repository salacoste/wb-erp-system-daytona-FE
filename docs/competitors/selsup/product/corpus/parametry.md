# Параметры в SelSup: создание, настройка и управление

В этой статье мы расскажем Вам о разделе [«Параметры»](https://selsup.ru/application/params/)‎, благодаря которому Вы сможете создавать и настраивать под себя новые параметры для добавленных в SelSup карточек.\
Это поможет вам быстрее создавать карточки товаров на всех маркетплейсах.\
А если у вас есть сайт, или вы используете 1С, то вам пригодится данный раздел. Он поможет добавлять параметры в SelSup, после чего будет возможность выгружать YML - файл с Вашими параметрами.

## Создание параметра

Чтобы создать новый параметр, перейдите в раздел [«‎Товары- Параметры»](https://selsup.ru/application/params/) и нажмите ***«‎*****Добавить параметр*****»***.‎‎

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_288.png.webp)

В открывшейся странице заполните Название параметра и обязательные поля, проставьте настройки добавляемого параметра:\
**Опубликован **- включите этот переключатель, чтобы параметр отобразился в карточках товара, если он выключен, то параметр отображаться не будет;\
**Использовать для всех категорий **- если переключатель включен, то параметр отобразится во всех категориях и во всех карточках. Если его выключить, то появится вкладка **«‎Категории»**‎, здесь Вы можете добавить категории для которых будет создан параметр;\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/05/kategoriya-v-parametre.png.webp)

**Обязательный **- включенный переключатель сделает заполнение этого параметра обязательным (если не заполнить, то карточка не создастся / не сохранится);\
**Разрешить выбор нескольких вариантов** - включенный переключатель позволит в одном параметре, из выпадающего списка значений выбрать несколько вариантов;\
**Название группы **- это поле необходимо заполнить, если Вы создаете несколько параметров и добавляете их в одну группу. В каждом параметре группы должно быть заполнено название группы, чтобы они были добавлены в эту группу;\
**Тип значения **- в этом поле необходимо выбрать, какое значение для заполнения будет присвоено параметру из выпадающего списка предложенных, например, текст или число;\
**Вид редактирования **- в поле выберите значение, которое будет использоваться при редактировании, например, выпадающий список значений параметра или ввод текста;\
**Параметр для **- выберите для чего создается параметр, для модели (карточки), категории, отображения или продукта.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_289.png.webp)

Красной звездочкой отмечены поля обязательные для заполнения.\
После того как заполните все нужные поля и выставите настройки, нажмите ***«*****Сохранить‎*****»***, чтобы параметр добавился.‎

Когда параметр создан зайдите в раздел [«‎Товары- Категории»](https://selsup.ru/application/categories/)‎ и выберите нужную, откроется страница настроек категории, либо из карточки товара нажмите на значок карандаша рядом с категорией и в настройках категории включите переключатель **«Отображать мои параметры‎»** (если переключатель выключен, то параметр не отобразится в карточке).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_290.png.webp)

Нажмите ***«Сохранить‎»***, чтобы добавить изменения.\

Добавленные параметры являются параметрами сервиса и отображаются только в SelSup, на маркетплейсы такие параметры не передаются.

## Редактирование параметра

Редактировать созданный параметр можно двумя способами:

1\. В разделе [«Товары - Параметры‎»](https://selsup.ru/application/params/)‎ выберите нужный и нажмите на него, откроется страница редактирования параметра.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_291.png.webp)

Для редактирования доступны все поля и настройки, внесите необходимые изменения, затем нажмите ***«‎*****Сохранить*****»***‎.

2\. Перейдите в раздел [«‎Товары»](https://selsup.ru/application/products)‎, выберите карточку нужного товара и откройте ее. В карточке найдите созданный параметр, откроется окно редактирования параметра. В этом окне Вы увидите две вкладки: Свойства и Правила.\
**Свойства:**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_292.png.webp)\
В этой вкладке Вы можете:\
- Выбрать для какой категории редактировать параметр, либо для всех, либо для текущей категории. Если хотите внести изменения только в текущей категории, активируйте переключатель «‎Изменить только для текущей категории»‎;\
- Изменить уровень параметра в соответствующем поле, например, вместо Модели привязать параметр к Цвету;\
- Связать параметр с нашим служебным параметром, для этого в соответствущем поле выберите нужный параметр SelSup из предложенных.

## Отображение параметра в аналитике

При создании параметра на странице\
**«Параметры → Создание параметра»** доступен тумблер **«Отображать в аналитике»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_44-1.png.webp)

Если тумблер включён:

- параметр становится доступен для использования в **аналитических отчётах**;

- значения параметра могут выводиться в Excel-файлы отчетов:

  - [**Лента заказов**;](https://selsup.ru/application/allOrders?ascending=true&dateFrom=2025-12-14T17%3A00%3A00.000Z&dateTo=2025-12-21T16%3A59%3A59.999Z&limit=100&organizationId&page=1&period=DAY&service&status&type)

  - [**Товарная аналитика**;](https://selsup.ru/application/productAnalytics/?dateFrom=2025-12-14T17%3A00%3A00.000Z&dateTo=2025-12-21T16%3A59%3A59.999Z&limit=100&page=1&period=DAY&productAnalyticField=BARCODE&sortBy=MARGIN&timeZone=7)

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_45-3.png.webp)
