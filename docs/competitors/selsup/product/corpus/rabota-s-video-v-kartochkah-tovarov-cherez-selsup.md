# Работа с видео в карточках товаров

С помощью [PIM-системы](../../help_cat/rabota-s-kartochkami-tovarov/index.html) в SelSup вы можете легко добавлять видео в карточки товаров и отправлять их на маркетплейсы — всё в одном окне, без лишних действий и переключений. Это экономит ваше время и помогает улучшать визуальную подачу товара, что напрямую влияет на конверсию.

Для массовой загрузки видео через Фотосъемки используйте отдельную инструкцию [Массовая загрузка видео через Фотосъемки](../massovaya-zagruzka-video-cherez-fotosemki/index.html). В этой статье рассмотрим добавление видео в карточки товаров через интерфейс SelSup.

## Как добавить видео в карточку товара?

- Перейдите в раздел [Товары ](https://selsup.ru/application/products)→ откройте карточку товара;
- Спуститесь до блока **Видео;**
- Нажмите на синее поле для выбора или перетащите видео с компьютера;

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/screenshot_381.png.webp)

- Включите тумблер нужного маркетплейса (Ozon или Яндекс Маркет).

- Нажмите **Сохранить** — видео сразу отправится в карточку на выбранном МП.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/screenshot_382.png.webp)

- Для **Wildberries** нажмите на иконку WB в верхней части карточки и выберите **Загрузить медиа на ВБ**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/screenshot_383.png.webp)

Если вы добавляете видео при создании новой карточки и тумблер маркетплейса (WB, Ozon, ЯндексМаркет) включён — отправка карточки на маркетплейс запуститься автоматически.

## Гибкое управление: на какие маркетплейсы отправлять видео

На загруженном видео отображаются иконки маркетплейсов, с которыми настроена интеграция.\
Хотите отправить видео только на WB? Включите только иконку WB.\
Если выключены все иконки — видео уйдёт маркетплейсы.

## Отправка нескольких видео на Ozon

Для одной карточки товара в SelSup можно отправить на Ozon до **5 видео**. Ограничение в 5 видео связано с ограничением самого Ozon при передаче данных по API.

Для этого нужно указать ссылки на видео в параметре **Ozon.Видео: ссылка** в карточке товара.

**Важно:** Ozon принимает ссылки только с **RuTube**, **VK Видео** и **Яндекс Диска**.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

### Как добавить ссылки на видео для Ozon

1.  Откройте карточку товара в SelSup.
2.  Перейдите к параметрам Ozon.
3.  Найдите параметр **Ozon.Видео: ссылка**.
4.  Укажите ссылку на видео.
5.  Если нужно добавить несколько видео:
    - В интерфейсе: создайте дополнительные поля для заполнения с помощью зелёной кнопки с плюсом.
    - В Excel-файле: укажите ссылки через точку с запятой без пробелов в столбце **Ozon.Видео: ссылка**.

Пример заполнения в Excel-файле:

https://rutube.ru/video/xxx/;https://vkvideo.ru/video-xxx;https://disk.360.yandex.ru/i/xxx

После этого сохраните карточку и отправьте её на маркетплейс.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/cpn6pwrzjo.png.webp)

### Где взять ссылку на видео

**Для RuTube:**

1.  Откройте нужное видео на RuTube.
2.  Нажмите **Поделиться**.
3.  Скопируйте ссылку.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/kjmn59ttg2.png.webp)

**Для VK Видео:**

1.  Проверьте, что в настройках вашего аккаунта в разделе **Приватность → Кто видит список моих видеозаписей** выбрано **Все пользователи**.
2.  Откройте ролик на сайте VK Видео.
3.  Откройте вкладку **Экспортировать**.
4.  Скопируйте ссылку из строки **Прямая ссылка**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/bivgkbl0au.png.webp)

**Для Яндекс Диска:**

1.  Откройте Яндекс Диск на устройстве или на сайте.
2.  Выберите видеофайл. Лучше использовать файл в формате **MP4**.
3.  Нажмите на файл правой кнопкой мыши и выберите **Поделиться**.
4.  Убедитесь, что пользователям, у которых есть ссылка, разрешён просмотр файла.
5.  Нажмите **Скопировать ссылку**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/r7hn3caxc0.png.webp)

## Замена и удаление видео:

- Чтобы заменить видео: удалите старое, загрузите новое и нажмите **Сохранить**.

- Чтобы удалить: просто удалите видео и сохраните изменения — оно исчезнет и на маркетплейсе.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/screenshot_384.png.webp)

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Массовое удаление видео:

Если нужно удалить видео сразу во всех карточках:

- Перейдите в [**Настройки → Мои организации**.](https://selsup.ru/application/organizations/)
- Найдите нужную организацию.
- В колонке **Удалить видео** нажмите на крестик — медиафайлы удалятся из всех карточек этой организации.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/screenshot_386.png.webp)
