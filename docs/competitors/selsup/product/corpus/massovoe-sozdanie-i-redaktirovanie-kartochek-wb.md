# Массовое создание и редактирование карточек WB

Массовое создание и редактирование карточек можно автоматизировать с помощью SelSup. Это позволит вам значительно сэкономить время, так как сервис может сделать это намного быстрее с помощью Excel-файла.

Если при работе с OZON, Wildberries, Яндекс Маркет и AliExpress настройки проводятся одинаково, то в Мегамаркет есть свои особенности, о которых мы подробнее говорили [здесь](../kak-pravilno-sozdat-kartochku-tovara-cherez-selsup-esli-vy-seller-sbermegamarket/index.html).\

## Как массово создать карточки

**Шаг 1.** Для того чтобы массово создать карточки через Selsup сначала нужно заполнить 1 карточку через интерфейс. Для этого зайдите в раздел [**Товары**](https://selsup.ru/application/products) и нажмите **Создать товар**. Более подробно о создании карточки товара мы рассказали в [инструкции](../kartockka_tovara/index.html).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_55.png.webp)

**Шаг 2.** Зайдите в раздел [**Товары - Категории**](https://selsup.ru/application/categories/). Здесь необходимо проставить связь между маркетплейсами (от куда и куда вы хотите перенести карточки товаров).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_101.png.webp)

Нажмите на название категории или на значок **Редактировать**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_102.png.webp)

Выберите подходящую категорию **Wildberries** из выпадающего списка и вставьте код **ТНВЭД**. SelSup покажет, какие документы потребуются для продажи товаров этой категории.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_103.png.webp)

Проставьте общие параметры, которые предлагает заполнить SelSup. Это необходимо для того, чтобы вам не пришлось заполнять эти параметры отдельно для каждой карточки товара. Так, они будут подтягиваться автоматически (Обратите внимание, что для разных категорий параметры могут отличаться).\
Также заполните поле **Параметры**, в нем можно выбирать параметры маркетплейса и задавать им значения.\
Когда все поля заполнены, нажмите **Сохранить**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_104.png.webp)

**Шаг 3.** Перенос карточек будет осуществляться по категориям. Зайдите в любой товар из Категории и включите тумблер Wildberries, чтобы появились параметры этого маркетплейса. Заполните их.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_105.png.webp)\
Если создаете карточку через интерфейс SelSup, то заполнив параметры WB нажмите **Сохранить‎** с включенным переключателем маркетплейса. Карточка будет отправлена на создание в Wildberries.

Если переносите товары массово, сделать это можно через Excel-файл, подробнее в последующих шагах.

**Шаг 4.** Далее зайдите в **Товары - Импорт товаров** во вкладку [**Массовое редактирование**](https://selsup.ru/application/productsImport/import) и нажмите **Скачать Excel**. Выберите категорию и скачайте файл.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_106.png.webp)

<p><strong>Шаг 5.</strong> Откройте скачанный файл. Заполните все необходимые поля. Для этого просто скопируйте параметры <strong>Wildberries</strong> с заполненной карточки на все остальные. Затем сохраните файл.</p>

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/ozon-perenos-tovarov-selsup-1.png.webp)

<p><strong>Шаг 6.</strong> Вернитесь в <strong>Товары - Импорт товаров</strong> во вкладку <a href="https://selsup.ru/application/productsImport/import"><strong>Массовое редактирование</strong></a>. Выберите организацию, для которой добавляете товары, выберите <strong>Wildberries </strong>и загрузите Excel-файл<strong>.</strong> Перетащите файл или выберите его нажатием на соответствующее поле.</p>
<p>![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_45-2.png.webp)</p>

<p>Готово! SelSup сам обработает файл, перенесет все параметры в систему и отправит карточки на создание в Wildberries.</p>

<strong>Важно!</strong> На стороне Wildberries <strong>действует суточный лимит на создание новых карточек товаров</strong>. Если за текущий день лимит уже исчерпан, Wildberries может отклонить создание новых карточек с ошибкой:
<p>&gt; Today you can't add product cards. You have already used up your daily limit — 1000. Try tomorrow.</p>
<p>В этом случае ошибка возникает не на стороне SelSup. Нужно дождаться следующего дня и повторить отправку либо заранее разбить файл на несколько частей, чтобы не превышать лимит создания новых карточек за сутки.</p>
<p>Ограничение относится именно к созданию новых карточек. Если нужно обновить уже существующие карточки, лимит не применяется.</p>

<p><strong>Шаг 7.</strong> Одна из особенностей переноса карточек на Wildberries заключается в том, что фотографии переносятся после создания карточек на маркетплейсе.<br />
Для переноса фотографий зайдите на страницу <a href="https://selsup.ru/application/photo/">Товары — Фото</a>, выберите вкладку «Товары без фото‎» и маркетплейс Wildberries.<br />
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_108.png.webp)</p>
<p><strong>Шаг 8.</strong> Нажмите кнопку «‎Загрузить фотографии Wildberries‎». Фотографии будут постепенно отправляться на Wildberries, при этом вы не должны уходить со страницы — иначе процесс загрузки прервется.</p>
<p>![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_109.png.webp)</p>
<p><strong>Шаг 9.</strong> После загрузки фото — перейдите на страницу <a href="https://selsup.ru/application/productsImport/wildberries">Импорт товаров с Wildberries</a>, и запустите импорт.<br />
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_110.png.webp)<br />
Он обновит статус загрузки фотографии и вы сможете опять отфильтровать товары без фото, если какие-то фотографии не загрузились.</p>

## Как массово редактировать карточки

Помимо привычного метода через Excel, теперь вы можете массово редактировать параметры карточек прямо в интерфейсе — точно так же, как в таблице. Подробно о возможности редактирования параметров без Excel-файлов читайте в отдельной [статье](../massovoe-redaktirovanie-parametrov-kartochki-cherez-interfejs/index.html).

Важно! При внесении массовых изменений в карточки товаров, созданные не через SelSup, существует риск их повреждения. Рекомендуем предварительно протестировать правки на одной карточке через Excel-выгрузку: если изменения применились корректно, можно редактировать остальные. Обратите внимание, что в случае ошибки карточки обычно остаются в продажах, но в личном кабинете маркетплейса перемещаются в раздел с ошибками, что может потребовать ручного исправления.

**Шаг 1.** Чтобы массово отредактировать карточки, для начала нужно вручную обновить одну карточку товара. Так, нужные вам параметры перенесутся в Excel.

**Мы не рекомендуем** вам заполнять данные сразу в Excel, так как малейшая ошибка, даже в пробеле, может привести к тому, что маркетплейс не примет значение и оставит его пустым.

Чтобы отредактировать карточку перейдите в раздел [**Товары,**](https://selsup.ru/application/products) нажмите на название карточки и вы попадёте в её внутренний редактор.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_111.png.webp)

**Шаг 2.** Появится окно с внутренним редактором карточки товара. В нём заполните всю необходимую информацию. Нажмите **Сохранить**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_112.png.webp)

**Шаг 3.** После этого перейдите в **Товары - Импорт товаров** во вкладку [**Массовое редактирование**](https://selsup.ru/application/productsImport/import) и нажмите **Скачать Excel**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_106.png.webp)

**Шаг 4.** Выберите организацию, категорию товара и нажмите на кнопку **Выгрузить новый файл**. Запустится загрузка. Дождитесь скачивания файла.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_113.png.webp)

**Шаг 5.** Выгрузится Excel-файл с товарами, где вы сможете их отредактировать. Через него вам нужно самостоятельно скопировать необходимые данные в параметры нужного маркетплейса. После чего сохраните файл.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/redactirovanie-massovoe-kartochek.png.webp)

Для удобной работы с ассортиментом, включающим товары и комплекты, в выгружаемом Excel-файле доступна фильтрация по типу номенклатуры. Воспользуйтесь новым столбцом «Комплект»: чтобы быстро найти все товары, просто отфильтруйте в этом столбце значение «Нет» — в результате в таблице останутся только позиции, отмеченные как товары.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_128-1.png.webp)

**Шаг 6.** Вернитесь в **Товары - Импорт товаров** во вкладку [**Массовое редактирование**](https://selsup.ru/application/productsImport/import). Выберите организацию, для которой добавляете товары, выберите **Wildberries **и загрузите Excel-файл**.** Перетащите файл или выберите его нажатием на соответствующее поле.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_107.png.webp)

Массовое редактирование завершено!

## Фильтрацией данных в Excel

Если фильтры в выгруженных из SelSup отчетах перестали работать корректно, выполните следующие действия:

**1. Выделите всю таблицу**, нажав на специальный маркер в левом верхнем углу листа (на пересечении заголовков строк и столбцов).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_49-1.png.webp)

**2. Перезагрузите фильтр**: на вкладке «Данные» дважды нажмите кнопку «Фильтр» (сначала для отключения, затем — для повторного включения).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/02/screenshot_50.png.webp)

**Важно!** Обратите внимание на вторую строку таблицы: она содержит служебные параметры, необходимые для работы системы. Эту строку нельзя удалять — мы скрыли её для вашего удобства. В некоторых случаях именно она может вызывать сбои в работе фильтров, особенно в устаревших версиях Excel. Предложенный выше способ решает эту проблему.

С более широкой инструкцией о возможностях интеграции с Wildberries можно ознакомиться по [ссылке](../integration-s-wildberries/index.html).
