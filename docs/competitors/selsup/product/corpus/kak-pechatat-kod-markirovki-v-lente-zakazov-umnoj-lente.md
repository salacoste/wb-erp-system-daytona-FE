# Как печатать код маркировки в ленте заказов (умной ленте)

В этой статье расскажем о новой удобной функции SelSup — **печати кода маркировки прямо в ленте заказов**.

Это одно из самых полезных обновлений для работы по **FBS**, которое заметно упрощает сборку и помогает избежать ошибок на складе.

Теперь вам не нужно искать коды вручную или печатать лишние маркировки заранее — всё делается прямо в заказах: быстро, точно и только для тех товаров, которые уже купили.

Функция особенно актуальна, если вы хотите ускорить отгрузки, снизить количество пересортов и сделать работу склада максимально простой и понятной.

## Для чего это нужно

Функция печати кода маркировки в ленте заказов помогает упростить работу с заказами по FBS и сократить количество ошибок на сборке.

Теперь вы можете:

- печатать коды маркировки **только для заказов FBS** прямо в ленте заказов;

-  получать коды **только на уже заказанные товары**, без лишних кодов и путаницы;

- упростить процесс отгрузки и снизить количество ошибок при сборке;

- работать быстрее: меньше ручных действий — больше эффективности и прибыли.

## Как включить и использовать печать кода маркировки в ленте заказов

Для автоматической печати кодов маркировки непосредственно в ленте заказов выполните следующие шаги:

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

### 1. Активация функции

- Перейдите в раздел **«Настройки» → «[Заказы](https://selsup.ru/application/settings/orders)»**.

- Найдите настройку **«Печатать код маркировки в ленте заказов»** и переведите соответствующий тумблер в активное положение.

- **Сохраните** изменения.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/05/screenshot_35.png.webp)

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

### 2. Получение и резервирование кодов маркировки

- Откройте раздел **«Заказы на отгрузку» → [«Со своего склада ФБС»](https://selsup.ru/application/fbsOrders/?ascending=true&limit=100&page=1&sortBy=CREATED&status=CREATED&type=FBS)**.

- Отметьте галочками нужные заказы.

- В верхнем меню действий (панель с синими кнопками) нажмите **«Получить маркировку»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/05/screenshot_36.png.webp)

- В появившемся окне подтвердите действие, нажав **«Получить маркировку»**, а затем **«Зарезервировать»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/05/screenshot_37.png.webp)

- **Пояснение:** Кнопка **«Зарезервировать»** закрепляет полученные коды маркировки за выбранными вами заказами.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

### 3. Печать ленты заказов с кодом

- Для печати используйте прямое подключение **принтера**.

  

  Важно: в файл ПДФ код маркировки не скачается.

  

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/05/screenshot_38.png.webp)

Функция печати кода в ленте заказов работает только при резервировании кодов через раздел «Заказы на отгрузку» (как описано выше). Если коды маркировки были привязаны к заказам через раздел «Задание», данная функция не сработает, и коды в ленте заказов печататься не будут.
