# Выбираем схему хранения на складе

SelSup поддерживает 2 схемы хранения и сборки заказов на складе:

1.  Когда на каждый товар клеится стикер с уникальным кодом товара. Больше подойдет для хранения одежды, товаров с размерным рядом,  а также товаров подлежащих маркировке через Честный знак и средних по размеру, но не для совсем мелких товаров.
2.  Без уникальный кодов. В 1 ячейке будет храниться товар с 1 штрихкодом. Подойдет для хранения больших партий одинаковых товаров или для очень мелких товаров (например, косметика).

Какую из них выбрать - решать вам в зависимости от вашего товара и способа хранения. Можно также комбинировать эти схемы работы с товаром.

<td style="padding-right: 40px"><h3 id="с-уникальным-кодом">С уникальным кодом</h3>
<p>На каждую единицу товара даже с одинаковым штрих-кодом клеится уникальный номер товара. В дальнейшем при сборке заказа поиск товара происходит по уникальному номеру.</p>
<h4 id="плюсы">Плюсы</h4>
<ul>
<li>эффективное использование места на складе для небольших партий одного товара - любое место может быть занято любым товаром</li>
<li>быстрая сборка заказов по уникальному номеру</li>
<li>полное прослеживание движения каждого товара (кто, во сколько его положил на полку, кто собрал заказ и тд)</li>
<li>более быстрая раскладка подсорта товара небольших партий - положить товар на любую ячейку, не нужно искать определенную ячейку этого же товара.</li>
</ul>
<h4 id="минусы">Минусы</h4>
<ul>
<li>на каждую единицу товара при приемке необходимо клеить стикер</li>
<li>при сборке заказов нужно искать конкретный номер товара</li>
<li>если у вас уже есть склад с большим количеством товаров, то придется обклеивать каждую единицу уникальным кодом</li>
</ul></td>
<td><h3 id="со-штрих-кодом-товара">Со штрих-кодом товара</h3>
<p>На товаре должен быть только штрих-код, не нужно клеить дополнительный уникальный стикер. В дальнейшем при сборке заказа вам нужно будет искать любую единицу товара с места хранения. В ячейке хранятся товары с одинаковым штрихкодом.</p>
<h4 id="плюсы-1">Плюсы</h4>
<ul>
<li>быстрая приемка и раскладка больших партий одинакового товара</li>
<li>нет дополнительных расходов на стикеризацию уникальным кодом каждой единицу товара</li>
<li>при сборке достаточно лишь подойти к нужной ячейке и взять любой из товаров.</li>
</ul>
<h4 id="минусы-1">Минусы</h4>
<ul>
<li>неэффективное заполнение помещений склада</li>
<li>отсутствие возможности отследить конкретную единицу товара - только партию</li>
</ul></td>
