## Для чего нужны теги в карточках товаров?

Мы добавили возможность тегирования (проставления тегов или хештегов) товаров, чтобы вы могли:\
- Группировать товары по любым признакам (акции, сезонность, поставщики и др.)\
- Быстро фильтровать товары в каталоге\
- Добавлять дополнительные характеристики, не предусмотренные стандартными полями\
- Массово назначать теги через файл загрузки

Это упрощает управление ассортиментом и ускоряет поиск нужных товаров.

Похожая система есть на Вайлдберриз под названием "ярлыки". На Озоне теги предназначены для другого.

## Как добавить или изменить теги через интерфейс

- В разделе [Товары](https://selsup.ru/application/products/?ascending=false&deleted=false&grouped=true&limit=50&page=1&sortBy=TOTALORDERS), откройте карточку товара и перейдите во вкладку **Теги**.

- Чтобы создать новый тег, нажмите **+**, введите имя тега и нажмите **Сохранить** — он будет автоматически добавлен к товару.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/screenshot_21.png.webp)

- Чтобы добавить существующий тег, найдите его через поиск и нажмите **Добавить связь с карточкой**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/screenshot_22.png.webp)

- Для редактирования тега, в поле **«Поиск»** введите название → нажмите на **«✎»** → отредактируйте → нажмите **«Сохранить»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/screenshot_23.png.webp)

- Для удаления тега, нажмите крестик рядом с тегом (удалится только связь с товаром, сам тег останется в системе).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/screenshot_24.png.webp)

При добавлении тега в карточку с несколькими размерами он присвоится всем размерам. Если для некоторых размеров тег не нужен, удалите его вручную для этих размеров.

## Массовое добавление и удаление тегов

- Перейдите в **Товары → Импорт товаров → [Массовое редактирование](https://selsup.ru/application/productsImport/)**[.](https://selsup.ru/application/productsImport/)

- Скачайте список товаров через кнопку **Скачать Excel**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/screenshot_25.png.webp)

- Найдите столбец **Теги** и впишите туда нужные теги (несколько тегов указываются через `;`).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/screenshot_27.png.webp)

- Для удаления тегов просто очистите значения в нужных строках.

- Загрузите файл обратно в SelSup.

- Если вы удаляете теги, включите тумблер **Удалять значения параметров, где пустые ячейки**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/screenshot_28.png.webp)

## Как фильтровать товары по тегам

В разделе **Товары** используйте фильтр **Теги**.\
Можно выбрать один или несколько тегов — в таблице отобразятся только товары, соответствующие выбранным тегам.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/screenshot_29.png.webp)

А если вы хотите более глубоко автоматизировать работу с товарной информацией — обратите внимание на модуль [**PIM-система**:](../../help_cat/rabota-s-kartochkami-tovarov/index.html) это централизованное хранение карточек, медиафайлов, синхронизация с маркетплейсами и разграничение прав для сотрудников. Автоматизируйте рутину и делайте работу быстрее и удобнее.

## Как использовать теги в Листе сборки FBS

Теги можно использовать не только в карточках товаров и фильтрах, но и в **Листе сборки FBS**.

Что доступно:

- отдельная колонка **Теги** в Листе сборки FBS;
- сортировка заказов по тегам в Листе сборки;
- настройка общего порядка сортировки в разделе **Настройки → Заказы**.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

#### Как включить сортировку по тегам

- Перейдите в раздел **Настройки → [Заказы](https://selsup.ru/application/settings/orders)**.
- В блоке **Лента заказов и лист сборки** выберите значение **По тегам** в выпадающем списке **Порядок сортировки в листе сборки**.
- Обязательно включите опцию **Ускорить сборку через ленту заказов по всем организациям**. Без этой настройки сортировка по тегам работать не будет.
- После этого нажмите **Сохранить**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/screenshot_199.png.webp)

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

#### Как добавить теги в Лист сборки FBS

- Перейдите в раздел **Настройки → [PDF Документы](https://selsup.ru/application/pdfDocuments/)**[.](https://selsup.ru/application/pdfDocuments/)
- Откройте шаблон **Лист сборки FBS**, кликнув по его названию.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/image-11.png.webp)

- Нажмите **Добавить** новый объект и выберите тип **Колонка таблицы**.
- В поле заголовка укажите, например, **Теги**.
- В качестве значения выберите **Теги** из выпадающего списка или укажите \`\${row.formattedTags}\`\` в поле **Текст**.
- После этого нажмите **Сохранить**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/image-10-1.png.webp)

Теперь в Листе сборки FBS появится отдельная колонка с тегами товаров. Если у товара теги не заданы, колонка останется пустой.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

#### Как работает сортировка

При выборе сортировки **По тегам** заказы в Листе сборки группируются по тегам товаров.

Товары с одинаковыми тегами отображаются рядом. Если у заказов несколько разных тегов, группы выводятся последовательно. Внутри групп применяется лексикографическая сортировка.

**Важно:** сортировка выполняется с учетом общей логики группировки:

- по сервису;
- по организации;
- по тегам.

Если используются несколько организаций или сервисов, сначала применяется группировка по ним, а затем сортировка по тегам.
