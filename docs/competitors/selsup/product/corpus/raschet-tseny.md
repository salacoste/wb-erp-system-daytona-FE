# Формула расчета розничной цены

Самая подробная статья по работе с ценами - [здесь](../prices/index.html).

По умолчанию Selsup рассчитывает розничую цену для маркетплейсов  как розничную цену, умноженную на 4, плюс стоимость доставки. Вы можете ввести свой коэффициент и стоимость доставки в разделе Настройки (синяя шестеренка) - вкладка [Закупки](https://selsup.ru/application/settings/purchases).
