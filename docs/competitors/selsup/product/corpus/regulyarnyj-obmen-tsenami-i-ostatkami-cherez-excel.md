# Регулярный обмен ценами и остатками через Excel

Регулярный обмен через **Excel по ссылке** позволяет автоматически загружать цены и остатки из Excel-файла, который поставщик размещает по URL.

SelSup получает файл по указанной ссылке, обрабатывает данные и обновляет цены или остатки по товарам.

Такой способ подходит, если поставщик не отправляет файл на почту, а передаёт прямую ссылку на регулярно обновляемый Excel-файл.

Перед настройкой обмена через Excel по ссылке рекомендуем проверить общие параметры регулярного обмена: организацию, маркетплейс, склад, периодичность обновления и правила передачи остатков. ## Как создать обмен через Excel

Перейдите в раздел **Закупки → Дропшиппинг → [Регулярные обмены](https://selsup.ru/application/dropShipping/dropShipping)** и нажмите **Добавить**.

В поле **Тип** выберите **Excel**.

После этого заполните параметры обмена и укажите ссылку на файл.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Какие данные нужно указать

В поле **Адрес сайта** укажите ссылку на Excel-файл.

По этой ссылке должен сразу открываться или скачиваться сам файл Excel. Если по ссылке открывается страница сайта, облачного хранилища или предпросмотр файла, такой вариант не подойдёт.

Например, ссылка на страницу просмотра файла в Яндекс.Диске не будет работать, потому что по ней открывается страница, а не сам Excel-файл.

Для регулярного обмена нужна прямая ссылка, по которой SelSup сможет получить файл и обработать его автоматически.

## Как работает обмен

После сохранения SelSup будет обращаться к указанной ссылке, получать Excel-файл и обрабатывать данные из него.

Данные из файла сопоставляются с товарами в SelSup по артикулу, штрих-коду или другому указанному параметру.

Если товар найден, SelSup обновит по нему цены или остатки в соответствии с настройками обмена.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## После настройки

После заполнения всех параметров нажмите **Сохранить**.

SelSup будет регулярно получать Excel-файл по указанной ссылке и обновлять данные по товарам.

Если включена передача данных на маркетплейсы, после обработки файла обновлённые цены и остатки будут передаваться на подключённые площадки.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Если обмен не сработал

Если данные из Excel-файла не обновились, проверьте:

- указана ли прямая ссылка на Excel-файл;
- открывается ли по ссылке сам файл, а не страница просмотра;
- доступен ли файл без дополнительной авторизации;
- не изменилась ли структура файла;
- совпадают ли артикулы или штрих-коды из файла с товарами в SelSup;
- выбраны ли нужные настройки обновления цен и остатков.

Для обмена через Excel по ссылке указывайте только прямую ссылку на файл. Ссылки на страницы предпросмотра, например в облачных хранилищах, не подойдут.
