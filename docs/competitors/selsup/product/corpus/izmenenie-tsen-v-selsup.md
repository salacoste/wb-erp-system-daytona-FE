В этой статье расскажем как менять цены на товары из SelSup.\

Раздел [Цены](https://selsup.ru/application/prices/) предназначен для управления ценами на маркетплейсах. При этом в файле excel вы можете увидеть вашу текущую и планируемую **наценку** и **маржинальность**, а также увидеть **разницу потенциального дохода** при смене цены.

Регулировка цен доступна в интерфейсе в разделе [Цены и акции - Цены](https://selsup.ru/application/prices/) – для более быстрого изменения.

## Настройки полей для работы в кабинете по ценам

** 1. Настройка столбцов по ценам**

Вы можете самостоятельно регулировать видимость столбцов, выберите "Столбцы" и включите тумблеры по нужным столбцам.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/screenshot_102.png.webp)

** 2. Товары "В наличии"**\
Можно управлять видимостью товаров "В наличии", нужно включить курок:\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/screenshot_103.png.webp)

** 3. Обновление цен с WB**

Вы можете обновить цены с Маркетплейса.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/screenshot_104.png.webp)\
**4. Фильтры**

Вы можете сделать выборку по фильтрам - нажмите **Фильтры**.

Откроются поля для ввода/выбора фильтров:

- **по категории** - выберите из выпадающего списка.
- **по поставщику** - выберите из выпадающего списка.
- **по организации** - выберите из выпадающего списка.
- **по бренду** - выберите из выпадающего списка.
- **по дубликатам** - любые/да/нет.
- **по типу** - любой/товар/цифровой товар/комплект/услуга.
- **по остатку FBO и FBS -** карточки по товарам, где есть остатки на маркетплейсах.
- **по избранным товарам** - для отслеживания определенных товаров.
- **по архивным карточкам.**
-  доступны тумблеры для фильтрации товаров **без закупочной цены** и **без дополнительных расходов**.

## Внесение изменений в цены товаров

**1 Обновить закупочные цены**

При заполнении/изменении закупочных цен можно нажать **"Обновить закупочные цены".\**
Вводить закупочную цену Вы можете как целыми числами, так и дробными.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/screenshot_106.png.webp)

**2. Заполнение цен через интерфейс**

**Дополнительные расходы** - можете указать упаковку товара\
**Расходы по продажам** - для маркетплейсов, кроме Wildberries, Ozon.\
Укажите **налог, желаемый % маржинальности**.\
**Желаемая прибыль (в руб.)** - минимальная прибыль, которую Вы хотите получить за товар.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/screenshot_108.png.webp)

**Процент выкупа** выгружается из аналитики/можно проставить самостоятельно для оценки рисков.\
**Логистика WB (руб.), Обратная логистика WB (руб.) -** рассчитываются самостоятельно, влияют на автоматический расчет **Расходов по продажам на МП** (столбец обычно в левой части интерфейса)\
**Коэффициент склада в %, Комиссия WB** - проставляются автоматически.\
SelSup показывает **Цену со скидкой по желаемой прибыли (в руб.), Цену со скидкой по желаемому % маржинальности** - по ним можно вручную указать цену **"Со скидкой новая желаемая"** и сохраняем запись по товару.**\**
WB может не принять новую желаемую цену со скидкой (Wildberries принимает данные по % скидки, SelSup отправляет ближайшее значение скидки для вашей желаемой цены).\
**Со скидкой новая расчетная** - цена, которую принял маркетплейс, может отличаться в копейках.\
**Новая валовая прибыль** - сколько хотим зарабатывать, укажет **Новую маржинальность** по тем параметрам и ценам, которые проставлены.\
**Текущая валовая прибыль** - прибыль по тем цифрам, которым введены сейчас (может быть минус).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/screenshot_109.png.webp)

По другим маркетплейсам (например, Яндекс.Маркет) может не быть столбцов - комиссия, логистика.

По данным настройкам рассчитается excel файл.

**3. Массовое изменение цен через Exсel**

Вам нужно скачать цены в формате Excel нажатием на кнопку **Скачать цены** и после изменений импортировать данные в SelSup через кнопку **Импорт**. Формируете задачу на отправку цен на маркетплейс для обновления цен.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/screenshot_81.png.webp)

Корректировать можно поля, выделенные зелёным цветом, и **Новые цены со скидкой** по маркетплейсам:

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/korrektirovka-excel.png.webp)

Остальные поля являются информативными и расчётными.

По столбцам «**Текущая наценка** …» и «**% текущей маржинальности** …» можно посмотреть, какие товары уже имеют отрицательную маржинальность или наценку ниже единицы, то есть продаются в убыток, либо наоборот имеют высокие показатели доходности.

**Заказы** в файле указаны за 2 недели. Соответственно **оборачиваемость** также рассчитывается за последние две недели. Если заказов за 2 недели не было, то проставляется автоматически оборачиваемость 999. Хорошей считается оборачиваемость до 70 дней.

В столбце **Разница потенциального дохода** рассчитано, какую сумму дохода вы потенциально можете потерять или заработать при изменении цены и продаже всего товарного остатка по новой цене.

Все показатели сведены также по категориям, брендам и артикулам на отдельных листах.\
Также по изменению цен Вы можете посмотреть ["**Управление ценами через SelSup на всех маркетплейсах"**](../prices/index.html)

**4 Массовое изменение цен из интерфейса**

Можно вносить массовые изменения по:\
- **категориям**;\
- **брендам**;\
- **организациям**;\
- **перенести цены с маркетплейса на маркетплейс**;\
- **изменить цену на %** (в Ozon лучше продавать товар дороже, чем на Wildberries) - можно указывать с минусом.\
- **изменить цену на сумму** - можно указать изменение в рублях.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/screenshot_98.png.webp)

**5 История изменения цен**

Вы можете посмотреть на вкладке [Цены и акции - История цен:](https://selsup.ru/application/priceHistory/)

**Данные от сервиса** - информация, которая приходит от маркетплейса.\
**Данные от пользователя** - отправленные пользователем цены, сам SelSup без пользователя не направляет цены. Будут отражен пользователь-отправитель, время отправки, отражены ошибки при отправке цен.

Можно выбрать отправки **по успешным/отправка с ошибками.**
