# Как перенести данные из одной организации в другую через ВПР

В этой статье расскажем, как перенести значения из файла одной организации в файл другой с помощью Excel.

Способ подойдет, если у вас есть две организации с одинаковыми товарами, и вы хотите быстро заполнить нужные столбцы во втором файле без ручного ввода.

Например, таким способом можно перенести:

- закупочную цену;
- дополнительные расходы;
- постоянные расходы;
- минимальную цену;
- другие значения из файла.

В этой статье в качестве примера покажем перенос **закупочной цены**, но по такому же принципу можно переносить и другие данные.

## Когда удобно использовать перенос через Excel

Если у вас уже заполнены данные в одной организации, их можно использовать для второй организации.

Это удобно, когда:

- товары в обеих организациях одинаковые;
- часть данных должна совпадать;
- нужно быстро перенести значения сразу для большого количества товаров.

Вместо ручного заполнения можно использовать Excel и формулу **ВПР**, чтобы автоматически подставить нужные значения из одного файла в другой.

## Какие файлы понадобятся

Для переноса понадобятся:

- файл с данными по **первой организации**, где нужный столбец уже заполнен;
- файл по **второй организации**, куда нужно подставить значения.

Оба файла можно скачать в нужном разделе SelSup, в зависимости от того, какие данные вы переносите.

## Как сопоставлять товары

Чтобы значение подставлялось корректно, нужно выбрать ключ для поиска.

Можно использовать:

- **штрихкод** — если он одинаковый в обеих организациях и уникален для товара;
- **Артикул + Цвет + Размер** — если поиск по штрихкоду использовать нельзя.

Если штрихкод совпадает в двух файлах, удобнее использовать именно его.\
Если штрихкодов несколько, они отличаются или не заполнены, лучше использовать составной ключ из нескольких столбцов.

## Шаг 1. Откройте оба файла в Excel

Откройте:

- файл с данными **первой организации**;
- файл с данными **второй организации**.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Шаг 2. Создайте вспомогательный ключ в файле первой организации

В файле первой организации добавьте справа новый столбец и назовите его, например, **Ключ**.

В первой строке с товаром вставьте формулу:

=D5&"\|"&E5&"\|"&F5

Формула объединит в один ключ:

- артикул,
- цвет,
- размер.

Протяните формулу вниз на все строки.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Шаг 3. Подготовьте столбец для переноса

Рядом со столбцом **Ключ** добавьте еще один вспомогательный столбец.

В него выведите значение из того столбца, который хотите перенести.

Например, если переносите **Закупочную цену, руб.**, формула будет такой:

=H5

Протяните формулу вниз.

Если нужно перенести другой столбец, вместо **H** укажите нужную колонку.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Шаг 4. Перенесите вспомогательные данные во второй файл

Перейдите в файл второй организации.

Создайте отдельный лист, например **Источник**.

Скопируйте из файла первой организации всю таблицу и вставьте ее на лист **Источник**.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Шаг 5. Создайте такой же ключ во втором файле

Во втором файле также добавьте столбец **Ключ**.

В первой строке с товаром вставьте такую же формулу:

=D5&"\|"&E5&"\|"&F5

Протяните формулу вниз до конца таблицы.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Шаг 6. Подставьте значения через ВПР

Теперь в нужный столбец во втором файле вставьте формулу ВПР.

Если переносите **закупочную цену**, формула будет такой:

=ЕСЛИОШИБКА(ВПР(\$B5;Источник!\$A:\$B;2;ЛОЖЬ);"")

В этой формуле:

- **\$B5** — значение, которое Excel ищет. Это ключ из файла **второй организации**, в который нужно подставить данные.
- **Источник** — название вспомогательного листа во **втором файле**, куда заранее скопированы данные из файла **первой организации**.
- **\$A:\$B** — диапазон столбцов на листе **Источник**, по которому работает поиск:
  - **A** — столбец с ключом из файла **первой организации**;
  - **B** — столбец со значением, которое нужно перенести из файла **первой организации**.
- **2** — номер столбца в указанном диапазоне, из которого нужно вернуть результат. В данном случае это столбец **B**.
- **ЛОЖЬ** — означает, что Excel ищет только **точное совпадение**.
- **ЕСЛИОШИБКА(...;"")** — если совпадение не найдено, ячейка останется пустой.

То есть Excel берет ключ из строки файла второй организации, ищет такой же ключ среди данных первой организации и подставляет найденное значение.

Протяните формулу вниз на все товары.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Шаг 7. Зафиксируйте значения

После того как значения подставились:

1.  выделите заполненный столбец;
2.  скопируйте его;
3.  вставьте в этот же столбец через **Специальная вставка → Значения**.

Это нужно, чтобы в файле остались не формулы, а готовые значения.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Шаг 8. Удалите вспомогательные данные

Перед загрузкой файла обратно в SelSup удалите:

- временный столбец **Ключ**;
- лист **Источник**, если он больше не нужен.

После редактирования импортируйте файл обратно в SelSup.

## Итог

Если у двух организаций одинаковые товары, данные из файла одной организации можно быстро перенести в файл другой через Excel.

В этой статье в качестве примера показан перенос **закупочной цены**, но по такому же принципу можно переносить и другие значения из выгрузки.
