# Возможности работы с чатами, вопросами и отзывами маркетплейсов в CRM SelSup

В этой статье расскажем, как работать с чатами, вопросами и отзывами маркетплейсов в CRM SelSup.

CRM SelSup помогает обрабатывать обращения покупателей **в одном окне**. Вам не нужно постоянно переключаться между кабинетами маркетплейсов: в SelSup можно работать сразу с данными из **Ozon** и **Wildberries**, быстро отвечать на сообщения, вопросы и отзывы, а также использовать готовые шаблоны ответов.

## Что нужно для начала работы

Для работы с чатами, вопросами и отзывами в CRM SelSup:

1.  Настройте интеграцию с маркетплейсом.
2.  Импортируйте карточки товаров в SelSup, чтобы по ним могли поступать вопросы и отзывы.

Импортировать данные можно с маркетплейсов **Ozon** и **Wildberries**.

Данные обновляются автоматически **каждые 10 минут**.

При первом запуске импорта - импортируются все **неотвеченные чаты, вопросы и отзывы** за весь период;

## Шаблоны ответов

Шаблоны помогают быстрее отвечать на типовые обращения покупателей.

Чтобы добавить шаблон:

1\. Перейдите во вкладку **Шаблоны**.

2\. Нажмите **Создать новый шаблон**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/03/screenshot_200.png.webp)

3\. Укажите **название шаблона,** выберите **тип шаблона** из выпадающего списка,  заполните **текст шаблона**.

4\. Нажмите **"Создать". **

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/03/screenshot_201.png.webp)

После этого шаблон можно будет выбрать при составлении ответа в чатах, вопросах и отзывах.

## Чаты

Для работы с чатами перейдите в раздел **CRM → Чаты**.

В этом разделе можно:

- просматривать сообщения покупателей;
- отвечать на сообщения прямо из SelSup;
- использовать **шаблоны ответов**;
- фильтровать чаты;
- запускать принудительное обновление чатов с маркетплейсов.

В разделе есть вкладки для новых и всех чатов. После ответа чат переходит в общий список.

При необходимости можно использовать фильтр чатов и отбирать обращения:

- по маркетплейсу;
- по дате последнего сообщения;
- по неотвеченным чатам;
- по организациям.

Также в разделе есть кнопки для **принудительного обновления чатов** с Ozon и Wildberries.

## Вопросы

Для работы с вопросами перейдите в раздел **CRM → Вопросы**.

Здесь можно:

- просматривать вопросы покупателей;
- отвечать на них прямо из SelSup;
- использовать шаблоны ответов;
- запускать импорт вопросов по кнопке с **закругленной стрелкой**.

В разделе доступны вкладки для вопросов без ответа, отвеченных и всех вопросов.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/03/screenshot_203.png.webp)

## Отзывы

Для работы с отзывами перейдите в раздел **CRM → Отзывы**.

Интерфейс раздела аналогичен вопросам. Здесь можно:

- просматривать отзывы покупателей;
- отвечать на отзывы в SelSup;
- использовать шаблоны ответов;
- запускать импорт отзывов по кнопке с **закругленной стрелкой**.

В разделе доступны вкладки для отзывов без ответа, отвеченных и всех отзывов.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/03/screenshot_203-1.png.webp)

## Почему это удобно

CRM SelSup помогает:

- работать с обращениями из **Ozon** и **Wildberries** в одном окне;
- быстрее отвечать покупателям;
- использовать готовые шаблоны;
- не переключаться между кабинетами маркетплейсов;
- контролировать новые и обработанные обращения в одном разделе.
