## Процесс объединения товаров при импорте

SelSup автоматически объединяет товары из разных источников, чтобы избежать дублей в каталоге.

- **Поиск по штрих-коду (ШК):** При импорте SelSup в первую очередь ищет товар по ШК. Если находит товар без привязки к маркетплейсу, она автоматически связывает с ним новую карточку.
- **Поиск по артикулу:** Если по ШК товар не найден, для некоторых типов импорта SelSup пытается найти его по артикулу.
- **Создание нового товара:** Если товар не найден ни по ШК, ни по артикулу — SelSup создает для него новую карточку.

**Почему иногда возникают дубли?**\
Если на момент импорта у товара не был указан штрихкод, SelSup не может найти существующую карточку и создает новую. В результате один и тот же товар может существовать в двух карточках для разных маркетплейсов.

Если у вас разные штрих-коды или артикулы - потребуется объединение, описали ниже шаги.

## Как объединить товары

** Шаг 1.** Перейдите в раздел [Товары -  Объединение](https://selsup.ru/application/productsImport/merge/)

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/01/screenshot_42.png.webp)

**Шаг 2.** Для корректного объединения товаров рекомендуется настроить отображение и фильтрацию:

**Включите тумблеры для удобства работы с объединением товаров**:

- **Показывать окно с объединяемыми товарами**: При включении этой опции SelSup выведет предупреждающее окно перед объединением товаров, где можно подтвердить действие.
- **Показывать две таблицы**: Включите эту настройку, чтобы видеть товары в двух таблицах одновременно. Это упростит поиск нужных позиций и их объединение.

**Настройте фильтры для поиска товаров**: Для обеих таблиц доступны фильтры, позволяющие находить товары по:

- Названию, штрих-коду, артикулу или бренду.
- Привязке к маркетплейсам (например, товары, которые созданы на одной платформе, но отсутствуют на другой).
- Выбору нужной организации.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/01/screenshot_43.png.webp)

** Шаг 3.**   Найдите одинаковые товары и  нажмите на кнопку "объединить". Сначала нажмите на товар, с которого будут перенесены данные, затем — на товар, в который будут перенесены данные.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/01/screenshot_44-1.png.webp)

**Шаг 4.** Откроется окно с предупреждением об объединении товаров. Проверьте, что данные выбраны корректно. Если всё верно, нажмите **«Объединить товары»** для завершения процесса.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/01/screenshot_45.png.webp)

## Как массово объединить дубликаты товаров

Вы можете массово объединить дубликаты товаров, если у них совпадают поля: артикулы, названия или другие характеристики. Объединение производится по ключу - он должен совпадать у двух разных товаров в SelSup, чтобы произошло объединение.

Для объединения товаров перейдите на страницу [Массового объединения карточек.](https://selsup.ru/application/productsImport/massMerge)\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/01/screenshot_65.png.webp)

На странице массового объединения отображаются маркетплейсы, с которыми вы работаете, а также список полей для каждого маркетплейса, которые будут участвовать в создании ключа для объединения.

- **Игнорировать дубликаты с одинаковым ключом** - в этом случае, если в рамках одного маркетплейса получаются разные товары - весь ключ будет игнорироваться и объединение не будет происходить по нему.
- **Выбор полей для ключа объединения:** Добавьте поля, по которым будет производиться объединение, для каждого маркетплейса. Порядок этих полей важен, так как он определяет точность объединения. Обычно объединение производится по артикулу товара, который подходит для большинства ситуаций (около 99% случаев). Однако для более сложных категорий можно добавлять и другие параметры, чтобы уточнить ключ.
- Для точного объединения товаров, у которых, например, **в артикуле есть общая часть (например, одинаковые цифры, буквы),** добавьте текстовое поле и введите эту повторяющуюся часть. Система будет объединять только те товары, в артикулах которых содержится указанный вами текстовый ключ.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/01/screenshot_26.png.webp)

При массовом объединении важно учитывать различия в структуре артикулов для маркетплейсов. Например, Wildberries использует артикул для обозначения каждого цвета товара, тогда как на других маркетплейсах артикул может назначаться каждому размеру. В этом случае, если вы объединяете товары одежды, учитывайте, что объединение может корректно сработать только в ситуациях, где один артикул относится к одному цвету товара.

**ВАЖНО: даже если у товаров совпадает ключ для объединения, SelSup не объединит их, если возникает конфликт по уже заполненным идентификаторам.**

Например, объединение не произойдет, если у товаров проставлены:

- разный ID 1С;
- разные непустые идентификаторы одного и того же маркетплейса (Артикул продавца Ozon, Артикул продавца Wildberries, SKU Яндекс Маркета или аналогичные артикулы других маркетплейсов).

Это ограничение нужно, чтобы SelSup не выбирал автоматически, какой из конфликтующих идентификаторов сохранить в карточке.

Если один из идентификаторов не заполнен или значения совпадают, конфликта нет — такие товары объединятся.

Нажмите кнопку **Объединить карточки** для запуска массового объединения.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/11/snimok-ekrana-2023-09-11-v-20.11.47.png.webp)

**Пример: как объединить карточки Wildberries и Яндекс.Маркет по ключу.**

Если в карточке товара используется **артикул продавца Wildberries**, то соответствующий товар на Яндекс.Маркете может быть определён по **SKU Яндекс.Маркет + размер**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/01/image-8.png.webp)

Чтобы массово объединить такие карточки между двумя маркетплейсами, вам нужно:

**Для Wildberries** выбрать параметры в следующем порядке:

1.  Артикул Wildberries
2.  Размер

⚠️ Обратите внимание: порядок выбранных параметров важен, так как он определяет структуру ключа. В данном случае ключ будет сформирован как "Артикул + Размер".

**Для Яндекс.Маркет** выберите:

- SKU продавца Яндекс.Маркет

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/01/image-1.png.webp)

После сохранения ключей система начнёт сопоставление карточек между Wildberries и Яндекс.Маркет на основе заданных параметров.
