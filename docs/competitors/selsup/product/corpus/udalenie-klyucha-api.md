# Удаление ключа API

Cуществует несколько способов как удалить ключ API.\

## Как удалить ключ из кабинета маркетплейса

Зайдите в личный кабинет маркетплейса и удалите ключ API. В этом случае связь между SelSup и маркетплейсом будет потеряна: SelSup не сможет ни получать данные, ни отправлять.

Мы всегда советуем называть ключ API именем сервиса для которого вы используете ключ - так вы легко сможете удалить нужный Вам ключ.

## Как удалить ключ из Selsup

Чтобы удалить ключ из SelSup, нужно зайти в раздел [Интеграции](https://selsup.ru/application/integration/) определенного маркетплейса и нажать **Удалить интеграцию.**
