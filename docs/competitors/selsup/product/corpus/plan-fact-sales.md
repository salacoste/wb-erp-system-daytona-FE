## Зачем нужен данный отчет

Отчет [План/Факт продаж](https://selsup.ru/application/salesPlanFact/) помогает селлерам планировать свои продажи, занося информацию в этот отчет и следить за выполнением поставленного плана.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Фильтры и поиск

Чтобы планировать свои продажи и просматривать факт выполнения продаж выберите:

- период планирования продаж/период за который хотите проверить выполнение плана;
- организацию, по которой планируете продажи или смотрите факт выполненных продаж;
- маркетплейс, по которому будете составлять план, если маркетплейс не выбирать, то планирование будет рассчитываться на все маркетплейсы, аналогично, если смотрите факт выполнения плана.

## План продаж

Здесь Вы можете заполнить план продаж, для этого проставьте необходимые фильтры.![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/07/plan-prodaz-e1748252263303.png.webp)Сформируется шаблон файла для выбранного периода, чтобы скачать его, нажмите **«Скачать в Excel‎»** (отчет можно просматривать только в Excel).\
Заполните скачанный файл планируемыми продажами в рублях и/или по штукам, также план можно вписывать либо по неделям, либо по месяцам, либо комбинированно. Нельзя указывать данные за год, колонки за год нужны для удобства.\
В заполнении файла Вам поможет отчет [Динамика продаж](https://selsup.ru/application/salesDynamic/), так как в нем Вы можете посмотреть данные по всем продажам за более ранние периоды и исходя их этих данных заполнить план продаж за выбранный период.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/07/plan-prodaz-fail-1.png.webp)

Далее заполненный файл загрузите обратно в SelSup, нажав кнопку **«‎Импорт»**. План продаж добавится и на основе него начнет формироваться Факт продаж.

**Обратите внимание:** данные из отчёта **«План/факт продаж»** также используются в отчёте [**«Рука на пульсе по-товарно»**](../ruka-na-pulse-po-tovarno/index.html).

После загрузки файла и пересчёта отчёта план по прибыли отображается в показателе **«Прибыль план»**.

## Факт продаж

Чтобы отслеживать выполнение запланированных продаж, выберете необходимые фильтры и скачайте сформированный Excel - файл, нажав кнопку **«Скачать в Excel‎»**.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/07/fact-prodaz.png.webp)В файле отчета Факт продаж сопоставляются планируемые продажи с фактическими продажами (из товарной аналитики) и информация по динамике остатков.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/07/fact-prodaz-fail.png.webp)Вы увидите выполнение плана в штуках и рублях по неделям, за месяц и за год (в пределах выбранного периода). В файл выгружаются только те товары, у которых есть либо план, либо факт продаж.
