# Массовое распределение заказов FBS по поставкам

В этой статье расскажем Вам о возможности распределять заказы FBS в SelSup по поставкам массово.\

## Массовое распределение заказов FBS по поставкам WB

Для массового распределения заказов по поставкам перейдите в раздел [Заказы на отгрузку - Со своего склада (FBS)](https://selsup.ru/application/fbsOrders/).\
На открывшейся странице проставьте обязательные фильтры:\
- Склад, с которого будут списаны остатки;\
- Организацию;\
- Маркетплейс, с которого пришел заказ, и создается распределение по поставкам.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/screenshot_130-1.png.webp)\
Отфильтруйте заказы в статусе **Новый**, выберите заказы, которые хотите добавить в поставку нажав на галочку слева от столбца **Статус**.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/perenesti-v-postavku.png.webp)Перейдите к полю **Перенести в поставку**, нажмите на него и выберите **Создать новую.** Откроется окно добавления поставки, заполните поля в открывшемся окне:\
- Название;\
- Дата доставки.\
Нажмите **Сохранить**.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/dobavlenie-postavki.png.webp)Поставка создастся в SelSup, но заказы к ней еще не привязались.\
Для добавления заказов в поставку нажмите на поле **Перенести в поставку** повторно и из выпадающего списка выберите созданную поставку, затем нажмите **Перенести**.\
Выбранные заказы будут добавлены в созданную поставку.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/perenesti.png.webp)\
Если хотите, чтобы несколько разных заказов были в разных поставках, создайте таким образом остальные поставки и добавьте в них заказы.

Готово!

Подробнее о разделе поставки читайте [тут](../postavki/index.html).
