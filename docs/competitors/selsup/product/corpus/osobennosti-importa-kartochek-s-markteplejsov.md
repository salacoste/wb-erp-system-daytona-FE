# Особенности импорта карточек с маркетплейсов

## Как импортируются карточки разделенные по цветам и размерам на маркетплейсе

После импорта карточек в SelSup, у них автоматически формируется поля: Артикул для объединения в одну карточку и Артикул цвета (Цвет). Для разных маркетплейсов SelSup использует параметры карточек:

- OZON: в качестве Артикула для объединения в одну карточку, используется поле Объединять на одной карточке, Артикул цвета - мы автоматически пытаемся извлечь из параметров товаров, с названиями Цвет, Вкус и тп. В качестве размера по умолчанию используются параметры Размер, Российский размер - иногда если SelSup обнаруживает дубликаты товара в одном цвете - он начинает подставлять в поле Размер "Артикул товара" - чтобы чаще импортировать карточки в SelSup. 
- WILDBERRIES: в качестве Артикул для объединения в одну карточку используется номер IMT - он по умолчанию не показывается на сервисе Wildberries, но используется для объединения номенклатуры в одну карточку. В качестве Цвета мы подставляем Артикул Wildberries - тк Wildberries перестал выделять нормальные названия цветов у себя, а цвета Wildberries которые указываются в карточке могут дублироваться. 
- Яндекс.Маркет: в качестве Артикула для объединения в одну карточку используется vendorCode у карточки - который объединяет несколько разных товаров. В качестве Цвета используется параметр Цвет - если он заполнен.
