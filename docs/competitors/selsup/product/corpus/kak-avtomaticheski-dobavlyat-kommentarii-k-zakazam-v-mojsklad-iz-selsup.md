# Как автоматически добавлять комментарии к заказам в МойСклад из SelSup

При работе с большим объемом заказов из маркетплейсов в МойСклад важно быстро понимать содержимое каждого заказа, не открывая его. Стандартный список заказов в МойСклад не отображает состав, что может замедлять работу. Решение этой проблемы — **настройка автоматического формирования комментариев** прямо в интеграции SelSup.

## Что это такое?

Это не просто ручное поле для комментариев. В разделе Настройки - [Интеграции с МойСклад](https://selsup.ru/application/integration/moysklad) в SelSup есть специальное поле **«Шаблон для формирования комментария»**. Этот шаблон автоматически заполняется данными из заказа и передается в МойСклад, где комментарий виден прямо в списке заказов.

## Как это работает?

- **Настройка в SelSup:** В настройках интеграции с [МойСклад](https://selsup.ru/application/integration/moysklad) вы находите поле «Шаблон для формирования комментария».

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/09/screenshot_78.png.webp)

- **Создание шаблона:** В этом поле вы прописываете специальные теги, которые автоматически подставляют данные из заказа. Например:

**Шаблон:** Заказ {{externalOrderId}}: {{#each products}} {{name}} {{/each}}

**Результат:** Заказ WB-12345: Футболка черная

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/09/screenshot_77.png.webp)

- **Автоматическая передача:** При создании нового заказа в МойСклад SelSup автоматически сгенерирует комментарий по вашему шаблону и передаст его вместе с остальными данными.

## Преимущества метода

- **Экономия времени:** Состав заказа виден мгновенно из общего списка.

- **Уменьшение количества ошибок:** Меньше кликов — меньше шансов что-то перепутать.

- **Автоматизация:** Достаточно один раз настроить шаблон, и все заказы будут комментироваться автоматически.

- **Гибкость:** Вы можете настроить шаблон под свои нужды, включая только ту информацию, которая важна именно вам.

Использование шаблонов для комментариев — это мощный инструмент для автоматизации и повышения эффективности работы между SelSup и МойСклад. Он помогает вашим менеджерам и кладовщикам быстро ориентироваться в заказах, сокращая время на обработку и минимизируя ошибки.

Настройте один раз — и пользуйтесь преимуществами каждый день!
