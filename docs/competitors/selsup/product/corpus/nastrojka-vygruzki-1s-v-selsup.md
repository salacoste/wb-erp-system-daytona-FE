# Настройка выгрузки 1с в SelSup

Когда вы настроили выгрузку данных из 1С, необходимо произвести так же настройку приемка данных в SelSup

Для этого перейдите на страницу [интеграции с 1С](https://selsup.ru/application/integration/1c)

Перейдите на вкладку Обмены и проверьте - успешность выгрузки из 1С

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/06/snimok-ekrana-2023-06-21-v-10.44.07.png.webp)

Файлы import.xml - это выгрузка каталога с карточками товаров, offers.xml - выгрузка предложений, где передаются остатки и цены на товары.

Если вы видите не нулевое значение в результатах: "ошибок: 32", как на примере, то можете перейти на страницу, чтобы посмотреть с какими товарами и какие ошибки возникли при импорте:

<https://selsup.ru/application/productsImport/>

Далее приступаем к настройке интеграции:

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/06/snimok-ekrana-2023-06-21-v-10.47.49.png.webp)

**Артикул модели из** - необходимо выбрать, из какого поля в выгрузке 1С будет браться артикул модели для объединения товаров на одну карточку. Это может быть поле Артикул - если вы указываете его в 1С или одно из других полей. Артикул обязательное поле для создания карточки в SelSup из 1с

**Объединять модели из выгрузки** - настройка нужна в основном для тех, кто в 1С использует размеры и объединяет товары на одну карточку, в большинстве случае настройку не нужно включать - если у вас нормально выгружается каталог товаров. В некоторых случаях 1с выгружает Товары разделенными на каждый размер в выгрузке import.xml, отдавая в поле групповой идентификатор, вы можете увидеть его - он содержит \# в теге и состоит из 2 идентификаторов 2e5fad2a-1009-11ee-be56-0242ac120002#411893be-1009-11ee-be56-0242ac120002. В этом случае в SelSup товары тоже будут разделены на разные модели. Если вы хотите исправить данное поведение и объединить модели в SelSup на одной карточке - включите этот переключатель и SelSup будет оставлять в качестве значение до \# и таким образом объединять разные размеры на одну карточку.

**Выгружать состав комплекта** - заменяет все комплекты в выгрузке для 1С на составные части этого комплекта, чтобы в 1С не выгружались комплекты

**Игнорировать выгрузку каталога товаров** - настройка позволяет вам в SelSup отключить создание новых товаров и импорт выгрузки каталога import.xml. В этом случае не будут создаваться новые товары, а только будет проставляться связь у существующих

**ID склада** - настройка заполняется только в том случае, если ваша 1С выгружает отдельные файлы с остатками и ценами. В обмене вы увидите выгрузку дополнительных файлов, помимо import и offers, они будут содержать prices или rests - в этом случае 1С отдельно выгружает остатки и цены. Тк SelSup не может сохранять настройки между разными файлами выгрузки, вам необходимо открыть файл rests и посмотреть идентификатор нужно склада

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/06/snimok-ekrana-2023-06-21-v-11.02.50.png.webp)\
На скриншоте ID склада нужно указать 6973318b-0101-11df-a868-00221534e4d3

На некоторых версиях 1С выгрузка выглядит по другому: ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/06/snimok-ekrana-2023-08-18-v-21.34.06.png.webp)

В этом случае ID нужно брать из атрибута ИдСклада

Вы можете указать связи с несколькими складами SelSup через связи со складами на странице склада.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/06/snimok-ekrana-2024-09-05-v-19.08.58.png.webp)

**Склад для остатков** - выберите склад на котором будут обновляться остатки в SelSup, при выгрузке из 1С, если вы хотите чтобы 1С изменяла остатки на этом складе SelSup

**Артикул товара из** - помимо артикула модели можно проставлять артикул товара из 1С, например чтобы он использовался для Ozon, Яндекс.Маркет, Aliexpress или СберМегаМаркет. Нужно выбрать из какого тега будет браться артикул товара. Он же будет проставляться в Артикул 1С

**Обновлять остатки товаров** - настройку необходимо включить, если вы хотите чтобы изменялись остатки товаров на складе SelSup при выгрузке из 1С

**Проставлять остаток 0, если не указан остаток** - настройку нужно в большинстве случаев включать, если ваша 1С НЕ отдает нулевой остаток в выгрузке и остатки НЕ передаются в отдельном файле drafts. Включите настройку, если: 1)остатки передаются в файле offers.xml и нет дополнительных файлов drafs на вкладке обмены. 2)Нулевой остаток не передается в файле, те отсутствует тег 0

**Выгружать номер поставки** - добавляет в выгрузку для 1С тег , содержащий номер поставки маркетплейса и если номера нет, выгружается ID поставки SelSup

**Выгружать дату доставки** - выгружать в ответе в списке реквизитов дату к которой необходимо  Дата отгрузки

**Выгружать заказы FBO** - включает в список заказов для 1С заказы со склада маркетплейса для учета.

**Выгружать заказы всех организаций** - тк интеграция с 1С настраивается для конкретной организации SelSup, заказы тоже будут выгружаться только для этой организации. Если нужно выгружать заказы всех организаций в одну 1С, то можно включить этот переключатель

**Принимать розничные заказы от 1С** - позволяет импортировать в SelSup розничные заказы, которые формируются в самой 1С для резерва и списания остатков

**Выгружать статус заказа** - выгружаете в ответе в списке реквизитов статус заказа Статус заказа

**Выгружать заказы с поставкой** - включает выгрузку заказов из SelSup, в которых проставлена поставка и поставка уже закрыта, чтобы выгружать в 1С заказы при закрытии поставки

**Отправлять цены на маркетплейсах** - настройку необходимо включить, если вы хотите передавать сразу цены из 1С на маркетплейсы. Необходимо так же указать названия типов цен или идентификаторы

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/06/snimok-ekrana-2023-06-21-v-11.19.31.png.webp)

Укажите названия типов цен - которые соответствуют указанным ценам в SelSup. Обычно достаточно указать только название, но если ваша 1С выгружает отдельно файл prices - вы это увидите на вкладке Обмены, то вместо Названий типов цен из 1С необходимо в поле указать ID типа цен. Посмотреть его можно в выгрузке prices

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/06/snimok-ekrana-2023-06-21-v-11.22.14.png.webp)

В данном случае необходимо указать ID b3ea4be8-3fb9-11ea-9918-08606ed8708d
