# Импорт товаров из WooCommerce

В этой статье расскажем, как импортировать карточки товаров из WooCommerce в SelSup.

Товары из WooCommerce импортируются, если у них заполнено значение артикула.

Для импорта товаров из WooCommerce после настройки <a href="../integratsiya-s-woocommerce/index.html" rel="noreferrer noopener" target="_blank">интеграции,</a> выполните следующие шаги:

1.  Перейдите в раздел <a href="https://selsup.ru/application/productsImport/" rel="noreferrer noopener" target="_blank"><strong>Товары — Импорт товаров</strong></a> и выберите вкладку **WooCommerce**.

2.  Выберите организацию, для которой нужно выполнить импорт, и нажмите **Импортировать товары сервиса WooCommerce**.

3.  Если нужно импортировать товары для всех организаций — нажмите **Для всех организаций**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_12.png.webp)

После запуска процесса:

- Результаты импорта отобразятся ниже на странице.

- В случае ошибок они появятся в таблице **Ошибки импорта** — там можно посмотреть причины и внести необходимые исправления, подробней в <a href="../vozmozhnye-oshibki-pri-importe-kartochek-iz-marketplejsov/index.html" rel="noreferrer noopener" target="_blank">статье</a>.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_14-1.png.webp)

Импортированные товары появятся в разделе <a href="https://selsup.ru/application/products" rel="noreferrer noopener" target="_blank"><strong>Товары</strong> </a>в общей таблице. Убедитесь, что:

- Новые позиции объединились с существующими карточками аналогичных товаров с других маркетплейсов.

Если карточки не были объединены или объединение выполнено некорректно — выполните корректировку вручную. Подробнее об объединении карточек читайте <a href="../merge/index.html" rel="noreferrer noopener" target="_blank">в статье </a>.
