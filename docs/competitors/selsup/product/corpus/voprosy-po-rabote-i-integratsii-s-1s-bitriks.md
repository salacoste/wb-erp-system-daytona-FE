# Вопросы по работе и интеграции с 1С

Данная инструкция устарела, сейчас используется для интеграции новый модуль.

## Как настроить обмен с сайтом в 1С?

 

- Адрес, логин и пароль из SelSup нужно вставить в 1С в настройки Обмена с сайтом.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/04/2023-04-27_16-37-09-300x133.png.webp)

 

- Выбрать, какими данными планируете обмениваться: заказами, товарами. Каталог товаров выгружается с ценами, заказы — с остатками.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/04/2023-04-27_16-53-45-300x171.png.webp)

- В 1С выбрать, какие данные выгружать. SelSup поддерживает только Характеристики. Файлы и Картинки не поддерживаются — их выбирать не нужно.

<!-- -->

- Выбрать выгрузку только изменённых объектов.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/04/2023-04-27_16-51-10-300x147.png.webp)

- Выбрать периодичность обмена данными.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/04/2023-04-27_16-52-02-300x169.png.webp)

Полную выгрузку товаров можно сделать один раз, а дальше обмениваться изменениями.
