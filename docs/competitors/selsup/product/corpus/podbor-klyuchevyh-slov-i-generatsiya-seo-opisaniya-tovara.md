# Генерация SEO описания

Чтобы товар был виден покупателям на маркетплейсах, важно не просто создать карточку — нужно грамотно оформить SEO-описание. В Selsup этот процесс автоматизирован и прост даже для новичка.

Теперь вы можете создавать SEO-описания товаров в один клик — на основе заранее подобранных ключевых слов. Это сокращает время на оформление карточек и повышает их эффективность в поисковой выдаче маркетплейсов.

Этот функционал реализован в рамках модуля PIM система, который можно подключить в любом [тарифе](https://selsup.ru/application/tariffs/tariffs_constructor). Подробнее о возможностях модуля PIM читайте <a href="../../help_cat/rabota-s-kartochkami-tovarov/index.html" data-end="1117" data-start="1103" rel="noopener">по ссылке</a>.

## Как работает генерация описаний?

Генерация SEO-описания в Selsup построена на **AI-алгоритме**, который анализирует данные и автоматически формирует эффективные тексты под требования маркетплейсов:

- Система анализирует частотность ключевых слов и составляет описание с их учётом;

- Учитываются правила поисковых систем маркетплейсов — длина, релевантность, естественность формулировок;

- Исключены повторы, "переспам" и нерелевантные фразы;

- На выходе — лаконичный, читаемый и оптимизированный текст, подходящий под конкретную товарную категорию.

## Как подобрать ключевые слова

Откройте карточку товара и выберите вкладку **Ключевые слова.**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_268.png.webp)

Если ранее вы уже создавали группы ключевых слов, выберите одну из них в поле **Выбрать группу ключевых слов для добавления ее к модели.**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_269.png.webp)

Также можно объединить несколько групп ключевых слов

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_53.png.webp)

Группа ключевых слов добавится к модели. На основе этих слов вы сможете создать SEO описание товара.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_282.png.webp)

Создать новую группу ключевых слов можно, если ввести в поисковой строке целевое слово и нажать **Найти**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_270.png.webp)

SelSup подберет ключевые слова и покажет частоту поисковых запросов по ним.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_271.png.webp)

С помощью правой части таблицы можно убрать ключевые слова, которые вы не хотите использовать.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_272.png.webp)

Это можно сделать двумя способами:

- Снять галочку в строке Ключевые слова, а потом поставить галочки напротив нужных слов.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_273.png.webp)

- Снимать галочки по одной напротив ненужных слов.

В левой части таблицы появятся ключевые фразы со словами, которые вы выбрали.

Когда выберете все слова, нажмите кнопку **Добавить**, чтобы создать группу ключевых слов.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_274.png.webp)

Появится окно со словами. Пропишите название для новой группы и нажмите **Сохранить**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/sozdat-gruppu-klyuchevyh-slov.png.webp)

После сохранения вы увидите созданную группу ключевых слов внизу страницы. Слова добавились к модели.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_282-1.png.webp)

После этого можно формировать SEO описание товара.

## Как сформировать SEO описание товара

Откройте раздел **Карточка** на этой же странице. Спуститесь вниз по странице.

Нажмите кнопку **Сгенерировать описание.**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_275.png.webp)

Откроется окно для генерации описания товара. Описание товара генерируется на основании слов, которые вы выбрали для данной модели.

Нажмите кнопку **Сгенерировать**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_283.png.webp)

В поле Описание товара появится сгенерированное SEO описание.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_281.png.webp)

К одной модели можно добавить несколько групп ключевых слов.

## Как редактировать группу ключевых слов

Изменить группу ключевых слов можно двумя способами.

**Способ 1.** Выберите группу ключевых слов с помощью поисковой строки. Нажмите кнопку **Редактировать**.

В открывшемся окне добавьте или удалите ключевые слова из списка. Нажмите кнопку **Сохранить**. Группа обновится.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_277.png.webp)

**Способ 2.** Выберите группу ключевых слов модели внизу страницы.

Внесите изменения в окне редактирования и нажмите **Сохранить**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_279.png.webp)

Чтобы удалить ненужную группу из карточки товара, просто нажмите на крестик рядом с названием группы.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/01/screenshot_280.png.webp)
