# Вопросы и ответы при работе с финансовой аналитикой

В этой статье разберем самые частые вопросы и ошибки при работе с финансовой аналитикой через SelSup.

## Частые вопросы

**1. Нет данных за период сроком давности более 3-х месяцев.**

**Причины:** Аналитика по API загружается только за 3 месяца  (так отдают данные маркетплейсы).

**Решения:**\
**1. Подключить платные подписки**\
Ozon ограничивает глубину данных в зависимости от тарифа. В бесплатном тарифе — только 3 месяца. В Премиум — 6 месяцев. А полный доступ ко всей истории — только в Премиум Плюс.

По WB даже базовый "Джем" дает доступ ко всей истории аналитики.

**2. Загрузить отчеты вручную**\
Если Вы хотите увидеть данные за больший период. Нужно загрузить данные файлом, загрузив в SelSup финансовые отчеты из маркетплейсов за нужный Вам период.\
Подробнее про загрузку отчетов рассказали [тут](../zagruzka-otchetov-vruchnuyu/index.html).

**2. Нет аналитических данных.**

**Причины:** Аналитика загружается не сразу, так как объем данных может быть большой.

**Решение:** Перезапустите загрузку аналитических отчетов в разделе Аналитика или Финансы, нажав кнопку "Перезагрузить аналитику".\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/07/perezagruzit.png.webp)\
**3. Можно ли через SelSup смотреть аналитику по ценам у конкурентов / внешнюю аналитику?**

**Ответ:** Внешнюю аналитику Ваших конкурентов через SelSup просмотреть невозможно. Вы можете использовать для этого другие сервисы аналитики.\
В SelSup Вы можете посмотреть 13 отчетов внутренней аналитики по вашим продажам, поставкам и полную финансовую аналитику. Подробнее об отчетах [тут](../../help_cat/otchety-selsup/index.html).
