# Как формируется значение «Проданный товар в закупочных ценах»

Чтобы понять, как формируется значение "Проданный товар в закупочных ценах"(столбец на скриншоте ниже) в отчете по юнит-экономике <a href="https://selsup.ru/application/productAnalytics/" class="MagicLink" data-magic-id="1754371027934" rel="noopener noreferrer" target="_blank">  https://selsup.ru/application/productAnalytics/</a> ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/image-9.png.webp)

Выполните следующие шаги:

- Перейдите в **Отчёт по операциям с маркетплейса** по этой ссылке: <a href="https://selsup.ru/application/profitReport/" class="MagicLink" data-magic-id="1754371027934" rel="noopener noreferrer" target="_blank">  https://selsup.ru/application/profitReport/</a>.

- Укажите тот же период, который использован в **Отчёте по юнит-экономике**.

- Нажмите кнопку "Экспорт" и скачайте файл (файл на скриншоте ниже).

В скачанном файле:

1.  Включите фильтр и найдите нужный товар по его ШК.

2.  В столбце "Закупочная цена на момент операции" посмотрите, какая была закупочная цена. Значение в столбце "Проданный товар в закупочных ценах" в отчёте по юнит-экономике формируется именно из этой закупочной цены за выбранный период.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/08/image-10.png.webp)

В столбце "Закупочная цена на момент операции" вы можете внести необходимые изменения в закупочную цену. После того как вы скорректировали данные, сохраните файл и загрузите его обратно через кнопку "Импорт" во вкладке **Отчет по операциям с маркетплейсами**. Это обновит информацию в системе на основании внесенных изменений.
