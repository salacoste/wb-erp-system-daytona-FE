## Импорт товаров из МегаМаркет

Автоматически импортировать карточки с маркетплейса МегаМаркет нельзя, так как у них нет API по товарам. Но можно это сделать вручную. Для работы «из одного окна» обязательно нужно передать в Selsup данные о ваших карточках из МегаМаркет. Для этого:

1.  Скачайте файл Excel из кабинета МегаМаркет на странице [Ассортимент -\> Готовые связки](https://partner.sbermegamarket.ru/main/catalog/matched)
2.  Загрузите скачанный файл  Excel на странице [Импорт товаров - вкладка МегаМаркет](https://selsup.ru/application/productsImport/sberMegaMarket).

Так у товаров будет указана ссылка на карточку МегаМаркет и артикул МегаМаркет, который будет использоваться для получения заказов с МегаМаркет.

Если артикул или штрих-код товаров в МегаМаркет совпадает с артикулом или штрих-кодом в Selsup, у товаров из файла «Готовые связки» автоматически проставятся ссылки на карточки в МегаМаркете в карточках этих товаров в Selsup. Если Selsup не увидит одинаковых артикулов или штрих-кодов, он создаст новые карточки на основе данных из файла "Готовые связки".

Если необходимо объединить карточки при различных артикулах и штрих-кодах, выполните следующие действия:

1.  Скачайте файл Excel из раздела [Товары по кнопке Экспорт;](https://selsup.ru/application/products)
2.  Скачайте файл Excel из кабинета МегаМаркет на странице [Ассортимент -\> Готовые связки;](https://partner.sbermegamarket.ru/main/catalog/matched)
3.  Скопируйте offer id из файла «Готовые связки» и вставьте его в файл Excel с товарами из Selsup в столбец «Артикул МегаМаркет». Удалите строки с товарами, которые не нужно объединять с МегаМаркет. В файле должны остаться товары, которые нужно объединить с товарами из МегаМаркет;
4.  Импортируйте этот файл, нажав кнопку «Импорт» в разделе [Товары;](https://selsup.ru/application/products)
5.  Импортируйте файл "Готовые связки" в разделе [Импорт товаров — вкладка МегаМаркет](https://selsup.ru/application/productsImport/sberMegaMarket).
