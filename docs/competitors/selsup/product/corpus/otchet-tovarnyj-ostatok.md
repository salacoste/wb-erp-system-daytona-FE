## Зачем нужен данный отчет

[Остаток по складам](https://selsup.ru/application/stockReport/) — один из трех отчетов, входящий в отчет [Товарный остаток](https://selsup.ru/application/productCurrent/).\
В этом отчете Вы можете просматривать  данные по остаткам на складах FBO по WB и Ozon в сумме и в разрезе по каждому складу FBO.

Чтобы перейти в этот отчет откройте раздел [Аналитика и финансы-Отчёты](https://selsup.ru/application/reports/) и выберите отчет [Товарный остаток](https://selsup.ru/application/productCurrent/), вкладка Остаток по складам\

## Интерфейс отчета

- Отчет можно смотреть только в Excel.
- Данные можно просмотреть только по двум маркетплейсам: по WB и Ozon, так на данный момент только они отдают информацию по остатку FBO по API.
- Выгружаются самые свежие данные. Если сегодня уже обновлялись данные, то выгрузятся сегодняшние, если нет — то прошлые.

## Отчет в Excel

Чтобы скачать отчет, на странице Остаток по складам нажмите "Скачать в Excel".

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/09/screenshot_22-1.png.webp)\
В скачанном файле Вы увидите:\
- Информацию по товарам, которые попали в отчет;\
- Сколько товаров находится в пути;\
- Итоговый остаток по всем складам маркетплейса;\
- Сколько остатков на том или ином складе.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/09/ost-wb.png.webp)

## Сравнение остатков FBO с отчетами маркетплейсов

Если вы хотите корректно сравнить остатки **FBO** в Selsup и на маркетплейсах, важно использовать **правильные отчёты** со стороны МП.

Для сравнения используйте:

**Ozon**\
Раздел **Аналитика → Отчёты → Управление остатками**\
Отчёт «Остатки и движение товаров на складах Ozon» <https://seller.ozon.ru/app/analytics/fulfillment-reports/stocks-and-movement-products-to-ozon-warehouses>

**Wildberries**\
Раздел **Аналитика → Отчёты → Отчёт по остаткам на складе** <https://seller.wildberries.ru/analytics-reports/warehouse-remains>

Использование именно этих отчётов позволяет получить актуальные данные и корректно сопоставить остатки FBO между Selsup и маркетплейсом.
