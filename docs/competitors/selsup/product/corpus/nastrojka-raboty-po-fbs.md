# Настройка работы по FBS

В этой статье расскажем Вам, как настроить SelSup для работы по FBS.\
Настройка работы по FBS аналогична [настройке по FBO](../nastrojka-raboty-po-fbo/index.html), различия только в настройке склада.\
Для начала работы по FBS настройте работу по *базовым настройкам*, затем переходите к *настройке склада и переносу остатков*.\
После настройки склада приступайте к остальным настройкам: *работа с карточками, формирование аналитики и маркировка товаров*.\

## Базовые настройки

1\. Зарегистрируйтесь и [добавьте организацию](../organizatsii/index.html).

2. [Проведите интеграцию с нужными маркетплейсами и сервисами.](../integratsiya/index.html)

3.[Импортируйте товары.](../../help_cat/import-tovarov-v-selsup/index.html)

4. [Объедините данные с разных маркетплейсов: товары, категории, бренды.](../../help_cat/obedinenie-tovarov/index.html)

5. [Добавьте производителей](../dobavlenie-proizvoditelej/index.html).

6.[Настройте печать этикеток.](../../help_cat/etiketki/index.html)

7. [Введите закупочные цены.](../vvod-zakupochnyh-tsen/index.html)
