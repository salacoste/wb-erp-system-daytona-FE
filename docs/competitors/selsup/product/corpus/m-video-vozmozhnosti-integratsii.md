# М.Видео. Возможности интеграции

В этой статье расскажем, какие возможности дает интеграция SelSup с М.Видео.

Интеграция позволяет связать товары SelSup с товарами М.Видео, передавать остатки, импортировать FBS-заказы и работать со статусами заказов.

## Подключение интеграции

Интеграция с М.Видео доступна в SelSup.

Если вы хотите подключить интеграцию, напишите в **службу поддержки SelSup**. Специалисты помогут с подключением и подскажут дальнейшие шаги.

## Импорт товаров

Импорт товаров из М.Видео в SelSup не поддерживается.

Чтобы работать с товарами через интеграцию, товары нужно связать вручную. После связи SelSup сможет передавать остатки и загружать FBS-заказы по связанным товарам.

Связь выполняется через Excel-файл с товарами.

Чтобы связать товары:

1.Перейдите в раздел [**Товары**](https://selsup.ru/application/products/?ascending=false&deleted=false&grouped=true&limit=50&page=1&sortBy=TOTALORDERS).

2.Скачайте Excel-файл с товарами.

3.Найдите в файле столбец **Артикль М.Видео**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/06/screenshot_235.png.webp)

4.Укажите в этом столбце артикул М.Видео для соответствующего товара. Если у товаров есть одинаковый признак, к примеру Название одинаковое, тогда можно упростить процесс сопоставления с помощью [ВПР](../kak-perenesti-dannye-iz-odnoj-organizatsii-v-druguyu-cherez-vpr/index.html).

5.Загрузите обновленный файл обратно в SelSup в разделе **Товары - Импорт товаров - [Массовое редактирование. ](https://selsup.ru/application/productsImport/)**

После загрузки файла товары SelSup будут связаны с товарами М.Видео по артикулу М.Видео.

Связь товаров нужна для передачи остатков и импорта заказов.

## Работа по FBS

С интеграцией М.Видео в SelSup можно работать по схеме FBS.

При работе по FBS товары хранятся на вашем складе. После поступления заказа вы собираете товар и передаете его для дальнейшей доставки покупателю.

В SelSup можно импортировать FBS-заказы из М.Видео и работать с ними в разделе заказов.

Данный функционал реализован в модуле **Умный склад**. Он обеспечивает синхронизацию, сборку и маршрутизацию товаров, интеграцию со службами доставки, видеофиксацию для защиты от потребительского терроризма и адресное хранение остатков. Подробнее о возможностях модуля читайте [здесь](../../help_cat/modul-umnyj-sklad/index.html).

## Передача остатков

После связи товаров SelSup может передавать остатки по товарам в М.Видео.

Это помогает поддерживать актуальное количество товаров на маркетплейсе и работать с остатками в одном окне вместе с другими интеграциями.

Для передачи остатков товары должны быть связаны с товарами М.Видео по артикулу М.Видео.
