# Регулярный обмен остатками через JSON API (API Core)

Регулярный обмен через **JSON API (API Core)** позволяет автоматически загружать остатки поставщика в SelSup.

SelSup получает данные через API Core, обрабатывает их и обновляет остатки по товарам на выбранном складе.

Такой способ подходит, если поставщик передаёт данные не файлом, а через API.

Перед настройкой обмена через JSON API рекомендуем проверить общие параметры регулярного обмена: организацию, склад, правила обновления и передачу остатков на маркетплейсы. ## Как создать обмен через JSON API

Перейдите в раздел **Закупки → Дропшиппинг → [Регулярные обмены](../regulyarnyj-obmen-tsenami-i-ostatkami-obshhie-nastrojki/index.html)** и нажмите **Добавить обмен**.

В поле **Тип** выберите **JSON API**.

После этого заполните параметры обмена и укажите данные для подключения.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Какие данные нужно указать

Для настройки обмена заполните:

- **Организацию** — организацию, для которой настраивается обмен;
- **Название обмена** — понятное название, по которому обмен будет проще найти в списке;
- **JSON-конфигурацию API** — настройки, по которым SelSup будет получать данные через API Core;
- **Склад** — склад, на котором должны обновляться остатки.

Также включите необходимые переключатели:

- **Обновление остатков** — чтобы SelSup загружал остатки из API Core;
- **Отправка остатков на маркетплейсы** — если после обновления остатков их нужно передавать на подключённые площадки.

## Как работает обмен

После сохранения SelSup получает остатки через API Core и сопоставляет их с товарами в системе.

Для сопоставления используются данные товара, например артикул или штрих-код. Если товар не найден в SelSup, остаток по нему не обновится.

Обновлённые остатки записываются на склад, выбранный в настройках обмена.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## После настройки

После заполнения всех параметров нажмите **Сохранить**.

Дождитесь выполнения обмена. После завершения обработки в списке регулярных обменов отобразится статус **«Успешная выгрузка»**.

## Как проверить результат

Чтобы проверить, обновились ли остатки:

1.  Перейдите в раздел **Склад → [Остатки на складе](https://selsup.ru/application/stocks/stocks?ascending=false&deleted=false&limit=200&modelId&query=&sortBy=CREATEDDATE&uniqSku=true&warehouseId=10129)**[.](https://selsup.ru/application/stocks/stocks?ascending=false&deleted=false&limit=200&modelId&query=&sortBy=CREATEDDATE&uniqSku=true&warehouseId=10129)
2.  Выберите склад, который был указан в настройках обмена.
3.  Найдите нужный товар.
4.  Проверьте, изменился ли остаток.

Если включена отправка остатков на маркетплейсы, после обновления в SelSup остатки будут передаваться на подключённые площадки.

## Если обмен не сработал

Если остатки не обновились, проверьте:

- указана ли корректная JSON-конфигурация API;
- доступен ли источник данных API Core;
- выбран ли склад для обновления остатков;
- включён ли переключатель **«Обновление остатков»**;
- есть ли товары в SelSup;
- совпадают ли артикулы или штрих-коды из API Core с товарами в SelSup;
- включена ли отправка остатков на маркетплейсы, если остатки должны передаваться дальше.

Если после обработки обмена остатки не изменились, сначала проверьте сопоставление товаров: артикулы и штрих-коды из API Core должны совпадать с данными товаров в SelSup.
