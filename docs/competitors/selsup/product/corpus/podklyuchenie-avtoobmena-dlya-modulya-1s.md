# Подключение автообмена для Модуля 1С

В данной статье расскажем вам как подключить автообмен для модуля 1С.

Важно! Приступать к подключению автообновления необходимо только после того как вы убедитесь, что все обмены из предыдущих статей работают.

Для подключения дополнительной обработки для автообмена необходимо выполнить следующие шаги:

1.  Скачайте на компьютер файл обработки:\
    Для 1C:УТ и 1C:КА:\
    ОбменSelSup_УТ.epfДля 1C:УНФ:\
    ОбменSelSup_УНФ.epfДля 1C:БП:\
    ИнтеграцияСSelSup_БП_cfe/ОбменSelSup_БП.epf

    ВНИМАНИЕ!!  Чтобы подключить наш модуль для 1С:Fresh нужно пройти контроль модуля в 1С:фреш след образом:

    [https://1cfresh.com/articles/so_addprocess_audit ](https://1cfresh.com/articles/so_addprocess_audit)и начать настройку автообмена с 10го пункта текущего раздела.

    Сами файлы для прохождения аудита доступны по ссылкам выше.

2.   Зайдите в 1С в раздел "Администрирование" - "Печатные формы, отчеты и обработки";\
    ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/12/admin.png.webp)\
    

3.   Перейдите в раздел "Дополнительные отчеты и обработки". Если пункт отсутствует или не активен поставьте галочку напротив надписи "Дополнительные отчеты и обработки", после чего заходите в раздел.\
    ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/12/razdel.png.webp)\
    

4.   Кликните по пункту "Создать".\
    ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/12/sozdat.png.webp)\
    5. Подтвердите готовность добавить новую дополнительную обработку, нажав кнопку "Продолжить".\
    ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/12/podtverdite.png.webp)\
    6. Выберите ранее скачанный файл дополнительной обработки "ОбменSelSup_УТ.epf". Нажмите "Открыть".\
    ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/12/otkrit.png.webp)\
    7. Нажмите кнопку "Размещение". Установите галочки напротив разделов в которых нужно отобразить ссылку на быстрый запуск дополнительной обработки, обычно это раздел "Интеграции". Нажмите "ОК".\
    ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/12/ok.png.webp)\
    8. Нажмите кнопку "...". Перенесите сотрудников, которым будет доступна данная обработка из левого окна в правое с помощью кнопки "\>" или сразу всех с помощью кнопки "\>\>". Нажмите "ОК".\
    ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/12/ok-2.png.webp)\
    9. Нажмите кнопку "Записать и закрыть". Обработка добавлена.\
    10. Для проверки обработки перейдите в раздел, который выбрали в размещении. По данной инструкции это раздел "Интеграции". В разделе "Сервис" выберите пункт "Дополнительные обработки".\
    ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/12/dop.png.webp)\
    Саму  обработку через указанный раздел запускать не надо, она будет использоваться только автоматического обмена.\
    11. Настройте нужное расписание.\
    ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/12/raspisanie.png.webp)12. После завершения настроек автообмена необходимо убедиться, что регламентные задания запущены. Просмотр и настройка существующих, а также создание новых регламентных заданий, доступны из панели действий подсистемы «Администрирование».\
    ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/03/photo_2024-09-25_15-27-57.jpg.webp)\
    Внимание! Для запуска регламентных заданий в облачной 1С нужно докупать опцию запуска 1с в клиент-серверном режиме.

Готово!
