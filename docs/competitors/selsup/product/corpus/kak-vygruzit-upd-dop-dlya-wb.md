## Что такое УПД ДОП

УПД ДОП — это документ первичной отчётности, на основании которого Wildberries принимает маркированные товары от продавцов. Если его не сделать, выпишут штраф в размере 1 рубля за каждый товар.

Подробности читайте [здесь](https://selsup.ru/blog/obyazatelnaya-markirovka-tovarov-na-vajldberriz-shtrafy-za-otsutstvie-upd-pri-otgruzke/).

## Обязательный шаг для новых пользователей SelSup

Если вы только подключились к SelSup, сначала необходимо включить интеграцию по API с Wildberries и импортировать товары в SelSup.

Как это сделать, читайте [здесь](../integration-s-wildberries/index.html).

Если вы хотите автоматизировать продажу маркированных товаров, то сразу включайте интеграцию с системой Честный знак. Об этом есть [видео](https://youtu.be/N4kvJuwUVZw), а также подробная [статья](../kak-rabotat-s-obyazatelnoj-markirovkoj-v-selsup/index.html).

**Интеграция с Честным знаком позволяет:**

- пользоваться одним личным кабинетом для всех задач,
- создавать карточки товаров в Честном знаке,
- получать коды маркировки,
- печатать этикетки в удобном формате,
- автоматически выводить товары из оборота.

## Как сформировать УПД ДОП для Wildberries через SelSup

Чтобы сделать УПД ДОП для Wildberries, перейдите в личный кабинет Wildberries, раздел [«Поставки»](https://seller.wildberries.ru/supplies-management/all-supplies).\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/02/postavki-wb.png.webp)

 

Найдите нужную поставку и откройте ее, затем нажмите **Скачать документы - Акт приемки**. Скачайте акт с товарами, подлежащими маркировке.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/02/akt-priemki.png.webp)

 

Загрузится zip-файл.

Затем нужно вернуться в SelSup в раздел [Заказы на отгрузку — На склад маркетплейса](https://selsup.ru/application/orders/). Нажмите кнопку **Создать из файла** и выберете файл с актом приемки из WB. Начнётся загрузка и покажется сообщение - либо об успешной загрузке, либо об ошибке.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/02/snimok-ekrana-2023-03-15-v-19.23.46-1024x442.png.webp)

После завершения загрузки SelSup создаст заказ на маркетплейсе.

------------------------------------------------------------------------

После создания заказа откройте заказ, нажмите кнопку **«УПД»** и выберите нужное действие:

1.  **Автоматическая отправка в ЭДО:**\
    В заказе нажмите кнопку **«УПД»**, затем выберите **«Отправить УПД с маркировкой»**. Документ будет отправлен в ЭДО вашему оператору для дальнейшей передачи в маркетплейс.

**Важно:** отправка УПД с маркировкой через **Контур.Диадок** из SelSup недоступна из-за ограничений со стороны Контур.Диадок.

Если при нажатии **«УПД» → «Отправить УПД с маркировкой»** появляется ошибка, скачайте файл УПД и загрузите его в ЭДО вручную.

2.  **Скачивание файла:**\
    Если нужно скачать документ, перейдите в заказ, нажмите **«УПД»** и выберите **«УПД с маркировкой»**. В этом файле будут только товары с кодами маркировки, а не все товары из заказа.Загруженный файл можно вручную [загрузить в ЭДО вашего оператора](../zagruzka-upd-dop-v-edo-kabinete-operatora/index.html) для отправки в маркетплейс.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/02/screenshot_79.png.webp)

## Если код маркировки уже привязан к другому заказу

Если после загрузки акта приемки возникают проблемы с формированием УПД ДОП, проверьте, к какому заказу  уже привязан код маркировки.

Если код маркировки уже был привязан к другому заказу, УПД ДОП будет сформирован без маркировки. Чтобы это исправить, выполните следующие действия.

Для этого перейдите в раздел **Маркировка → [Коды маркировки](https://selsup.ru/application/codes/?ascending=false&limit=100&organizationId=1&sortBy=ID)**[.](https://selsup.ru/application/codes/?ascending=false&limit=100&organizationId=1&sortBy=ID)\
В поле поиска введите код маркировки и посмотрите значение в столбце **«Поставка»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/02/excel_bkbaxdfhnw.png.webp)

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/02/mspaint_rkh5tq17n4.png.webp)

Если код маркировки уже привязан к более старому заказу, SelSup не переносит его в новый документ автоматически. Это помогает избежать дублирования кода маркировки и ошибок, связанных с повторной отгрузкой одного и того же кода.

Если нужно, чтобы при загрузке нового акта код маркировки был перенесён из старого заказа в новый документ, включите тумблер **«Перезаписать данные из файла»** в разделе **Заказы на отгрузку → [На склад маркетплейса](https://selsup.ru/application/orders/?actual=true&ascending=false&limit=100&page=1&sortBy=CREATEDDATE&type=FBM)** перед импортом акта.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/02/mspaint_fahc1nznkq.png.webp)

После этого при импорте акта SelSup обновит привязку кода маркировки — код будет перенесён из старого заказа в новый документ.

Если после этого проблема сохраняется, обратитесь в техническую поддержку SelSup.

## Ошибка при формировании УПД ДОП в SelSup: неправильно обрезается код маркировки

При создании УПД ДОП в SelSup может возникнуть ошибка: коды маркировки обрезаются неверно, из-за чего поставка с маркированной продукцией не принимается.

**Причина:** если коды маркировки были добавлены в SelSup путем сканирования, система не знает их товарную группу. Без этой информации корректная обработка кодов и формирование УПД ДОП невозможно.

**Решение:** чтобы устранить ошибку, нужно обновить данные по кодам и запросить информацию из системы **«Честный ЗНАК»**.

 **Инструкция по обновлению кодов маркировки**

1.  Перейдите в раздел [«Коды маркировки»](https://selsup.ru/application/codes/?ascending=false&limit=100&organizationId=1&sortBy=ID) в SelSup.

2.  Выберите нужное действие:

    - **Для всех кодов сразу:** нажмите *«Обновить все»*.

    - **Для одного кода:** выделите его в списке и нажмите *«Обновить»*.

3.  После этого система автоматически:

    - отправит запрос в «Честный ЗНАК»;

    - получит и сохранит информацию о товарной группе для выбранных кодов.

**Результат:** после обновления система будет знать товарную группу и сможет корректно обрезать коды маркировки для автоматического формирования УПД ДОП.

**Важно:** обновите коды до создания УПД, если они были внесены через сканирование.

SelSup — это мощная интеграция с Честным знаком для автоматизации торговли на Wildberries и других площадках. Кроме этого у SelSup ещё много полезных функций: учёт товаров, печать этикеток, обработка заказов по FBS, сборка поставки по FBO, финансовый учёт и товарная аналитика.
