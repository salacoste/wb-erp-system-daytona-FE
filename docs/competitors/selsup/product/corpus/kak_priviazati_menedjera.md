# Как привязать менеджера к товару

Во многих отчётах SelSup (при выгрузке Excel) можно видеть, **какой менеджер закреплён за товаром**. Это удобно, чтобы анализировать эффективность работы менеджеров и сравнивать результаты по продажам/маржинальности/остаткам.

Чтобы менеджеры отображались в отчётах, их нужно **предварительно привязать к товарам**.

## Как привязать менеджера к товарам

1.  Перейдите в раздел **Товары → Импорт товаров → [вкладка «Массовое редактирование»](https://selsup.ru/application/productsImport/import)** и нажмите **«Скачать Excel»**, чтобы получить файл со списком товаров.

2.  В скачанном файле заполните нужный столбец менеджера:

    - **Менеджер Yandex**

    - **Менеджер Ozon**

    - **Менеджер WB**

    - или **Менеджер товара основной**

    Выберите соответствующего менеджера из выпадающего списка.

    **Важно**: менеджеры в списке берутся из раздела [**Настройки → Сотрудники**](https://selsup.ru/application/persons/). Заранее убедитесь, что нужные сотрудники добавлены. Как добавить сотрудников — смотрите в [статье про сотрудников.](../sotrudniki/index.html)![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/screenshot_200-1.png.webp)

3.  Сохраните файл с внесёнными изменениями.

4.  Вернитесь в **Товары → Импорт товаров → вкладка «Массовое редактирование»** и загрузите отредактированный файл в синее поле (**маркетплейс выбирать не нужно**).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/08/screenshot_201-1.png.webp)

Готово! Теперь в Excel-отчётах будет отображаться менеджер, закреплённый за каждым товаром.

## Где это отображается

После привязки менеджеров вы сможете видеть их в Excel-выгрузках и/или отчётах, где предусмотрен вывод менеджера по товару:

- **Товарная аналитика (Юнит-экономика)**

- [**AI стратегии**](../ai-strategii/index.html) — в этом разделе отображается только **основной менеджер товара**. Менеджеры маркетплейсов здесь не выводятся.

- [**РНП (рука на пульсе по-товарно)**](../ruka-na-pulse-po-tovarno/index.html)

> После выполнения шагов выше вы сможете открыть нужный отчёт и скачать Excel — менеджер будет подтягиваться из привязки товара.
