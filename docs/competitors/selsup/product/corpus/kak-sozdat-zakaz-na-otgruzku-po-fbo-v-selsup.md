## Особенности отгрузки товаров на склад маркетплейса через SelSup

С помощью **SelSup** можно удобно:

- собирать данные по заказам;
- выгружать шаблоны с товарами для создания поставок;
- создавать и отслеживать отгрузки.

> ⚠️ Маркетплейсы **не передают данные по заказам FBO через API**, поэтому создание и отслеживание этапов отгрузок в SelSup и на самих маркетплейсах **не связаны между собой**.

**Отдельно по Ozon:**

Для **Ozon** можно **создать отгрузку на склад маркетплейса напрямую из SelSup** — **до этапа выбора таймслота доставки**, подробней в [статье](../sozdanie-zakaza-na-ozon/index.html).

## Создание заказа на склад маркетплейса

**Важно:** на странице отгрузок есть две разные кнопки — **«Создать заказ»** и **«Создать из файла»**.

У них разный функционал и назначение: **«Создать заказ»** используется для создания заказа на отгрузку, а **«Создать из файла»** — для формирования документов на основе загруженного файла.

Подробнее о различиях рассказываем ниже.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

### Создать заказ на отгрузку

Кнопка **«Создать заказ»** используется для создания FBO-отгрузки.

Заполните обязательные поля, нажмите **«Сохранить»**, а затем добавьте товары вручную, через планирование поставок или загрузите файл уже **внутри созданного заказа**, как описано ниже.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/chrome_7kfcgpoze9.png.webp)

**Шаг 1.** Перейдите в раздел [Заказы на отгрузку - На склад маркетплейса](https://selsup.ru/application/orders/) и нажмите **Создать заказ**.

**Заполните необходимые поля:**

- **Название** отгрузки;
- **Организация**;
- **Маркетплейс**, на который создаете отгрузку;
- **Склад маркетплейса**, на который будет отгружен товар;
- **Склад списания остатков**

*Включите переключатель* ***Списать остатки,*** *если ведете учет остатков в SelSup.*

При выборе маркетплейса Wildberries появится поле "Тип" - тип поставки на WB.

* Если Вы выбрали неверный тип заказа  - не беспокойтесь!* *После загрузки на WB, маркетплейс сам укажет тип поставки, и вы сможете его скорректировать в SelSup.*

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_108.png.webp)

------------------------------------------------------------------------

**Шаг 2.** Добавьте в заказ товары одним из способов:

- используйте планирование поставок по складам;
- введите или отсканируйте штрих-код товара в строке поиска;
- выберите товары из списка, нажав **+1** в столбце **Добавить**;
- загрузите файл со списком товаров и их количеством.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_109.png.webp)

Если у товара есть несколько размеров или других параметров, они будут добавлены сразу. Чтобы выбрать конкретный размер, нажмите на него, как показано на скриншоте.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/nazvanie-i-razmer.png.webp)

------------------------------------------------------------------------

**Шаг 3.** Укажите количество товара для отгрузки. Введите нужное значение в столбце **Количество**.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/kolichestvo.png.webp)

------------------------------------------------------------------------

**Шаг 4.** Настройте количество этикеток для печати одним из способов:

\- в разделе [Настройки- этикетки](https://selsup.ru/application/labels/), выберите товарную этикетку и укажите нужное количество. Подробнее о настройке и печати этикеток рассказано [в статье](../nastrojka-pechati-etiketok/index.html).

\- или укажите нужное число в столбце **Печать**. При нажатии на кнопку **Печать** SelSup печатает сразу 2 этикетки: одну для товара, другую — для упаковки.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/pechat.png.webp)

------------------------------------------------------------------------

**Шаг 5.** Нажмите **Сохранить**.

- Для создания заказа в Ozon — следуйте инструкции по [ссылке](../sozdanie-zakaza-na-ozon/index.html).

- Для создания заказа на Wildberries — перейдите к следующему шагу инструкции.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_59.png.webp)

### Сформировать документы из файла

Кнопка **«Создать из файла»** не используется для обычного создания заказа на отгрузку. Она предназначена для формирования документов на основе загруженного файла.

В окне **«Создать из файла»** можно выбрать тип документа:

- **Акт приёмки.** В этом случае в SelSup создастся заказ с названием «Акт №». Это способ хранения актов приёмки Wildberries. Подробнее об этом мы рассказываем [в нашей статье](../vozmozhnost-hraneniya-aktov-priemki-wildberries-v-selsup/index.html).
- **Уведомление о выкупе.** В этом случае SelSup не создаёт заказ на отгрузку, а формирует **УПД по НДС** для Wildberries в формате XML. Готовый файл можно использовать для передачи данных по НДС через ЭДО.

При создании из **Акта приёмки** загрузите файл формата **xlsx**.

При создании из **Уведомления о выкупе** загрузите файл уведомления в формате **xlsx**.

## Планирование поставок

В SelSup можно спланировать поставку на склад маркетплейса с учётом продаж и остатков на складе.

Чтобы перейти к планированию, разверните вкладку **«Планирование поставок»** в заказе на отгрузку. Подробную инструкцию по планированию поставок можно найти в [**статье**](../planirovanie-postavok-v-zakazah-na-otgruzku/index.html).\

## Статусы заказа на отгрузку

В отгрузках на склад маркетплейса отображается строка статусов отгрузки:\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_156-1.png.webp)\
**Новый** - этап создания и заполнения отгрузки в SelSup и на маркетплейсе.

**Собран** - когда товар собран на вашем складе.

**Упакован** - переходите к этому этапу, когда товары полностью упакованы по коробам.

**Готов к поставке** - используйте этот статус, когда поставки созданы на маркетплейсе. Здесь важно заполнить поле **«Поставка»**, которое объединяет заказы, отправляемые в один день.

**Отгружен** - товары из отгрузки отправлены на склад маркетплейса.

**Закрыт** - отгрузка принята маркетплейсом, закройте ее в SelSup.

**Возврат** - если не отгрузили товары и нужно вернуть остатки на склад.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Резервирование остатков

При сохранении заказа в статусе **Новый** - остатки резервируются. Подробную информацию о резервировании остатков для FBO можно найти в  **[статье](../rezervirovanie-ostatkov-pod-otgruzku-na-fbo/index.html)**.

Важно: не удаляйте и не восстанавливайте уже отгруженный заказ, если нужно повторно отгрузить товары. При восстановлении такого заказа остатки не будут снова взяты в резерв, так как позиции заказа уже считаются возвращенными. Если нужно оформить повторную отгрузку, создайте новый заказ.

## Как получить коды маркировки для отгрузки на маркетплейс

Если в отгрузке на маркетплейс есть товары, подлежащие маркировке, появляется блок для работы с «Честным знаком». Для [категорий](https://selsup.ru/application/categories/) товаров с маркировкой должна быть включена галочка **"Товары категории маркируются"** и указан ТНВЭД, который подлежит маркировке. Необходимо пройти все пункты для получения кодов маркировки и ввода их в оборот. Подробности о получении кодов маркировки из отгрузки по FBO можно найти в данной **[статье](../rabota-s-chestnym-znakom-po-fbo/index.html)**.\

## Как закрыть отгрузку

Чтобы закрыть отгрузку, перейдите в раздел [Заказы на отгрузку - На склад маркетплейса.](https://selsup.ru/application/orders/) Выберите нужную отгрузку, проверьте, что все предыдущие этапы выполнены и маркетплейс принял отгрузку. Нажмите кнопку **Следующий шаг**, чтобы перевести отгрузку в статус **"Закрыт"**. На этом отгрузка товаров завершена, ваш товар передан и принят на складе маркетплейса.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_61.png.webp)

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Как удалить отгрузку

Для удаления отгрузки на склад маркетплейса перейдите в раздел [Заказы на отгрузку - На склад маркетплейса. ](https://selsup.ru/application/orders/)Найдите нужную отгрузку и нажмите на красный крестик в столбце **Удалить**.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/05/screenshot_62.png.webp)
