## Общая информация по учету аналитики по API

- Данные получаем по API: продажи, возвраты, расходы по продажам на мп записываем в 2 строки: **логистика** (доставка покупателю и expess доставка покупателю) **и услуги** ((комиссия, эквайринг), размещение товаров на витрине, складская обработка, участие в программе лояльности, буст продаж, рассрочка).
- отдельной строкой не выделяем Рекламу (данные в записываются в общих услугах). В планах выделять рекламу как отдельную статью.
- Не учитываем хранение. В планах реализации есть.
- Не выделяем из комиссии СПП (скидка софинансирования)
- Используемые методы API  https://yandex.ru/dev/market/partner-api/doc/ru/reference/stats/getOrdersStats
- Аналитика по Яндексу обновляется каждые 30 минут. Посмотреть запуск задач можно по ссылке: https://selsup.ru/application/tasks/. Задача называется Импорт аналитики с Яндекс.Маркета
- Чтобы импортировать заказы FBO по Яндекс маркету нужно запустить задачу Импорт заказов FBO

## Сроки подгрузки аналитики

- **Продажи:** SelSup загружает данные о заказах и выручке **каждый день в режиме онлайн** через API Яндекс Маркета. Информация может обновляться с задержкой до 4 часов, но остаётся максимально актуальной.

- **Финансы:** Итоговые финансовые отчеты Яндекс Маркет предоставляет раз в неделю. Как только мы получаем финальные данные — система **автоматически корректирует** показатели, чтобы обеспечить точность аналитики.

## За какие периоды доступны данные?

- **По API:** Данные доступны за последние 3 месяца.

- **Ручная загрузка:** Если возникли проблемы с автоматической загрузкой (например, сбой на стороне маркетплейса), вы всегда можете **загрузить отчёт вручную** через раздел «Импорт».

## Как вручную загрузить отчеты

Помимо автоматического получения данных через API маркетплейсов, в SelSup доступен резервный вариант – ручная загрузка отчетов. Исторические отчеты служат вашей финансовой подушкой безопасности при временных сбоях API маркетплейса, позволяя сохранить видимость прибыли.

**Важно понимать:** мы сознательно фокусируемся на стабильности "живой" аналитики через API текущих продаж и инструментах роста. Исторические данные могут терять актуальность из-за постоянных изменений форматов отчетов маркетплейсов. Ваш рост требует четких данных сегодняшнего дня – этому и посвящены наши основные усилия!

Для максимально точной картины рекомендуем использовать ручную загрузку исключительно как временное решение при технических неполадках. Основной упор делайте на автоматизированную аналитику – она гарантирует бесперебойный мониторинг ваших финансовых показателей.

Если вам нужно загрузить аналитику за более ранний период это можно сделать по АПИ на странице [Аналитика](https://selsup.ru/application/analytics/):

## Отчеты в SelSup

**[Отчет о прибылях и убытках (P&L)](https://selsup.ru/application/analytics/)**

**Нюанс - комиссия записывается в** услуги.

В расходах по продаже на МП по Яндексу можно видеть 2 строки - логистика и услуги. См. отчет Товарная аналитика - в планах выделить также данные статьи расходов.

[**Отчет Лента заказов**](https://selsup.ru/application/allOrders)

Заказы Яндекс FBS попадают, если вы работаете по FBS через Селсап

Заказы Яндекс FBO пока запускаются в ручном режиме - нужно запустить задачу Импорт заказов FBO на странице https://selsup.ru/application/tasks/ или на странице [Лента заказов](https://selsup.ru/application/allOrders) нажать на кнопку "перезагрузить заказы FBO". Преимущества обновления на странице заказов в том, что начальная дата, с которой происходит обновление - та, которая указана у пользователя в фильтрах.

**[Отчет Товарная аналитика](https://selsup.ru/application/productAnalytics/)**

Показываем фактическую юнит-экономику в разрезе карточки товара.

Заполняются 2 колонки - услуги (сюда включена комиссия, реклама и все другие услуги) и логистика.

В [профит репорт Селсап](https://selsup.ru/application/profitReport/) вы можете увидеть услуги с разбивкой на статьи. Колонка - "Обоснование для оплаты" разбивает услуги по статьям.

В планах выделить из услуг отдельно Комиссию (+эквайринг) и рекламу (комплекс услуг по рекламе). И отдельно оставить услуги.

Корректно работает для Яндекс Маркета (данные берутся из профит репорта)

## Нюансы аналитики с Яндекс Маркета

1.  Отчеты от Яндекс Маркета динамичные, как только поменялся статус заказа - меняются цифры в аналитике.

Например с доставлено на возврат - тут же меняются цифры. По АПИ они отдают быстрее, а в отчете (в лк Яндекс Маркета) могут быть еще старые.

2\. Бывают услуги (чаще всего - Возврат невыкупленных товаров и вознаграждение за продажу товаров) - у себя в отчете они показывают 0, а в отчете отдают цифры. Мы данные услуги записываем в расходы.
