# Где скачать файл для участия в акции в Ozon

### Как скачать файл для участия в акции в Ozon

Перейдите в ЛК Ozon, раздел Продвижение - Акции.

Нажмите на нужную акцию, в которой хотите участвовать. На открывшейся странице нажмите "Добавить товары", затем "Импорт в XLS-файле".\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/04/import-1.png.webp)\
В открывшемся окошке нажмите "Скачать".\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/04/skachai-fail.png.webp)\
Загрузите файл акций на странице [Товары - Акции, вкладка "Расчет прибыли"](https://selsup.ru/application/promotions/).

 

Выгруженный файл необходимо открыть и удалить строки - которые вам не выгодно добавлять в акции, с учетом дополнительных полей, которые добавит SelSup. После отбора нужных артикулов загрузите файл обратно в Ozon и нажмите кнопку Сохранить изменения
