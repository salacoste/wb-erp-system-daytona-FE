## Преимущества интеграции SelSup с МегаМаркет

Автоматизация через API дает вам:

- **Безопасность** — защита от ошибок при передаче данных

- **Контроль прибыли** — точная аналитика доходов и расходов

- **Экономия времени** — автоматическая выгрузка остатков

- **Масштабирование** — одновременная работа с несколькими схемами (FBS/FBO)

Подробнее обо всех преимуществах - [здесь](../integration-api-marketplaces/index.html).

## Настройка интеграции

- Для каждой схемы работы (FBS/FBO) создайте отдельную организацию в SelSup

- Рекомендуем названия: *"ИП Иванова_FBS"*, *"ИП Иванова_FBO"*

Подробно про настройку интеграции с МегаМаркет рассказываем [тут](../integratsiya-sbermegamarket/index.html).

## Импорт карточек

Импорт карточек напрямую по кнопке из МегаМаркет невозможен — API этого не поддерживает. Подробнее про особенности импорта карточек из МегаМаркета читайте [здесь](../import-kartochek-s-megamarketa/index.html).

## Настройка работы по FBS и передача остатков

**Обязательно прочитайте подробную инструкцию по переносу остатков** в SelSup и настройке работы по FBS [здесь](../perenos-ostatkov/index.html).

- В SelSup перейдите в **Склад → [Склады](https://selsup.ru/application/warehouses/)**.

- Добавьте склад МегаМаркет в блоке **Связи со складами маркетплейсов**.

- Укажите ID склада и организацию.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/03/screenshot_379.png.webp) Данный функционал реализован в **Модуле Умный склад. **Он обеспечивает синхронизацию, сборку и маршрутизацию товаров, интеграцию со службами доставки, формирует уведомление о видеофиксации для защиты от потребительского терроризма, адресное хранение остатков. Подробнее о возможностях модуля читайте [здесь](../../help_cat/modul-umnyj-sklad/index.html).

## Настройка работы по FBO

В разделе **Настройки - [Интеграции](https://selsup.ru/application/integration/) - МегаМаркет** включите переключатель **Магазин FBO**, чтобы SelSup не резервировал товары под заказы FBO. ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2023/03/screenshot_179.png.webp) Затем следуйте [инструкции по настройке FBO.](../integratsiya-s-megamarket/index.html)

## Создание карточек товаров через SelSup

Создание товаров в МегаМаркет происходит через YML-фид — файл, содержащий все товарные данные.

 **Важно** **соблюдать последовательность:**

1.  Сначала загрузите YML-фид в Личный кабинет МегаМаркет.

2.  Затем выполняйте склейку карточек.

Это предотвратит дублирование и ошибки.

**Не имеет значения, как изначально создавать карточки.** Можно сделать это в SelSup или импортировать с Wildberries или Ozon. В любом случае SelSup сформирует YML-фид.

**Что дальше:**

- В SelSup найдите ссылку на YML-фид:\
  **Настройки → Интеграции → [МегаМаркет](https://selsup.ru/application/integration/megamarket)**
- Перейдите в **Кабинет селлера → Ассортимент → Загрузить фид**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/12/screenshot_20221215_082002_youtube.jpg.webp) ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/12/screenshot_20221215_082042_youtube.jpg.webp)

- Вставьте ссылку на YML-фид в личном кабинете МегаМаркет

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/12/screenshot_20221215_082124_youtube.jpg.webp)

Если вы уже продаете товары на МегаМаркет по FBS, необходимо обязательно проставить артикул МегаМаркета в SelSup у уже заведенных товаров и проставить остатки в SelSup. Иначе при подключении фида они будут убраны с остатков самим МегаМаркетом

- После загрузки товары появятся в разделе **Ассортимент → Сводка по ассортименту** во вкладке **«Соответствие не найдено»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/12/screenshot_20221215_082303_youtube.jpg.webp)

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/12/screenshot_20221215_082409_youtube.jpg.webp)

- Чтобы товар отобразился в МегаМаркет:

Нажмите кнопку **«Создать карточку»**

Заполните параметры вручную

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2022/12/screenshot_20221215_082555_youtube.jpg.webp)

Если МегаМаркет заинтересован в ваших товарах, ваш менеджер может помочь заполнить параметры. Попробуйте обратиться к нему.

**После того как карточки будут полностью заполнены, они появятся на витрине МегаМаркет. А вы сможете пользоваться инструментами SelSup для работы по FBS.** Для удобного управления карточками используйте **PIM-систему** от SelSup, подробнее [по ссылке.](../../help_cat/rabota-s-kartochkami-tovarov/index.html)

## Управление ценами

Используйте <a href="../../help_cat/modul-ai-findir/index.html" rel="noopener noreferrer" target="_blank">Модуль AI-Финдир</a> для:

- [Массового переноса цен](https://selsup.ru/application/prices/massPrices) между площадками

Управление ценами происходит через раздел [Цены,](https://selsup.ru/application/prices/) подробней о данном разделе в [статье](../prices/index.html).

## Маркировка товаров Честный знак

В SelSup доступен [Модуль Маркировка](../../help_cat/markirovka/index.html), с помощью которого можно:

- Создавать карточки Честного знака

- Получать и печатать КИЗ+ШК

- Передавать коды для FBS-заказов

- Отслеживать статусы заказов и кодов

Передача кодов маркировки в МегаМаркет осуществляется:

- Через ТСД при сборке

- В заданиях по [комплектации](https://selsup.ru/application/task/packOrder)

- Задание [Сборка заказов](https://selsup.ru/application/task/collectOrder) — отметить заказ собранными

Полное руководство по работе с маркировкой в [статье](../kak-rabotat-s-obyazatelnoj-markirovkoj-v-selsup/index.html).
