# Повторная печать маркировки

Если вам поступают товары уже с нанесённой маркировкой от поставщика, но при этом отсутствуют исходные PDF-файлы с кодами, это может вызвать сложности при последующей отгрузке на ФБО. На товарах есть маркировки, но напечатать их повторно без оригиналов — непросто.\
SelSup предлагает простой и надежный способ для решения этой задачи. Всё работает за счёт гибкой настройки задания "Возврат товара" и автоматической печати маркировки. Ниже пошаговая инструкция.

## Подготовка системы

1\. **Интеграция с "Честным знаком"**

 Убедитесь, что ваш кабинет в системе интегрирован с "Честным знаком". Это необходимо для подтягивания данных о товаре и кодах маркировки. Подробней о том как настроить интеграцию рассказали в [статье](../integratsiya-s-chestnym-znakom/index.html).

2\. **Настройка принтера**

 Установите приложение QZ- Tray (если не установлено) для прямой печати этикеток. Инструкция по [ссылке](../qz-tray/index.html).

3\. **Выбор шаблона этикетки **

Перейдите в раздел **Настройки - [Этикетки.](https://t03.selsup-team.ru/application/labels/)** Выберите шаблон **"Маркировка Честный знак"** с нужным размером и сохраните изменения.

Подробней рассказали [тут](../nastrojka-printera/index.html).

4\. **Связать карточки c Честным знаком**

 Как связать карточки SelSup с карточками Честного знака по GTIN рассказали [тут](../import-kartochek-iz-chestnogo-znaka/index.html).

Если нет связи с товаром или 1 GTIN для нескольких товаров, то SelSup попросит отсканировать штрих-код товара.

## Печать маркировки

- Перейдите в [**Настройки → Заказы**](https://selsup.ru/application/settings/orders) и включите тумблер **В задании 'Возврат товара' только печатать этикетки**

Эта настройка позволит использовать задание "Возврат товара" исключительно для повторной печати маркировки, без оформления возврата.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/screenshot_398.png.webp)

- Перейдите в [**Задания → Возврат товара**](https://selsup.ru/application/task/refund) и поставьте галочку **Маркировка Честный ЗНАК**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/screenshot_391.png.webp)

- Отсканируйте маркировку с товара — SelSup сгенерирует и распечатает дубликат этикетки.

- Код маркировки автоматически добавится в ваш кабинет.

## Исправление кодов маркировки при обновлении

В некоторых случаях при печати дубликата кода маркировки, например через задание [«Возврат товара»](https://selsup.ru/application/task/refund), код может не считаться валидным в системе «Честный ЗНАК».

Чтобы снизить риск такой ошибки, перейдите в раздел [**Настройки → Общие**](https://selsup.ru/application/settings/common) и включите тумблер **«Исправлять код маркировки при обновлении»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/06/2026.06.18_chrome_g6hw.png.webp)

Настройка помогает восстановить полный КИЗ при обновлении кода маркировки, если код был добавлен в SelSup через сканирование.

**Когда использовать:**

- если нужно повторно напечатать уже существующий код маркировки, а не создать новый;
- если код маркировки был добавлен в SelSup через сканирование;

**Обратите внимание:** настройка работает только для кодов, которые были добавлены сканированием. Если КИЗ был импортирован из Честного знака, автоматическое исправление для него не сработает: при обновлении такой код останется неполным.

**Результат:**

После включения настройки все дублированные коды, добавленные через сканирование, будут автоматически исправляться при обновлении и приниматься системой «Честный ЗНАК» без ошибок.

Это помогает корректно печатать дубликаты кодов и снижает риск ошибок при работе с маркировкой.

Ознакомиться со всеми возможностями модуля "Маркировка" можно [здесь](../../help_cat/markirovka/index.html).
