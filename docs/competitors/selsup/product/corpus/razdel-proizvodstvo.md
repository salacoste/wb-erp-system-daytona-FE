## Создание производственных процессов

В разделе **"Производство → Процессы"** настраиваются этапы производства:

- Для добавления нового процесса перейдите в раздел **"Производство → [Процессы](https://selsup.ru/application/manufacture/processes/)"** и нажмите кнопку **"Добавить процесс"**

- В открывшемся окне укажите название процесса и нажмите **"Сохранить"**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_7.png.webp)

- Для добавления этапов в созданный процесс нажмите на кнопку добавления этапов в столбце **"Действия"**

- Нажмите **"Добавить этап процесса"**, укажите название, при необходимости добавьте описание и сохраните

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_9.png.webp)

- В столбце "Действия" доступны функции редактирования (значок карандаша) и удаления (значок корзины) для этапов и процессов.

## Формирование технологических карт

В разделе **"Производство → Техкарты"** создается основная производственная документация:

- Для создания новой техкарты перейдите в **"Производство → [Техкарты](https://selsup.ru/application/manufacture/processing-plans/)"** и нажмите **"Создать новую техкарту"**

- Укажите название, описание и выберите ранее добавленный процесс, затем нажмите **"Создать"**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_10.png.webp)

Для удобства работы с большим количеством документации в разделе **«Производство → Техкарты»** доступны дополнительные инструменты:

- В верхней части списка можно воспользоваться поиском по названию или процессу, чтобы быстро найти нужную техкарту.
- Если требуется создать новую техкарту на основе уже существующей, используйте функцию копирования. Для этого в столбце **«Действия»** нажмите кнопку **«Копировать»** напротив нужной карты.
- SelSup автоматически создаст копию техкарты с новым ID. При этом все параметры — описание, процессы, материалы, результат и зарплаты — будут перенесены без изменений.
- После копирования вы сможете при необходимости отредактировать созданную техкарту.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/browser_aafvtmkfat.png.webp)

- В созданной техкарте можно настроить:

  **Раздел "Материалы"** — добавление необходимых компонентов с указанием конкретных материалов и их количества

  **Раздел "Результат"** — настройка выпускаемой продукции

  **Дополнительные разделы** — учет заработной платы во вкладке "Зарплата" и прикрепление документов во вкладке "Документы"

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_13.png.webp)

## Работа с производственными заказами

В разделе **"Производство → [Производственные заказы](https://selsup.ru/application/manufacture/production-orders/)"**:

- Заполните название, выберите дату начала и окончания производства, а также технологическую карту, затем нажмите **"Создать заказ"**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_14.png.webp)

- В открывшемся окне нажмите **"Перейти к заказу"**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_15.png.webp)

- Проверьте корректность данных во вкладках **"Детали"**, **"Материалы"**, **"Результат"**

- Если все данные корректны, нажмите **"Подтвердить заказ"**. В открывшемся окне выберите склад списания материалов и склад приёмки продукции, затем подтвердите заказ

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_16.png.webp)

**Важный момент**: при подтверждении SelSup автоматически резервирует материалы для производства.

По завершении производства нажмите **"Заказ выполнен"**. SelSup автоматически спишет остатки материалов и добавит остатки для товаров из раздела "Результат".

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_17.png.webp)

## Производственные заказы из FBS-заказов

В разделе FBS-заказов можно создать производственный заказ по товарам из заказов. Это удобно, если товар нужно сначала произвести, а затем отгрузить покупателю.

Для создания производственного заказа у товара должна быть настроена [техкарта](index.html). В техкарте должны быть указаны:

- материал;
- результат производства;
- план производства;
- хотя бы один этап производства.

**Как создать производственный заказ из FBS-заказа**

1.  Выберите нужный FBS-заказ в таблице заказов.
2.  Нажмите **«Создать производственный заказ»**.
3.  В открывшемся окне выберите склад, с которого нужно списать материалы.
4.  Выберите склад, на который нужно принять готовый товар после производства.
5.  Подтвердите создание производственного заказа.

В разделе [Производство → Производственные заказы](https://selsup.ru/application/manufacture/production-orders/) появятся производственные заказы по выбранным FBS-заказам. Они будут созданы в статусе **«Подтверждён»**.

Остатки материалов из техкарты будут зарезервированы на выбранном складе.

После завершения производственного заказа материалы спишутся, готовый товар поступит на склад приёмки результата, а сам производственный заказ перейдёт в статус **«Выполнен»**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/chrome_2026.05.22_bcov4k.png.webp)

- Если выбрать несколько FBS-заказов на один и тот же товар, SelSup создаст один общий производственный заказ на нужное количество товара.
- Если заказы в таблице не выбраны вручную, SelSup создаст производственные заказы по всем подходящим заказам, для которых производственный заказ ещё не был создан.
- Если по FBS заказу уже создан производственный заказ, повторно он не создаётся, а в разделе заказов в столбце **«Есть производственный заказ?»** будет отображаться галочка.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/image.png.webp)

### Как рассчитывается норматив

Норматив показывает, сколько раз нужно выполнить техкарту, чтобы произвести нужное количество готового товара.

При создании производственного заказа из FBS, SelSup считает норматив по общему количеству товара в FBS-заказах и количеству результата, которое получается по техкарте за 1 норматив.

**Формула расчёта:**

Норматив = количество товара в FBS-заказах / количество результата за 1 норматив

Если при расчёте получается дробное значение, **SelSup округляет норматив вверх**. Это нужно, чтобы после производства готового товара точно хватило для выполнения заказов.

**Пример расчёта**

Допустим, по техкарте за **1 норматив** производится **3 шт.** товара.

Если в FBS-заказах нужно произвести **4 шт.**, SelSup рассчитает норматив так:

4 / 3 = 1,33

**Результат:** система округлит значение вверх и создаст производственный заказ с нормативом **2**. После завершения такого производственного заказа на склад поступит **6 шт.** товара.

------------------------------------------------------------------------

Если в одном FBS-заказе нужно произвести **7 шт.** товара, расчёт будет таким:

7 / 3 = 2,33

**Результат:** SelSup округлит значение вверх и создаст производственный заказ с нормативом **3**. После завершения производственного заказа на склад поступит **9 шт.** товара.

**Обратите внимание:** из-за округления вверх готового товара может получиться больше, чем требуется по FBS-заказам. Остаток останется на складе приёмки результата.

### Если товар не подходит для создания производственного заказа

Если для товара не настроена техкарта, не указан материал, результат производства или этап производства, **такой товар не будет обработан.**

После выполнения действия SelSup покажет список ошибок: какие товары не удалось обработать и какие производственные заказы не были подтверждены.

## Диаграмма Ганта

В разделе **Производство → Производственные заказы** производственные заказы можно просматривать на диаграмме Ганта. Диаграмма помогает быстро оценить загрузку производства, сроки выполнения заказов и текущий статус каждого заказа.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/chrome_8fevgixucj.png.webp)

На диаграмме заказы отображаются по статусам:

- **голубым** — черновики
- **зелёным** — подтверждённые
- **синим** — выполненные

Также доступна **фильтрация заказов по периодам**: Четверть дня, Полдня, День, Неделя и Месяц.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/chrome_ftpwoalrhp.png.webp)

**При нажатии на конкретный заказ** в диаграмме SelSup показывает дополнительную информацию: дату начала, дедлайн и прогресс выполнения.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/chrome_5u5s6koump.png.webp)

## Заключение

SelSup предоставляет полный набор инструментов для управления производством — от создания технологических процессов до анализа себестоимости продукции. Система позволяет эффективно планировать производственные операции, контролировать использование материалов и анализировать финансовые результаты.

*В ближайших обновлениях будет добавлен функционал отслеживания прогресса по этапам производства, что сделает управление производственными процессами еще более эффективным.*
