# Откуда можно печатать этикетки в SelSup

В этой статье Вы узнаете из каких разделов можно распечатать этикетку в SelSup.

Что-то сломалось, уже чиним Перезагрузите страницу или попробуйте позже

## Откуда можно печатать этикетки

1\. Из раздела [Товары‎](https://selsup.ru/application/products):\
Для этого выберите товар и нажмите кнопку **Печать**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/screenshot_219.png.webp)

2\. Из раздела [Заказы на отгрузку — Со своего склада (FBS)‎](https://selsup.ru/application/fbsOrders/):\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/screenshot_220.png.webp)\
3. Из раздела [‎Заказы на отгрузку — На склад маркетплейса (FBO)](https://selsup.ru/application/orders/)‎:\
Выберите нужную поставку на склад маркетплейса и нажмите на нее, внутри поставки увидите кнопки для печати этикетки.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/screenshot_222.png.webp)\
4. Из приемок на склад (раздел [Склад — Приемки на склад](https://selsup.ru/application/incomeOrders/)):\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/06/screenshot_223.png.webp)\
5. При печати ленты заказов совместно с этикетками товаров в PDF.\
Все про печать ленты заказов и настройках [здесь.](../nastrojka-pechati-umnoj-lenty/index.html)

По всему сервису выведены иконки принтера, откуда вы можете напечатать этикетки.
