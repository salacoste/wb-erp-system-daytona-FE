# Массовая загрузка видео через Фотосъемки

В этой статье расскажем, как загружать видео через раздел **Фотосъемки**, какие форматы поддерживаются и что важно учитывать при передаче видео на маркетплейсы.

## Какие форматы видео поддерживаются

Для загрузки через Фотосъемки поддерживаются видеофайлы с расширением:

- **mp4**
- **mov**

Если файл имеет другое расширение, SelSup не сможет определить его как видео.

## В каких типах фотосессий можно загружать видео

Загрузка видео поддерживается не во всех вариантах фотосессий.

Видео можно загружать в следующих типах:

- **файлы с ракурсами**
- **файлы с артикулами и порядком**

В варианте **структура папок для товаров** загрузка видео не используется.

Перед началом работы выберите подходящий вариант структуры загрузки видео. Для каждого варианта нужно по-своему подготовить файлы. Ниже описаны доступные форматы и требования к ним.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Файлы с ракурсами

В этом варианте вы можете подготовить одну папку, в которой будут постоянно загружаться файлы по следующей структуре:

`{название артикула модели}_{цвет}_{название ракурса}.mp4`

или

`{название артикула модели}_{цвет}_{название ракурса}.mov`

Ракурсы и их позиции можно задать в форме.

По умолчанию порядок файлов определяется цифрой в конце имени файла: `1`, `2`, `3` и так далее.

Также можно использовать буквенные обозначения ракурсов. Например:

- **P** — первый
- **B** — второй
- **PN** — третий

SelSup сопоставляет текстовый ракурс с его порядковым номером и определяет порядок файла в карточке товара.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/04/browser_dmfca86wbu.png.webp)

Если какой-то ракурс отсутствует, он будет пропущен, а остальные файлы обработаются в правильной последовательности.

## Файлы с артикулами и порядком

В SelSup также доступен формат загрузки **файлы с артикулами и порядком**.

В этом варианте все файлы загружаются в одну папку, без создания отдельных папок для каждого товара.

Чтобы SelSup корректно определил товар, в названии файла нужно указывать артикул в начале имени файла. Например:

`article_1.mp4`\
`article_2.mov`

Порядок файлов определяется по последней цифре в названии файла. Например, файл с окончанием `_1` будет первым, `_2` — вторым и так далее.

Такой формат удобно использовать, если нужно быстро подготовить и загрузить видео без дополнительной структуры папок.

Если в SelSup есть одинаковые товары в нескольких организациях, можно загрузить видео сразу на все организации по артикулу.

При необходимости можно использовать вложенные папки, если товары распределены по ним. Главное, чтобы в начале имени файла был указан нужный артикул.

## Что важно учитывать для Wildberries

Для Wildberries важно быть особенно внимательными при обновлении медиа.

Если у товара уже есть видео, его нужно передавать вместе с фотографиями. Поэтому, если видео уже используется в карточке, его нужно заранее загрузить **ссылкой**, если оно есть.

Если видео не передать, при обновлении фотографий существующее видео может быть затерто.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Сколько видео можно загружать

Для одного товара рекомендуется использовать одно видео.

Исключение составляет Ozon: в SelSup можно отправить на Ozon до **5 видео** для одной карточки товара.

**Важно:** для Ozon ссылки на видео можно указывать в параметре **Ozon.Видео: ссылка**.

Подробнее об этом рассказываем [в нашей статье](../rabota-s-video-v-kartochkah-tovarov-cherez-selsup/index.html).

## Что сделать после подготовки файлов

После того как вы подготовили видеофайлы, загрузите их на **Яндекс.Диск** или **Google Диск**, а затем настройте фотосессию в SelSup.

Подробная инструкция по подключению диска и дальнейшей настройке фотосессии описана в статье **[Фотосъёмки](../photo/index.html)**.

## Итог

Через раздел **Фотосъемки** в SelSup можно загружать не только фотографии, но и видео.

Загрузка видео поддерживается для форматов:

- **файлы с ракурсами**
- **файлы с артикулами и порядком**

Для Wildberries важно передавать видео вместе с фотографиями, иначе существующее видео в карточке может быть затерто.

Для корректной загрузки используйте видео в формате mp4 или mov и указывайте в названии файла нужный артикул, если работаете с форматом «файлы с артикулами и порядком».
