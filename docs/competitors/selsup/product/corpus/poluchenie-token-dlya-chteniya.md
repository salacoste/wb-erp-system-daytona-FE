# Получение токена для чтения

В этой статье:

- 
- <a href="#poluchenie-tokena-wildberries" rel="nofollow">Получение токена Wildberries</a>
- <a href="#poluchenie-tokena-ozon" rel="nofollow">Получение токена Ozon</a>

В некоторых случаях для разбора проблем с данными от маркетплейсов требуется предоставление токена на чтение для того, чтобы разработчики могли посмотреть из-за чего возникает проблема, тк доступа к вашим токенам у сотрудников SelSup нет. После разбора проблемы вы сможете удалить токен

Внимание! Обязательно получайте только токен на чтение данных, тк это позволяет запретить доступ по токену к изменению любых данных.

## Получение токена Wildberries

Перейдите на страницу доступа к API с аккаунта владельца (только он может получать токены API):

<https://seller.wildberries.ru/supplier-settings/access-to-api>

Нажмите создать новый токен

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/snimok-ekrana-2024-04-18-v-08.16.22.png.webp)

Укажите название токена, обязательно выберите Только на чтение, укажите нужные доступы, нажмите Создать токен.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/snimok-ekrana-2024-04-18-v-08.17.27.png.webp)

Скопируйте и перешли токен поддержке

## Получение токена Ozon

Перейдите на страницу доступа к API:

<https://seller.ozon.ru/app/settings/api-keys?currentTab=sellerApi>

Нажмите кнопку Сгенерировать ключ:

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/snimok-ekrana-2024-04-18-v-08.39.42.png.webp)

Введите название ключа, выберите уровень доступа Admin read only - который позволяет только просматривать данные и нажмите Сгенерировать

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/snimok-ekrana-2024-04-18-v-08.41.00.png.webp)
