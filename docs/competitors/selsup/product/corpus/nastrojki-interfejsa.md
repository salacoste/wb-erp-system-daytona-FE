# Настройка меню

В этой статье расскажем, как настроить отображение разделов в левом меню SelSup.

Чтобы открыть настройки меню, перейдите в раздел **Настройки → [Настройка меню](https://selsup.ru/application/interfaceSetup/)**[.](https://selsup.ru/application/interfaceSetup/)

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/11/screenshot_196.png.webp)

В этом разделе можно **включать и отключать отображение** отдельных разделов и подразделов в левом меню сайта. Для этого используйте переключатели рядом с названиями пунктов.

Если переключатель **включен**, раздел будет отображаться в меню.\
Если переключатель **выключен**, раздел будет скрыт.

Вы можете настроить:

- целые разделы меню,
- отдельные подразделы внутри разделов.

После внесения изменений нажмите кнопку **Сохранить**.

Настройка помогает оставить в меню только те разделы, которые нужны для работы.
