# Процент выкупа

**Процент выкупа** — это ключевой показатель эффективности, который отражает долю заказов, оплаченных и полученных покупателями, от общего числа созданных заказов. Он помогает оценить, насколько успешно товары проходят весь путь от заказа до конечного покупателя.

## Где посмотреть процент выкупа в SelSup?

В SelSup этот показатель доступен в двух разделах, где значения могут незначительно отличаться **из-за разных принципов расчета**.

**Раздел «[Цены](https://selsup.ru/application/prices/?deleted=false&grouped=true&limit=50&onlyUnprofitable=false&onlyUnpurchased=false&query=&sortBy=TOTALORDERS)»**

- **Ozon:** данные берутся из Profit Report ([Отчет по операциям с маркетплейса](https://selsup.ru/application/profitReport/?clientOrganizationId=1&dateFrom=2025-11-02T17%3A00%3A00.000Z&dateTo=2025-11-09T16%3A59%3A59.999Z&field=ORGANIZATION&limit=100&timeZone=7)) **за всё время**.
- **Wildberries:** данные напрямую тянутся из API Wildberries (воронка продаж) **за год**.
- **Остальные маркетплейсы:** в данном разделе процент выкупа не рассчитывается.

**Отчет «[Товарная аналитика](https://selsup.ru/application/productAnalytics/?dateFrom=2025-11-02T17%3A00%3A00.000Z&dateTo=2025-11-09T16%3A59%3A59.999Z&limit=100&page=1&period=DAY&productAnalyticField=BARCODE&sortBy=MARGIN&timeZone=7)»** (раздел «Аналитика и финансы»)

- **Ozon:** учитываются данные из Profit Report только за **указанный в фильтре период**.
- **Wildberries:** берутся данные из воронки продаж SelSup за **указанный в фильтре период**.
- **Остальные маркетплейсы (Яндекс Маркет и др.):** расчет происходит на основе данных о заказах также за **указанный в фильтре промежуток времени**.

## Как рассчитывается процент выкупа?

Формула расчета зависит от маркетплейса.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

#### Wildberries (ВБ)

**Формула:**\
`% выкупа = Выкупы/ (Выкупы + Отмены)`

- **Выкуп** — это заказы, которые покупатель **получил, оплатил и окончательно оставил у себя**. Если товар был возвращён, он **не входит** в эту цифру.
- **Отмены** — это заказы, которые были аннулированы и не дошли до конечного покупателя.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

#### Ozon (Озон)

**Формула:**\
`% выкупа = Продажи / (Продажи + Возвраты)`

- **Важная особенность:** Мы анализируем данные по каждому **отправлению**. Если по конкретному отправлению был зафиксирован возврат, то в расчетах оно учитывается **только как возврат**, даже если изначально была проведена операция продажи. Таким образом, каждое отправление имеет единственный итоговый статус: либо продажа, либо возврат.
- SelSup учитывает возвраты и отмены, объединяя их по всем размерам одной модели. Исключение составляют отмены, сделанные сразу после оформления заказа, до момента его отправки в пункт выдачи — такие случаи не включаются в расчет, поскольку по ним не было транзакций.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

#### Все остальные маркетплейсы (Яндекс Маркет, AliExpress и др.)

**Формула:**\
`% выкупа = Завершенные заказы / (Завершенные заказы + Возвраты + Отмены)`

## Почему значения в «Ценах» и «Товарной аналитике» могут отличаться?

Разница возникает по двум причинам:

1.  **Разный период расчета:** В разделе «Цены» отображается показатель за всё время, а в «Товарной аналитике» — только за выбранный вами период.
2.  **Разные алгоритмы расчета:** Для формирования отчета «Товарная аналитика» применяются фильтры, которые могут учитывать данные иначе, чем в разделе «Цены».

**Регулярный мониторинг этого показателя помогает своевременно выявлять проблемы (например, с качеством товара или его описанием) и повышать общую эффективность продаж.**
