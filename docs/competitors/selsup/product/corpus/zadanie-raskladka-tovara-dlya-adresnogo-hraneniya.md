# Задание «Раскладка товара» для адресного хранения

Задание «Раскладка товара» предназначено для перемещения товаров, находящихся в ячейке для неразмещенных позиций, на их постоянные места хранения.

## Формирование списка товаров для раскладки

Если при создании приемки товаров не была указана ячейка хранения, товары автоматически помещаются в **ячейку для неразмещенных товаров**. Адрес этой ячейки можно задать в разделе **«Склад» → «[Склады](https://selsup.ru/application/warehouses/)»**, выбрав нужный склад и указав ее в настройках.

## Процесс работы с заданием

- Перейдите в раздел **«Задания»** и выберите **«[Раскладка товаров](https://selsup.ru/application/task/productLayoutTask)»**.
- Для начала работы отсканируйте штрихкод товара или выберите его из списка.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_22.png.webp)

- Выберите товар из списка (по умолчанию предложено 5 шт. товара) или отсканируйте штрих-код нужного товара.
- Затем отсканируйте штрихкод новой ячейки хранения или выберите ее из списка.
- Укажите количество товара для перемещения.
- Нажмите кнопку "Переместить".

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/11/screenshot_25-1.png.webp)

После подтверждения операция перемещения будет выполнена, а товар получит новый адрес хранения на складе.

## Основные случаи использования задания

- **Систематизация хранения:** Позволяет содержать склад в порядке, оперативно распределяя вновь поступившие товары.

- **Работа с неразмещенными позициями:** Все товары, принятые без указания ячейки, автоматически собираются в одном месте для последующей обработки.

- **Процесс перемещения:** Четкий пошаговый сценарий гарантирует безошибочное выполнение операции.
