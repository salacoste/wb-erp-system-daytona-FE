# Работа с рич-контентом на маркетплейсах через SelSup

При работе с карточками товаров на маркетплейсах многие продавцы сталкиваются с необходимостью передачи Rich-контента (дополнительных медиаматериалов, описаний, инструкций и т.д.). Однако здесь есть важные нюансы, которые зависят от платформы. Разберемся, как обстоят дела на Wildberries и Ozon.

### Wildberries

На Wildberries передача Rich-контента через API **невозможна**. Платформа не предоставляет технической возможности для интеграции дополнительных медиаматериалов или структурированных данных через API. Это означает, что все элементы Rich-контента необходимо добавлять вручную через личный кабинет.

### Ozon

В отличие от Wildberries, Ozon позволяет заполнять параметры Rich-контента напрямую через API при создании или обновлении карточки товара. Данные передаются в формате JSON, что позволяет автоматизировать процесс и массово обновлять карточки без ручного вмешательства.

### Копирование карточек конкурентов

Если вы используете [функцию копирования](../kopirovanie-kartochek-konkurentov/index.html) карточек конкурентов для ускорения заполнения, стоит учитывать важное ограничение:\
**рич-контент конкурентов скопировать невозможно**. В новую карточку переносится только базовая информация — характеристики, название, описание.

Работая через SelSup, вы экономите время на создании и управлении карточками, а значит можете сосредоточиться на том, что действительно повышает продажи — качественном рич-контенте и конкурентных преимуществах вашего товара.
