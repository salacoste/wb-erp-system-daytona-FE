# Импорт товаров из inSales

Для импорта товаров из inSales после настройки [интеграции,](../integratsiya-s-insales/index.html) выполните следующие шаги:

1.  Перейдите в раздел [**Товары — Импорт товаров**](https://selsup.ru/application/productsImport/) и выберите вкладку **inSales**.
2.  Выберите организацию, для которой нужно выполнить импорт, и нажмите **Импортировать товары сервиса inSales**.
3.  Если нужно импортировать товары для всех организаций — нажмите **Для всех организаций**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/04/screenshot_8.png.webp)

После запуска процесса:

- Результаты импорта отобразятся ниже на странице.
- В случае ошибок они появятся в таблице **Ошибки импорта** — там можно посмотреть причины и внести необходимые исправления, подробней в [статье](../vozmozhnye-oshibki-pri-importe-kartochek-iz-marketplejsov/index.html).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/04/screenshot_10.png.webp)

Импортированные товары появятся в разделе [**Товары**](https://selsup.ru/application/products) в общей таблице. Убедитесь, что:

- Новые позиции объединились с существующими карточками аналогичных товаров с других маркетплейсов.

Если карточки не были объединены или объединение выполнено некорректно — выполните корректировку вручную. Подробнее об объединении карточек читайте [в статье ](../merge/index.html).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/04/screenshot_12.png.webp)

InSales технически не поддерживает передачу артикула из поля «Артикул»
