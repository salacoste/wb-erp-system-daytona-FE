# Как импортируются карточки из Wildberries

В данной статье вы найдете описание того, как SelSup импортирует товары с маркетплейса Wildberries. Это позволит вам понимать, почему те или иные карточки объединились, а какие-то нет.

## Уровни карточек в SelSup

В SelSup карточки могут разделяться на три уровня:

1.  **Модель**
2.  **Цвет** (либо визуальное отличие товара в одной модели)
3.  **Размер**

Есть категории, в которых вы практически не заметите этих уровней, так как в них нет разделения по цвету или размеру. Это настраивается в категории, и по умолчанию при импорте SelSup считает, что по цвету разделяются только категории "Одежда" и "Обувь".

## Процесс импорта карточки

1.  **Поиск существующего товара**:
    - Самым первым шагом для импорта карточки является поиск уже существующего товара по **штрих-коду**.
    - Если товар находится, SelSup всегда обновляет связь Wildberries у этого товара, а не пытается создавать новый.
    - У Wildberries используется **Артикул Wildberries**, который SelSup тоже проверяет на наличие. SelSup не будет создавать новый цвет, если удается найти существующий по артикулу Wildberries.
2.  **Создание карточки**:
    - Если по штрих-коду и артикулу не удалось найти товар, SelSup начинает создание карточки.
    - В качестве артикула модели SelSup ставит **идентификатор IMT Wildberries** (не путайте с номером номенклатуры — это совершенно разные идентификаторы).
      - Значение IMT используется для объединения разных цветов в одну модель у Wildberries, но он не виден практически нигде в интерфейсе Wildberries.
      - Ранее артикул модели можно было заполнить на Wildberries, но при переходе на новое API они убрали этот артикул, объединив его с артикулом цвета.
3.  **Определение цвета**:
    - В качестве **Цвета** SelSup подставляет **Артикул Wildberries**, чтобы потом можно было выбрать из него часть, которая относится именно к цвету.
