# Сбор СПП товаров через расширение SelSup

В этой статье расскажем, как собирать СПП товаров через расширение SelSup.

Сбор СПП помогает получать актуальные данные из личного кабинета Wildberries и использовать их в SelSup без ручного переноса. После запуска данные будут доступны в нужных разделах SelSup и помогут быстрее анализировать товары.

## Чем полезен сбор СПП

Сбор СПП помогает получать актуальные данные о скидке постоянного покупателя по товарам Wildberries и использовать их в SelSup для анализа.

Это полезно, чтобы:

- видеть актуальные данные по СПП без ручной проверки в кабинете Wildberries;
- использовать их в отчётах SelSup;
- быстрее анализировать цены и скидки по товарам;
- принимать решения по товарам на основе более полной информации.

## Что нужно для работы

Перед началом убедитесь, что:

1.  Установлено **расширение SelSup для браузера** по [ссылке](https://chromewebstore.google.com/detail/selsup/hfmbddfdicohkiacmfbanlkelblackeo?hl=ru).
2.  Выполнена **авторизация в расширении** через логин и пароль от аккаунта SelSup. Как авторизоваться в расширении, рассказали в [инструкции](../nastrojka-integratsii-rasshireniya-selsup-dlya-ai-findir/index.html).
3.  В SelSup настроена **интеграция с маркетплейсом** по API. Инструкции по настройке интеграций с маркетплейсами находятся в [разделе](../../help_cat/integratsii-s-marketplejsami-i-servisami/index.html).
4.  В SelSup уже **есть товары**. Общая инструкция по импорту товаров доступна в [статье](../import/index.html).

## Как запустить сбор СПП

- Откройте расширение и нажмите Собрать СПП.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/04/chrome_bljcha3p4t.png.webp)

После этого откроется раздел Цены и скидки в личном кабинете Wildberries: <a href="https://seller.wildberries.ru/discount-and-prices" data-magic="link">https://seller.wildberries.ru/discount-and-prices</a> и начнется сбор данных.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Где посмотреть результат

После завершения процесса данные по СПП отобразятся:

- в отчёте [**Рука на Пульсе.**](https://selsup.ru/application/productPulseReport/) Подробней об отчете в [отдельной статье](../ruka-na-pulse-po-tovarno/index.html).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/04/browser_whi9vwpui8-1.png.webp)

- в разделе [**Цены и Акции.**](https://selsup.ru/application/prices/groupPrices/?createdIn=WILDBERRIES&deleted=false&grouped=true&limit=50&query=&sortBy=TOTALORDERS) Подробней о данном разделе в [статье](../prices/index.html).

## Почему это удобно

Без расширения для такой проверки пришлось бы вручную открывать раздел **Цены и скидки** в личном кабинете Wildberries и сверять данные по каждому товару отдельно. Если товаров много, это занимает много времени.

Расширение SelSup делает этот процесс удобнее: оно помогает быстро собрать данные по СПП, использовать их в SelSup для анализа и работать с актуальной информацией без ручного переноса.

Все **возможности работы расширения SelSup **описаны в [статье](../vozmozhnosti-raboty-rasshireniya/index.html).
