В модуле **«Умный склад»** появилась новая функция, которая поможет селлерам защититься от **снижения СПП** и избежать **риска аут оф сток** на Wildberries.

Теперь, когда **остаток по FBO достигает нуля или заданного минимального порога**, система автоматически начинает передавать остаток **FBS** на маркетплейс.

Вы можете выбрать один из двух способов передачи остатков:

## Передача FBS при достижении минимального порога FBO

**Шаг 1:** Перейдите в [**Настройки → Мои организации**.](https://selsup.ru/application/organizations/)

**Шаг 2:** Прокрутите таблицу вправо, где находятся столбцы **"Установить минимальный порог остатков на FBO"**.

**Шаг 3:** Укажите минимальный порог остатков для одного или нескольких маркетплейсов таких как **ЯндексМаркет, Wildberries, Ozon** и нажмите **Сохранить**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2025/03/screenshot_192.png.webp)

После сохранения остаток FBS будет передаваться как **0**, **пока остаток FBO не преодолеет указанный минимальный порог**.\
При преодолении порога остаток FBS начнёт передаваться. Например, если минимальный порог равен **2**, остаток по FBS начнёт передаваться, когда остаток FBO станет **1**.

При работе с данными Яндекс Маркета важно учитывать: если в вашем аккаунте большое количество товаров или заказов, функция может быть временно недоступна из-за превышения лимитов платформы. В этом случае вы увидите ошибку 400 «Превышен лимит запросов». Это ограничение со стороны Яндекс, а не нашей системы.

## Как это работает и как часто обновляются остатки

Когда происходит обновление остатков FBS, мы проверяем остаток FBO:\
- Если есть остаток FBO, то по FBS отправляется 0.\
- Если нет остатка FBO, то отправляется остаток FBS, который на складе

Автоматическое обновление остатков на маркетплейсах происходит в следующих случаях:

- по конкретному товару при поступлении нового заказа, если включена настройка «Синхронизировать остатки»
- по конкретному товару при изменении остатка, например после приёмки, списания, отгрузки на FBO или ручного обновления остатка
- по всем товарам один раз в день **при автоматическом ночном запуске** «Импорт с обновлением остатков» **в 00:00 по МСК**. При необходимости его можно запустить вручную в разделе «Заказы на отгрузку → Со своего склада FBS», как описано выше
- при обновлении остатков через дропшиппинг, прайс-листы или сторонние сервисы по API

**Важно**: только при запуске **«Импорт с обновлением остатков»** обновляются остатки по всем товарам из базы.

## Зачем это нужно?

✅ Предотвращает **снижение СПП** на Wildberries\
✅ Минимизирует **риск аут оф сток**\
✅ Помогает **оптимизировать запасы**\
✅ Дает **гибкость в управлении остатками**
