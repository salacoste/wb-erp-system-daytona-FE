## Зачем нужен свой каталог категорий?

Создание собственного каталога категорий особенно актуально для тех, кто работает сразу с несколькими маркетплейсами. В SelSup пользователи могут сформировать свой справочник категорий, который объединяет все нужные категории с разных платформ. Это позволяет:

- создавать карточки товаров одновременно на всех маркетплейсах;
- проводить анализ продаж по маркетплейсам;
- легко сравнивать показатели по категориям.

Каталог категорий помогает эффективнее управлять ассортиментом: выставлять скидки, анализировать продажи и актуализировать данные по конкретным группам товаров. Например, если вы продаете верхнюю одежду, можно выделить в каталоге отдельные категории для демисезонных курток, зимних курток и ветровок. На маркетплейсах нет категории для «демисезонных курток» или «зимних курток», так как классификация по сезонам не предусмотрена. Но, благодаря собственному каталогу, вы сможете выделить демисезонные куртки в отдельную категорию и:

- установить для них нужные скидки;
- провести анализ продаж по сезонности;
- сравнить результаты продаж за текущий и предыдущий годы.

Вы можете создавать любые категории, которые вам понадобятся: куртки с капюшоном и без, из кожи и кожзаменителя, с карманами и без — полный контроль над каталогом остается за вами.

## Дополнительные преимущества создания своего каталога

Мы знаем, как важно экономить ваше время, и SelSup разработан для продавцов с большим количеством товарных карточек. Возможность создания каталога категорий ускоряет процесс работы с маркетплейсами в несколько раз. Более того, на этапе создания категории предусмотрена функция автоматического добавления общих параметров для всех товаров в выбранной категории. Вы можете задать единые параметры для товаров внутри категории — например, «Уход за вещами» или другие данные, которые будут автоматически проставляться для всех карточек категории.\

## Виды каталога товаров

Создание собственного каталога в SelSup гибкое — он не обязательно должен быть сложной иерархией с множеством подкатегорий. Вы можете добавить только те категории, которые действительно нужны вашему бизнесу.

Если вы, к примеру, продаете только куртки, вам достаточно создать категории «куртки зимние» и «куртки демисезонные». Если же ассортимент включает разные виды одежды, будет логично создать родительскую категорию «Куртки» с подкатегориями «зимние» и «демисезонные». Можно выделить категории еще глубже — например, в «зимние куртки» добавить дочерние категории «с капюшоном» и «без капюшона».

## Создание категории товара

Для создания категории перейдите в раздел [Товары- Категории](https://selsup.ru/application/categories/), нажмите **Добавить категорию**:\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/12/screenshot_49.png.webp)

Появится окно добавления категории. На примере создания иерархичного каталога разберем, как создать родительскую категорию. Например, вам нужно создать категорию **Куртки**. Укажите название категории (в данном случае — «Куртки»), выберите категории маркетплейсов Wildberries и Ozon, код ТНВЭД и тип категории.

**Код ТНВЭД** — это уникальный номер для каждого товара, который зависит от его характеристик. Этот код позволяет определить:

- какие документы нужны для реализации товара,
- требуется ли маркировка,
- как будут рассчитаны таможенные платежи при импорте.

Начните вводить в поле ТНВЭД название товара, и система предложит варианты, соответствующие вашей категории. Например, если вы вводите **Куртки**, появятся коды, разделенные по половозрастным категориям (мужские, женские, детские) и материалам, из которых изготовлена куртка. Выберите подходящий код.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/12/kategoriya.png.webp)

 

После выбора кода ТНВЭД вы увидите информацию о том, какой документ требуется для продажи товара (например, декларация соответствия, сертификат или отказное письмо).

Выберите маркируются товары или нет, также SelSup определит это автоматически на основе выбранного кода ТНВЭД. Нажмите **Сохранить**.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/12/tnved.png.webp)

Категории маркетплейсов Ozon и Wildberries отличаются, и создание своего каталога позволяет вам анализировать продажи в разных разрезах. Например, вы хотите добавить категорию «Куртки зимние» как подкатегорию «Курток».

Снова нажмите **Добавить категорию** и заполните поля:

- Укажите название категории — «Куртки зимние»,
- В поле «Родительская категория» выберите «Куртки» из списка.

Остальные данные будут заполнены автоматически. Нажмите **Сохранить**, и новая подкатегория будет добавлена к каталогу.

Весь созданный каталог категорий товаров доступен в разделе [Товары- Категории](https://selsup.ru/application/categories/).
