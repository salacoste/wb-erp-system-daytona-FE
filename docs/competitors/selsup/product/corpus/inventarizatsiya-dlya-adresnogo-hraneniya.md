# Инвентаризация для адресного хранения

В этой статье расскажем, как провести инвентаризацию на своем складе для адресного хранения по ячейкам.

## Задания - Инвентаризация

Для инвентаризации склада с адресным хранением можно воспользоваться разделом [Задания - Инвентаризация](https://selsup.ru/application/task/inventoryBarcode).

Инвентаризацию через задания можно проводить только при первоначальном размещении товаров по ячейкам. Если использовать Задания → Инвентаризация для нового прихода с адресным хранением, система обнулит остатки товаров, которые есть в ячейке, но отсутствуют в текущей поставке. Чтобы избежать потерь данных, для пополнения существующих ячеек используйте инвентаризацию через скад

Перейдите в раздел [Задания» — «Инвентаризация](https://selsup.ru/application/task/inventoryBarcode), выберите склад, затем нажмите **«Начать инвентаризацию»**, если она еще не была начата. Для уже созданной инвентаризации сразу нажмите на её дату (инвентаризации запущенные в разделе  [Склад - Инвентаризации](https://selsup.ru/application/inventories/) также отобразятся здесь).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/11/screenshot_165.png.webp)

После нажатия на дату откроется задание по инвентаризации товаров на складе:\
1. Отсканируйте штрих-код ячейки хранения.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/04/snimok-ekrana-2024-04-22-v-12.35.16.png.webp)\
2. Отсканируйте штрих-код товара, который лежит в данной ячейке.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/11/inventarizaciya.png.webp)Введите количество этого товара в ячейке, указав нужное значение в столбце **"Количество".**\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/11/kolichestvo.png.webp)Можно также отсканировать все товары, находящиеся в ячейке. Пока вы сканируете штрих-коды, SelSup автоматически подсчитает количество товаров.

Когда отсканируете все товары, нажмите кнопку **«‎‎Товаров больше нет‎»**‎, чтобы пометить ненайденные товары как потерянные.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/12/tovarov-bolshe-net.png.webp)Повторите процесс для всех ячеек и товаров в них.\
Инвентаризация завершена!

***Важно провести инвентаризацию для первой ячейки, даже если физически в ней нет товаров. Так как при приемке на склад все остатки записываются в первую ячейку, если в момент приемки вы не укажете ячейку для каждого товара (как это сделать, рассказали в [этой статье](../razmeshhenie-i-priemka-tovara-s-adresnym-hraneniem/index.html)). Без инвентаризации в первой ячейке есть риск задублирования остатков. Чтобы этого избежать, отсканируйте ШК ячейки, и если в ней нет товаров, нажмите "Товаров больше нет". Если товары есть, отсканируйте их ШК и укажите остаток.***

Обратите внимание, что открыть новую инвентаризацию может только сотрудник с ролями Администратор или Сотрудник склада. Другие роли не могут создавать инвентаризацию.

## Склад - Инвентаризация

Перейдите в раздел [Склад - Инвентаризации](https://selsup.ru/application/inventories/), выберите склад и нажмите на кнопку **«‎Начать инвентаризацию‎»‎.**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/11/screenshot_160.png.webp)

Сформируется файл с текущими остатками на выбранном складе. Нажмите на дату создания инвентаризации, чтобы перейти к ней.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/12/data-nachala-inventarizacii.png.webp)Так как инвентаризация проводится для склада с адресным хранением, скачайте файл с разбивкой по ячейкам, включив переключатель **«Скачивать файл с остатками с разбивкой по ячейкам хранения»**, затем нажмите **«Скачать текущие остатки товаров».**

В скачанном файле вы увидите данные о каждой единице товара, включая её местоположение на складе. В этом же файле вы сможете при необходимости изменить ячейки для каждой партии товара.

Подробнее о формате и особенностях файла рассказываем [тут](../skachat-ostatki/index.html).

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/11/screenshot_162.png.webp)

Проверьте остатки и их расположение по ячейкам, внесите нужные изменения в файл и загрузите отредактированный Excel - файл обратно в SelSup через кнопку **«‎Загрузить измененные остатки товаров‎»‎.**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/11/screenshot_163.png.webp)\
Если у вас включена галочка **«Синхронизировать остатки»‎** на странице [Мои организации](https://selsup.ru/application/organizations/), то через некоторое время SelSup обновит остатки на всех маркетплейсах. Чтобы изменения были видны сразу, перейдите в раздел [Заказы на отгрузку - Со своего склада](https://selsup.ru/application/fbsOrders/) и нажмите кнопку **«‎Импорт с обновлением остатков»**‎ (работает при включенной галочке «‎Синхронизировать остатки‎»).\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/11/screenshot_164.png.webp)

Как принять товар через Приемку, рассказали в [статье](../razmeshhenie-i-priemka-tovara-s-adresnym-hraneniem/index.html).

О том, как проводить инвентаризацию без адресного хранения, рассказываем [тут](../inventarizatsiya/index.html).
