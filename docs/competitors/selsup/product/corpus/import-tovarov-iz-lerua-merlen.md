## Импорт товаров из Лемана ПРО (Леруа)

Мы реализовали возможность импорта данных из Леруа Мерлен, которая позволяет упростить процесс работы с карточками и обновления остатков. Импорт автоматически сопоставляет товары и проставляет ID Леруа Мерлен на основе GUID.

**Как работает импорт:**

**Шаг 1**. В выгруженных данных Леруа есть **артикул поставщика** и **GUID**. Для упрощения сопоставления значение **GUID** нужно проставить равным **артикулу поставщика**.

**Шаг 2.** Далее, экспортируйте файл с **GUID** из личного кабинета Леруа:

- Перейдите на вкладку **"Товары"** в личном кабинете Леруа.
- Отметьте галочками все товары.
- В нижней части страницы нажмите кнопку **"Изменить атрибуты"**.
- Скачайте архив с файлами. В этих файлах будет содержаться **GUID товаров**.
- ![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/07/screenshot_30.png.webp)

**Шаг 4.** Перейдите в раздел [Товары,](https://selsup.ru/application/products) нажмите кнопку **"Экспорт"** и в открывшемся окне нажмите **"Выгрузить новый файл"**.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/07/tovari-lerua.png.webp)\
**Шаг 5.** В загруженном файле в столбце **"Артикул Леруа Мерлен"** укажите соответствующий GUID.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/07/screenshot_151.png.webp)

**Шаг 6.** Затем отредактированный файл загрузите обратно в SelSup, раздел [Товары - Импорт товаров - вкладка Массовое редактирование.](https://selsup.ru/application/productsImport/)

Загрузите файл в соответствующее окно без выбора маркетплейса для отправки карточек.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/07/screenshot_152.png.webp)

**Шаг 7.** После этого запустите импорт данных в Селсап  в разделе [Товары - Импорт Товаров.](https://selsup.ru/application/productsImport/leroyMerlin) Выберите организацию и нажмите  **Импортировать товары Leroy Merlin** для определенной организации или нажмите **Для всех организаций**.  Импорт автоматически проставит **ID Леруа Мерлен**  на основе указанных **GUID товаров**.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/07/screenshot_31.png.webp)\
Таким образом, карточки товаров в SelSup будут связаны с карточками товаров в Лемана ПРО. При импорте заказов SelSup будет проверять артикул и карточку товара, и если они совпадают с данными на Лемана ПРО, то заказ в SelSup создастся с этим товаром.

Также обратите внимание, что после проставления связей с карточками у товаров в SelSup не появится значок Лемана ПРО со ссылкой на карточку товара на маркетплейсе, как это происходит с другими маркетплейсами после импорта товаров.\
![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2024/07/lerua-1.png.webp)
