# Сборка заказов с ДТ (ГТД)

Если вы отправляете на маркетплейсы Ozon или Wildberries товары, для которых нужно передавать номер **ДТ** — декларации на товары, также известной как **ГТД** — грузовая таможенная декларация, в этой инструкции вы узнаете, как указать и передать номер декларации через SelSup.

## Как передать ДТ (ГТД)

**Шаг 1. Укажите номер ДТ (ГТД) в приёмке на склад**

1.  Создайте [новую приёмку на склад](https://selsup.ru/application/order/inc).
2.  Укажите способ ввода в оборот **«Импорт»**.
3.  Заполните информацию по ДТ (ГТД).
4.  Добавьте товары, которые идут с указанным номером декларации.

Номер ДТ (ГТД) можно указать один на всю приёмку — в общем блоке, или отдельно в таблице с товарами. Во втором случае можно задать разные номера ДТ (ГТД) для разных товаров.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/12/gtd-1-1024x228.png.webp)

**Шаг 2. Оприходуйте товары на склад**

Сохраните приёмку на склад и нажмите **«Оприходовать»**. После этого остатки товаров будут приняты на склад, а у остатков сохранится номер ДТ (ГТД) из приёмки.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/12/screenshot_51-1024x503.png.webp)

**Как номер ДТ (ГТД) передаётся на маркетплейс:**

Когда поступит новый FBS-заказ и остатки товара будут зарезервированы под заказ, при сборке заказа SelSup автоматически отправит в заказ Ozon или Wildberries номер ДТ (ГТД).

Номер берётся из остатков зарезервированного товара: какой номер ДТ (ГТД) указан в остатке на складе, такой номер будет передан на маркетплейс.

## Как массово указать номер ДТ (ГТД) через Excel

Номер ДТ (ГТД) также можно массово заполнить через Excel в разделе [Склад → Инвентаризация](https://selsup.ru/application/inventories/).

**Чтобы массово заполнить номер ДТ (ГТД):**

1.  Перейдите в раздел [**Склад → Инвентаризация**](https://selsup.ru/application/inventories/).
2.  Перед скачиванием файла включите тумблер **«Выводить номер ГТД»**.
3.  Скачайте текущие остатки товаров.
4.  Заполните или измените столбец **ГТД** в Excel-файле.
5.  Загрузите изменённый файл обратно в SelSup.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2021/12/2026.05.29_chrome_j9y6.png.webp)

После загрузки файла номер ДТ (ГТД) сохранится в остатках на складе и будет использоваться при передаче данных в заказах.
