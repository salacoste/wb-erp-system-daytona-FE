# Сбор данных для воронки продаж через расширение SelSup

В этой статье расскажем, как загружать данные для отчёта «Воронка продаж» через расширение SelSup.

Сбор данных помогает получать показатели из личного кабинета Wildberries и использовать их в SelSup без ручного переноса. После завершения загрузки данные будут доступны в отчёте «Воронка продаж» и помогут быстрее анализировать эффективность товаров.

## Чем полезна загрузка данных для воронки продаж

Загрузка данных для воронки продаж помогает получать актуальные показатели по товарам Wildberries и использовать их в SelSup для анализа.

Сейчас в воронку продаж через расширение можно загрузить показатели: CTR и показы.

Эти данные доступны только при подключённой подписке «Джем» на Wildberries. Без неё Wildberries не показывает эти параметры.

Это полезно, чтобы:

- видеть актуальные показатели без ручной проверки в кабинете Wildberries;
- использовать их в отчёте «Воронка продаж»;
- быстрее анализировать эффективность карточек товаров;
- принимать решения на основе более полной информации.

## Что нужно для работы

Перед началом убедитесь, что:

1.  Установлено **расширение SelSup для браузера** по [ссылке](https://chromewebstore.google.com/detail/selsup/hfmbddfdicohkiacmfbanlkelblackeo?hl=ru).
2.  Выполнена **авторизация в расширении** через логин и пароль от аккаунта SelSup. Как авторизоваться в расширении, рассказали в [инструкции](../nastrojka-integratsii-rasshireniya-selsup-dlya-ai-findir/index.html).
3.  В SelSup настроена **интеграция с маркетплейсом** по API. Инструкции по настройке интеграций с маркетплейсами находятся в [разделе](../../help_cat/integratsii-s-marketplejsami-i-servisami/index.html).
4.  В SelSup уже **есть товары**. Общая инструкция по импорту товаров доступна в [статье](../import/index.html).
5.  Подключена подписка «Джем» на Wildberries, иначе данные по CTR и показам будут недоступны.

## Как запустить сбор данных

1.  Нажмите на расширение и откройте настройки.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/04/grjm5swl7n.png.webp)

2\. Выберите одну или несколько организаций в SelSup, по которым нужно загружать данные и укажите начальную дату периода для анализа воронки.

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/04/image-12.png.webp)

3\. Откройте расширение и нажмите **Обновить данные воронки продаж.**

![](../../out/selsup.ru/_kage/selsup.ru/wp-content/webp-express/webp-images/uploads/2026/04/giars0vrko.png.webp)

После запуска в браузере в фоновом режиме откроется вкладка «Аналитика» в личном кабинете Wildberries, и расширение начнёт обрабатывать информацию на странице.

Во время сбора данных вы можете переключиться на другую вкладку и продолжать работу, но не взаимодействуйте со страницей, на которой работает расширение. Если нажимать кнопки или менять данные на этой странице, процесс может завершиться с ошибкой, и его придётся запускать заново.

## Где посмотреть результат

После завершения процесса данные по CTR и показам будут доступны в отчёте [**«Воронка продаж»**](https://selsup.ru/application/salesFunnel/?dateFrom=2026-03-22T17%3A00%3A00.000Z&dateTo=2026-03-29T16%3A59%3A59.999Z&limit=50&organizationId=101937&service=WILDBERRIES&timezone=7) в SelSup.

Подробней о данном отчете в [статье](../voronka_prodazh/index.html).

## Почему это удобно

Без расширения для такой проверки пришлось бы вручную открывать раздел аналитики в личном кабинете Wildberries и переносить показатели отдельно. Если товаров много, это занимает много времени.

Расширение SelSup делает этот процесс удобнее: оно помогает быстро собрать данные по CTR и показам, использовать их в отчёте «Воронка продаж» и работать с актуальной информацией без ручного переноса.
