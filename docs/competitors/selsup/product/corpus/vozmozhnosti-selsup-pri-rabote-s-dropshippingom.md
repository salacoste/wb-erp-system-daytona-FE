# Возможности SelSup при работе с дропшиппингом

В этой статье расскажем обо всех возможностях, которые предлагает Selsup при работе с дропшиппингом, как их можно применить и упростить свою работу.

- <a href="#zakupki-iz-zakazov-v-selsup" rel="nofollow">Закупки из заказов в SelSup</a>

В SelSup поддерживаются различные способы интеграции для обновления остатков и цен при работе по модели дропшиппинга:

- **Электронная почта** — SelSup автоматически заходит на указанный почтовый ящик, обрабатывает входящие письма и извлекает данные. Рекомендуем использовать отдельный почтовый ящик.
- **YML** — автоматическая обработка YML-файла по ссылке. Удобно при наличии YML-фида от поставщика.
- **Excel** — загрузка и обработка Excel-файла по ссылке. Подходит для стандартных табличных файлов формата .xlsx.
- **JSON API / API Core** — если остатки передаются через API Core.
- **API** — требуется индивидуальная разработка. Напишите в чат технической поддержки или менеджеру для расчета стоимости.
- **Sima-Land** — прямая API-интеграция с личным кабинетом Sima-Land для автоматической синхронизации остатков и цен.

## Возможности SelSup при работе с дропшиппингом

- Регулярный обмен с данными поставщиками: остатки, цены;
- Онлайн-обновление остатков на маркетплейсах;
- Обнуление остатков, если товар пропал из прайс-листа;
- Создание заказа поставщику;
- Создание товаров из yml;
- Формирование списков товаров для закупщиков.

## Регулярный обмен в SelSup

SelSup регулярно проверяет данные поставщиков, автоматически обрабатывает их и передаёт обновлённые остатки и цены на маркетплейсы.

Регулярный обмен помогает сократить время на сверку прайс-листов и снизить риск ошибок при продажах. Если SelSup обнаружит, что товар закончился у поставщика, остатки на маркетплейсах могут быть автоматически обнулены. Это помогает избежать заказов на товары, которых уже нет в наличии.

Перед настройкой регулярного обмена рекомендуем ознакомиться с общими параметрами: как выбрать организацию, маркетплейс, склад, способ обновления и правила передачи остатков. Подробнее — [в статье **«Регулярный обмен ценами и остатками: общие настройки»**.](../regulyarnyj-obmen-tsenami-i-ostatkami-obshhie-nastrojki/index.html)

Для регулярного обмена можно использовать разные способы передачи данных:

- **Электронная почта** — если поставщик отправляет файл с ценами и остатками на почтовый ящик. Подробнее — [в статье **«Регулярный обмен через электронную почту»**.](../regulyarnyj-obmen-cherez-elektronnuyu-pochtu/index.html)
- **Excel по ссылке** — если поставщик размещает Excel-файл по прямой ссылке. Подробнее — [в статье **«Регулярный обмен ценами и остатками через Excel»**.](../regulyarnyj-obmen-tsenami-i-ostatkami-cherez-excel/index.html)
- **YML** — если поставщик передаёт данные через YML-файл по ссылке. Подробнее — [в статье **«Регулярный обмен ценами и остатками через YML»**.](../regulyarnyj-obmen-tsenami-i-ostatkami-cherez-yml/index.html)
- **JSON API (API Core)** — если остатки поставщика загружаются через API Core. Подробнее — [в статье **«Регулярный обмен остатками через JSON API (API Core)»**.](../regulyarnyj-obmen-ostatkami-cherez-json-api-api-core/index.html)

Если нужно загрузить или обновить данные из прайс-листа поставщика вручную, используйте [инструкцию **«Прайс-листы поставщиков для обновления остатков и цен на маркетплейсах»**.](../prajs-listy-postavshhikov-dlya-obnovleniya-ostatkov-i-tsen-na-marketplejsah/index.html)

## Создание карточек в SelSup

В SelSup реализована возможность создавать карточки товаров на маркетплейсе. Если в прайс-листе вашего поставщика появился новый товар, SelSup создаст его у себя. Чтобы импортировать товары из прайс-листов, используйте функцию **Импорт товаров из YML** **файлов**. Подробно о том, как это сделать, рассказали в данной [**статье.**](../import-tovarov-iz-yml-fajlov/index.html)

## Закупки из заказов в SelSup

Возможность закупки из заказов позволяет вам закупать товары в момент, когда приходит заказ от покупателя, затем сразу собирать и отправлять заказ. При этом вы можете использовать склад с собственными остатками. Подробнее о функции закупки из заказов рассказали в данной [**статье**](../zakupki-iz-zakazov/index.html).\
Вы можете создать закупку для поставщиков и отправить заказы напрямую поставщикам.

В едином окне SelSup вы сможете увидеть товары, остатки, цены, сколько времени прошло с момента заказа товара.

Для торговли на маркетплейсах необязательно иметь собственный склад. SelSup поможет вам организовать дропшиппинг с нуля или автоматизировать выстроенные процессы.
