# inSales. Возможности интеграции

Интеграция inSales с SelSup помогает автоматизировать ключевые процессы интернет-магазина и ускоряет рутинные задачи:

- Импорт товаров – загружайте карточки в SelSup.
- Единое управление карточками для всех маркетплейсов
- Синхронизация остатков в реальном времени.
- Работа по схеме FBS (отправка заказов со своего склада)

## Управление карточками через Selsup

SelSup предлагает мощный модуль [PIM-система](../../help_cat/rabota-s-kartochkami-tovarov/index.html) для:

- централизованного создания карточек

- работы с медиафайлами

- разграничения прав пользователей

- экспорта карточек на разные площадки

API inSales не позволяет редактировать карточки напрямую, но вы можете импортировать их в SelSup и публиковать на другие маркетплейсы. Как это сделать, подробно описано в [статье](../perenos-kartochek/index.html).

## Работа по FBS

Данный функционал реализован в **Модуле Умный склад. **Он обеспечивает синхронизацию, сборку и маршрутизацию товаров, интеграцию со службами доставки, видеофиксацию для защиты от потребительского терроризма, адресное хранение остатков. Подробнее о возможностях модуля читайте [здесь](../../help_cat/modul-umnyj-sklad/index.html).

Важно! Без настройки мультисклада в личном кабинете inSales остатки не будут синхронизироваться.

**Как это работает?**

- Настраиваете мультисклад в inSales. Как подключить мультисклад описано в [инструкции](https://www.insales.ru/collection/doc-products/product/multisklad-hranenie-ostatkov-na-raznyh-skladah).
- Связываете склады в Селсап со складом inSales для синхронизации остатков. Подробней в [инструкции](../perenos-ostatkov/index.html)
- Работа по FBS c inSales не отличается от работы по FBS c другими маркетплейсами. [Подробнее тут.](../sborka-fbs/index.html)
- Для автоматической печати стикеров потребуется интеграция со службой доставки [СДЭК](../sdek/index.html), [Почта России](../vozmozhnosti-integratsii-s-pochtoj-rossii/index.html). Данные интеграции также доступны для подключения в SelSup.

## Передача цен из SelSup

**Можно передавать цену в inSales из карточки товара из поля "Цена со скидкой"**

Для этого должны быть выполнены следующие условия:

1.  **Настроена интеграция с Ozon**

2.  **Цены отправляются только вместе с отправкой остатков**

После настройки интеграции при каждом обновлении остатков в inSales будет автоматически передаваться цена из поля "Цена со скидкой".

## Как бренд косметики вышел на Wildberries и Ozon за неделю

**Компания:** *BeautyLine* (натуральная косметика, сайт на inSales)

**Проблема:**

- Все карточки создавались вручную для каждого маркетплейса.

- Часто возникали ошибки в ценах и описаниях.

- Не хватало времени на контроль остатков.

**Решение:**

- Импортировали все карточки из inSales в SelSup.
- Настроили экспорт на Wildberries и Ozon.
- Подключили автоматическую синхронизацию остатков.

**Результат:**

+2 новых маркетплейса за 7 дней.

-70% ошибок в карточках.

3 часа в день сэкономлено на рутине.

## Почему SelSup — лучшее решение для inSales

**Экономия времени** – больше не нужно вручную вносить товары и остатки.\
**Минимум ошибок** – автоматическая синхронизация данных.\
**Готовность к масштабированию** – интеграция с PIM и службами доставки.
