# Аналитика по складам

В этой статье расскажем расскажем Вам о разделе **Аналитика по складам**, какую информацию можно увидеть данном разделе, и как он может Вам помочь.

- <a href="#interfejs-razdela" rel="nofollow">Интерфейс раздела</a>

Чтобы увидеть аналитику по складам, перейдите в раздел **Склад** - **Склады** вкладка [**Аналитика**](https://selsup.ru/application/warehouses/analytics).

## Для чего нужен данный раздел

В этом разделе вы сможете увидеть суммарную информацию по остаткам, товарным позициям, закупочным ценам и дополнительным расходам с разбивкой по каждому складу. Благодаря данному разделу Вы будете видеть общую картину по остаткам на каждом складе и понимать с какого склада Вам приоритетнее вести продажи.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## В каких случаях склад попадает в раздел Аналитика

Склад будет отображаться в данном разделе в том случае,  если в SelSup на нем есть остатки.

<a href="#tocmenu" class="kamatoc-gotop" rel="nofollow">Вверх <em></em></a>

## Интерфейс раздела

\- **склад** — склад, на котором есть остатки.\
- **количество позиций** — количество позиций товаров на складе.\
- **количество** — общее количество всех остатков на складе.\
- **остаток в закупочных ценах** — общая сумма в закупочных ценах всех остатков.\
- **сумма дополнительных расходов** — общая сумма дополнительных расходов по всем остаткам.
