# Маркировка, Честный Знак, этикетки и печать

## Назначение

Модуль обеспечивает сквозную работу с обязательной маркировкой товаров (Честный Знак / «ЧЗ», система МЕРКУРИЙ для ветеринарных ВСД) и печатью этикеток всех типов в SelSup. Модуль закрывает два базовых сценария: (1) коды маркировки уже получены/переданы поставщиком и их нужно хранить, резервировать, сканировать и передавать на маркетплейсы; (2) коды нужно получить через SelSup — создать карточки в Национальном каталоге, заказать коды через СУЗ, подписать ЭЦП, ввести в оборот, распечатать этикетки КИЗ+ШК, вывести из оборота. Модуль работает параллельно по схемам FBS и FBO, поддерживает агрегацию кодов (комплекты/наборы/транспортные упаковки), возвраты, обработку ошибок, передачу кодов между своими организациями, формирование УПД/УПД ДОП, а также гибкую настройку шаблонов этикеток, принтеров (через QZ Tray), штрихкодов и уникальных кодов учёта единиц товара.

## Возможности (capabilities)

1. **Хранилище кодов маркировки** — централизованное хранилище всех полученных/переданных кодов (раздел «Маркировка → Коды маркировки»), с видимостью свободных/зарезервированных кодов и их привязок к товарам, заказам, поставкам. Заменяет Excel-таблицы и исключает повторное использование кодов.
2. **Создание карточек товаров в Национальном каталоге / Честном Знаке** — карточки создаются из SelSup, подписываются ЭЦП, отправляются на модерацию и публикацию. Доступна отправка карточки в архив (удаление напрямую в ЧЗ невозможно).
3. **Получение кодов маркировки через СУЗ** — заказ кодов маркировки по товарам заказа на отгрузку/приёмки, с созданием заказа СУЗ (не более 10 позиций и отдельный заказ на каждый тип товара — единица/комплект/набор/групповая упаковка), контролем статусов «Обработан», выдачей ровно по количеству товаров.
4. **Подписание карточек и документов ЭЦП** — подписание карточек Национального каталога и документов (ввод/вывод/возврат/УПД) через подключённый сертификат ЭЦП (КриптоПро + браузер-плагин), через токен Честного Знака (действует 10 часов).
5. **Ввод кодов в оборот** — формирование и отправка документа «Ввод в оборот» с разными способами выпуска (Производство, Импорт, Маркировка остатков, Перемаркировка, Комиссия от ФЛ). Предупреждение об удалении криптохвоста после ввода.
6. **Вывод кодов из оборота** — по FBS (коды в выкупленных заказах / статусах «В пути», «Отправлен», «Завершен») и по FBO (импорт 10-го отчёта WB «Отчёт по товарам с обязательной маркировкой» — по API или Excel, с автоопределением товара, класса, даты продажи, номера чека).
7. **Возврат кодов в оборот** — для заказов в статусах «Отменен», «Отменен покупателем», «Возврат» после вывода из оборота.
8. **Отчёт о нанесении маркировки** — отдельный этап для категорий, кроме Одежды/Обуви/Парфюмерии/Шин/Электроники: сканирование нанесённых кодов, списание неиссканированных (статус «Испорченные»), либо массовое добавление всех кодов кнопкой «Добавить все», отправка отчёта в ЧЗ и смена статусов.
9. **Резервирование свободных кодов** — закрепление свободных кодов за товарами FBO-поставки/FBS-заказа, со снятием резерва (удалением связи с товаром и поставкой).
10. **Передача кодов между организациями** — формирование УПД для передачи кодов между своими организациями (по названию/ИНН); обе организации должны быть добавлены в «Мои организации»; корректное определение владельца кода по ИНН после обновления.
11. **Агрегация кодов маркировки** — три сценария: «Наборы и комплекты» (код комплекта создан в ЧЗ), агрегация комплекта в заказе (коды комплекта и комплектующих получены через заказ SelSup), задание «Агрегация» (агрегированный код создаётся в SelSup на основе позиции и GLN организации, минимум 2 вложенных кода, вводимых в оборот до агрегации).
12. **Печать кодов маркировки (КИЗ)** — печать из заказа (столбец «Маркировка», кнопка «Маркировка»), из раздела «Коды маркировки», в Ленте заказов / Умной ленте; печать длинного кода с криптохвостом — только до ввода в оборот.
13. **Повторная печать маркировки** — через задание «Возврат товара» в режиме «только печатать этикетки» (сканирование КИЗ → генерация дубликата), с настройкой «Исправлять код маркировки при обновлении» для восстановления полного КИЗ, добавленного сканированием.
14. **Передача кодов на маркетплейсы** — автоматическая отправка кодов при сканировании в заданиях «Комплектация заказов» и «Сборка заказов» (для WB, Ozon, Яндекс.Маркет, МегаМаркет), с проверкой принятия (жёлтая/серая галочка в столбце «Остатки») и повторной отправкой при ошибке.
15. **Проверка маркировки при сборке/комплектации** — тумблер «Проверять маркировку Честного знака» в заданиях; сканирование товара → запрос КИЗ → привязка к заказу; замена ошибочно отсканированного кода через повторное сканирование.
16. **Импорт маркировки из Ozon** — автоматическое получение кодов из Ozon при обновлении заказа (для ввода/вывода из оборота в SelSup).
17. **Импорт карточек и кодов из Честного Знака** — кнопка «Импортировать из Честного знака» в разделе «Коды маркировки» (в т.ч. «Нужно вывести из оборота»).
18. **Удаление/замена неверных кодов** — отметка кода статусом «Ошибочный» с исключением из документов; замена ошибочного кода в задании «Сборка заказов».
19. **Автоотслеживание смены организации кода** — при обновлении статуса код переносится в новую организацию (если она есть в SelSup) или переводится в «Ошибочный» (если организации нет).
20. **Гибкая система шаблонов этикеток** — готовые шаблоны (товарная, маркировка, ШК короба, этикетка ячейки/хранения, заказы WB/Ozon/Яндекс/МегаМаркет, ленты заказов 58×40 и 75×120, этикетка поставки, ШК поставки, видеофиксация, DBS-заказ, документы A4 и др.) + конструктор своих этикеток с объектами Текст/Штрихкод/Изображение и подстановками.
21. **Печать этикеток в один клик через QZ Tray** — прямая печать на принтер без диалогового окна, с привязкой принтера к шаблону (разные принтеры под разные форматы WB 58×40, Ozon 120×80, A4 и т.д.); fallback на PDF.
22. **Настройка количества этикеток** — «Сколько печатаем этикеток?» для Ленты заказов (по умолчанию 2: на товар + на пакет); печать по значку принтера зависит от числа нажатий.
23. **Умная лента / Лента заказов** — печать этикеток товаров совместно со стикерами заказов, с кодом маркировки, датой заказа на МП (с учётом часового пояса), объединение в единый PDF через виртуальный принтер (BullZip).
24. **Генерация штрихкодов** — 5 способов: из Национального каталога/ЧЗ, из GS1 РУС (GTIN, коды на «46…»), из маркетплейсов (WB), из диапазона, вручную; с проверкой уникальности и дублированием между организациями.
25. **Уникальные коды учёта единиц товара** — наклейки на каждую единицу для прослеживания жизненного цикла (приёмка → размещение → отгрузка → возврат); привязка к штрихкоду, коду маркировки, серийному номеру, сроку хранения, закупочной/розничной цене (тариф премиум).
26. **Этикетка видеофиксации** — дополнительная защита от потребительского терроризма/подмены; печать в FBO/FBS, в Умной ленте, при комплектации; опционально с именем сборщика.
27. **Настройка форматов этикеток FBS** — 58×40 для WB (по умолчанию), настройка 58×40 для Ozon (в ЛК Ozon) и Яндекс.Маркета (в настройках заказов SelSup), адаптация умной ленты.
28. **Настройка PDF-документов** — шаблоны листов сборки FBS/FBO/перемещений, шаблон для карго, закупка из заказа (редактируемые колонки, изображения, штрихкоды).
29. **Настройка категорий под маркировку** — ТНВЭД, тип категории (товарная группа ЧЗ), тумблер «Товары категории маркируются» (автовключение по ТНВЭД); требование одинакового ТНВЭД в категории.
30. **Управление сертификатами качества** — добавление сертификатов/деклараций (привязка к категории/бренду) для подписания КИЗ и документов; проверка номера по реестру Росаккредитации.
31. **Управление производителями** — обязательное указание ИНН производителя, совпадающего с ЧЗ и ЭЦП; создание производителей с корректным ИНН.
32. **Работа с ВСД (Меркурий)** — ручной ввод номера ВСД для маркируемых ветеринарных товаров в столбце «Номер ВСД» заказа/приёмки.
33. **Разнообразие штрихкодов на этикетке** — EAN 13, EAN 8, Code 128, QR Code, Data Matrix, GS1 Data Matrix; QR-код может шифровать ссылку.
34. **Подстановки данных на этикетке** — `${product.printName}`, `${product.view.model.title}`, `${product.view.model.laundry}` (уход за вещами), `${product.view.model.brand.logoUrl}` (логотип бренда), `${order.formattedCreatedDate}`, `${order.formattedCreatedDateTime}` и др.

## Ключевые сценарии (workflows)

### A. Подготовка к работе с Честным Знаком
1. Получить ЭЦП, установить КриптоПро + КриптоПро ЭЦП браузер-плагин.
2. Зарегистрироваться в Честном Знаке (выбор ЭЦП, e-mail, телефон).
3. Вступить в ГС1 РУС (для GTIN на «46…»): до 100 карточек бесплатно, далее 3000 ₽/год через Национальный каталог.
4. В SelSup: настроить интеграцию с ЧЗ (Интеграции → Честный знак → «Работать с Честный знак» → ввести OMS Id → «Получить идентификатор соединения» (нужен ЭЦП) → «Получить Токен» → «Проверить СУЗ»).
5. Добавить производителей и указать корректный ИНН (как в ЭЦП/ЧЗ).
6. Настроить категории: ТНВЭД, тип категории (товарная группа ЧЗ), тумблер «Товары категории маркируются».
7. Добавить сертификаты качества.
8. Настроить этикетки маркировки (58×40 или 58×80).

### B. Получение кодов маркировки (FBO и FBS, единый интерфейс)
1. Создать заказ на отгрузку «На склад маркетплейса» (FBO) или приёмку на склад (FBS): название, склад, грузополучатель/организация, способ ввода в оборот, товары. Указать номер ВСД при необходимости.
2. В заказе появляется окно этапов получения кодов маркировки.
3. Нажать «Получить маркировку» → создаётся заказ СУЗ; дождаться статуса «Обработан».
4. Нажать «Подписать карточки» (можно до или после получения маркировки).
5. Нажать «Ввести в оборот маркировку» → создаётся документ «Ввод в оборот»; подтвердить удаление криптохвоста.
6. Перейти во вкладку «Документы», нажать «Обновить статус кодов маркировки».
7. Для FBS через приёмку: после ввода в оборот — «Сохранить» → «Оприходовать» (если товар принимается на склад); если только маркировка — НЕ нажимать «Оприходовать».
8. Распечатать коды маркировки (до ввода в оборот — с криптохвостом) и наклеить.

### C. Печать кода маркировки в Ленте заказов / Умной ленте (FBS)
1. Включить «Печатать код маркировки в ленте заказов» (Настройки → Заказы).
2. В «Заказы на отгрузку → Со своего склада ФБС» выбрать заказы → «Получить маркировку» → «Зарезервировать».
3. Печать ленты заказов с кодом — только через прямой принтер (в PDF код не скачивается). Работает только при резервировании через «Заказы на отгрузку», не через «Задания».

### D. Отгрузка по FBO (товар уже промаркирован / маркируется при отгрузке)
1. «Заказы на отгрузку → На склад маркетплейса» → «Создать заказ» (название, грузополучатель, организация, склад, «Списать с остатков», товары).
2. Если товар не промаркирован — выполнить этапы получения маркировки (сценарий B), распечатать, наклеить, отгрузить.
3. Маркетплейс сканирует коды при приёмке → получить Акт приёмки / УПД ДОП из ЛК маркетплейса.
4. В SelSup: «Заказы на отгрузку → На склад МП» → «Создать из файла» → загрузить Акт WB (принятые коды брать только из Акта, не из старого УПД).
5. Из нового заказа скачать «УПД с маркировкой» (только маркированные товары) или «УПД» (все товары) → загрузить в ЭДО.
6. Привязка маркировки, полученной не через SelSup: только вручную в заказе FBO / через задание «Упаковка FBO» / «Упаковка с добавлением в заказ» (при включённой опции «Разрешить сканировать только маркировку при упаковке FBO»).

### E. Передача кодов на маркетплейс и проверка (FBS)
1. Задания → «Комплектация заказов» или «Сборка заказов».
2. Включить «Проверять маркировку Честного знака», выбрать организацию, склад, маркетплейс.
3. Сканировать штрихкод товара/заказа → SelSup запросит КИЗ → отсканировать КИЗ → автопередача на маркетплейс.
4. Проверить статус в «Заказы на отгрузку → Со своего склада» в столбце «Остатки»: жёлтая галочка — принят, серая — ошибка (повторить сканирование).

### F. Ввод/вывод/возврат в оборот из раздела «Маркировка»
1. «Маркировка → Коды маркировки», выбрать коды.
2. «Ввести в оборот» / «Вывод из оборота» / «Возврат в оборот» → создаётся документ → «Подписать» → проверить статус «Успешно».
3. Статусы кода для операций: ввод — «Нанесен», вывод — «Введен в оборот», возврат — «Выведен из оборота».
4. Вывод по FBO через импорт 10-го отчёта WB (Маркировка → Документы → «Импортировать документ»).

### G. Агрегация кодов
1. **«Наборы и комплекты»** (код создан в ЧЗ): задание «Наборы и комплекты» или вкладка «Агрегация» в заказе → отсканировать код комплекта → отсканировать коды составных единиц → подписать → отправка в ЧЗ.
2. **Агрегация комплекта в заказе**: карточка товара тип «Комплект» + состав комплекта + GTIN комплектующих → добавить в заказ → получить маркировку (комплект + комплектующие) → в заказе «Агрегация» → «Агрегировать комплекты» → подписать документ. В оборот вводятся только комплектующие; комплект вводит ЧЗ автоматически.
3. **Задание «Агрегация»** (код создаётся в SelSup): Маркировка → Агрегация → выбрать товар-упаковку → указать первые 7 цифр GLN → отсканировать ≥2 кодов → «Агрегировать» → печать кода.

### H. Возврат товара с маркировкой
1. Задания → «Возврат товара».
2. Найти заказ одним из способов: (1) сканирование стикера заказа (QR/ШК) — рекомендуется; (2) сканирование штрихкода товара → выбор заказа из списка; (3) сканирование КИЗ/DataMatrix.
3. Нажать «Возврат получен» → автозврат остатков на склад.
4. Альтернатива: «Заказы на отгрузку → Со своего склада» → фильтр Статус = «Возврат» → «Возврат получен и вернуть остатки на склад».

### I. Повторная печать маркировки (товар от поставщика без PDF)
1. Настроить интеграцию с ЧЗ, QZ Tray, шаблон «Маркировка Честный знак», связать карточки по GTIN.
2. Настройки → Заказы → включить «В задании 'Возврат товара' только печатать этикетки».
3. Задания → «Возврат товара» → поставить «Маркировка Честный ЗНАК».
4. Отсканировать маркировку с товара → дубликат этикетки; код добавляется в кабинет.
5. При необходимости включить «Исправлять код маркировки при обновлении» (Настройки → Общие) для восстановления полного КИЗ, добавленного сканированием.

### J. Настройка и печать этикеток
1. Настройки → Этикетки: выбрать/добавить шаблоны, задать принтер для каждого (QZ Tray установлен), «Сколько печатаем этикеток?».
2. Редактировать шаблон: объекты Текст/Штрихкод/Изображение, подстановки, шрифт, размер, перенос строк, отступы, условие, превью.
3. Печать из: Товары, Заказы FBS, Заказы FBO, Приёмки, Лента заказов, значки принтера по сервису.
4. Умная лента: Настройки → Заказы → «Печатать этикетку товара»; для PDF — BullZip + «Объединить».
5. Этикетка видеофиксации: добавить шаблон, Настройки → FBS-заказы → «Печатать этикетку о видеофиксации» (или тумблер в Комплектации).

### K. Уникальные коды (адресное хранение)
1. Приёмки → Создать поступление → добавить товар, количество → «Уникальные коды» → печать файла → наклеить.
2. Задание «Размещение»: сканировать уникальный код → ШК товара (если не связан) → ШК ячейки.
3. Задание «Привязать код к товару» (исправление ошибки привязки).
4. Задание «Отметить собранные» (если собирали вне SelSup).

## Сущности (entities)

- **Код маркировки (КИЗ / DataMatrix)**: атрибуты — значение кода (короткое/длинное с криптохвостом), GTIN (извлекается, между (01) и (21)), серийный номер, криптохвосты (после 91/92), статус (Создан, Получен, Нанесён, Введён в оборот, Выведен из оборота, Передан, Списан, Выбыл, Ошибочный), тип (Единица/Комплект/Групповая упаковка/Набор), организация-владелец (ИНН), привязка к товару/заказу/поставке, срок годности, способ эмиссии/выпуска.
- **Документ маркировки**: тип (Ввод в оборот, Вывод из оборота, Отмена кода, Возврат в оборот, УПД, УПД ДОП, Отчёт о нанесении), статус (Создан, Принят, Успешно, Ошибка), номер, дата продажи, номер чека, организация, связь с кодами.
- **Заказ СУЗ**: идентификатор, статус (Обработан и др.), товары/типы, не более 10 позиций, причина ошибки.
- **Карточка Национального каталога / ЧЗ**: код товара, GTIN, ТНВЭД, ОКПД2, тип (в т.ч. Техническая карточка), статус модерации («Ожидает подписания», «Готов к заказу КМ»), производитель (ИНН), сертификат.
- **Этикетка (шаблон)**: тип/шаблон, ширина/высота (мм), ширина/высота изображения (px), объекты (Текст/Штрихкод/Изображение), «Сколько печатаем этикеток?», принтер, подстановки, превью-товар.
- **Объект этикетки**: тип, текст/подстановка, шрифт, размер, перенос строк, максимальное число строк, отступы, условие, вид штрихкода (EAN13/EAN8/Code128/QR/DataMatrix/GS1 DataMatrix), высота/выравнивание.
- **Штрихкод товара**: значение, способ генерации (ЧЗ/GS1 РУС/маркетплейс/диапазон/ручной), дублирование между организациями, связь с GTIN.
- **Уникальный код единицы товара**: код, привязка к штрихкоду/КИЗ, статус, склад, поступление, заказ, сотрудник/дата размещения и сборки, серийный номер, срок хранения, закупочная/розничная цена.
- **Агрегированный код**: код упаковки/комплекта, GLN организации (первые 7 цифр), вложенные КИЗ (≥2), тип сценария агрегации.
- **Категория (для маркировки)**: ТНВЭД, тип категории (товарная группа ЧЗ), тумблер «маркируются», ОКПД2.
- **Производитель**: ИНН (обязателен, совпадает с ЭЦП/ЧЗ).
- **Сертификат качества**: тип (Сертификат/Декларация), номер (по реестру Росаккредитации), категория/бренд.
- **Принтер / QZ Tray**: привязка к шаблону, статус подключения, сертификат SelSup.
- **Артикул поставщика**: пара артикул + поставщик, связь с товаром/групповой карточкой.
- **ВСД (Меркурий)**: номер (ручной ввод), привязка к товару.

## Интеграции

- **Честный Знак (СУЗ / Национальный каталог / ГИС МТ)**: создание и подписание карточек, заказ кодов маркировки (OMS Id, токен на 10 ч, идентификатор соединения), ввод/вывод/возврат в оборот, отчёт о нанесении, агрегация, импорт кодов, обновление статусов, определение владельца по ИНН.
- **Меркурий (через ручной ввод ВСД)**: номер ветеринарного сопроводительного документа для маркируемых товаров (автоподтягивания нет).
- **КриптоПро / ЭЦП**: подписание карточек, документов, получение токена и идентификатора соединения ЧЗ.
- **GS1 РУС**: получение GTIN (коды на «46…»), GLN организации (для агрегации); вход через логин/пароль или через ЧЗ.
- **QZ Tray + Java**: мост браузер↔принтер для прямой печати этикеток в один клик без диалогового окна (с сертификатом SelSup).
- **BullZip PDF Printer (виртуальный)**: объединение этикеток товара и заказа в единый PDF ленты заказов.
- **Wildberries (через API и Excel)**: импорт 10-го отчёта «Отчёт по товарам с обязательной маркировкой» (вывод из оборота, автоопределение товара/класса/даты/чека), передача кодов через задания, приёмка через Акт/УПД ДОП.
- **Ozon**: автоматический импорт кодов маркировки из заказа при обновлении; настройка этикетки 58×40 в ЛК Ozon.
- **Яндекс.Маркет**: настройка формата этикетки 58×40/40×58 в SelSup; передача кодов.
- **СберМегаМаркет**: передача кодов через ТСД/задания комплектации/сборки; работа по FBS/FBO через отдельные организации.
- **Маркетплейсы (общее)**: генерация штрихкодов из маркетплейсов (WB), использование стикеров заказов, сканирование стикера для возврата.
- **ЭДО**: выгрузка УПД / УПД ДОП (с маркировкой / полный) для загрузки в кабинет оператора ЭДО.
- **ТСД / сканеры штрихкодов**: сканирование КИЗ/ШК/уникальных кодов в заданиях (комплектация, сборка, размещение, возврат, привязка).
- **Принтеры (Zebra, Godex, TSC, Xprinter и др.)**: печать на термотрансферных/термо этикетках, сатиновой ленте; настройка через ОС.

## Настройки (settings)

- **Интеграция с Честным Знаком**: тумблер «Работать с Честный знак», OMS Id, «Получить идентификатор соединения», «Получить Токен», «Проверить СУЗ», статусы «Уже настроено»/«Частично настроено».
- **Настройки → Заказы**: «Печатать код маркировки в ленте заказов», «Печатать этикетку товара», «В задании 'Возврат товара' только печатать этикетки», формат этикетки Яндекс.Маркета (40×58 / 58×40).
- **Настройки → Общие**: «Отчет о нанесении в товарах», «Исправлять код маркировки при обновлении».
- **Настройки → FBS-заказы**: «Печатать этикетку о видеофиксации», Умная лента.
- **Настройки → Этикетки**: список шаблонов, выбор/создание/редактирование, принтер на шаблон, «Сколько печатаем этикеток?», установка QZ Tray, форматы маркировки (58×40 / 58×80), умная лента 75×120, видеофиксация.
- **Настройки → Штрих-коды**: способ получения (ЧЗ/GS1 РУС/маркетплейс/диапазон), добавление диапазона, логин/пароль GS1 РУС.
- **Настройки → Товары**: «Возможность дублирования штрих-кода в товарах разных организаций».
- **Настройки → Поставки**: «Разрешить сканировать только маркировку при упаковке FBO».
- **Настройки → PDF Документы**: шаблоны листов сборки FBS/FBO/перемещений, карго, закупка из заказа.
- **Настройки → Мои организации**: организации (ИНН), обе стороны для передачи кодов.
- **Настройки → Сертификаты**: документы качества (тип, номер, категория/бренд).
- **Товары → Категории**: ТНВЭД, тип категории, тумблер «Товары категории маркируются».
- **Товары → Производители**: ИНН производителя.
- **Закупки → Поставщики → Артикулы поставщиков**: артикул + поставщик, импорт для групповых карточек.

## Бизнес-правила и ограничения

- Для получения маркировки товар должен: относиться к категории с тумблером «маркируются», иметь ТНВЭД и товарную группу (тип категории); карточка в ЧЗ должна пройти модерацию и быть подписанной/опубликованной.
- Коды выдаются ровно по количеству товаров в заказе/приёмке; при увеличении количества — новый заказ СУЗ; при уменьшении — излишек остаётся в буфере SelSup.
- Один заказ СУЗ — не более 10 позиций и отдельный заказ на каждый тип товара (единица/комплект/набор/групповая упаковка).
- Криптохвост удаляется после ввода в оборот; печать длинного кода с криптохвостом — только до ввода.
- Статусы кода для операций: ввод — «Нанесён», вывод — «Введён в оборот», возврат — «Выведен из оборота». Выводить можно только из статуса «В обороте».
- Срок вывода из оборота: 3 рабочих дня (продажа конечному потребителю через маркетплейсы FBS) или 30 календарных дней (порча/утрата, возврат поставщику, инвентаризация) — иначе штраф.
- По FBO ввод/вывод из оборота обычно выполняет маркетплейс; селлер может делать это самостоятельно при ошибках/старых кодах.
- Для ввода/вывода цена продажи обязательна (берётся из заказа FBS или карточки); иначе ошибка «Не заполнено поле "Цена за единицу"».
- Передача кодов между организациями: обе организации в «Мои организации»; владелец определяется по ИНН (обновить код при неверном владельце).
- Агрегация: вложенные коды должны быть введены в оборот до агрегации; выведенные из оборота агрегировать нельзя; минимум 2 кода для задания «Агрегация»; GLN — первые 7 цифр.
- Комплект: в оборот вводятся только комплектующие; комплект вводит ЧЗ автоматически; тип карточки «Комплект» + состав + GTIN комплектующих.
- Принятые коды FBO брать только из Акта приёмки WB, не из старого УПД (иначе несовпадение).
- Печать кода маркировки в ленте заказов работает только при резервировании через «Заказы на отгрузку» (не через «Задания»), только на прямой принтер (не PDF).
- Карточки в ЧЗ нельзя удалить — только отправить в архив.
- На товарной этикетке выводится один штрихкод (по умолчанию первый); для печати конкретного — создать поставку нужного маркетплейса.
- У товаров одной категории — одинаковый ТНВЭД; при разных ТНВЭД — разделить карточку/категорию.
- Второй GTIN добавляется в поле «Штрих-код» (SelSup связывает КИЗ с товаром по GTIN из кода).
- ИНН производителя должен совпадать с ЧЗ и ЭЦП; иначе ошибки.
- GS1 РУС: бесплатно до 100 карточек; свыше — 3000 ₽/год через Национальный каталог (24000 ₽ напрямую).
- Стоимость одного кода маркировки — 60 копеек с НДС.
- Уникальные коды доступны на тарифе премиум или за доп. плату.
- Закупка из заказов и часть функций — дополнительные услуги к тарифу.
- Техподдержка оказывается только по шаблонным этикеткам (не по кастомным).
- Объединение этикетки товара и этикетки заказа в один PDF невозможно в браузере — нужен виртуальный принтер (BullZip).

## Открытые вопросы / чего не хватает в доках

- Точная модель данных/схема БД кодов маркировки, документов, заказов СУЗ (атрибуты и связи) не приведена — только UI-описание.
- Детальный список категорий, для которых требуется «Отчёт о нанесении» (указаны исключения: одежда/обувь/парфюмерия/шины/электроника), но не полный перечень.
- Полный перечень товарных групп ЧЗ и доступных способов ввода в оборот по каждой группе (упоминается, что «не все способы доступны» — без конкретики).
- Поведение при частичной ошибке заказа СУЗ (часть позиций получена, часть нет) — детально не описано.
- Механика определения класса/категории при импорте 10-го отчёта WB — описано поверхностно.
- Точные правила сопоставления КИЗ↔товар при нескольких GTIN/ШК (алгоритм разрешения коллизий).
- Лимиты API Честного Знака, частота обновления статусов, поведение при недоступности сервиса.
- Детали работы с КИЗ, полученными от поставщика, при массовых операциях (буферизация, повторное использование) — без технических границ.
- Расширенный каталог ошибок ЧЗ и их кодов (приведены ~10, полный реестр отсутствует).
- Полный список подстановок (variables) для шаблонов этикеток — приведены выборочно.
- Интеграция с 1С в части маркировки/этикеток в данных статьях не раскрыта.
- Инструменты аудита/истории изменений кодов и документов (кто/когда сменил статус) — частично только для уникальных кодов.
- Алгоритм «Исправлять код маркировки при обновлении» (как именно восстанавливается полный КИЗ) — без технических деталей.
- Поведение системы при превышении лимитов заказов СУЗ, при конкурентном резервировании кодов.
- Детальная настройка принтеров под не-Zebra/Godex модели — ограничено.
