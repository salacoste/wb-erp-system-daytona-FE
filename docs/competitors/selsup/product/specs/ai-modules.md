# AI-модули

> Спецификация для воссоздания функционала. Источник: статьи базы знаний SelSup (corpus).

## Назначение

Модуль «AI-модули» объединяет все функции на основе искусственного интеллекта, которые SelSup предоставляет селлерам на маркетплейсах (Wildberries, Ozon и др.). Назначение — автоматизировать рутину (заполнение карточек, генерация контента), генерировать продающий визуал и видео, прогнозировать спрос, планировать поставки и поставок, и переводить аналитику в готовый список приоритетных действий («что сделать прямо сейчас, какой эффект ожидается»).

Модуль покрывает три слоя работы продавца:
1. **Создание контента** — авто-заполнение параметров карточек, генерация фото/серий фото/видео, SEO-описания и ключевые слова.
2. **Принятие решений** — AI-стратегии (конвейер задач по товарам), отчёты «Рука на пульсе» и «Рука на пульсе по-товарно» (финдир + рекомендации), сбор данных расширением браузера.
3. **Планирование операций** — «Точные поставки» (AI-планировщик): расчёт что, сколько и на какие склады везти.

Многие AI-функции тарифицируются как отдельные дополнения (генерация фото, PIM-модуль для SEO) и/или требуют модуля «AI Финдир» и браузерного расширения SelSup.

## Возможности (capabilities)

### 1. AI-Стратегии (конвейер задач по товарам)
- Формирует список готовых задач по товарам на основе аналитики (а не «голых» цифр).
- Каждая задача содержит: проблему понятным языком, конкретное действие, потенциальный эффект/приоритет, изменение прибыли, статус и ответственного.
- Цикл ведения задач: **Открыто → В работе → Готово**.
- Сортировка задач по эффекту/приоритету, рекомендованный ритм — 3–7 задач в день (или 20–40 минут фокуса), топ-20 в неделю.
- Фиксация результата одной строкой («до/после»).
- На данный момент работает **только для Wildberries**.

### 2. «Формализатор» (AI-создание карточек / авто-заполнение параметров)
- AI-помощник, который анализирует текстовое описание товара (название, характеристики, описание) и извлекает структурированные параметры в формате требований маркетплейсов (WB, Ozon и др.).
- Сокращает ручной труд на ~80%.
- Никогда не перезаписывает уже заполненные параметры (безопасность данных).
- Принцип «показать-подтвердить»: предложенные значения выделяются оранжевым, можно удалить лишнее крестиком (✕), затем «Сохранить».
- Извлечение идёт только из предоставленного текста, формат единиц измерения сохраняется.
- Требует предварительного указания категории маркетплейса в карточке (иначе параметры для этого МП не предложатся).
- Оптимизирован для одновременной работы с требованиями нескольких МП (кросс-платформенные продажи).

### 3. AI Редактор фото
Встроенный фоторедактор для подготовки изображений карточек прямо в интерфейсе, без внешних программ. Состоит из нескольких подсценариев:

- **Генератор изображений по промту.** Пользователь описывает желаемое изображение/правку текстом → нейросеть генерирует. Варианты интеграции в карточку: «Добавить в начало» (новое фото становится первым, остальные остаются) или «Заменить» (заменяет исходное фото на той же позиции, старое удаляется).
- **AI Фотосессии.** «Примерка» товара на профессиональную модель из встроенного каталога (или свою модель) без организации реальной съёмки. Позволяет держать серию изображений визуально цельной. Шаги: выбор модели → выбор ракурса + индивидуальный промт → «Начать фотосессию» → перегенерация/«Готово» → «Сохранить». Возможна локальная загрузка через «Скачать». Нельзя заменить одежду на нижнее бельё на готовом фото (ограничение генерации) — для этого используется вкладка AI Редактор с правкой по промту.
- **AI Фотоворонка продаж.** За один сценарий собирает серию из 7+/8/9/10 продающих фото: «Сгенерировать контент-план» → выбор количества → правка плана → «Подтвердить план и начать генерацию» → поштучная перегенерация/подтверждение → «Завершить серию» → итоговая сетка → «Добавить фото в карточку». Обеспечивает единый стиль и последовательность.
- **Мои шаблоны.** Сохранение удачных изображений в личные шаблоны для повторного использования и единого визуального стиля. Сохранение через «Сохранить» + название; использование через «+» → выбор шаблона.
- **Прочие инструменты обработки:** «Удалить фон», «Улучшить фото» (AI-апскейл/коррекция), «Галерея» (добавить фото поверх / использовать как новое), «Сгенерировать фото» по промту, «Изменить размер», «Текст» (добавляется как редактируемый объект, а не вшитый в пиксели), «Фигуры», «Загрузить фон» (после удаления старого фона; нельзя выделять основное фото при загрузке фона).
- **Глубокие настройки (для профессионалов):** интеллектуальные фильтры/коррекция (гамма, насыщенность отдельных цветов, оттенок, уровень шума), полная работа со слоями (группировка, порядок, фиксация, названия).
- **Умный предпросмотр для маркетплейсов.** Предпросмотр изображения в каталогах Ozon и Wildberries одним кликом — для выбора главного фото, оптимизации под выдачу.
- Редактирование по одному фото с обязательным «Сохранить» перед переходом.
- Для генерации требуется платное дополнение к тарифу; в карточке появляется кнопка генерации, в разделе «Тариф» — счётчик оставшихся генераций.
- Фото с маркетплейсов (Ozon, WB и др.) редактируются сразу; фото с внешних сайтов могут блокироваться доменом — тогда нужно загрузить изображение в SelSup.

### 4. AI-генерация видео для товаров
- Создание видеороликов для карточек на основе 2 фотографий товара + текстового промта (описание движения, например «Плавное вращение модели, акцент на деталях»).
- Расположение: карточка товара → блок «Видео» → «Сгенерировать видео».
- После генерации — «Сохранить», включение тумблера Ozon/Wildberries и «Сохранить» для отправки на МП.
- Советы: качественные фото с разных ракурсов, подробный промт движений/акцентов.

### 5. Подбор ключевых слов и генерация SEO-описания
- Часть модуля **PIM-система** (отдельно подключаемый модуль, доступен в любом тарифе).
- **Подбор ключевых слов:** в карточке товара → вкладка «Ключевые слова» → ввод целевого слова → «Найти» → SelSup подбирает слова и показывает частоту поисковых запросов; можно снимать/ставить галочки, объединять несколько групп; создаётся именованная «группа ключевых слов».
- **Генерация SEO-описания:** на основе выбранных для модели ключевых слов AI формирует текст с учётом частотности, правил поисковых систем МП (длина, релевантность, естественность), без повторов и переспама. Кнопка «Сгенерировать описание» → «Сгенерировать» → текст в поле «Описание товара». К одной модели можно добавлять несколько групп ключевых слов.
- Группы ключевых слов можно редактировать (через поисковую строку «Редактировать» или прямо в карточке) и удалять (крестик).

### 6. Точные поставки (AI-планировщик)
Инструмент планирования поставок на МП на основе данных SelSup и маркетплейсов. Анализирует спрос за период, остатки FBO, товары в пути, выбранные склады/кластеры, дату будущей поставки и доп. параметры.
- Поддержка **Wildberries и Ozon** (расчёт); интеграции настраиваются и для Яндекс.Маркета.
- Режимы расчёта: «Ручное распределение» (пользователь выбирает склады/кластеры). Режим «Умное Распределение» — в разработке.
- Вкладки результата: **Рекомендация** (таблица товаров/дефицита/количества к поставке), **Детализация** (разбор по складам), **Документы поставок** (созданные поставки).
- **AI-Прогноз** — в разработке.
- Считает «с учётом выгоды продавца», а не только рекомендации МП: пересчитывает рекомендацию под выбранные склады, перераспределяет количество между доступными направлениями.
- Ручная корректировка количества к поставке (плюс/минус, ввод числа вручную).
- Создание поставок из выбранных строк рекомендации.
- Справочные данные по Wildberries: типы упаковки (Короб, Монопаллета, Суперсейф, Поштучная паллета) с зелёной подсветкой доступности (обновление 1 раз в день по API WB), коэффициенты складов (приёмки/хранения/логистики). Пока справочно, в расчёте не участвуют.

### 7. AI Финдир — расширение SelSup (browser extension)
Браузерное расширение — часть модуля «AI Финдир». После авторизации под аккаунтом SelSup собирает данные прямо на страницах маркетплейсов и передаёт в SelSup:
- позиции товаров в выдаче МП по ключевым запросам;
- рейтинг и отзывы товаров;
- СПП (скидка за участие в акциях) товаров Wildberries для анализа цен/скидок;
- данные для отчёта «Воронка продаж» (CTR и показы);
- запуск всех настроенных процессов расширения сразу.
- Доступные функции определяются подключёнными модулями и тарифом; без авторизации функции передачи данных не работают.

### 8. Отчёт «Рука на пульсе» (сводный)
- Отчёт руководителя (бета-версия), отслеживает план/факт продаж, прибыль/расходы, товарный остаток.
- Просмотр только в интерфейсе (без выгрузки).
- Фильтры: период, организация, маркетплейс (без выбора — по всем), параметр детализации (штрих-код / цветомодель / категория).
- Поиск товара по названию, штрих-коду или артикулу; просмотр по всем товарам или по конкретному.
- Столбцы: параметры товара (категория, бренд, артикул для объединения, название, цвет, размер, штрих-код), План общий шт., Факт общий шт. (из отчёта «План/факт продаж»), Количество продаж руб., Валовая прибыль (= Итого к оплате по API − Себестоимость − Самовыкуп), Общий расход за период (логистика, комиссия, СПП на WB, штрафы, доплаты WB, услуги, прочие начисления, платное хранение, реклама), Общий товарный остаток (FBS+FBO), Средняя прибыль за единицу, Средние расходы на единицу, Стоимость рекламы на 1 заказ. Расположение столбцов настраивается.

### 9. Отчёт «Рука на пульсе по-товарно» (финдир + рекомендации)
Детальный товарный отчёт — «личный финансовый директор для каждого товара».
- Фильтры: организация, маркетплейс (WB/Ozon; для Ozon нужна интеграция, для рекламных показателей — Ozon Performance), период, поиск товара, выбор отображаемых показателей.
- Отчёт формируется не по всем товарам: сначала «избранные», затем товары с наибольшим числом заказов за последние 2 месяца; обычно до ~1000 (может быть чуть больше).
- Автообновление каждую ночь; ручное «Обновить данные».
- Подсказки-рекомендации при наведении на изменившийся показатель (зелёная ↗ / красная ↘ стрелка): что делать (например, ↓% выкупа → проверить карточку, отзывы, фото; ↓конверсия в заказ → не увеличивать рекламу, проверить отзывы/конкурентов; ↓переходы → обновить главное фото).
- Целевые нормативы: **ДРР ≤ 10%**, **маржинальность ~30%**, **оборачиваемость ≤ дней до конца сезона**.
- Целевая нагрузка менеджера: до 15 карточек на одном МП, KPI по маржинальной прибыли.
- Показатели агрегируются из множества источников (см. «Интеграции» и «Сущности»): цены/СПП, рейтинг/отзывы, прибыль/маржа/выручка, заказы/выкуп/отмены, воронка продаж (корзина, CR, выкуп), рекламная аналитика (бюджет, ДРР, клики, показы, CTR), ABC-анализ, остатки FBO/FBS, оборачиваемость, план прибыли, позиции в выдаче.
- Часть показателей заполняется вручную: Комментарий, Бюджет реклама план, Дней до конца сезона (можно массово через Excel), Размеры, Подсорт план, Выручка план шт.
- Стратегии управления: ежедневная планёрка с фиксацией в «Комментариях», ведение поля «Стратегия» по товару.

## Ключевые сценарии (workflows)

### Сценарий A. Работа с AI-Стратегиями
1. Открыть раздел «AI стратегии» (`/application/aiTasks`).
2. Отсортировать задачи по эффекту/приоритету.
3. Взять на день 3–7 задач (топ-20 на неделю).
4. У каждой задачи назначить одного владельца (исполнителей может быть несколько, ответственность — одна).
5. Выполнить конкретный шаг (обновить фото, уточнить комплектацию, вырезать нерентабельные запросы, сделать подсорт и т.п.).
6. Перевести статус: Открыто → В работе → Готово.
7. Зафиксировать результат одной строкой («до/после») + следить за ключевыми метриками.
- Для отображения менеджера в отчёте привязать его к товару через поле «Менеджер товара основной».

### Сценарий B. Авто-заполнение параметров карточки (Формализатор)
1. В карточке товара заранее указать категорию нужного маркетплейса (WB, Ozon и др.).
2. Заполнить/проверить текстовые данные: название, характеристики, описание.
3. Нажать кнопку «AI-создание».
4. Просмотреть предложенные параметры (выделены оранжевым).
5. Удалить лишнее крестиком (✕) рядом со значением.
6. Нажать «Сохранить» — обновления применяются; уже заполненные параметры не затрагиваются.

### Сценарий C. Генерация/правка фото (AI Редактор)
1. Открыть редактор: из карточки товара (кнопка «Открыть в редакторе») или из вкладки «AI Редактор».
2. Выбрать подсценарий:
   - **Генерация по промту:** ввести промт → «Применить» → выбрать «Добавить в начало» или «Заменить».
   - **Фотосессия:** выбрать модель (из каталога/свою) → выбрать ракурс + промт → «Начать фотосессию» → «Перегенерировать фото»/«Готово» → «Сохранить» (опционально «Скачать»).
   - **Фотоворонка продаж:** «Сгенерировать контент-план» → выбрать 7/8/9/10 фото → правка плана → «Подтвердить план и начать генерацию» → перегенерация/подтверждение каждого → «Завершить серию» → «Добавить фото в карточку».
3. При необходимости использовать инструменты: Удалить фон, Улучшить фото, Галерея, Изменить размер, Текст, Фигуры, Загрузить фон.
4. Включить «Умный предпросмотр» для Ozon/WB и проверить вид в выдаче.
5. «Сохранить» каждое фото перед переходом к следующему.
6. Для отправки на МП — включить тумблер фото и «Сохранить» в карточке.

### Сценарий D. Генерация видео для товара
1. Карточка товара → блок «Видео».
2. «Сгенерировать видео».
3. Выбрать 2 фотографии товара.
4. Написать промт движения (ракурс, динамика, акценты).
5. «Применить» → дождаться обработки.
6. «Сохранить».
7. Включить тумблер Ozon/Wildberries → «Сохранить» для отправки на МП.

### Сценарий E. Подбор ключевых слов и генерация SEO
1. Карточка товара → вкладка «Ключевые слова».
2. (Опционально) выбрать существующую группу или объединить несколько.
3. Для новой группы: ввести целевое слово → «Найти» → посмотреть частотность → снять/поставить галочки → «Добавить» → задать название группы → «Сохранить».
4. Раздел «Карточка» → «Сгенерировать описание» → «Сгенерировать».
5. Проверить SEO-описание в поле «Описание товара».
6. При необходимости отредактировать/удалить группу ключевых слов.

### Сценарий F. Расчёт и создание поставки (Точные поставки)
1. Открыть раздел «Точные поставки».
2. Убедиться, что настроена интеграция (WB/Ozon); дождаться быстрого импорта товаров, заказов FBS/FBO за 2 недели, остатков FBO, ночного импорта.
3. Выбрать маркетплейс (WB или Ozon) и организацию.
4. Заполнить настройки: Режим расчёта (Ручное распределение), Кластеры и/или Склады, Период анализа, Планируемая дата поставки, Планировать на (дней, по умолчанию 30), Рекомендовать от.
5. Включить доп. настройки при необходимости: Считать по заказам (по умолчанию вкл), Учитывать FBS, Распределять не попавшие в выборку рекомендации. (AI-Прогноз, Умное Распределение, Ограничить по остатку FBS — в разработке.)
6. Нажать «Рассчитать» («Очистить» — сброс).
7. Изучить вкладку «Рекомендация» (при необходимости «Детализация») и проверить данные.
8. Скорректировать количество вручную (плюс/минус или ввод числа).
9. Выбрать товары → «Создать поставки».
10. Перейти во вкладку «Документы поставок» для просмотра созданных поставок.

### Сценарий G. Сбор данных расширением AI Финдир
1. Установить расширение SelSup из Chrome Web Store.
2. Открыть расширение, ввести логин/пароль аккаунта SelSup → «Войти».
3. Проверить доступные функции (по тарифу/модулям).
4. На страницах маркетплейсов собирать: позиции в выдаче, рейтинг и отзывы, СПП WB, данные для «Воронки продаж» (CTR/показы).
5. Запускать все настроенные процессы сразу.
6. Результаты появляются в соответствующих разделах/отчётах SelSup.

### Сценарий H. Работа с «Рукой на пульсе по-товарно»
1. Перейти: Аналитика и финансы → Отчёты → Рука на пульсе по-товарно.
2. Выбрать организацию, маркетплейс (для Ozon — интеграция + Ozon Performance для рекламы), период.
3. Заполнить плановые значения: «Прибыль (план)», «Дней до конца сезона», «Размеры», «Бюджет реклама план».
4. Анализировать показатели: смотреть красные/зелёные стрелки, наводить курсор для подсказок-рекомендаций.
5. Управлять оборачиваемостью: сравнить «Дней до конца сезона» и «Оборачиваемость»; если оборачиваемость больше — плавно снижать цену со скидкой (на 3–5% в день), следить за ростом заказов.
6. Анализировать рекламную воронку «снизу вверх»: выкуп/CR заказ → CR корзина/переходы → показы; не увеличивать бюджет, пока не решена проблема карточки/цены.
7. Зафиксировать действия в «Комментарии» и «Стратегии».
8. Ежедневная планёрка: только красные стрелки → тултип → решение → комментарий → проверка динамики на следующий день.

## Сущности (entities)

### Задача AI-Стратегий
- Проблема (текст, понятный язык: низкий выкуп, рост ДРР, риск Out of Stock, продажа в минус и т.п.)
- Рекомендуемое действие (конкретный следующий шаг)
- Потенциальный эффект / приоритет
- Прибыль (дельта чистой прибыли за последние 14 дней vs предыдущие 14 дней)
- Статус (Открыто / В работе / Готово)
- Владелец задачи / ответственный (один)
- Исполнитель(и) (опционально)
- Товар (ссылка на карточку) и маркетплейс (только WB на данный момент)

### Карточка товара (в части AI)
- Категория маркетплейса (WB/Ozon/…) — обязательна для Формализатора
- Текстовые данные: название, характеристики, описание
- Параметры (атрибуты маркетплейса: материал, размеры, цвет, вес и т.д.) — заполняются/не перезаписываются
- Менеджер товара основной (для отображения в AI-стратегиях и Рука на пульсе)
- Избранность (влияет на попадание в «Рука на пульсе по-товарно»)

### Изображение товара (в AI Редакторе)
- Источник (маркетплейс / внешнее / загруженное в SelSup)
- Позиция в галерее
- Слои (текстовые объекты, фигуры, фон) — редактируемые
- Глубокие параметры (гамма, насыщенность, оттенок, шум и др.)
- Шаблон («Мои шаблоны»: название, изображение)
- Привязка к предпросмотру Ozon/WB

### Серия фото (AI Фотоворонка продаж)
- Контент-план (на 7/8/9/10 фото)
- Статус генерации каждого фото (перегенерировать / подтверждено)
- Итоговая сетка
- Привязка к карточке

### Видео товара
- 2 исходных фото
- Промт движения
- Маркетплейс назначения (тумблер Ozon/Wildberries)
- Статус (сгенерировано / сохранено / отправлено)

### Группа ключевых слов
- Название группы
- Список ключевых слов
- Частота поисковых запросов по словам
- Привязка к модели (карточке) — возможно несколько групп на модель
- Редактируемость (добавление/удаление слов)

### SEO-описание товара
- Исходные группы ключевых слов
- Сгенерированный текст
- Соответствие правилам МП (длина, релевантность, естественность)

### Расчёт поставки (Точные поставки)
Параметры расчёта:
- Маркетплейс (WB/Ozon), организация
- Режим расчёта (Ручное распределение; «Умное Распределение» — в разработке)
- Кластеры / Склады (один или несколько)
- Период анализа (даты; по умолчанию 30 дней)
- Планируемая дата поставки
- Планировать на (дней; по умолчанию 30)
- Рекомендовать от (минимальное количество в рекомендации)
- Доп. настройки: Считать по заказам (вкл/выкл), Учитывать FBS, Ограничить по остатку FBS (в разработке), Распределять не попавшие в выборку рекомендации, AI-Прогноз (в разработке)
Результат:
- Таблица рекомендаций: Название, Артикул для объединения, Остаток (FBO по вошедшим складам), Поставляется (в незавершённых поставках), FBO/FBS (заказы/продажи), Дефицит, Склады и количество, Типы упаковки (Короб/Монопаллета/Суперсейф/Поштучная паллета), Коэффициенты складов (только WB), Стоимость (= закупочная цена × количество)
- Детализация по складу: Остаток FBO, Поставляется, Хватит (дн.), Спрос за период, Дефицит
- Документы поставок (созданные через планирование)

### Данные расширения AI Финдир
- Позиции товаров в выдаче по ключевым запросам
- Рейтинг и отзывы товаров
- СПП товаров WB
- Данные «Воронки продаж» (CTR, показы)
- Учётная запись SelSup (авторизация)

### Показатели отчёта «Рука на пульсе по-товарно»
(агрегируются из источников; см. «Интеграции»)
- Цена с СПП / Цена со скидкой / СПП руб. / СПП % (Цены и Акции)
- Рейтинг / Отзывы (Товары, через расширение)
- Прибыль факт / Прибыль на 1 SKU / Себестоимость 1 SKU / % Маржа / Выручка факт руб. / Выручка факт шт. (Товарная аналитика, Отчёт по операциям)
- Заказы / Выкуп шт. / Отмены (Отчёт по заказам — Ozon)
- Корзина / CR корзина / Заказы / CR в заказ / Выкуп шт. / Отмены / % выкупа (Воронка Продаж — WB)
- Бюджет реклама факт / Аукцион бюджет / АРК бюджет / ДРР % / Клики / Показы / CTR % (Рекламная аналитика WB и Ozon Performance)
- ABC по выручке / ABC по прибыли (ABC-анализ)
- Остаток FBS / Остаток FBO / Оборачиваемость (отчёты по остаткам)
- Прибыль план (План/факт продаж)
- Позиция (отчёт «Позиции», через расширение)
- Вручную: Комментарий, Бюджет реклама план, Дней до конца сезона, Размеры, Подсорт план, Выручка план шт., Стратегия

### Показатели отчёта «Рука на пульсе» (сводного)
- План общий шт. / Факт общий шт. (из План/факт продаж)
- Количество продаж руб.
- Валовая прибыль (= Итого к оплате по API − Себестоимость − Самовыкуп)
- Общий расход за период (логистика, комиссия, СПП WB, штрафы, доплаты WB, услуги, прочие начисления, платное хранение, реклама)
- Общий товарный остаток (FBS+FBO)
- Средняя прибыль за единицу (= Выручка / (Продажи − Возвраты))
- Средние расходы на единицу (= Общий расход / Продажи)
- Стоимость рекламы на 1 заказ

## Интеграции

### Маркетплейсы (API)
- **Wildberries**: API остатков FBO, заказов FBO/FBS, продаж; API типов упаковки складов и коэффициентов (обновление 1 раз в день); рекламная аналитика (аукцион/АРК бюджеты, ДРР, клики, показы); СПП товаров (через расширение); позиции в выдаче (через расширение); отправка фото/видео в карточки. AI-Стратегии — только WB.
- **Ozon**: API заказов/продаж/остатков; рекламные показатели через **Ozon Performance** (отдельное подключение); отчёт по заказам (Лента заказов). Расчёт Точных поставок — поддержан.
- **Яндекс Маркет**: настройка интеграции в модуле Точные поставки возможна, но расчёт поставок пока только WB/Ozon.

### Ozon Performance
- Подключается отдельно; даёт рекламные показатели для Ozon в «Рука на пульсе по-товарно» (бюджет, ДРР, клики, показы, CTR). Без него реклама по Ozon не отображается.

### Браузерное расширение SelSup (часть модуля AI Финдир)
- Устанавливается из Chrome Web Store.
- Авторизация под аккаунтом SelSup.
- Собирает на страницах МП: позиции товаров в выдаче по запросам, рейтинг и отзывы, СПП WB, данные для «Воронки продаж» (CTR, показы).
- Передаёт данные в SelSup; без авторизации функции передачи не работают.
- Видимость функций зависит от тарифа и подключённых модулей.

### Внутренние источники SelSup (для отчётов и AI)
- Отчёт «План/факт продаж» (план прибыли, план/факт шт.)
- Отчёт «Товарная аналитика» и «Отчёт по операциям с маркетплейса» (прибыль, маржа, выручка, себестоимость)
- Отчёт «Воронка Продаж» (корзина, CR, выкуп, отмены, показы/CTR)
- Отчёт «Отчет по заказам (Лента заказов)» (Ozon: заказы, выкуп, отмены)
- Отчёт «ABC-анализ» (ABC по выручке/прибыли)
- Отчёты по остаткам (FBO/FBS, оборачиваемость, динамика остатков)
- Отчёт «Позиции» (позиция товара в выдаче)
- Раздел «Цены и Акции → Цены» (цена с СПП, цена со скидкой, СПП руб./%)
- Раздел «Товары» (рейтинг, отзывы, менеджер)
- Раздел «Аналитика и финансы → Реклама» (принудительное обновление рекламных данных; авто — 1 раз в сутки)
- Отчёт «Остатки по складам» (FBO-остатки, товары в поставках/в пути) — основа расчёта Точных поставок

### Импорт данных (для Точных поставок)
- При настройке интеграции: быстрый импорт товаров + заказы FBS/FBO за 2 недели + остатки FBO + ночной автоимпорт товаров.
- Импорт WB: не объединять карточки по цветам/размерам; использовать артикул WB для объединения в одну карточку в SelSup.
- Для полного импорта рекомендуется раздел «Товары → Импорт товаров».

## Бизнес-правила и ограничения

### AI-Стратегии
- Работают **только для Wildberries**.
- Менеджеры маркетплейсов (Ozon, WB, Яндекс.Маркет) в отчёте AI-стратегий не отображаются — отображается только «Менеджер товара основной».
- У каждой задачи — один владелец (ответственный).
- Подход: не расширять список задач, а сужать (топ-5 в день / топ-20 в неделю).

### Формализатор
- Извлечение только из предоставленного текста.
- Сохранение формата единиц измерения.
- Игнорирование уже заполненных параметров (никогда не перезаписывает).
- Обязательный предпросмотр перед применением; применение только после подтверждения.
- Для появления параметров МП нужна заранее выбранная категория этого МП.

### AI Редактор фото
- Для генерации требуется платное дополнение к тарифу (счётчик генераций).
- Фото с внешних сайтов может блокироваться доменом — нужно загрузить в SelSup.
- В AI Фотосессиях нельзя заменить одежду на нижнее бельё на готовом фото (ограничение генерации).
- Текст добавляется как редактируемый объект (не «вшивается» в изображение), чтобы избежать ошибок генерации.
- При загрузке фона нельзя выделять основное фото — действие применяется к фону.
- Редактирование по одному фото с обязательным «Сохранить» перед переходом.

### Точные поставки
- Расчёт только для WB и Ozon.
- По умолчанию: Период анализа 30 дней, Планировать на 30 дней.
- Потребность и рекомендации округляются вверх (чтобы не занижать).
- Отрицательная рекомендация выводится как 0 (остатков/поставок/в пути достаточно).
- FBS распределяется по складам пропорционально FBO-спросу; если FBO-спроса нет — распределить FBS не по чему.
- Типы упаковки и коэффициенты складов (WB) — пока справочно, в расчёте не участвуют.
- Ручная корректировка количества доступна (финальное решение за пользователем).
- Возможные причины пустого расчёта: не выбран МП/организация/кластеры/склады; нет продаж/заказов за период; слишком короткий период; слишком высокий порог «Рекомендовать от»; неактуальные данные.

### AI Финдир (расширение)
- Без авторизации функции передачи данных не работают.
- Видимость функций ограничена тарифом и подключёнными модулями.

### Отчёты «Рука на пульсе»
- Сводный отчёт — бета, просмотр только в интерфейсе.
- «Рука на пульсе по-товарно»: формируется не по всем товарам (избранные + топ по заказам за 2 месяца, ~до 1000); обновляется каждую ночь; Ozon требует интеграцию + Ozon Performance для рекламы.
- Целевые нормативы: ДРР ≤ 10%, маржинальность ~30%, оборачиваемость ≤ дней до конца сезона.
- Рекомендуемая нагрузка менеджера: до 15 карточек на МП.

### Тарификация
- Генерация фото — отдельное дополнение (счётчик генераций).
- SEO/ключевые слова — модуль PIM-система (отдельно подключаемый, доступен в любом тарифе).
- AI Финдир / расширение — отдельный модуль с доступностью функций по тарифу.

## Открытые вопросы / чего не хватает в доках

1. **Тарифные детали:** точная стоимость и лимиты генераций фото/видео, состав модуля PIM, стоимость модуля AI Финдир — в статьях не раскрыты (только «приобрести дополнение», «счётчик генераций»). Нет информации о тарифных планах, квотах на AI-генерацию, правилах списания генераций при перегенерации.

2. **Покрытие маркетплейсов:** AI-Стратегии — только WB; расчёт поставок — только WB/Ozon. Не описано, когда появятся Ozon/Яндекс/СберМегаМаркет/AliExpress для AI-Стратегий и когда расчёт поставок расширится на другие МП.

3. **В разработке (явно отмечено в доках):**
   - Точные поставки: режим «Умное Распределение», «AI-Прогноз», «Ограничить по остатку FBS».
   - Типы упаковки и коэффициенты складов WB пока справочны (не участвуют в расчёте).
   - Авто-заполнение «Дней до конца сезона» последующих товаров.
   - Фильтр по менеджеру в «Рука на пульсе по-товарно» (каждый менеджер видит только свои карточки).

4. **Параметры AI-моделей:** не описаны используемые модели, лимиты промтов, форматы вывода, поддерживаемые языки, качество/разрешение генерируемых фото и видео, длительность видео, форматы экспорта.
