# Импорт/экспорт и перенос карточек

## Назначение

Модуль обеспечивает централизованное поступление товарных карточек в SelSup из внешних источников и их дальнейшее распределение между площадками и организациями. Он решает три задачи:

1. **Импорт товаров** — загрузка карточек из маркетплейсов (Wildberries, Ozon, Яндекс.Маркет, МегаМаркет, AliExpress, Avito, Магнит Маркет, Леман ПРО/Леруа), внешних CMS и учётных систем (МойСклад, inSales, WooCommerce, Lamoda, Webasyst, SimaLand), файлов (Excel/XLSX, YML/XML) и системы маркировки «Честный Знак» (Национальный каталог).
2. **Массовое создание/редактирование и перенос карточек** между маркетплейсами (например, WB→Ozon, WB→Яндекс.Маркет) и между организациями внутри SelSup, включая выгрузку карточек во внешние системы (МойСклад, YML-фиды для МегаМаркет/Яндекс.Маркет).
3. **Сопоставление (матчинг) и обработка ошибок** — объединение карточек из разных источников в единую товарную позицию SelSup по штрих-коду/артикулу, ведение журнала «Ошибки импорта» и средств ручного исправления (объединение карточек, изменение артикулов/штрих-кодов).

Ключевая идея модуля — «единое окно»: один товар в SelSup связывается с карточками на всех маркетплейсах, что позволяет управлять остатками, ценами, заказами и маркировкой из одного интерфейса.

## Возможности (capabilities)

1. **Импорт карточек из маркетплейсов по API (автоматический)** — Wildberries, Ozon, Яндекс.Маркет, AliExpress, Lamoda, Магнит Маркет; загрузка ассортимента продавца в SelSup нажатием кнопки или по расписанию.
2. **Импорт карточек из источников без API по товарам (ручной через файл)** — МегаМаркет (Excel «Готовые связки»), Avito (Excel «Автозагрузка»), Леман ПРО/Леруа (связь по GUID), Честный Знак (Excel с GTIN), YML-файлы, файлы из внешних CMS.
3. **Импорт из внешних CMS/учётных систем** — МойСклад (двусторонний: импорт в SelSup и выгрузка из SelSup в МС), inSales, WooCommerce, Lamoda, Webasyst, SimaLand (часть — прямым импортом, часть — установкой связи по артикулу сайта).
4. **Ночной автоматический импорт** — фоновая задача, запускающаяся каждую ночь: обновляет ранее созданные товары и добавляет новые, как ручной импорт. Настраивается тумблером на каждой вкладке импорта для каждой организации/маркетплейса.
5. **Быстрый импорт** — загрузка только новых позиций без обновления существующих и без параметров маркетплейса; после него запускается фоновый процесс подтягивания остальных параметров. До завершения фонового импорта карточки нельзя редактировать или отправлять на маркетплейс.
6. **Импорт по бренду** — поле «Бренд для импорта» ограничивает загрузку товарами одного бренда (доступно для Ozon, Wildberries, Яндекс.Маркета). Название бренда указывается точно как в ЛК маркетплейса.
7. **Трёхуровневая модель карточки** — Модель → Цвет (визуальное отличие) → Размер. При импорте автоматически формируются поля «Артикул для объединения в одну карточку» и «Артикул цвета (Цвет)» по правилам, специфичным для каждого маркетплейса.
8. **Объединение (матчинг) карточек** — автоматическое связывание товаров из разных источников в одну карточку SelSup по штрих-коду и/или артикулу; ручное и массовое объединение через отдельный инструмент (merge).
9. **Импорт/выгрузка через Excel (XLSX)** — единый файл товаров с цветовой разметкой блоков (обязательные поля, общие параметры SelSup, блоки параметров каждого маркетплейса). Используется и для создания, и для массового редактирования десятков параметров.
10. **Импорт из YML/XML** — загрузка товаров по ссылке на YML-файл (с авторизацией), с выбором поля-ключа для объединения (offerId/vendorCode) и опцией импорта всех параметров.
11. **Массовое создание и редактирование карточек на маркетплейсах** — WB, Ozon, Яндекс.Маркет, AliExpress: заполнение одной карточки-эталона в интерфейсе, копирование её параметров и массовая отправка через Excel-файл.
12. **Перенос карточек между маркетплейсами** — перенос ассортимента с одной площадки на другую через категории (сопоставление категорий, ТН ВЭД) и Excel/YML.
13. **Перенос карточек между организациями** — два способа: через интерфейс (мастер «Перенести между организациями») и через Excel; с опциями переноса/генерации штрих-кодов, объединения по остаткам и отправки на маркетплейс после переноса.
14. **Выгрузка YML-фидов** — формирование SelSup YML-файла (с логином/паролем) для загрузки товаров в Яндекс.Маркет и МегаМаркет.
15. **Двусторонний обмен с МойСклад** — импорт товаров из МС в SelSup (товар → модель, модификация → размер) и создание/выгрузка карточек из SelSup в МС (через карточку, создание нового товара или массово через Excel с указанием «Отправить карточки после импорта в: МойСклад»).
16. **Связь с Честным Знаком / Национальным каталогом** — связывание карточек по GTIN (EAN-13 без первой цифры); создание карточек в Честном Знаке из SelSup (3 этапа: создание → подписание → публикация); точечное получение кодов маркировки в момент операций вместо массового импорта всех кодов.
17. **Выбор источника поля «Артикул» (для МойСклад)** — использование в качестве артикула «Код МС», «Внешний код МС» или значения дополнительного поля МС.
18. **Импорт только видимых/актуальных карточек** (Ozon) — исключает архивные и завершённые позиции.
19. **Импорт товаров с определённого склада** (Ozon) — фильтр загрузки по складу, зарегистрированному на маркетплейсе.
20. **Обновление габаритов и веса при импорте** — синхронизация физических параметров при расхождении с маркетплейсом.
21. **Управление обновлением внутренних параметров SelSup** — Название/Описание при импорте с маркетплейсов НЕ обновляются автоматически; предусмотрены средства ручного и массового (через Excel) обновления.
22. **Настройка режимов объединения по цветам/размерам** — тумблер «Не объединять карточки по цветам и размерам» (Ozon, WB, Яндекс.Маркет) с диалогом выбора стратегии объединения.
23. **Журнал «Ошибки импорта»** — таблица под окном загрузки с указанием товара и причины ошибки; файл с ошибками доступен для скачивания; статистика (добавлено/обновлено/с ошибками) для Магнит Маркет и др.
24. **Дублирование штрих-кодов в разных организациях** — глобальная настройка, разрешающая одинаковые ШК в разных организациях (в рамках одной организации ШК остаются уникальными); используется при импорте и переносе.
25. **Массовое обновление фотографий** — из Ozon (запуск импорта или «Заменить изображения на ссылки из Ozon»), загрузка фото в SelSup напрямую, страница «Товары без фото» и кнопки «Загрузить фотографии [Маркетплейс]» (например, для WB фото переносятся после создания карточек).
26. **Массовые операции через Excel, выходящие за рамки карточек** — назначение менеджеров, сезонность, теги, мин/макс остаток FBS, обнуление остатков, вид товара (товар/комплект), коэффициенты коррекции и продаж, единицы измерения, количество штук в коробе.

## Ключевые сценарии (workflows)

### WF-1. Импорт товаров из маркетплейса по API (на примере Ozon/WB/Яндекс.Маркет)
1. Настроить интеграцию с маркетплейсом (API-ключ, при необходимости — ключ статистики WB).
2. Открыть раздел **Товары → Импорт товаров**, выбрать вкладку маркетплейса.
3. Выбрать организацию (если их несколько) и, при необходимости, производителя (обязательно, если товар подлежит маркировке).
4. Настроить параметры импорта: ночной автоимпорт, быстрый импорт, бренд для импорта, импорт только видимых / с определённого склада (Ozon), обновление габаритов и веса, режим объединения по цветам/размерам.
5. Нажать «Импортировать товары [Маркетплейс]».
6. Дождаться результатов; ошибки появятся в таблице «Ошибки импорта».
7. Проверить объединение с карточками других маркетплейсов (столбец «Ссылки» должен содержать значки всех площадок); при необходимости объединить вручную.

### WF-2. Быстрый первичный импорт ассортимента
1. Включить тумблер «Быстрый импорт».
2. Запустить импорт — создаются карточки без параметров маркетплейса (только новые позиции).
3. Дождаться завершения фонового процесса подтягивания параметров (до этого карточки нельзя редактировать/отправлять).

### WF-3. Импорт из МегаМаркет (без API по товарам)
1. В кабинете МегаМаркета: **Ассортимент → Готовые связки**, скачать Excel.
2. В SelSup: **Товары → Импорт товаров → вкладка МегаМаркет**, загрузить файл.
3. Если артикул/ШК совпадают с существующими товарами SelSup — проставятся ссылки и «Артикул МегаМаркет»; иначе создаются новые карточки.
4. При несовпадающих артикулах/ШК: скачать Excel из SelSup (Экспорт), скопировать offer id из «Готовых связок» в столбец «Артикул МегаМаркет», импортировать этот файл, затем импортировать «Готовые связки».

### WF-4. Импорт объявлений из Avito
1. В кабинете Avito: **Автозагрузка → Настройки → Скачать файл с объявлениями**, отметить нужные, указать e-mail, создать файл.
2. Скачать файл из письма.
3. В SelSup: **Товары → Импорт товаров → Avito**, выбрать организацию и (при необходимости) производителя, загрузить файл.
4. В карточки переносятся все параметры (категория, модель, бренд, страна, название, цена со скидкой, фото).

### WF-5. Импорт/связывание из CMS без прямого импорта (Webasyst, SimaLand)
1. В SelSup открыть карточку товара, заполнить поле «Артикул [сервиса]» (ID артикула из CMS) / «Артикул на сайте».
2. Для массовой установки: скачать Excel (Массовое редактирование / Экспорт), заполнить столбец «Артикул на сайте», загрузить обратно; затем на вкладке сервиса нажать «Импортировать товары [сервиса]» (для Webasyst) для связывания.
3. После связи доступны обновление остатков и импорт заказов по FBS.

### WF-6. Импорт из YML-файла
1. **Товары → Импорт товаров → вкладка YML**.
2. Указать организацию, ссылку на YML, данные авторизации (логин/пароль).
3. Выбрать поле-ключ объединения у товара SelSup и поле, из которого берётся артикул в YML (по умолчанию offerId, можно vendorCode).
4. (Опц.) включить «Импортировать параметры из YML».
5. Нажать «Импортировать из YML»; ошибки (например, `product_not_found` при отсутствии артикула) — в таблице «Ошибки импорта».

### WF-7. Массовое создание карточек на маркетплейсе (WB/Ozon/Яндекс.Маркет)
1. Импортировать товары в SelSup из исходного маркетплейса (если ещё не загружены).
2. В **Товары → Категории** сопоставить внутреннюю категорию с категорией целевого маркетплейса, указать ТН ВЭД и параметры по умолчанию (например, «Тип» для Ozon — обязательный).
3. Заполнить Бренд и Производителя.
4. Заполнить 1 карточку-эталон вручную: открыть товар, включить тумблер маркетплейса, заполнить параметры, сохранить с отправкой (или скопировать параметры значком копирования и вставить в другие карточки — цвета копированию не подлежат).
5. В **Массовое редактирование → Скачать Excel**, выбрать организацию/категорию (и фильтр «Не созданы в [Маркетплейс]»), выгрузить файл.
6. Скопировать параметры с эталонной карточки на остальные; заполнить обязательные поля (для Ozon: размер — только числа, цвет — из справочника Ozon маленькими буквами, габариты, цена со/без скидки, «Артикул Ozon» при необходимости, «Бренд в одежде и обуви»).
7. Загрузить файл, выбрав организацию и целевой маркетплейс; при необходимости указать «Отправить карточки после импорта в: [Маркетплейс]».
8. Проверить появление в ЛК маркетплейса (для WB фото переносятся отдельно через «Товары без фото → Загрузить фотографии WB», затем повторный импорт WB обновляет статус фото).

### WF-8. Перенос карточек между организациями (через интерфейс)
1. В **Товары → Создать товар → Перенести между организациями** выбрать «Перенос карточек между организациями через интерфейс».
2. Выбрать исходную организацию и одну/несколько целевых.
3. Настроить параметры: «Перенести вместе с ШК» или «При переносе генерировать новый ШК»; тумблер «Объединить товары по остаткам» (по умолчанию включён — синхронизирует остатки между организациями).
4. Выбрать товары (все/часть/через фильтры), нажать «Перенести».
5. Выбрать «Не отправлять» (только в SelSup) или «Отправить» на создание в маркетплейс (требуются связи категорий с категорией маркетплейса).

### WF-9. Перенос карточек между организациями (через Excel)
1. **Создать товар → Перенести между организациями → через Excel**.
2. Выбрать организацию, фильтры, «Выгрузить новый файл».
3. В файле: удалить ID из первого столбца; удалить старую организацию / добавить целевую; при различии брендов — изменить столбец «Бренд»; при различии ШК — очистить столбец «Штрих-код» (и проверить настройки штрих-кодов: источник «Маркетплейсы»).
4. В разделе переноса выбрать организацию и (опц.) маркетплейс для отправки, загрузить файл.

### WF-10. Выгрузка/создание карточек в МойСклад из SelSup
1. Для существующего товара: открыть карточку, включить тумблер «МойСклад», сохранить.
2. Для нового товара: «Создать товар», заполнить поля, включить «МойСклад», сохранить.
3. Массово: **Массовое редактирование → Скачать Excel**, оставить нужные товары, загрузить, в поле «Отправить карточки после импорта в:» выбрать «МойСклад».
4. Связь подтверждается иконкой «МС» и заполненным «ID МойСклад»; при отсутствии связи — «Найти и связать карточки» в карточке товара.

### WF-11. Связь с Честным Знаком и создание карточки маркировки
1. Настроить интеграцию с Честным Знаком (токен), добавить производителя с ИНН, для категорий указать ТН ВЭД (категории под маркировку).
2. Связывание по GTIN: скачать Excel (вкладка «Честный знак»), заполнить столбец GTIN (должен начинаться с 2 или 4; GTIN без первой цифры = штрих-код EAN-13), загрузить обратно; либо заполнить GTIN в карточке.
3. Создание карточки в Честном Знаке (для производителей/импортёров): «Создать товар» (или открыть существующий), включить тумблер Честного знака, заполнить параметры (единица измерения, «Тип товара в Честном знаке»: комплект/набор/групповая упаковка/единица), сохранить.
4. Этапы: создание → подписание (до или после получения кодов, через значок Честного знака или пункт в Заказе на отгрузку/Приёмке) → публикация (после модерации в ЛК Честного знака).
5. Коды маркировки добавляются автоматически в момент операций (сборка FBS, оприходование, выгрузка акта FBO), а не массовым импортом.

### WF-12. Загрузка карточек в Яндекс.Маркет через YML
1. На странице интеграции с Яндекс.Маркетом включить работу с маркетплейсом, скопировать ссылку YML и получить логин/пароль.
2. Открыть ссылку в браузере с авторизацией — получить XML-файл.
3. В кабинете Яндекс.Маркета: **Товары → Каталог → Загрузить товары → По ссылке / Много товаров → Все товары разом**, выбрать файл.
4. (Опц. цикл) скачать файл из ЛК ЯМ, импортировать в SelSup, экспортировать, дозаполнить обязательные поля, загрузить обратно.

### WF-13. Массовое редактирование параметров через Excel
1. Скачать Excel (Экспорт в Товарах или Массовое редактирование → Скачать Excel).
2. Внести изменения, соблюдая правила: не менять названия колонок, не удалять служебную строку, одинаковые параметры держать в общих параметрах SelSup.
3. В Массовом редактировании загрузить файл с настройками: организация, «Удалять значения параметров, где пустые ячейки», «Отправлять только новые карточки на маркетплейсы», «Обновлять существующие товары по комбинации (артикул, цвет и размер)», «Отправить карточки после импорта в: [Маркетплейс]».

## Сущности (entities)

- **Товар (карточка) SelSup** — агрегирующая сущность; атрибуты: Название, Описание, Артикул (для объединения в одну карточку / артикул модели), Цвет (артикул цвета), Размер, Бренд, Производитель, Категория, габариты и вес, фото, единица измерения и количество в ед. изм., вид товара (товар/комплект), теги, сезонность, менеджеры, коэффициенты (коррекции, продаж), количество штук в коробе, мин/макс остаток FBS.
- **Модель / Цвет / Размер** — трёхуровневая иерархия внутри товара; по умолчанию разделение по цвету применяется для категорий «Одежда» и «Обувь».
- **Связи с маркетплейсами (пер-артикулы площадок)**: Артикул/ID Wildberries (IMT как артикул модели, «Артикул WB» как цвет), Артикул/ID Ozon, vendorCode/ID Яндекс.Маркета, Артикул МегаМаркета, Артикул Avito, ID AliExpress, Артикул Lamoda (Артикул продавца Lamoda), Артикул на сайте (для Webasyst/SimaLand/прочих CMS), Идентификатор на сайте, Артикул Леруа Мерлен (GUID), ID МегаМаркет, ID МойСклад, Карточка Wildberries/Ozon (информационные ID).
- **Штрих-код (ШК)** — первичный ключ матчинга; правило уникальности в рамках организации с опцией дублирования между организациями.
- **GTIN** — глобальный код для связи с Национальным каталогом / Честным Знаком; должен начинаться с 2 или 4; GTIN без первой цифры = EAN-13 (штрих-код).
- **Категория SelSup** — внутренняя категория с сопоставлением категориям маркетплейсов, ТН ВЭД и параметрами по умолчанию; драйвер массового создания.
- **Организация** — контейрер товаров; настройки дублирования ШК и принадлежности карточек.
- **Производитель** — обязателен для товаров с маркировкой; связан с ИНН для Честного Знака.
- **Excel-файл товаров (XLSX)** — транспортная сущность: цветовые блоки (оранжевые — обязательные, голубые — общие параметры SelSup, светло-голубые — Ozon, розовые — WB, жёлтые — Яндекс.Маркет, прочие блоки — другие маркетплейсы); содержит служебную (скрытую) вторую строку и ID в первом столбце.
- **YML/XML-фид** — транспортная сущность с offerId/vendorCode; генерируется SelSup для ЯМ и МегаМаркет с доступом по логину/паролю.
- **Задача импорта/переноса** — фоновая задача с журналом ошибок и статистикой (добавлено/обновлено/с ошибками).
- **Журнал «Ошибки импорта»** — записи вида «товар + причина» (например, не уникальный артикул, дублирующий ШК, «Товар уже создан», `product_not_found`, `API Ozon: Internal error`, `error_no_business_id_yandex_market`).
- **Код маркировки (Честный Знак)** — привязывается к товару через GTIN; не выгружается массово.

## Интеграции

- **Wildberries** — автоматический импорт по API (ключ API + ключ статистики для цен со скидкой); массовое создание/редактирование карточек; загрузка фото через отдельный процесс; учёт суточного лимита WB на создание карточек (1000/день).
- **Ozon** — автоматический импорт по API (параметр «Объединять на одной карточке» → артикул модели; извлечение цвета/размера из параметров; при дубликате размеров — подстановка Артикула Ozon в Размер); импорт только видимых / с определённого склада; массовое создание; обработка внутренних ошибок Ozon (`Internal error`).
- **Яндекс.Маркет** — автоматический импорт по API (vendorCode → артикул для объединения; «Цвет» → цвет); создание через интерфейс/Excel (запрет символов «пробел» и спецсимволов в параметрах, обязательное фото) и через YML-фид; цены загружаются отдельным потоком.
- **МегаМаркет (СберМегаМаркет)** — нет API по товарам: импорт через Excel «Готовые связки»; выгрузка через YML-фид (требует цену со скидкой, категорию, «Артикул МегаМаркета»); соблюдение очерёдности «сначала YML-фид, затем склейка».
- **AliExpress** — автоматический импорт по API; массовое создание/редактирование.
- **Avito** — нет карточек, только объявления: импорт через Excel «Автозагрузки» (с переносом всех параметров и фото).
- **Магнит Маркет** — автоматический импорт по API (ключ); настройка дублирования ШК между организациями; статистика импорта.
- **Леман ПРО (Леруа Мерлен)** — связь по GUID (GUID = артикул поставщика), проставляемому через Excel; значок маркетплейса в карточке не появляется.
- **Lamoda** — автоматический импорт по API (после настройки интеграции); импорт для одной или всех организаций; ключевое поле «Артикул продавца Lamoda».
- **МойСклад** — двусторонний обмен: импорт товаров (модель/модификация), выбор источника артикула (Код/Внешний код/доп. поле), обновление закупочных цен и типов товаров при импорте, создание/выгрузка карточек из SelSup в МС.
- **inSales** — автоматический импорт (ограничение: InSales не передаёт артикул из поля «Артикул»); импорт для одной/всех организаций.
- **WooCommerce** — автоматический импорт (требуется заполненный артикул товара в WooCommerce).
- **Webasyst** — импорт напрямую невозможен; связь по «Артикул Webasyst»/«Артикул на сайте» (ручная или массовая через Excel + запуск связывания на вкладке Webasyst).
- **SimaLand** — импорт напрямую невозможен; связь по «Артикул SimaLand» (ручная или массовая через Excel).
- **YML/XML-файлы** — универсальный импорт по ссылке с авторизацией; выбор ключа объединения (offerId/vendorCode).
- **Честный Знак (Национальный каталог)** — импорт карточек невозможен (ограничение Национального каталога); связь по GTIN; создание карточек в Честном Знаке из SelSup (создание/подписание/публикация); точечное получение кодов маркировки.
- **1С** — упоминается в контексте ограничений: импорт фотографий из 1С невозможен (прочий обмен рассматривается в отдельных модулях).

## Настройки (settings)

- **Автоматически импортировать товары ночью** — тумблер на каждой вкладке импорта (WB, Ozon, Яндекс.Маркет, МойСклад и др.), per организация/маркетплейс.
- **Быстрый импорт** — тумблер (только новые позиции, без параметров).
- **Бренд для импорта** — текстовое поле (точное совпадение с ЛК маркетплейса).
- **Импорт только видимых карточек** (Ozon) — тумблер.
- **Импорт товаров с определённого склада** (Ozon) — выбор склада.
- **Не объединять карточки по цветам и размерам** — тумблер с диалогом выбора стратегии объединения (Ozon, WB, Яндекс.Маркет).
- **Обновлять габариты и вес при импорте** — тумблер.
- **Использовать название Wildberries в качестве названия товара SelSup** / **Всегда генерировать название** / **Обновить название, описание в карточках SelSup** — настройки импорта WB.
- **Возможность дублировать штрих-код в разных организациях** — глобальная настройка (Товары → Настройки / Настройки → Штрих-коды).
- **Источник штрих-кодов: «Маркетплейсы»** — настройка генерации ШК.
- **Тип артикула для МойСклад** — «Код МС» / «Внешний код МС» / «Дополнительное поле» (Интеграции → МойСклад).
- **Изменить цены товаров в SelSup при импорте из МС** / **Изменить типы товаров в SelSup при импорте из МС** — тумблеры МойСклад.
- **Параметры импорта YML** — ссылка на файл, логин/пароль, поле-ключ объединения, поле источника артикула, «Импортировать параметры из YML».
- **Параметры массового редактирования (Excel)** — организация, «Удалять значения параметров, где пустые ячейки», «Отправлять только новые карточки на маркетплейсы», «Обновлять существующие товары по комбинации (артикул, цвет и размер)», «Отправить карточки после импорта в: [Маркетплейс]».

- **Выбор производителя** — обязателен для маркируемых товаров при импорте с любого маркетплейса.
- **Настройки категорий** — сопоставление категорий маркетплейсов, ТН ВЭД, параметры по умолчанию.

## Бизнес-правила и ограничения

- **Матчинг优先итет**: поиск существующего товара сначала по штрих-коду, затем по артикулу маркетплейса; при нахождении — обновление связи, а не создание дубликата.
- **Уникальность комбинации**: комбинация «Артикул + Цвет + Размер» не должна дублироваться в SelSup; при дублировании возникает ошибка «Товар уже создан».
- **Поля «Артикул», «Цвет», «Размер»** в SelSup не дублируются — в каждом столбце уникальное значение; при отсутствии размера в «Размер» подставляется артикул товара (на отображение на маркетплейсе не влияет).
- **Внутренние параметры SelSup (Название, Описание)** при импорте с маркетплейсов автоматически НЕ обновляются — только поля маркетплейсов.
- **Маркировка**: выбор производителя обязателен для маркируемых товаров; без него корректная передача данных для маркировки невозможна.
- **GTIN** должен начинаться с цифры 2 или 4; GTIN без первой цифры соответствует штрих-коду EAN-13.
- **Карточка в Честный Знак отправляется только один раз**; после публикации обновление через API невозможно; удаление опубликованной карточки и изменение часто невозможны.
- **Коды маркировки** не выгружаются из Честного Знака массово — система получает их точечно в момент операций (сборка FBS, оприходование, акт FBO).
- **WB: суточный лимит на создание новых карточек** (например, 1000/день); обновление существующих лимитом не ограничено. Фото WB переносятся после создания карточек отдельным процессом.
- **Цены со скидкой WB**: импортируются только при вставленном ключе статистики и после «Обновить цены» в разделе Цены.
- **Яндекс.Маркет**: создание карточки требует обязательного фото; запрещены символы «пробел» и `!@#$%^&*№;%:?*+` в параметрах; цены выделены в отдельную загрузку.
- **МегаМаркет**: нет API по товарам — только Excel «Готовые связки» (импорт) и YML-фид (выгрузка); для попадания в фид обязательны цена со скидкой, категория, «Артикул МегаМаркета»; очерёдность — сначала YML-фид, затем склейка (иначе расклейка/потеря остатков); нельзя указывать ссылку YML в ЛК при уже продающихся товарах до проставления «Артикул МегаМаркета» и переноса остатков FBS.
- **inSales** технически не передаёт артикул из поля «Артикул».
- **WooCommerce**: товары импортируются только при заполненном артикуле.
- **Webasyst / SimaLand**: прямой импорт карточек невозможен — только установка связи.
- **Леруа/Леман ПРО**: значок маркетплейса со ссылкой не появляется (в отличие от других МП); связь по GUID.
- **Лимит тарифа**: 1 ед. × 1 размер × 1 цвет = 1 товар; при превышении — ошибка «Лимит превышен».
- **Excel-файл**: нельзя менять названия колонок, удалять служебную (скрытую) вторую строку и ID в первом столбце; при ссылках не использовать «Enter».
- **Массовое редактирование карточек, созданных не через SelSup**, несёт риск их повреждения — рекомендуется сначала тестировать правки на одной карточке.
- **Перенос между организациями**: при объединении по остаткам изменение остатка в одной организации синхронно меняет остаток в другой; при использовании одинаковых ШК требуется включить дублирование ШК между организациями.

## Открытые вопросы / чего не хватает в доках

- Точные списки обязательных и необязательных полей Excel-файла по каждому маркетплейсу приведены фрагментарно (детально — только для Ozon и WB); нет полного реестра столбцов с типами и форматами значений.
- Не описаны форматы файлов «Готовые связки» МегаМаркета и файла Avito «Автозагрузка» (структура колонок, кодировки).
- Не описаны пределы/таймауты API, ограничения на размер YML/Excel и количество товаров за один импорт.
- Нет сведений о частоте ночного импорта, времени его запуска и обработке коллизий при одновременном ручном и ночном импорте.
- Не описано поведение «Быстрого импорта» при сбое фонового процесса подтягивания параметров (как восстановить, как принудительно дозапустить).
- Нет детального описания алгоритма извлечения цвета/размера из параметров Ozon (перечень наименований параметров «Цвет, Вкус и т.п.» не формализован).
- Не описаны правила конфликт-резолва при матчинге, когда совпадают ШК, но различаются бренды/категории.
- Не описан механизм версионирования/отката при массовом редактировании через Excel (отсутствует undo).
- Не детализирована двусторонняя синхронизация с МойСклад (поведение при конфликте цен/типов товаров, частота, направление приоритета).
- Не описана работа с 1С в части импорта карточек (упомянут лишь запрет на импорт фото).
- Нет описания интеграции с СДЭК в контексте карточек (упоминается только в перечне интеграций).
- Не формализованы правила валидации GTIN помимо «начинается с 2 или 4» (контрольная сумма EAN-13 и т.п.).
- Не описаны ограничения по правам пользователей/ролям для запуска импорта и переноса между организациями.
- Нет описания того, как именно обрабатываются ошибки на стороне целевого маркетплейса при массовом создании (статусы, повторная отправка, частичные успехи), кроме общих ссылок на ЛК маркетплейса.
