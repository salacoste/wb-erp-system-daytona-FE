# CRM, покупатели и конкуренты

> Спецификация модуля SelSup для воссоздания функциональности. Источники — 10 статей базы знаний (разделы CRM, Покупатели, Воронка продаж, расширение SelSup, Реклама, Шаблоны писем, Telegram-бот).

## Назначение

Модуль объединяет работу с коммуникациями и данными, связанными с покупателями и конкурентной средой на маркетплейсах:

- **Единое окно обработки обращений покупателей** — чаты, вопросы и отзывы из Ozon и Wildberries в одном интерфейсе SelSup, без переключения между кабинетами маркетплейсов.
- **База данных покупателей** (раздел «Покупатели») — история заказов, контакты (телефоны, адреса) для собственных маркетинговых активностей, анализа источников привлечения и рассылок.
- **Аналитика воронки продаж** (Wildberries) — понимание, на каком этапе пути покупателя теряются конверсии.
- **Сбор данных конкурентов и собственного ассортимента через браузерное расширение SelSup** — позиции товаров в выдаче по ключевым запросам, рейтинги и количество отзывов, СПП (скидка постоянного покупателя), а также дополнительные показатели воронки (CTR, показы).
- **Учёт рекламных кампаний и расходов на рекламу** по маркетплейсам с потоварной детализацией.
- **Шаблоны писем** и отправка писем клиентам из заказов (опт/розница) через интеграцию с почтовым сервисом.
- **Уведомления в Telegram** о новых заказах FBS/FBS Express, заканчивающихся остатках FBO, ошибках дропшиппинга, плюс канал новостей и связь с техподдержкой.

## Возможности (capabilities)

### CRM: чаты, вопросы, отзывы
1. **Просмотр обращений покупателей в одном окне** — сообщения, вопросы и отзывы из Ozon и Wildberries.
2. **Ответы покупателям прямо из SelSup** — в чатах, вопросах и отзывах, без перехода в кабинет маркетплейса.
3. **Использование шаблонов ответов** при составлении ответов во всех трёх типах обращений.
4. **Автоматическое обновление данных каждые 10 минут** (чаты, вопросы, отзывы подтягиваются по API маркетплейсов).
5. **Принудительное обновление чатов** с Ozon и Wildberries по кнопке.
6. **Принудительный импорт вопросов/отзывов** по кнопке с «закруглённой стрелкой».
7. **Фильтрация обращений**: по маркетплейсу, по дате последнего сообщения, по неотвеченным, по организациям.
8. **Вкладки состояний**: «новые/без ответа», «отвеченные», «все» (для чатов, вопросов и отзывов отдельно).
9. **Первый импорт неотвеченных обращений за весь период** при первом запуске.
10. **Шаблоны ответов** — создание шаблонов с названием, типом (из выпадающего списка) и текстом; выбор шаблона при ответе.

### Раздел «Покупатели»
11. **База данных клиентов** — централизованный список покупателей.
12. **Хранение истории заказов**, телефонов и адресов клиентов.
13. **Автоматическое попадание покупателей в базу** при работе по схемам DBS, realFBS Ozon, из интернет-магазина (при подключённой интеграции).
14. **Выгрузка покупателей в Excel** для SMS- и email-рассылок.
15. *(Анонсировано)* Сведения об источнике привлечения клиента.

### Воронка продаж (Wildberries)
16. **Отчёт «Воронка продаж»** — этапы пути покупателя по каждому товару с конверсиями.
17. **Автоматическая загрузка данных за предыдущий месяц** при первом подключении.
18. **Ежедневное обновление воронки за последние 7 дней** (для устойчивости к поздним обновлениям WB).
19. **Ручное «Обновить данные»** — пересчёт/загрузка за последние 30 дней.
20. **Фильтрация отчёта**: период, организация, артикул товара.
21. **Показатели воронки**: остатки FBO на WB, просмотры карточки, добавления в корзину, созданные заказы, фактические покупки (выкупы), отмены заказов.
22. **Процентные конверсии между этапами**: просмотры → корзина, корзина → заказ, % выкупа.
23. **Дополнительные параметры карточки**: оценка карточки (рейтинг качества от маркетплейса), оценка пользователей (средняя оценка; пусто при отсутствии оценок).
24. **Дополнение воронки показателями CTR и показы**, собранными через расширение (требуется подписка «Джем» на WB).

### Браузерное расширение SelSup (сбор данных)
25. **Расширение для браузера (Chrome)** с авторизацией по логину/паролю SelSup.
26. **Сбор данных для воронки продаж (CTR, показы)** из личного кабинета WB в фоновом режиме.
27. **Сбор позиций товаров в выдаче** по ключевым запросам (Ozon, WB, Яндекс.Маркет) — робот обходит заданное число товаров, фиксирует попадание в топ и номер позиции.
28. **Настройка глубины обхода** (например, топ-150) и списка маркетплейс + поисковых запросов.
29. **Повторная проверка позиций** по уже добавленным запросам («Запустить проверку позиций»).
30. **Сбор рейтинга и количества отзывов** товаров по Wildberries и Ozon с прогресс-баром (всего/осталось/обработано/успешно).
31. **Остановка сбора** отзывов/рейтинга по кнопке.
32. **Сбор СПП (скидки постоянного покупателя)** по товарам Wildberries из раздела «Цены и скидки» кабинета WB.
33. **Запись собранных данных** в карточки товаров и отчёты SelSup.

### Реклама
34. **Просмотр рекламных кампаний** («Мои кампании»), подтянутых по API маркетплейсов.
35. **Фильтрация кампаний** по организации, статусу, дате.
36. **Статусы кампаний**: «в процессе удаления», «готова к запуску», «кампания завершена», «отменена», «идут показы», «кампания на паузе».
37. **Ручное «Перезагрузить данные по кампаниям»** при непередаче кампании по API.
38. **Статистика по кампаниям** («Статистика»): по кликам, просмотрам, затратам, средней стоимости — в диаграммах и таблице.
39. **Поиск кампании** по ID кампании или по артикулу/названию.
40. **Учёт рекламных расходов с потоварной детализацией** для WB (API «Продвижения», по каждому SKU + ДРР) и Ozon (через Ozon Performance API).
41. **Учёт рекламных расходов в финансовых отчётах**: Товарная аналитика (Юнит-экономика), P&L, Аналитика и финансы (структура выручки/расходов/расходов на маркетплейсе), Отчёт по операциям.

### Шаблоны писем и почтовая интеграция
42. **Создание шаблона письма** (заголовок + контент) — ровно один шаблон на аккаунт.
43. **Редактирование и удаление** шаблона письма.
44. **Интеграция с почтовым сервисом** (Настройки → Интеграции → «Доп. функции для работы с заказами»).
45. **Отправка письма из заказа** (оптового/розничного) по шаблону — кнопка-конверт «Отправить по почте», выбор шаблона, указание email получателя.

### Telegram-бот и уведомления
46. **Уведомления о новых заказах FBS и FBS Express**.
47. **Уведомления о заканчивающихся остатках FBO** (по настраиваемому порогу).
48. **Уведомления об ошибках дропшиппинга** (подключается).
49. **Гибкое управление подписками**: отключение FBS/Express, отвязка аккаунта.
50. **Подписка на новостной канал SelSup** и связь с техподдержкой из Telegram.

## Ключевые сценарии (workflows)

### WF-1. Обработка обращения покупателя (чат/вопрос/отзыв)
1. Настроить интеграцию с маркетплейсом (Ozon/WB) и импортировать карточки товаров.
2. Система автоматически (каждые 10 минут) подтягивает обращения; при первом запуске — все неотвеченные за весь период.
3. Перейти в CRM → Чаты / Вопросы / Отзывы.
4. Открыть вкладку «новые/без ответа».
5. Прочитать обращение, при необходимости применить фильтр (по маркетплейсу/дате/организации/неотвеченным).
6. Выбрать готовый шаблон ответа или написать вручную, отправить ответ.
7. После ответа обращение переходит в общий список («отвеченные/все»).
8. (Опц.) Нажать принудительное обновление/импорт для немедленного получения свежих данных.

### WF-2. Создание шаблона ответа
1. CRM → вкладка «Шаблоны».
2. «Создать новый шаблон».
3. Указать название, выбрать тип шаблона из списка, заполнить текст.
4. «Создать» → шаблон доступен в чатах/вопросах/отзывах.

### WF-3. Работа с базой покупателей и рассылка
1. Раздел «Заказы на отгрузку» → «Покупатели» (появляется, когда есть хотя бы один клиент).
2. Просмотреть историю заказов, телефоны, адреса.
3. Нажать выгрузку в Excel.
4. Использовать файл для SMS/email-рассылок.

### WF-4. Анализ воронки продаж
1. Подключить модуль AI-Финдир (проверить тариф).
2. При первом подключении система загружает данные за предыдущий месяц; далее ежедневно — за последние 7 дней.
3. Перейти: Аналитика и финансы → Отчёты → Воронка продаж.
4. Выбрать период, организацию, (опц.) артикул.
5. Проанализировать этапы, конверсии, оценки карточки/пользователей; найти слабое место.
6. Если данные не обновились — нажать «Обновить данные» (пересчёт за 30 дней), дождаться и обновить страницу.

### WF-5. Сбор показателей воронки (CTR/показы) через расширение
1. Установить расширение SelSup, авторизоваться.
2. Иметь API-интеграцию с WB и товары в SelSup; подключить подписку «Джем» на WB.
3. Открыть настройки расширения, выбрать организации, указать начальную дату периода.
4. Нажать «Обновить данные воронки продаж» — расширение откроет вкладку «Аналитика» кабинета WB и соберёт данные в фоне.
5. Не взаимодействовать со страницей, где работает расширение.
6. Результат — в отчёте «Воронка продаж».

### WF-6. Отслеживание позиций товаров через расширение
1. Предусловия: расширение установлено и авторизовано, есть API-интеграция и товары.
2. В настройках расширения указать глубину обхода (например, 150), сохранить.
3. Добавить маркетплейс (WB/Ozon/Яндекс.Маркет) и ключевой запрос; можно несколько запросов.
4. Нажать «Запустить обход» — расширение открывает маркетплейс, обходит выдачу, проверяет наличие товара и фиксирует позицию.
5. Для повторной проверки — «Запустить проверку позиций».
6. Результат — в отчёте «Позиции» (Аналитика и финансы → Отчёт «Позиции»), тумблер «Мои карточки»; также в отчёте «Рука на пульсе по-товарно». Можно запускать регулярно.

### WF-7. Сбор рейтинга и отзывов через расширение
1. Предусловия (см. WF-6).
2. Открыть настройки расширения, указать количество товаров для сбора, сохранить.
3. Нажать «Обновить рейтинг и отзывы».
4. Контролировать ход в окне сбора (всего/осталось/обработано/собрано); можно «Остановить».
5. Результат — в отчёте «Рука на пульсе по-товарно» и в разделе «Товары» (столбцы «Количество отзывов», «Рейтинг», отдельно WB и Ozon); доступен экспорт в Excel.

### WF-8. Сбор СПП через расширение
1. Предусловия (см. WF-6).
2. Открыть расширение, нажать «Собрать СПП».
3. Расширение открывает `seller.wildberries.ru/discount-and-prices` и собирает данные.
4. Результат — в отчёте «Рука на Пульсе» и разделе «Цены и Акции».

### WF-9. Работа с рекламой и сверка расходов
1. Перейти: Аналитика и финансы → Реклама → «Мои кампании». При необходимости — «Перезагрузить данные по кампаниям».
2. Фильтровать/искать кампании по организации, статусу, дате, ID или артикулу.
3. Открыть «Статистику» — клики/просмотры/затраты/средняя стоимость в диаграммах и таблице.
4. Для потоварной аналитики Ozon — подключить Ozon Performance API (загрузка за 62 дня ночью, далее ежесуточно).
5. Сверить расходы с финотчётом WB (учесть: WB «прячет» рекламу в «прочие выплаты/удержания», даты списания сдвинуты на 1–3 дня; SelSup берёт данные напрямую из API WB «Продвижения»).

### WF-10. Отправка письма клиенту по шаблону
1. Настроить интеграцию с почтовым сервисом; создать шаблон письма в Настройки → Шаблоны писем.
2. В заказе (опт/розница) указать email получателя.
3. Нажать «Отправить по почте» (иконка конверта).
4. Выбрать шаблон, проверить email, нажать «Отправить».

### WF-11. Подключение Telegram-бота
1. Проверить наличие дополнения в тарифе (конструктор тарифов).
2. Настройки → Telegram-боты → перейти по ссылке → Открыть Telegram.
3. В чате бота нажать «Запустить» → «Перейти» → подтвердить.
4. Авторизоваться в SelSup в открывшейся странице → «Аккаунт успешно подключён».
5. Для FBO-остатков: Настройки → Остатки, указать порог FBO по организации.
6. При необходимости включить/отключить уведомления (FBS, Express, ошибки дропшиппинга, отвязка аккаунта).

## Сущности (entities)

### Чат (Chat)
- `id`; `marketplace` (Ozon/WB); `organization`; `customer`; `messages[]`; `lastMessageDate`; `isUnanswered` (status); `sourceType = chat`.

### Вопрос (Question)
- `id`; `marketplace`; `organization`; `product` (карточка); `questionText`; `answerText`; `status` (без ответа / отвечен); `date`.

### Отзыв (Review)
- `id`; `marketplace`; `organization`; `product`; `rating`; `reviewText`; `answerText`; `status` (без ответа / отвечен); `date`.

### Шаблон ответа (ResponseTemplate)
- `id`; `name` (название); `type` (тип из списка); `text` (текст); применим в чатах/вопросах/отзывах.

### Покупатель (Customer)
- `id`; `phone`; `address`; `ordersHistory[]`; (плановое) `acquisitionSource`; `source` = DBS / realFBS Ozon / интернет-магазин.

### Отчёт «Воронка продаж» (SalesFunnelRecord) — на товар за период
- `organization`; `product` (артикул); `period`;
- `fboStocksWB` (остатки FBO); `views` (просмотры); `cartAdds` (добавления в корзину); `ordersCreated` (заказы); `purchases` (выкупы); `cancellations` (отмены);
- `conversionViewsToCart`; `conversionCartToOrder`; `redemptionRate`;
- `cardRating` (оценка карточки маркетплейсом); `usersRating` (оценка пользователей, может быть пусто);
- (через расширение) `ctr`; `impressions` (показы).

### Позиция товара (ProductPosition) — через расширение
- `product`; `marketplace` (WB/Ozon/Яндекс.Маркет); `searchQuery`; `depth` (глубина обхода, напр. 150); `position` (номер в выдаче или «не в топе»); `date`.

### Рейтинг/отзывы товара (ProductRating) — через расширение
- `product`; `rating`; `reviewsCount`; разбивка по `marketplace` (WB / Ozon).

### СПП товара (ProductSPP) — через расширение
- `product`; `spp` (скидка постоянного покупателя, WB); `date`.

### Рекламная кампания (AdCampaign)
- `id` (ID кампании); `name`; `organization`; `marketplace`; `status` (в процессе удаления / готова к запуску / завершена / отменена / идут показы / на паузе); `date`;
- статистика: `clicks`, `views`, `spend`, `avgCost`; потоварная разбивка `skuSpend[]` (WB, +ДРР).

### Шаблон письма (EmailTemplate)
- `id`; `subject` (заголовок); `content` (контент); ограничение — один шаблон на аккаунт.

### Telegram-подписка (TelegramNotificationConfig)
- `account` (привязка аккаунта SelSup ↔ Telegram); флаги: `notifyFBS`, `notifyExpress`, `notifyDropshippingErrors`, `fboThreshold` (порог остатка FBO по организации); `linked`/`unlinked`.

## Интеграции

| Интеграция | Что делает |
|---|---|
| **Wildberries API** | Чаты/вопросы/отзывы (каждые 10 мин + ручной импорт); воронка продаж (ежедневно за 7 дней, ручное за 30); рекламные кампании и расходы (API «Продвижения», потоварно по SKU + ДРР); СПП (через расширение из кабинета). |
| **Ozon API** | Чаты/вопросы/отзывы; рекламные расходы общей суммой (строка «Реклама OZON»); позиции товаров; рейтинг/отзывы. |
| **Ozon Performance API** | Потоварная аналитика рекламных расходов Ozon (загрузка за 62 дня ночью, далее ежесуточно за предыдущий день). |
| **Яндекс.Маркет API** | Отслеживание позиций товаров; рекламные расходы — в общей строке «Услуги» (кроме логистики). |
| **Мегамаркет** | Реклама — временно недоступно (в разработке). |
| **Браузерное расширение SelSup (Chrome)** | Сбор CTR/показов для воронки; позиций в выдаче; рейтинга/отзывов; СПП — из личных кабинетов маркетплейсов в фоне. |
| **Почтовый сервис (SMTP/email)** | Отправка писем клиентам по шаблонам из оптовых/розничных заказов. Требует email получателя. |
| **Telegram (бот)** | Уведомления о новых заказах FBS/FBS Express, заканчивающихся остатках FBO, ошибках дропшиппинга; новостной канал; связь с техподдержкой. |
| **Интернет-магазин** | Пополнение базы покупателей данными клиентов ИМ (при подключённой интеграции). |
| **Подписка WB «Джем»** | Внешнее условие: без неё WB не отдаёт CTR и показы для воронки. |

## Настройки (settings)

- **CRM / шаблоны ответов**: название, тип, текст шаблона.
- **Расширение SelSup**:
  - выбор организаций для сбора;
  - начальная дата периода воронки;
  - глубина обхода позиций (число товаров);
  - список пар «маркетплейс + ключевой запрос»;
  - количество товаров для сбора рейтинга/отзывов.
- **Воронка продаж**: выбор периода, организации, артикула; кнопка «Обновить данные» (30 дней).
- **Раздел «Покупатели»**: фильтры, экспорт в Excel.
- **Реклама**: фильтры (организация, статус, дата), поиск по ID/артикулу; «Перезагрузить данные по кампаниям».
- **Шаблоны писем** (Настройки → Шаблоны писем): один шаблон (заголовок + контент).
- **Интеграция с почтой** (Настройки → Интеграции → «Доп. функции для работы с заказами»): учётные данные почтового сервиса.
- **Telegram-боты** (Настройки → Telegram-боты): привязка аккаунта, переключатели FBS/Express/ошибки дропшиппинга, отвязка.
- **Остатки** (Настройки → Остатки): порог остатка FBO по организации для Telegram-уведомлений.
- **Мои организации**: автоматический импорт заказов (включает немедленные FBS-уведомления).
- **Тариф/конструктор тарифов**: модуль AI-Финдир (доступ к воронке продаж), дополнение для Telegram-бота.

## Бизнес-правила и ограничения

- **Источник обращений**: CRM работает только с Ozon и Wildberries.
- **Частота автообновления обращений**: каждые 10 минут.
- **Первый импорт**: только неотвеченные чаты/вопросы/отзывы за весь период.
- **Раздел «Покупатели» скрыт**, если в базе нет ни одного клиента.
- **Источники покупателей**: DBS, realFBS Ozon, интернет-магазин (через интеграцию).
- **Воронка продаж** доступна только при подключённом модуле **AI-Финдир** (возможна доплата по тарифу).
- **Воронка**: первый импорт — за предыдущий месяц; ежедневный — за последние 7 дней; ручной — за 30 дней.
- **Показатели CTR/показы** доступны только при подписке **«Джем» на Wildberries**.
- **Расширение**: во время сбора нельзя взаимодействовать со страницей маркетплейса, иначе процесс прерывается с ошибкой.
- **Отслеживание позиций**: поддерживается для Ozon, WB, Яндекс.Маркет.
- **Реклама — статистика доступна за 30 дней** с момента добавления токена; возможны расхождения (раздел в разработке).
- **Реклама WB**: пополнение кабинета с расчётного счёта и бонусные средства WB **не учитываются** в SelSup (не попадают в P&L) — только реальные потоки через API «Продвижения».
- **Расхождения WB ↔ SelSup**: WB смешивает рекламу в «прочие выплаты/удержания» без детализации, даты списания сдвинуты на 1–3 дня — это не ошибка, плата за детализацию.
- **Реклама Ozon**: по API — только общей суммой без разбивки; потоварно — только через Ozon Performance API.
- **Реклама Яндекс.Маркет**: внутри строки «Услуги» (без логистики).
- **Реклама Мегамаркет**: временно недоступна.
- **Шаблон письма**: ровно один на аккаунт (для изменений — редактирование).
- **Отправка письма**: обязательна настроенная почтовая интеграция и email получателя.
- **Telegram-бот**: требует соответствующего дополнения в тарифе; FBS-уведомления работают сразу при включённом авт. импорте заказов; FBO-уведомления — по порогу остатка.
