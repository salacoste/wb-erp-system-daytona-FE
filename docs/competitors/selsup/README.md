# SelSup competitor knowledge base

Локальная копия базы знаний/аналитики SelSup для будущего анализа фич и продуктовых правок.

## Где читать

- `product/AGENT_GUIDE.md` — навигация для ИИ-агента.
- `product/manifest.json` — машинно-читаемый индекс артефактов.
- `product/INDEX.md` — реестр 419 исходных статей SelSup.
- `product/corpus/` — первоисточник: очищенные markdown-статьи из `selsup.ru/help`.
- `product/specs/` — сгенерированные спецификации по модулям.
- `product/design/` — dev-ready дизайны фаз.
