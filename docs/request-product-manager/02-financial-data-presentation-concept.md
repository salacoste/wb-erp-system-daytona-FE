## Краткое описание

✅ **РЕАЛИЗОВАНА** концепция отображения финансовой аналитики для владельцев бизнеса на Wildberries. Фокус на **понимании бизнеса**, а не на копировании WB Dashboard.

**Ключевой принцип**: Презентация данных **от широкого к узкому** — воронка денег от оплаты покупателей до чистой прибыли.

---

## Целевая аудитория

**Владелец малого/среднего бизнеса на WB**, который хочет:

- Понять, сколько он **реально заработал**
- Видеть, **куда уходят деньги**
- Принимать решения по **оптимизации расходов**
- **Не быть бухгалтером** — простые, понятные метрики

**НЕ целевая аудитория**:

- Бухгалтеры (им нужен WB Dashboard для сверки)
- Аналитики данных (им нужны сырые данные)

---

## Концепция: Воронка денег ✅ РЕАЛИЗОВАНО

### Принцип "От широкого к узкому"

Показываем путь денег от **максимальной суммы** (оплата покупателей) до **минимальной** (чистая прибыль).

**Ключевая идея**: Дельта между "Продали" и "Получили на счёт" = ВСЕ удержания WB. Эту дельту разбиваем на категории.

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  ████████████████████████████████████████████  100%             │
│  1. ВАША ЦЕНА (retail_price)                   500,000₽        │
│     Цена, которую ВЫ установили на товары                       │
│     Источник: Request Backend #58 (ОЖИДАЕТ РЕАЛИЗАЦИИ)          │
│                                                                 │
│  ↓ Скидка WB (СПП, акции)                      -100,000₽  -20% │
│    (расчётное: retail_price - retail_with_discount)             │
│                                                                 │
│  ██████████████████████████████████░░░░░░░░░░  80%              │
│  2. ОПЛАТИЛИ ПОКУПАТЕЛИ (sales_gross)           400,000₽       │
│     Реальная сумма, которую заплатили покупатели                │
│     Источник: retail_price_with_discount (✅ УЖЕ ЕСТЬ)          │
│                                                                 │
│  ↓ Возвраты товаров (returns_gross)             -40,000₽  -10% │
│                                                                 │
│  █████████████████████████████░░░░░░░░░░░░░░░  72%              │
│  3. ОБОРОТ НЕТТО (sale_gross)                   360,000₽       │
│     Фактический оборот после возвратов                          │
│     Формула: sales_gross - returns_gross (✅ УЖЕ ЕСТЬ)          │
│                                                                 │
│  ═══════════════════════════════════════════════════════════   │
│  УДЕРЖАНИЯ WB (дельта = sale_gross - payout_total)              │
│  ═══════════════════════════════════════════════════════════   │
│                                                                 │
│  ↓ Комиссия маркетплейса (total_commission_rub) -90,000₽  -25% │
│  ↓ Логистика (logistics_cost)                   -36,000₽  -10% │
│  ↓ Хранение (storage_cost)                       -7,200₽   -2% │
│  ↓ Штрафы (penalties_total)                          -0₽   -0% │
│  ↓ Прочие удержания (other_adjustments_net)     -18,000₽   -5% │
│                                                                 │
│  █████████████████░░░░░░░░░░░░░░░░░░░░░░░░░░░  42%              │
│  4. НА СЧЁТ (payout_total)                      208,800₽       │
│     Сумма, которую WB перечислит вам (✅ УЖЕ ЕСТЬ)              │
│                                                                 │
│  ↓ Себестоимость товаров (cogs_total)          -120,000₽       │
│                                                                 │
│  █████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  18%              │
│  5. ПРИБЫЛЬ (gross_profit)                       88,800₽       │
│     Ваш реальный заработок (✅ УЖЕ ЕСТЬ при 100% COGS)          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Формула дельты (Все удержания WB)

```
ДЕЛЬТА = sale_gross - payout_total = ВСЕ УДЕРЖАНИЯ WB

Пример W49:
  Оборот (sale_gross):        360,000₽
- На счёт (payout_total):    -208,800₽
═══════════════════════════════════════
  ДЕЛЬТА (удержания WB):      151,200₽   (42% от оборота)

Разбивка дельты по категориям:
├─ Комиссия WB:                90,000₽   (60% дельты)
├─ Логистика:                  36,000₽   (24% дельты)
├─ Хранение:                    7,200₽   (5% дельты)
└─ Прочие:                     18,000₽   (12% дельты)
```

## Детальная структура данных

### Уровень 1: Ваша цена → Оплата покупателей

| Показатель              | Поле API             | Описание                                             |
| ----------------------- | -------------------- | ---------------------------------------------------- |
| **Ваша цена**           | `retail_price_total` | Сумма по вашим установленным ценам (до скидок WB)    |
| **Скидка WB**           | `wb_discount_total`  | СПП + акции WB = retail_price - retail_with_discount |
| **Оплатили покупатели** | `sales_gross`        | retail_price_with_discount для продаж                |

**Инсайт для пользователя**:

> "WB дал скидку 20% от вашей цены. Это нормально для вашей категории."

### Уровень 2: Оплата покупателей → Оборот

| Показатель              | Поле API        | Описание                    |
| ----------------------- | --------------- | --------------------------- |
| **Оплатили покупатели** | `sales_gross`   | Сумма продаж                |
| **Возвраты**            | `returns_gross` | Сумма возвращённых товаров  |
| **Оборот (нетто)**      | `sale_gross`    | sales_gross - returns_gross |

**Инсайт для пользователя**:

> "Возвраты 10% — выше нормы (5-7%). Проверьте качество описаний и фото."

### Уровень 3: Оборот → На счёт

| Показатель                | Поле API                | Описание                     | % от оборота |
| ------------------------- | ----------------------- | ---------------------------- | ------------ |
| **Оборот**                | `sale_gross`            | База для расчёта             | 100%         |
| **Комиссия маркетплейса** | `total_commission_rub`  | Основная комиссия WB         | ~25%         |
| **Логистика**             | `logistics_cost`        | Доставка + возврат на склад  | ~10%         |
| **Хранение**              | `storage_cost`          | Плата за хранение на складах | ~2%          |
| **Платная приёмка**       | `paid_acceptance_cost`  | Если превышены лимиты        | ~0-1%        |
| **Штрафы**                | `penalties_total`       | Брак, пересорт и т.д.        | 0% (норма)   |
| **Эквайринг**             | `acquiring_fee`         | Комиссия за платежи          | ~1%          |
| **Программа лояльности**  | `loyalty_fee`           | Баллы покупателей            | ~1%          |
| **Прочие удержания**      | `other_adjustments_net` | WB.Продвижение, Джем и др.   | варьируется  |
| **─────────────**         |                         |                              |              |
| **На счёт**               | `payout_total`          | Итого к перечислению         | ~40-50%      |

**Инсайты для пользователя**:

> "Комиссия 25% — норма для вашей категории."
> "Логистика 15% — выше нормы (10%). Оптимизируйте упаковку или выберите склады ближе к покупателям."
> "⚠️ Штрафы 5,000₽ — разберитесь с причинами!"

### Уровень 4: На счёт → Прибыль

| Показатель               | Поле API       | Описание                     |
| ------------------------ | -------------- | ---------------------------- |
| **На счёт**              | `payout_total` | Перечисление от WB           |
| **Себестоимость (COGS)** | `cogs_total`   | Закупочная стоимость товаров |
| **Прибыль**              | `gross_profit` | payout - cogs                |
| **Маржа**                | `margin_pct`   | profit / payout × 100%       |

**Инсайт для пользователя**:

> "Маржа 25% — хороший показатель! Держите её выше 20%."
> "⚠️ 3 товара с отрицательной маржой. [Посмотреть →]"

## Терминология

### Рекомендуемая терминология (бизнес-язык)

| Термин                    | Значение                       | Почему так                               |
| ------------------------- | ------------------------------ | ---------------------------------------- |
| **Ваша цена**             | retail_price                   | Понятно — это то, что установил продавец |
| **Скидка WB**             | retail - retail_with_discount  | Честно показываем, сколько "съедает" WB  |
| **Оплатили покупатели**   | retail_with_discount (продажи) | Реальные деньги от покупателей           |
| **Возвраты**              | returns_gross                  | Просто и понятно                         |
| **Оборот**                | sale_gross (нетто)             | Бизнес-термин, понятный всем             |
| **Комиссия маркетплейса** | total_commission_rub           | Без аббревиатур "ВВ"                     |
| **На счёт**               | payout_total                   | Человечнее, чем "К перечислению"         |
| **Прибыль**               | gross_profit                   | Главная метрика для бизнеса              |

### НЕ рекомендуемая терминология

| НЕ использовать         | Почему                      | Заменить на           |
| ----------------------- | --------------------------- | --------------------- |
| gross                   | Технический термин          | (убрать из UI)        |
| Продажа / Продажи       | Путается с WB терминологией | Оборот                |
| К перечислению за товар | Длинно, казённо             | На счёт               |
| Комиссия ВВ             | Аббревиатура непонятна      | Комиссия маркетплейса |
| net_for_pay             | Технический термин          | (только в API)        |

### Новые поля (опционально для Phase 2)

Если решим показывать "Вашу цену" и "Скидку WB", потребуются новые поля:

| Поле                 | Формула                          | Описание                     | Приоритет |
| -------------------- | -------------------------------- | ---------------------------- | --------- |
| `retail_price_total` | SUM(retail_price × qty)          | Сумма по установленным ценам | LOW       |
| `wb_discount_total`  | retail_price_total - sales_gross | Скидка WB (СПП + акции)      | LOW       |
| `wb_discount_pct`    | wb_discount / retail_price × 100 | % скидки WB                  | LOW       |

**Важно**: Поле `retail_price` (цена до скидки WB) есть в `wb_finance_raw`, но пока не агрегируется в `weekly_payout_summary`. Это можно добавить позже, если будет бизнес-потребность.
