# Руководство по доступности ежедневных данных

**Дата**: 2026-02-01
**Статус**: Справочный документ

---

## Проблема

До завершения недели и формирования недельного финансового отчёта WB, многие метрики недоступны:
- Выкупы (salesGross)
- COGS выкупов
- Логистика
- Хранение
- Теоретическая прибыль

**Вопрос**: Какие данные мы можем показывать пользователю в реальном времени?

---

## Доступные данные в реальном времени

### 1. FBO Заказы (Обновление каждые 5-60 мин)

**Endpoint**: `GET /v1/orders/fbo?from={date}&to={date}`

| Метрика | Доступность | Описание |
|---------|-------------|----------|
| Количество заказов | ✅ Реальное время | Точное количество |
| Сумма заказов | ✅ Реальное время | В рублях (корректно) |

### 2. FBS Заказы (Обновление каждые 5 мин)

**Endpoint**: `GET /v1/orders?from={date}&to={date}`

| Метрика | Доступность | Примечание |
|---------|-------------|------------|
| Количество заказов | ✅ Реальное время | Точное |
| Сумма заказов | ⚠️ БАГ! | Сейчас в копейках, нужно /100 |
| Статусы заказов | ✅ | new, confirm, complete, cancel |
| Тип доставки | ✅ | fbs, cargoType |
| B2B флаг | ✅ | isB2B для оптовых |

### 3. Рекламные затраты (Реальное время)

**Endpoint**: `GET /v1/analytics/advertising?from={date}&to={date}`

| Метрика | Доступность | Описание |
|---------|-------------|----------|
| Общие затраты | ✅ Реальное время | totalSpend в рублях |
| По кампаниям | ✅ | Детализация по advertId |
| CTR, CPC, CPM | ✅ | Метрики эффективности |
| Просмотры/клики | ✅ | views, clicks |

### 4. Ежедневные продажи (Daily Sales)

**Endpoint**: `GET /v1/analytics/weekly/finance-summary` (использует daily_sales_raw для текущей недели)

| Метрика | Доступность | Примечание |
|---------|-------------|------------|
| retailAmount | ✅ | Розничная выручка |
| ppvzForPay | ✅ | К перечислению продавцу |
| deliveryCost | ✅ | Стоимость доставки |
| commissions | ✅ | Комиссии WB |
| Returns | ✅ | Возвраты |

**Важно**: daily_sales_raw заполняется с задержкой 1-2 дня от WB API.

## Недоступные данные до закрытия недели

| Метрика | Причина | Когда появляется |
|---------|---------|------------------|
| **Выкупы (sales)** | WB рассчитывает после доставки | Вт-Ср после закрытия недели |
| **COGS выкупов** | Зависит от выкупов | Вт-Ср после закрытия недели |
| **Логистика total** | WB агрегирует по неделям | Вт-Ср после закрытия недели |
| **Хранение total** | WB агрегирует по неделям | Вт-Ср после закрытия недели |
| **Gross Profit** | Требует всех компонентов | Вт-Ср после закрытия недели |

### Индикаторы состояния данных:

```typescript
type DataAvailability =
  | 'realtime'      // ✅ Доступно в реальном времени
  | 'delayed'       // ⏳ Задержка 1-2 дня
  | 'pending_week'  // 📅 Ожидание закрытия недели
  | 'unavailable';  // ❌ Недоступно

interface MetricStatus {
  value: number | null;
  availability: DataAvailability;
  lastUpdated?: Date;
  expectedAt?: Date;  // Для pending_week
}
```

## API Endpoints Summary

### Реальное время (≤ 5 мин задержка)
| Endpoint | Данные |
|----------|--------|
| `GET /v1/orders` | FBS заказы |
| `GET /v1/orders/fbo` | FBO заказы |
| `GET /v1/analytics/advertising` | Рекламные затраты |
| `GET /v1/analytics/fulfillment/summary` | Агрегаты FBO/FBS |

### С задержкой (1-2 дня)
| Endpoint | Данные |
|----------|--------|
| `GET /v1/analytics/weekly/finance-summary` (daily mode) | Ежедневные продажи |

### Только после закрытия недели
| Endpoint | Данные |
|----------|--------|
| `GET /v1/analytics/weekly/finance-summary` (weekly mode) | Полный финансовый отчёт |

### 2. Эстимация недоступных метрик

На основе исторических данных можно давать прогноз:

```typescript
// Прогноз логистики на основе количества заказов
const estimatedLogistics = ordersCount * avgLogisticsCostPerOrder;

// Прогноз выкупов на основе конверсии
const estimatedSales = ordersRevenue * historicalBuyoutRate;
```
