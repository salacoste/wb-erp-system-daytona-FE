## 1. Executive Summary

Конкурент (многоплощадочный аналитический сервис **Selsup-класса** — WB + Ozon + Яндекс.Маркет + Ali + СберМегаМаркет) предоставляет **два связанных представления** финансового отчёта:

1. **Временной ряд P&L** (метрики × недели) — экран со скриншота.
2. **Многомерная разбивка P&L** (Excel-выгрузка) — по 5 срезам: **по ШК / по Цветомодели / по артикулу / по бренду / по категории**, до **72 колонок** в срезе «по ШК».

**Наша система имеет структурные аналоги обоих представлений:**

| Представление конкурента | Наш аналог | Статус |
|---|---|---|
| Временной ряд P&L (метрики × недели) | `/analytics/finance-history` (новая страница, реализована) | ✅ Построено (базовый набор метрик) |
| Разбивка по SKU | `/analytics/sku` (`SkuFinancialsTable`) | ⚠️ Есть, но у́же по полям |
| Разбивка по бренду | `/analytics/brand` | ⚠️ Есть, у́же |
| Разбивка по категории | `/analytics/category` | ⚠️ Есть, у́же |
| Разбивка по цветомодели / артикулу | — | ❌ Нет (нет модели вариантов) |

**Покрытие по полям (срез «по ШК», 72 поля):**
- ✅ **Полностью есть (или тривиально вычисляется): 30 (42%)**
- ⚠️ **Частично / только на уровне кабинета / нужна проводка: 16 (22%)**
- ❌ **Жёсткий гэп (нет источника данных): 26 (36%)**

→ **~64% покрыто с учётом вычислимых метрик, 36% — жёсткие гэпы.**

**Ключевые гэпы (концентрированы в 6 областях):**
1. **Реклама на уровне SKU + ДРР %** (нет атрибуции рекламы на SKU).
2. **Мультиплатформенность** (мы только WB; у конкурента 5 площадок).
3. **Варианты товара** (цвет/размер/цветомодель) — нет в финансовой модели.
4. **Самовыкупы** (детектор фрода) — отсутствуют.
5. **Остаток в закупочных ценах** + покаскадный остаток FBO/FBS.
6. **Чистая прибыль после налога на SKU** (налог сейчас только на уровне кабинета) + **СПП** + **аккаунт-менеджеры**.

> **Вывод PM:** мы не проигрываем по **структуре** (аналогичные страницы есть, включая только что построенный временной ряд), но проигрываем по **полноте полей** и **мультиплатформенности**. Догонять следует точечно — по ценности, а не копируя все 72 колонки.

## 6. Что УЖЕ есть и лучше, чем у конкурента (не терять)

Чтобы разработка не «сгладила» наши преимущества при догонянии:

1. **Persona-дашборд** (Owner/Ops/CFO с пресетами KPI) — у конкурента нет.
2. **Profit Waterfall** (визуальный каскад Выручка → −COGS → −расходы → Чистая) — вместо плоской строки.
3. **Status Strip** (консолидация алертов) — чище, чем стопки баннеров.
4. **COGS-coverage** как канонический индикатор + CTA.
5. **A11y** (axe-core 0 нарушений, WCAG 2.1 AA) + компактные числа (`formatCurrencyCompact`).
6. **Гранулярные срезы** (SKU/бренд/категория) с drill-down.
7. **Новый временной ряд P&L** `/analytics/finance-history` (метрики × недели с WoW-дельтами) — паритет со скриншотом конкурента уже достигнут.

## 7. Рекомендованный план (эпики для бэклога)

| Эпик | Тип | Описание | Ожидаемый прирост покрытия |
|---|---|---|---|
| **FR-1** | FE-only | Вычисляемые колонки долей (BD/BE/BC) на `/analytics/sku` + `/brand` + `/category` | +3 поля (≈+4%) |
| **FR-2** | BE+FE | Атрибуция рекламы на SKU + ДРР % (AF, AG, AH) | +3 поля (≈+4%), высокая ценность |
| **FR-3** | BE+FE | Чистая прибыль после налога per-SKU (BA) + налог/НДС на SKU (AJ, AK, AL) | +4 поля (≈+6%) |
| **FR-4** | BE+FE | Остаток в закупочных ценах + доли остатка (AU, BF, AR–AT wiring) | +5 полей (≈+7%) |
| **FR-5** | BE | СПП (Z) + Отмены (O) + Доп. расходы (AO) | +3 поля (≈+4%) |
| **FR-6** | Стратегический | Мультиплатформенность (Ozon/Yandex) — отдельная программа | +7 полей (≈+10%) |
| **FR-7** | Стратегический | Варианты товара (цвет/размер/цветомодель) | +3 поля (≈+4%) |

> Реализация **FR-1 + FR-2 + FR-3** поднимает покрытие с ~62% до ~76% и закрывает **самые ценные** для пользователя гэпы (реклама, чистая прибыль, доли). FR-6/FR-7 — стратегические, не блокируют паритет по core-P&L.
