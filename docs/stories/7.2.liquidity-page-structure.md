# Story 7.2: Liquidity Analysis Page Structure & Distribution Dashboard

## Status

Draft

---

## Story

**As a** seller,
**I want** a dedicated Liquidity Analysis page with portfolio distribution dashboard,
**so that** I can see how my inventory is distributed by liquidity and identify frozen capital.

---

## Acceptance Criteria

### Functional Requirements

1. **Page Route**: `/analytics/liquidity` accessible from navigation
2. **Distribution Dashboard**: Pie chart + 4 category cards showing:
   - 🟢 Highly Liquid (≤30 days): X SKUs, Y₽ (Z%)
   - 🟡 Medium Liquid (31-60 days): X SKUs, Y₽ (Z%)
   - 🟠 Low Liquid (61-90 days): X SKUs, Y₽ (Z%)
   - 🔴 Illiquid (>90 days): X SKUs, Y₽ (Z%) ⚠️
3. **Frozen Capital Display**: Total frozen capital with target comparison
4. **Benchmarks Section**: Your performance vs targets vs industry average
5. **Card Click Filter**: Clicking card filters table to that category
6. **Refresh Button**: Manual data refresh with "Last updated" timestamp
7. **Loading State**: Skeleton loader while fetching
8. **Empty State**: Message when no inventory data
9. **Error State**: User-friendly error on API failure

### Integration Requirements

10. Navigation link added to sidebar under "Analytics"
11. Uses data from Story 7.1 hook
12. Follows existing analytics page patterns

### Quality Requirements

13. Responsive design (desktop + tablet + mobile)
14. Accessibility: WCAG AA compliance
15. Performance: Dashboard renders in <500ms

### Distribution Card Component

```typescript
interface LiquidityCategoryCardProps {
  category: LiquidityCategory;
  count: number;
  value: number;
  pct: number;
  avgTurnoverDays: number;
  isActive: boolean;
  onClick: () => void;
}

function LiquidityCategoryCard({
  category,
  count,
  value,
  pct,
  avgTurnoverDays,
  isActive,
  onClick
}: LiquidityCategoryCardProps) {
  const bgColor = isActive ? getLiquidityStatusBgColor(category) : 'bg-white';
  const icon = getLiquidityStatusIcon(category);
  const label = getLiquidityStatusLabel(category);
  const targetShare = getTargetShare(category);

  return (
    <Card
      className={cn(
        'cursor-pointer transition-all hover:shadow-md',
        bgColor,
        isActive && 'ring-2 ring-offset-2'
      )}
      onClick={onClick}
    >
      <CardHeader>
        <span className="text-2xl">{icon}</span>
        <CardTitle className="text-sm">{label}</CardTitle>
      </CardHeader>
      <CardContent>
        <div className="text-lg font-bold">
          {count} SKU | {formatCurrency(value)}
        </div>
        <div className="text-sm text-muted-foreground">
          Оборот: {formatTurnoverDays(avgTurnoverDays)}
        </div>
        <div className="text-xs text-muted-foreground">
          Цель: {targetShare}
        </div>
      </CardContent>
    </Card>
  );
}
```
