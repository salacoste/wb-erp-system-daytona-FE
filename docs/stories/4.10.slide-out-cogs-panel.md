# Story 4.10: Slide-out COGS Assignment Panel

## Overview

**Epic**: Epic 4 - COGS Management
**Story ID**: 4.10
**Priority**: Medium
**Effort**: 3-5 часов
**Status**: ✅ Complete

---

## Story

**As a** пользователь страницы управления себестоимостью,
**I want** видеть таблицу товаров на полную ширину экрана и форму COGS в выезжающей панели справа,
**so that** я могу просматривать больше товаров одновременно и фокусироваться на форме только при назначении себестоимости.

## Problem Statement

### Текущее состояние (As-Is)

Страница `/cogs` использует **фиксированный двухколоночный layout** (`lg:grid-cols-2`):

- Левая колонка (50%): Таблица товаров (`ProductList`)
- Правая колонка (50%): Форма назначения COGS (`SingleCogsForm`)

**Проблемы:**

1. **Потеря пространства**: Форма COGS занимает 50% экрана даже когда товар не выбран
2. **Empty State**: Пользователь видит placeholder "Товар не выбран" вместо полезного контента
3. **Меньше товаров видно**: Таблица показывает меньше данных из-за урезанной ширины
4. **Плохой UX на широких мониторах**: На 2K/4K мониторах 50% таблицы - это избыточно узко

### Желаемое состояние (To-Be)

- **Таблица на полную ширину** когда товар не выбран
- **Slide-out панель справа** появляется только при выборе товара
- **Overlay** с затемнением фокусирует внимание на форме
- **Закрытие**: кнопка X, клик на overlay, Escape, кнопка "Отмена"

## User Stories

### US-1: Просмотр полного списка товаров

**Как** пользователь страницы COGS
**Я хочу** видеть таблицу товаров на всю ширину экрана
**Чтобы** просматривать больше информации одновременно без лишних пустых блоков

### US-2: Назначение COGS через slide-out панель

**Как** пользователь
**Я хочу** чтобы форма COGS выезжала справа при клике на товар
**Чтобы** сфокусироваться на назначении себестоимости без переключения страниц

### US-3: Закрытие панели

**Как** пользователь
**Я хочу** закрыть панель несколькими способами (X, Escape, клик вне, Отмена)
**Чтобы** быстро вернуться к просмотру списка товаров

### Архитектура изменений

#### 1. Обновить `sheet.tsx` - добавить вариант `wide`

```typescript
const sheetVariants = cva(
  "fixed z-50 gap-4 bg-background p-6 shadow-lg",
  {
    variants: {
      side: {
        // ...existing
        right: "inset-y-0 right-0 h-full w-3/4 border-l sm:max-w-sm",
      },
      size: {
        default: "",
        wide: "sm:max-w-md lg:max-w-lg",  // ~480-512px для формы COGS
      }
    },
    defaultVariants: {
      side: "right",
      size: "default",
    },
  }
)
```

#### 2. Рефакторинг `cogs/page.tsx`

**Before:**

```tsx
<div className="grid gap-6 lg:grid-cols-2">
  <Card>{/* ProductList */}</Card>
  <Card>{/* SingleCogsForm или EmptyState */}</Card>
</div>
```

**After:**

```tsx
<div className="space-y-6">
  <Card className="w-full">
    <ProductList onProductSelect={handleProductSelect} />
  </Card>

  <Sheet open={!!selectedProduct} onOpenChange={handleSheetClose}>
    <SheetContent side="right" size="wide">
      <SheetHeader>
        <SheetTitle>Назначение себестоимости</SheetTitle>
        <SheetDescription>
          Укажите себестоимость для товара {selectedProduct?.nm_id}
        </SheetDescription>
      </SheetHeader>

      <SingleCogsForm
        nmId={selectedProduct.nm_id}
        productName={selectedProduct.sa_name}
        existingCogs={selectedProduct.cogs}
        onSuccess={handleCogsSuccess}
        onCancel={handleSheetClose}
      />
    </SheetContent>
  </Sheet>
</div>
```

#### 3. State Management

```typescript
const [selectedProduct, setSelectedProduct] = useState<ProductListItem | null>(null)

const handleProductSelect = (product: ProductListItem) => {
  setSelectedProduct(product)
}

const handleSheetClose = () => {
  setSelectedProduct(null)
}

const handleCogsSuccess = () => {
  // Опционально: закрыть панель или показать success state
  setSelectedProduct(null)
}
```
