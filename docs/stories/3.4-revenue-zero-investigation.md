# Проблема: Revenue (Вайлдберриз реализовал Товар) всегда показывает 0 в трендах

**Дата:** 2025-11-22  
**Story:** 3.4 (Trend Graphs for Key Metrics)  
**Приоритет:** HIGH  
**Статус:** 🔍 Исследование

## 🔍 Анализ проблемы

### Симптомы

На графике трендов значение "Вайлдберриз реализовал Товар" (Revenue) всегда показывает **0** для всех недель, хотя пользователь утверждает, что это не может быть правильно.

### Проверка данных в БД

**Кабинет:** `f75836f7-c0bc-4b2c-823c-a1f3508cce8e` (активный)

**Результаты запроса:**

```sql
SELECT week, sale_gross_total, to_pay_goods_total
FROM weekly_payout_total
WHERE cabinet_id = 'f75836f7-c0bc-4b2c-823c-a1f3508cce8e'
ORDER BY week DESC LIMIT 10;
```

| Неделя   | sale_gross_total | to_pay_goods_total |
| -------- | ---------------- | ------------------ |
| 2025-W46 | **0.00**         | 195470.62          |
| 2025-W45 | **0.00**         | 194730.40          |
| 2025-W44 | **0.00**         | 254857.18          |
| 2025-W43 | **0.00**         | 226205.27          |
| 2025-W42 | **0.00**         | 283230.24          |
| 2025-W41 | **0.00**         | 281572.02          |
| 2025-W40 | **0.00**         | 384079.04          |
| 2025-W39 | **0.00**         | 340100.47          |

**Вывод:** В БД для этого кабинета действительно все значения `sale_gross_total = 0.00`.

### Проверка других кабинетов

**Кабинет:** `63e9ebc3-0203-4819-82ed-390f19f92e14`

**Результаты:**

```sql
SELECT week, sale_gross_total, to_pay_goods_total
FROM weekly_payout_total
WHERE cabinet_id = '63e9ebc3-0203-4819-82ed-390f19f92e14'
AND sale_gross_total > 0;
```

| Неделя   | sale_gross_total | to_pay_goods_total |
| -------- | ---------------- | ------------------ |
| 2025-W36 | **311381.04**    | 283210.63          |
| 2025-W34 | **383993.26**    | 335931.08          |

**Вывод:** У других кабинетов есть ненулевые значения `sale_gross_total`.

## 🔍 Проверка кода frontend

### Текущая реализация в `useTrends.ts`

```typescript
// Строка 60-61: Выбор summary
const summary = summaryResponse.summary_total || summaryResponse.summary_rus

// Строка 68: Извлечение revenue
const revenue = summary.sale_gross_total ?? summary.sale_gross ?? 0
```

**Логика:**

1. Используется `summary_total` (консолидированный) или fallback на `summary_rus`
2. Извлекается `sale_gross_total` или fallback на `sale_gross`
3. Если оба `undefined`, используется `0`

### Потенциальные проблемы

1. **Проблема 1: Данные в БД действительно 0**
   - Если в БД `sale_gross_total = 0.00`, то API вернет `0.00`
   - Frontend корректно отображает `0.00`
   - **Но:** Пользователь утверждает, что это неправильно

2. **Проблема 2: Backend не агрегирует данные правильно**
   - Возможно, backend не заполняет `sale_gross_total` при агрегации
   - Нужно проверить, что отдает API

3. **Проблема 3: Используем неправильный summary**
   - Возможно, данные есть в `summary_rus` или `summary_eaeu`, но мы используем `summary_total`
   - Нужно проверить все три summary

4. **Проблема 4: Поле называется по-другому**
   - Возможно, в API ответе поле называется не `sale_gross_total`, а как-то иначе
   - Нужно проверить полную структуру ответа
