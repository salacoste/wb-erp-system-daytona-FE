# Story 6.3: Stockout Table & Detail Panel

## Status

✅ Ready for QA

---

## Story

**As a** seller,
**I want** to see a detailed table of products with stockout risk and expandable details,
**so that** I can make informed reorder decisions.

---

## Acceptance Criteria

### Table Requirements

1. **Table displays all SKUs** with stock data
2. **Columns include**:
   - Status icon (⬛🔴🟠🟡🟢) — 5 статусов: out_of_stock, critical, warning, low, healthy
   - SKU / Article
   - Product name
   - Stock (units)
   - In Transit (units)
   - Velocity (units/day)
   - Days until stockout
   - Recommended reorder qty
   - Reorder value (₽)
   - Action button
3. **Sortable**: Click column headers to sort
4. **Filterable**: Filter by status (from cards or dropdown)
5. **Searchable**: Search by SKU or product name
6. **Row colors**: Background color based on status
7. **Pagination**: Handle 100+ SKUs with pagination

### Detail Panel

8. **Expandable rows**: Click row to expand detail panel
9. **Detail panel shows**:
   - Current situation summary
   - 7-day forecast (daily breakdown)
   - Reorder calculation breakdown
   - Cost/profit analysis
   - Supplier info (if available)
10. **Velocity trend chart**: Mini sparkline in detail panel

### Actions

11. **Action buttons**: "Заказать" / "Планировать" based on status
12. **Export**: CSV export of table data

### 📂 Expandable Row Design

#### Expand/Collapse Behavior

> **✅ ОБНОВЛЕНО 2025-12-12: Multiple open (UX решение Q9)**

| Property                  | Value                                                                  |
| ------------------------- | ---------------------------------------------------------------------- |
| Trigger                   | **Chevron icon only** (not entire row - prevents accidental expansion) |
| Animation                 | Slide down, 200ms ease-out                                             |
| Multiple expanded         | **Yes** — пользователь может сравнивать несколько SKU одновременно     |

**Обоснование**: Закрытие одной панели при открытии другой раздражает пользователей при сравнении товаров.

- Closed: `ChevronRight` (Lucide)
- Open: `ChevronDown` (Lucide)
- Color: `text-gray-400`, hover: `text-gray-600`
- Transition: Rotate 90° on expand

### 💰 COGS Missing Indicator (UX решение Q5)

> **✅ ДОБАВЛЕНО 2025-12-12**

**Проблема**: Для SKU без себестоимости нельзя рассчитать маржу и прибыль.

**Решение**: Em-dash + Tooltip + CTA

| Элемент     | Визуализация                              |
| ----------- | ----------------------------------------- |
| **Маржа**   | `—` серым цветом (`text-gray-400`)        |
| **Tooltip** | "Укажите себестоимость для расчёта маржи" |
| **Иконка**  | `CircleHelp` (h-3 w-3) рядом с `—`        |
| **CTA**     | Link "Указать COGS" в detail panel        |

**Пример в таблице**:

```typescript
{hasCogs ? (
  <span className="text-green-600">{formatPercent(margin)}</span>
) : (
  <span className="text-gray-400 flex items-center gap-1">
    —
    <Tooltip content="Укажите себестоимость для расчёта маржи">
      <CircleHelp className="h-3 w-3" />
    </Tooltip>
  </span>
)}
```
