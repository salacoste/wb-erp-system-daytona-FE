## 🔴 CRITICAL Questions — Ответы

### Q1: Дизайн для `out_of_stock` статуса

**Решение:** Новый статус с уникальным визуальным стилем

| Атрибут      | Значение             | Обоснование                                                      |
| ------------ | -------------------- | ---------------------------------------------------------------- |
| **Цвет**     | `#1F2937` (Gray-800) | Чёрный/тёмно-серый = "мёртвый" товар. Красный уже занят critical |
| **Иконка**   | `PackageX` (Lucide)  | Перечёркнутая коробка = нет товара                               |
| **Label RU** | `Нет в наличии`      | Короткий вариант: `Нет`                                          |
| **Позиция**  | **Первый** в списке  | Самый критичный → первый                                         |

### Q3: 4 или 5 карточек в Dashboard?

**Решение: 5 карточек** (отдельная для `out_of_stock`)

**Обоснование:**

1. Разные действия: `out_of_stock` = "срочно заказать", `critical` = "скоро закончится"
2. Разная срочность: 0 остаток vs 1-7 дней
3. Бизнес-метрика: Количество "мёртвых" SKU — важный KPI

**Layout:**

```
┌──────────────────────────────────────────────────────────────┐
│  ⬛ Нет в     🔴 Критично   🟠 Внимание   🟡 Низкий   🟢 Норма │
│  наличии     (0-7 дн)      (7-14 дн)    (14-30 дн)  (>30 дн) │
│     12          8             15           45         120    │
└──────────────────────────────────────────────────────────────┘
```

## 🟡 MEDIUM Questions — Ответы

### Q4: Распределение по складам

**Решение: Tooltip + Detail Panel**

| Контекст         | Реализация                     |
| ---------------- | ------------------------------ |
| **Таблица**      | Основной склад + badge `+N`    |
| **Tooltip**      | Hover на `+N` → список складов |
| **Detail Panel** | Полная таблица склад → остаток |

**Пример:**

```
| Артикул | Остаток | Склады           |
|---------|---------|------------------|
| 12345   | 150 шт  | Коледино +2      | ← hover показывает все
```

### Q6: Иконки velocity trend

**✅ ПОДТВЕРЖДЕНО:**

| Trend       | Иконка | Цвет             | Lucide Component |
| ----------- | ------ | ---------------- | ---------------- |
| `growing`   | ↗️     | `text-green-600` | `TrendingUp`     |
| `stable`    | ➡️     | `text-gray-500`  | `Minus`          |
| `declining` | ↘️     | `text-red-600`   | `TrendingDown`   |

**Контекст:** Для продаж growing = хорошо (зелёный), declining = плохо (красный)
