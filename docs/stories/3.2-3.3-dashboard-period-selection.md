# Dashboard: Период отображения данных по умолчанию

**Дата:** 2025-11-21  
**Stories:** 3.2 (Key Metric Cards Display), 3.3 (Expense Breakdown Visualization)

---

## 📅 Текущее поведение

### Период по умолчанию

**Dashboard показывает данные за самую новую (последнюю) неделю** из списка доступных недель.

### Логика выбора недели

1. **Получение списка доступных недель:**
   - Endpoint: `GET /v1/analytics/weekly/available-weeks`
   - Backend возвращает недели отсортированными по убыванию (`ORDER BY week DESC`)
   - Формат ответа: `{ data: [{ week: "2025-W46", start_date: "2025-11-09" }, ...] }`

2. **Выбор недели:**
   - Frontend использует **первую неделю из массива** (`weeks[0]`)
   - Так как backend сортирует по убыванию, первая неделя = самая новая

3. **Получение данных:**
   - Endpoint: `GET /v1/analytics/weekly/finance-summary?week={latestWeek}`
   - Используется выбранная неделя для получения метрик и расходов

### Код реализации

**Файл:** `src/hooks/useDashboard.ts` (строки 49-74)

```typescript
// Получаем список доступных недель
const weeksResponse = await apiClient.get('/v1/analytics/weekly/available-weeks')
const weeks = weeksArray.map((w) => w.week)

// Выбираем первую неделю (самую новую)
const latestWeek = weeks[0]  // ← Самая новая неделя

// Получаем данные за эту неделю
const summaryResponse = await apiClient.get(
  `/v1/analytics/weekly/finance-summary?week=${latestWeek}`
)
```

**Файл:** `src/hooks/useExpenses.ts` (строки 33-60)

```typescript
// Аналогичная логика для расходов
const latestWeek = weeks[0]  // ← Самая новая неделя
const summaryResponse = await apiClient.get(
  `/v1/analytics/weekly/finance-summary?week=${latestWeek}`
)
```

## 🔄 Обновление данных

### Автоматическое обновление

- **При фокусе окна:** `refetchOnWindowFocus: true` в TanStack Query
- **Stale time:** 30 секунд (данные считаются свежими 30 секунд)
- **Cache time:** 5 минут (данные хранятся в кеше 5 минут)

### Когда данные обновляются

1. При открытии/переключении на вкладку браузера
2. При ручном обновлении страницы (F5)
3. При клике на кнопку "Повторить" в случае ошибки

### Что происходит при обновлении

1. Запрашивается актуальный список доступных недель
2. Выбирается первая неделя (самая новая)
3. Если появилась новая неделя, она автоматически становится выбранной
4. Данные обновляются для новой недели

## ⚠️ Важные замечания

### 1. Нет выбора периода пользователем

**Текущая реализация:**

- ❌ Пользователь **не может выбрать** период отображения
- ❌ Всегда показывается только самая новая неделя
- ❌ Нет возможности посмотреть данные за другие недели

### 2. Пустой список недель

Если `available-weeks` возвращает пустой массив:

- Метрики не отображаются (показывается "Нет данных")
- Расходы не отображаются (показывается сообщение о недоступности данных)
- Это нормальное состояние, если данные еще не обработаны

### 3. Гарантия доступности данных (Story 2.7)

После деплоя Story 2.7:

- ✅ Если неделя есть в списке `available-weeks`, данные гарантированно доступны через `finance-summary`
- ✅ Не нужно делать множественные запросы для проверки доступности
- ✅ Race condition устранен
