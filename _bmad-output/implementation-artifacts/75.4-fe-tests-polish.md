### Previous Story Learnings (75.1 + 75.2 + 75.3)

**Critical patterns established in 75.1–75.3:**
- `parseDecimal()` from `@/lib/decimal-utils` for ALL Decimal-as-string fields
- Page pattern: `page.tsx` → `usePageState` hook → sub-components in `components/custom/`
- Use `<form onSubmit>` wrapper in dialogs for Enter-key support
- Use `aria-label` on icon-only buttons (NOT `title`)
- Use `aria-describedby` + `aria-invalid` on ALL form inputs with validation errors
- Use regular `Button` (NOT `AlertDialogAction`) for async operations in AlertDialogs
- Block dialog close during pending mutation: `onOpenChange={v => !v && !mutation.isPending && onClose()}`
- Column interface pattern: `interface Column { key: string; label: string; align?: 'right' }`
- ProductCombobox: Popover+Command with `shouldFilter={false}` for server-side filtering
- 300ms debounce on ProductCombobox search to prevent API flood
- Cached `selectedLabel` in ProductCombobox to preserve display after popover close
- BulkAddDialog: 3-step wizard (input→preview→results) with CSV/tab/semicolon parsing
- SKU Packaging uses POST upsert (no PUT endpoint) — `useCreateSkuPackaging` for both create and edit

### Test Pattern Reference

**Hook tests** (follow `src/hooks-v1/__tests__/useBulkCogsAssignment.test.ts` pattern):
```typescript
import { describe, it, expect, vi, beforeEach, afterEach } from 'vitest'
import { renderHook, waitFor, act } from '@testing-library/react'
import { createQueryWrapper } from '@/test/utils/test-utils'

// Mock API functions
vi.mock('@/lib/api/shipment-cost', () => ({
  getBoxTypes: vi.fn(),
  createBoxType: vi.fn(),
  // ...
}))

import { getBoxTypes, createBoxType } from '@/lib/api/shipment-cost'

describe('useBoxTypes', () => {
  beforeEach(() => { vi.clearAllMocks() })
  afterEach(() => { vi.restoreAllMocks() })

  it('fetches box types on mount', async () => {
    vi.mocked(getBoxTypes).mockResolvedValue(mockBoxTypes)
    const { result } = renderHook(() => useBoxTypes(), {
      wrapper: createQueryWrapper(),
    })
    await waitFor(() => expect(result.current.isSuccess).toBe(true))
    expect(result.current.data).toEqual(mockBoxTypes)
  })
})
```

### Anti-Patterns to Avoid

- **Do NOT recreate `decimal-utils.test.ts`** — it already exists and covers all edge cases
- **Do NOT use `@testing-library/jest-dom` imports** — project uses Vitest's `expect` with matchers from test setup
- **Do NOT mock entire `@tanstack/react-query`** unless testing invalidation — use `createQueryWrapper()` instead
- **Do NOT use `fireEvent`** — use `userEvent.setup()` for user interactions (project convention)
- **Do NOT create test fixtures in `src/test/fixtures/`** — inline mock data in test files (scope too small for shared fixtures)
- **Do NOT skip `aria-label` assertions on icon-only buttons** — this was a 75.2 review finding
- **Do NOT skip `aria-describedby`/`aria-invalid` assertions on form inputs** — this was a 75.3 review finding
