## Insights

- **I-1**: Agent wave size of 8-10 is optimal — larger waves increase rate-limit probability without proportional throughput gain
- **I-2**: "Fix" agents should run AFTER stub agents complete, not concurrently — concurrent fixes create merge conflicts
- **I-3**: Single-file agents (1 file per agent) have higher success rate than multi-file agents for complex component tests
- **I-4**: Radix UI components (RadioGroup, Dialog, Popover) consistently require jsdom-specific test patterns — should document these
