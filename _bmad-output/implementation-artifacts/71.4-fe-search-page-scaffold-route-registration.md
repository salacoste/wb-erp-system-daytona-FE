# Story 71.4: Search Page Scaffold & Route Registration

Status: done

## Story

As a **seller navigating the dashboard**,
I want to find and access a Search Analytics page from the sidebar and analytics hub,
so that I can view search-attributed orders and keyword data in one place.

## Acceptance Criteria

1. **AC1: Route registered** — `ROUTES.ANALYTICS.SEARCH` equals `'/analytics/search'`, is listed in `isProtectedRoute()`, and the route redirects correctly in the browser.
2. **AC2: Sidebar item** — Sidebar shows "Поиск" item with `Search` icon (lucide-react) between "Аналитика возвратов" and "Мониторинг". Clicking navigates to `/analytics/search`.
3. **AC3: Analytics hub card** — Analytics hub page (`/analytics`) shows a "Поисковая аналитика" card in the `strategic` section with `Search` icon, description "Поисковые запросы, позиции и заказы", and a "Джем" badge.
4. **AC4: Page renders with tabs** — `/analytics/search` renders a page with title "Поисковая аналитика", wrapped in `<RequireJam requiredTier="standard">`, containing 3 tabs: "Заказы" (default active), "По товарам", "По запросам". Tab content is placeholder text for now (implemented in stories 71.5-71.7).
5. **AC5: Tests pass** — Unit tests cover: route constant exists, sidebar renders Search item, page renders with RequireJam, tab switching works. `npm run lint && npm run type-check` passes.
6. **AC6: All source files under 200 lines** — Page, PageContent, and test files each under 200 lines.
