# Story 75.2: Box Types CRUD Page

Status: done

## Story

As a **seller**,
I want to manage box type dimensions (length, width, height),
so that I can define the packaging I use for shipments to WB warehouses.

## Acceptance Criteria

1. **Empty state**: When no box types exist, display "Добавьте типы коробок для расчёта стоимости доставки" with a primary CTA "Добавить тип коробки"
2. **DataTable**: When box types exist, display columns: Название, Размеры (Д×Ш×В, см), Объём (см³), Действия — volume formatted with Russian locale
3. **Create dialog**: Form with fields: name (required), length (required, > 0), width (required, > 0), height (required, > 0). Submits `POST /v1/box-types`, refreshes list. Inline validation errors.
4. **Edit dialog**: Pre-filled with current values. Submits `PUT /v1/box-types/:id`, refreshes list.
5. **Deactivate**: Confirmation dialog, then `DELETE /v1/box-types/:id` (soft-delete). Box type disappears from active list.
6. **Decimal parsing**: All Decimal-as-string fields rendered via `parseDecimal()` from `@/lib/decimal-utils`
7. **Error handling**: API errors (409 duplicate name, 409 has bindings) shown as toast or inline message
8. **Loading/error states**: Skeleton loading, error alert with retry button
9. **All files ≤ 200 lines**, `@/` imports, no `any` types, `'use client'` only on files with React hooks

### Backend API — Box Types (Exact Spec)

| Method | Path | Status | Notes |
|--------|------|--------|-------|
| `POST` | `/v1/box-types` | 201 | Body: `{ name, lengthCm, widthCm, heightCm }` (numbers). Returns BoxType with Decimal strings. Errors: 400 validation, 409 duplicate name |
| `GET` | `/v1/box-types?includeInactive=false` | 200 | Returns `BoxType[]`. Default excludes inactive |
| `GET` | `/v1/box-types/:id` | 200/404 | Returns single `BoxType` |
| `PUT` | `/v1/box-types/:id` | 200 | Partial body: `{ name?, lengthCm?, widthCm?, heightCm? }`. Errors: 400, 404, 409 (name conflict or dimension change with bindings) |
| `DELETE` | `/v1/box-types/:id` | 200 | Soft-delete via `isActive: false`. Returns deactivated BoxType. Errors: 404, 409 (has sku_packaging or box_line bindings) |

### BoxType Response Shape (from backend)

```typescript
// All dimension/volume fields are Decimal strings!
interface BoxType {
  id: string              // UUID
  cabinetId: string       // UUID
  name: string            // Unique per cabinet
  lengthCm: string        // "60.00"
  widthCm: string         // "40.00"
  heightCm: string        // "40.00"
  volumeCm3: string       // "96000.0000" (auto-calculated by backend)
  isActive: boolean
  createdAt: string       // ISO datetime
  updatedAt: string       // ISO datetime
}
```

### Error Handling (409 Responses)

The `apiClient` throws on non-2xx responses. Catch in the mutation's `onError`:

```typescript
const createMutation = useCreateBoxType()
// On submit:
createMutation.mutateAsync(data).catch(err => {
  // err.message likely contains the backend error
  // Show toast or set local error state
})
```

For 409 errors:
- **Duplicate name**: "Тип коробки с таким названием уже существует"
- **Has bindings on deactivate**: "Невозможно деактивировать — есть привязки к товарам"

### Formatting Utility

Use local `formatCurrency`-style pattern for volumes. Russian locale number formatting:

```typescript
parseDecimal(volumeCm3).toLocaleString('ru-RU') // "96 000" for volumeCm3
```

Do NOT import `formatCurrency` from other modules — it's for monetary values. Volume is just a formatted number with unit suffix "см³".
