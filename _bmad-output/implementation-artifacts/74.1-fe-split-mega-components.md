### Proven Extraction Patterns (from Epics 72-73)

**Table Column Extraction** (BuyoutTable refactor, 72.5):
```typescript
// buyout-table-columns.tsx pattern:
export function getBuyoutColumns(options: ColumnOptions): ColumnDef[] {
  return [
    { header: '...', cell: (row) => formatValue(row.field) },
    // ...
  ]
}
```
Follow this exact pattern for PerformanceMetricsTable, SkuFinancialsTable, FinancialSummaryTable.

**Chart Config Extraction** (DailyTrendChart, 72.3):
```typescript
// daily-trend-config.ts pattern:
export const CHART_CONFIG = { ... }
export const TOOLTIP_CONFIG = { ... }
```
Follow for PnLWaterfall chart config.

**Sub-Component Extraction** (Sidebar, code review):
```typescript
// Original file becomes thin orchestrator:
import { NavigationItems } from './sidebar-navigation'
import { SubComponent } from './SubComponent'
export default function MainComponent() { /* orchestration only */ }
```

### Critical Rules

1. **NEVER change functionality** — this is pure structural refactoring
2. **Re-export from original path** — consumers must not need changes
3. **Run tests after EACH file split** — don't batch validation
4. **Keep `'use client'` directive** — must be on every client component file
5. **File size limit is 200 lines** — ESLint enforced, no exceptions
6. **Extracted files also ≤200 lines** — don't just move the problem

### Import Backward Compatibility Pattern

```typescript
// In original file (e.g., FinancialSummaryTable.tsx):
export { FinancialSummaryTable } from './financial-summary/FinancialSummaryTable'
export type { FinancialSummaryTableProps } from './financial-summary/FinancialSummaryTable'
```
This keeps all existing consumers working without changes.

### Project Structure Notes

- Path alias: `@/components/custom/` → `src/components/custom/`
- `'use client'` required on ALL component files using hooks/state
- shadcn/ui components in `src/components/ui/` — DO NOT EDIT
- Test files co-located with source or in `__tests__/` subdirectory
