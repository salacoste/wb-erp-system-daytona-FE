### Critical: brandName NOT Sortable

`FunnelParams.sort` only supports: `'openCardCount' | 'ordersCount' | 'buyoutCount' | 'totalConversion' | 'cancelRate'`. The `brandName` column is **not sortable** — it's a plain `<TableHead>` without `<SortBtn>`, matching how "nmId", "Артикул", and "Корзина" are currently handled.

### Type: brandName Already Available

`FunnelProductItem.brandName?: string` was added in Story 72.1-FE (types alignment). No type changes needed. The backend funnel endpoint already returns `brandName` when available.

### Truncation Pattern

Follow the BuyoutTable row pattern for brand name truncation:
```tsx
<TableCell className="text-sm max-w-40 truncate" title={item.brandName || undefined}>
  {item.brandName || '—'}
</TableCell>
```
- `max-w-40` (160px) constrains column width
- `truncate` adds text-overflow ellipsis
- `title` native tooltip shows full name on hover
- This is the same pattern used in buyout-table-columns.tsx line 80-84
