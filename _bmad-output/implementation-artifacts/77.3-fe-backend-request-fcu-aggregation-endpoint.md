### Key Technical Context

**FCU formula** (from request #161):
```
FCU = PCU + DCU
PCU = Production Cost per Unit (from COGS table)
DCU = Delivery Cost per Unit (calculated by shipment cost allocation)
```

**Data model for the aggregation query** (from request #161 §2):
```
Shipment (1) → (N) ShipmentPallet (1) → (N) ShipmentBoxLine
   │ status = CONFIRMED                        │ has: nmId, deliveryCostPerUnit,
   │ confirmedAt                                │      finalCostPerUnit, unitCostRub
   ▼
ShipmentCostSnapshot (frozen on confirm)
```

**ShipmentBoxLine calculated fields** (Decimal strings from Prisma):
| Field | Meaning |
|-------|---------|
| `productionCostPerUnit` (DB: `production_cost_per_unit`) | PCU — production cost per unit |
| `deliveryCostPerUnit` | DCU — delivery cost per unit |
| `finalCostPerUnit` | FCU = PCU + DCU |
| `finalCostLine` | FCL = FCU × totalUnits |

**Frontend consumer** — Story 77.4 will create:

### SQL Sketch (to include in request doc)

```sql
-- Per-SKU FCU from latest confirmed shipment
SELECT DISTINCT ON (bl.nm_id)
  bl.nm_id                AS "nmId",
  p.vendor_code           AS "productName",
  bl.production_cost_per_unit::float AS "latestPcu",
  bl.delivery_cost_per_unit::float AS "latestDcu",
  bl.final_cost_per_unit::float   AS "latestFcu",
  s.id                    AS "shipmentId",
  s.name                  AS "shipmentName",
  s.confirmed_at          AS "confirmedAt"
FROM shipment_box_lines bl
  JOIN shipment_pallets sp ON sp.id = bl.pallet_id
  JOIN shipments s ON s.id = sp.shipment_id
  LEFT JOIN products p ON p.nm_id = bl.nm_id
WHERE s.status = 'CONFIRMED'
  AND s.cabinet_id = :cabinetId
  AND bl.final_cost_per_unit IS NOT NULL
ORDER BY bl.nm_id, s.confirmed_at DESC;
```

**Index recommendation**: `CREATE INDEX idx_shipments_cabinet_status_confirmed ON shipments (cabinet_id, status, confirmed_at DESC)`
