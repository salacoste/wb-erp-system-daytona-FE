### Product List Source: Funnel API, Not Products API

The AC says "Options sourced from the current funnel data." This means:
- **DO**: Fetch all products from `useFunnelData(from, to, { limit: 1000 })` — these are products with funnel activity in the date range
- **DON'T**: Use `useProducts()` hook (that searches the products catalog, not funnel data)

The product list fetch is a separate React Query call with its own cache key (different `limit` from the table's paginated fetch). Each `FunnelProductItem` has: `nmId`, `vendorCode`, `brandName` — use these for the combobox options.

### Product Options Extraction Pattern

```typescript
// Inside FunnelProductFilter:
const { data } = useFunnelData(from, to, { limit: 1000 })
const products = useMemo(() => {
  const items = (data?.items ?? []) as FunnelProductItem[]
  return items.map(i => ({ nmId: i.nmId, name: i.vendorCode ?? `nmId: ${i.nmId}`, brand: i.brandName }))
}, [data])

// Client-side search (no debounce — data is local):
const filtered = products.filter(p =>
  p.name.toLowerCase().includes(search.toLowerCase()) ||
  p.brand?.toLowerCase().includes(search.toLowerCase()) ||
  String(p.nmId).includes(search)
)
```

### URL Param Pattern: Extend Existing compare Toggle

FunnelPageContent already manages `?compare=wow` via `useSearchParams`. Add `nmIds` alongside it:

```typescript
// Read
const nmIdsParam = searchParams.get('nmIds')
const nmIds = nmIdsParam ? nmIdsParam.split(',').map(Number).filter(n => !isNaN(n)) : []

// Write (in setNmIds callback)
function setNmIds(ids: number[]) {
  const params = new URLSearchParams(searchParams.toString())
  if (ids.length > 0) {
    params.set('nmIds', ids.join(','))
  } else {
    params.delete('nmIds')
  }
  const qs = params.toString()
  router.replace(qs ? `${pathname}?${qs}` : pathname)
}
```

**Important**: This preserves the existing `compare` param. Both params coexist: `?compare=wow&nmIds=123,456`.

When the user changes the product filter, the table pagination must reset to page 1 (offset=0). In FunnelTable.tsx:


**Gotcha**: Use a stable reference for nmIds comparison. Since arrays from URL params create new references on every render, use `JSON.stringify(nmIds)` as the useEffect dependency or derive nmIds as a string in the parent.

### FunnelChart Filtering Decision

The `FunnelChart` component uses `groupBy: 'day'` (time series, not per-product). The AC doesn't mention chart filtering. **Decision**: Pass `nmIds` to `FunnelChart` for API-level filtering (backend sums metrics for selected products per day). This gives correct daily trends for the filtered set without any chart code changes — just pass the prop through.
