## Dev Notes

### Proven Extraction Patterns (from Story 74.1)

**Page State Hook Extraction** (sku/page.tsx, 74.1 Task 6):
```typescript
// useSkuPageState.ts pattern:
'use client'
export function useSkuPageState() {
  // All useState, URL params, data hooks
  return { ...state, ...handlers, ...data }
}
```
Follow this exact pattern for analytics/page.tsx, advertising/page.tsx, brand/page.tsx, category/page.tsx, storage/page.tsx.

**Barrel Re-Export** (when component is imported by external consumers):
```typescript
// Original file becomes thin re-export:
export { ComponentName } from './subfolder/ComponentName'
export type { PropsType } from './subfolder/types'
```
Only needed for SupplyPlanningTable and SupplyPlanningDetail (imported by other components). Page files don't need barrels.

**Sub-Component Extraction** (PnLWaterfall sections, 74.1 Task 2):
```typescript
// Section component receives pre-computed props:
interface SectionProps { data: SomeType; onAction: () => void }
export function SectionComponent({ data, onAction }: SectionProps) { ... }
```

### Critical Rules

1. **NEVER change functionality** — this is pure structural refactoring
2. **Keep `'use client'` directive** — must be on every .tsx component file and hook files using React hooks
3. **Run tests after EACH file split** — don't batch validation
4. **File size limit is 200 lines** — ESLint enforced, no exceptions
5. **Extracted files also ≤200 lines** — don't just move the problem
6. **Type re-exports in barrels** — include all exported types (lesson from 74.1 code review)
7. **Page files are self-contained** — no barrel re-export needed for Next.js page files

### Shared Hook Opportunity (Task 3)

Brand and category pages share ~90% identical code. Extract `useMarginPageState.ts` to `src/app/(dashboard)/analytics/shared/` directory as a shared hook. Both pages call it with their specific data hook.

- shadcn/ui components in `src/components/ui/` — DO NOT EDIT
- Existing components/ directories: advertising (24 files), supply-planning (8 files), storage (11 files)
