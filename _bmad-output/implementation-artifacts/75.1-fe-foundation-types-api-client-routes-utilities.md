## Dev Notes

### Backend API Reference

**Box Types** (`/v1/box-types`) — 5 endpoints:

| Method | Path | Function Name | Notes |
|--------|------|---------------|-------|
| `POST` | `/v1/box-types` | `createBoxType` | Body: `{ name, lengthCm, widthCm, heightCm }` → 201 |
| `GET` | `/v1/box-types?includeInactive=false` | `getBoxTypes` | Returns `BoxType[]` |
| `GET` | `/v1/box-types/:id` | `getBoxType` | Returns `BoxType` or 404 |
| `PUT` | `/v1/box-types/:id` | `updateBoxType` | Body: partial `{ name?, lengthCm?, widthCm?, heightCm? }` → 200 |
| `DELETE` | `/v1/box-types/:id` | `deactivateBoxType` | Soft-delete: returns `BoxType` with `isActive: false`. 409 if has bindings |

**SKU Packaging** (`/v1/sku-packaging`) — 5 endpoints:

| Method | Path | Function Name | Notes |
|--------|------|---------------|-------|
| `POST` | `/v1/sku-packaging` | `createSkuPackaging` | Body: `{ nmId, boxTypeId, unitsPerBox }` → 201 |
| `POST` | `/v1/sku-packaging/bulk` | `bulkCreateSkuPackaging` | Body: `{ items: [...] }` → 201 with partial success |
| `GET` | `/v1/sku-packaging?nmId=&boxTypeId=` | `getSkuPackaging` | Returns `SkuPackaging[]` with nested `boxType` + `product` |
| `GET` | `/v1/sku-packaging/:nmId` | `getSkuPackagingByNmId` | Returns single `SkuPackaging` or 404 |
| `DELETE` | `/v1/sku-packaging/:nmId` | `deleteSkuPackaging` | Returns 204. 409 if used in shipment box lines |

### Decimal-as-String Pattern (CRITICAL)

Backend returns Prisma DECIMAL fields as **strings**: `"96000.0000"`, `"60.00"`, `"40.00"`. The frontend MUST `parseFloat()` these before rendering or calculating.

**Exception**: The `/v1/shipments/:id/calculate` response returns **numbers** (not strings). This is specific to the calculate endpoint only.

```typescript
// src/lib/decimal-utils.ts
export function parseDecimal(value: string | number | null | undefined): number {
  if (value === null || value === undefined) return 0
  if (typeof value === 'number') return Number.isNaN(value) ? 0 : value
  const parsed = parseFloat(value)
  return Number.isNaN(parsed) ? 0 : parsed
}
```

- All paths use `@/` aliases (configured in tsconfig.json)
- API modules go in `src/lib/api/` (domain subfolders allowed — `shipment-cost/`)
- Types go in `src/types/` (one file per domain)
