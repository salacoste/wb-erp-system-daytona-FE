## User Story

**As a** seller viewing the advertising analytics page,
**I want** to see a visual timeline of which days have complete synced data and which have gaps,
**so that** I can understand if missing data is affecting my analytics accuracy.

### Backend Already Returns dataGaps — No API Changes Needed

The `SyncStatusResponse` type already includes gap data:

```typescript
// src/types/advertising-analytics.ts:371
export interface SyncStatusResponse {
  lastSyncAt: string | null
  nextScheduledSync: string
  status: SyncTaskStatus
  campaignsSynced: number
  dataAvailableFrom: string | null  // "2025-12-01"
  dataAvailableTo: string | null    // "2026-03-07"
  dataLagDays?: number | null
  healthStatus?: 'ok' | 'warning' | 'stale' | 'no_data'
  dataGaps?: Array<{ from: string; to: string; missingDays: number }>
}
```

- **API endpoint**: `GET /v1/analytics/advertising/sync-status` (no params)
- **Hook**: `useAdvertisingSyncStatus()` in `@/hooks/useAdvertisingAnalytics`
- **Already used in page.tsx line 129**: `const { data: syncStatus } = useAdvertisingSyncStatus({ refetchInterval: 0 })`
- **No new API calls needed** — just pass existing `syncStatus` to the new component

### Data Source: syncStatus (NOT daily analytics data)

The timeline derives day statuses from:
1. **Selected date range** (`from`, `to`) — from page's date range picker state
2. **`syncStatus.dataGaps`** — ranges of missing data
3. **`syncStatus.dataAvailableFrom` / `dataAvailableTo`** — bounds of available data

Algorithm in `deriveDayStatuses`:
```typescript
for each day in [from, to]:
  if day < dataAvailableFrom or day > dataAvailableTo → 'unavailable' (gray)
  else if day falls within any dataGaps range → 'missing' (red)
  else → 'complete' (green)
```

**Simplification**: The epic mentions "yellow = partial" but `dataGaps` doesn't provide per-day record counts. Stick with 3 states (complete/missing/unavailable). "Partial" can be added later if backend provides per-day counts.

### Tooltip Pattern: Use shadcn Tooltip

The existing `SyncStatusIndicator.tsx` already uses shadcn Tooltip:


For the timeline, wrap each cell in a `Tooltip`. Use `TooltipProvider` once around the entire timeline container (not per cell — this avoids 90 nested providers).

### Collapsible Pattern: CSS transition (NOT shadcn Collapsible)

Use simple CSS for the collapsible:
```tsx
const [expanded, setExpanded] = useState(false)

  'overflow-hidden transition-all duration-200',

```

This avoids adding a shadcn Collapsible dependency. The pattern is lighter and sufficient for this use case.
