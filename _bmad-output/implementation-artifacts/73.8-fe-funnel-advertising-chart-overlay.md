# Story 73.8: Funnel + Advertising Chart Overlay

Status: done

## Story

As a **seller analyzing marketing effectiveness**,
I want **to see ad spend overlaid on the funnel time series chart**,
so that **I can visually correlate advertising investment with funnel performance**.

## Acceptance Criteria

1. **AC-1: Toggle activation** — Given funnel chart visible with toggle off, When "Показать расходы на рекламу" clicked, Then ad spend line appears on secondary Y-axis
2. **AC-2: Dual-scale rendering** — Given ad spend 500K on a week with 100 orders, When chart renders, Then both metrics visible on their respective scales (funnel counts left, ₽ right)
3. **AC-3: Missing ad data** — Given no advertising data for selected period, When toggle clicked, Then toast "Нет данных о рекламе за выбранный период"
4. **AC-4: Tooltip overlay** — Given overlay is active, When hovering a data point, Then tooltip shows both funnel metric + ad spend for that date

### Data Sources

**Funnel time series**: `useFunnelTimeSeries(from, to)` from `@/hooks/use-funnel-analytics`
- Returns `data?.items` as `FunnelDayItem[]`
- Type from `@/types/analytics-funnel`:
  ```
  FunnelDayItem { date, openCardCount, addToCartCount, ordersCount, buyoutCount,
    cancelCount, cartConversion, orderConversion, buyoutConversion, cancelRate, totalConversion }
  ```

**Advertising daily**: `useAdvertisingAnalytics({...params, include_daily: true})` from `@/hooks/advertising/hooks`
- Returns `data?.daily` as `AdvertisingDailyItem[]`
- Type from `@/types/advertising-analytics`:
  ```
  AdvertisingDailyItem { date, spend, views, clicks, orders, ctr?, cpc?, revenue_attributed? }
  ```
- **IMPORTANT**: Use same `from`/`to` as funnel date range for alignment (AC-4 date sync)
- Params: `{ from: apiFrom, to: apiTo, include_daily: true }` — no need for view_by/sort when only using daily

### Merge Strategy

```typescript
// In funnel-overlay-config.ts or separate util
function mergeFunnelAndAdDaily(
  funnelDays: FunnelDayItem[],
  adDaily: AdvertisingDailyItem[] | undefined
): MergedChartData[] {
  // Build map from ad daily by date
  const adMap = new Map(adDaily?.map(d => [d.date, d]) ?? [])
  return funnelDays.map(day => ({
    ...day,
    adSpend: adMap.get(day.date)?.spend ?? null,
  }))
}
```

### Previous Story Learnings (73.7-FE)

1. **ESLint 200-line limit is strict** — estimate file sizes before writing, use atomic full-file writes
2. **Russian locale** for all user-facing text
3. **Data formatters**: Extract to config/utils file, don't duplicate across components
4. **useMemo dependency granularity**: Extract sub-properties (e.g., `data?.items`) before using as deps
5. **RequireJam** not needed here — funnel page is already inside RequireJam gate
6. **fmtCurrency pattern**: Format as `Intl.NumberFormat('ru-RU', { style: 'currency', currency: 'RUB', maximumFractionDigits: 0 })` → "12 500 ₽"
