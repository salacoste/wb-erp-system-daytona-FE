# Story 71.3: RequireJam Gating Component

Status: done

## Story

As a **non-Jam seller visiting the search analytics page**,
I want to see a compelling blurred preview of real search data with an upgrade prompt,
so that I understand the value of Jam subscription and am motivated to upgrade.

## Acceptance Criteria

1. **AC1: Tier gating works** — Given user has `tier: 'none'`, When `<RequireJam requiredTier="standard">` wraps search content, Then blurred overlay shows with upgrade CTA. Given user has `tier: 'advanced'`, When `<RequireJam requiredTier="standard">` wraps content, Then children render normally without overlay.
2. **AC2: Loading state** — Given Jam status is loading, When component renders, Then skeleton placeholder is shown (no flash of content or gate).
3. **AC3: WCAG keyboard/ARIA** — Given blurred overlay is shown, When user tabs through page, Then CTA button receives focus with visible focus ring. ARIA labels present on overlay and CTA.
4. **AC4: Tests pass** — Unit tests cover: tier sufficient/insufficient, loading state, error state, keyboard focus, ARIA attributes. `npm run lint` passes.
5. **AC5: All files under 200 lines** — Component + test files each under 200 lines.

### Component Implementation — Key Decisions

```typescript
// Tier comparison — add to src/types/cabinet.ts
export const JAM_TIER_LEVEL: Record<JamTier, number> = {
  none: 0,
  standard: 1,
  advanced: 2,
}

export function isJamTierSufficient(userTier: JamTier, requiredTier: JamTier): boolean {
  return JAM_TIER_LEVEL[userTier] >= JAM_TIER_LEVEL[requiredTier]
}
```

```typescript
// RequireJam component structure
interface RequireJamProps {
  requiredTier: JamTier
  children: React.ReactNode
  previewContent?: React.ReactNode
}

export function RequireJam({ requiredTier, children, previewContent }: RequireJamProps) {
  const { cabinetId } = useAuthStore()
  const { data, isLoading, isError } = useJamStatus(cabinetId)

  // Loading → skeleton
  if (isLoading) {
    return <div className="space-y-4"><Skeleton className="h-8 w-full" /><Skeleton className="h-32 w-full" /></div>
  }

  // Error → fail-open (render children)
  if (isError || !data) return <>{children}</>

  // Sufficient tier → render children
  if (isJamTierSufficient(data.tier, requiredTier)) return <>{children}</>

  // Insufficient → blur overlay
  return (
    <div className="relative">
      <div className="blur-[8px] opacity-40 pointer-events-none" aria-hidden="true">
        {previewContent ?? children}
      </div>
      <div
        className="absolute inset-0 bg-white/60 backdrop-blur-sm z-10 rounded-lg flex items-center justify-center"
        role="region"
        aria-label="Требуется подписка WB Джем"
      >
        {/* CTA card */}
      </div>
    </div>
  )
}
```
