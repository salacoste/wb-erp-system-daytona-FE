## Dev Notes

### hooks/ vs hooks-v1/ Architecture

**Critical**: The codebase has TWO identical copies of every hook:
- `src/hooks/` — **PRIMARY** (189 consumer imports)
- `src/hooks-v1/` — **MIRROR** (1 consumer import, used by tests)

**Strategy for this story**: Split `hooks/` files. For `hooks-v1/`, either:
- Option A: Make `hooks-v1/` files re-export from `hooks/` (simplest, DRY)
- Option B: Apply identical splits to both directories
- **Recommended: Option A** — update `hooks-v1/*.ts` to be simple barrel re-exports from `hooks/`

### Barrel Re-Export Pattern (Preserves Consumer API)

```typescript
// hooks/useMarginAnalytics.ts (after split — becomes barrel)
export { useMarginAnalyticsBySku } from './margin-analytics/useMarginAnalyticsBySku'
export { useMarginAnalyticsByBrand } from './margin-analytics/useMarginAnalyticsByBrand'
export { useMarginAnalyticsByCategory } from './margin-analytics/useMarginAnalyticsByCategory'
export { useCabinetLevelExpenses } from './margin-analytics/useCabinetLevelExpenses'
export type { MarginAnalyticsFilters, CabinetLevelExpenses } from './margin-analytics/margin-analytics-query-keys'
```

This ensures **AC #3**: consumers keep importing from same path, no updates needed.

### Extraction Patterns (from Stories 74.1-74.3)

**Hook Split Pattern** (NEW for 74.4):
```typescript
// query-keys.ts — Pure data, NO 'use client'
export const hookQueryKeys = {
  all: ['hookName'] as const,
  byId: (id: string) => [...hookQueryKeys.all, id] as const,
}

// types.ts — Pure data, NO 'use client'
export interface HookOptions { ... }
export interface HookResult { ... }

// useHookName.ts — HAS 'use client' (React hooks used)
'use client'
import { useQuery } from '@tanstack/react-query'
import { hookQueryKeys } from './query-keys'
import type { HookOptions } from './types'
```

**Constants/Config**: Pure data files do NOT need `'use client'` (74.2 lesson)
**Type files**: Pure type files do NOT need `'use client'`
**Hook files**: MUST have `'use client'` if they use React hooks

### Critical Rules

1. **NEVER change functionality** — this is pure structural refactoring
2. **Keep `'use client'` directive** — must be on hook files using React hooks
3. **Pure data/config/type files do NOT need `'use client'`** — lesson from 74.2-74.3
4. **Don't duplicate types** — import from source (74.2 code review finding)
5. **Run tests after EACH file split** — don't batch validation
6. **File size limit is 200 lines** — ESLint enforced, no exceptions
7. **Extracted files also ≤200 lines** — don't just move the problem
8. **Barrel re-exports preserve consumer API** — AC #3 critical
9. **DRY: hooks-v1/ should re-export from hooks/** — don't maintain two copies
