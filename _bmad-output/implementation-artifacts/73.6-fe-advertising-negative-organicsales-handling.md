## User Story

**As a** seller viewing the advertising analytics page,
**I want** negative organicSales values to be clearly flagged with an explanation and filterable,
**so that** I understand that over-attribution occurred and can exclude those entries from my analysis.

---

## Acceptance Criteria

### AC-1: Negative OrganicSales Display in Tables
- [x] In PerformanceMetricsTable: negative values already show amber warning icon + "Переатрибуция" badge + tooltip (VERIFIED existing implementation)
- [x] In MergedGroupTable aggregate row: negative organicSales shows amber warning icon + "Переатрибуция" badge + tooltip (matching PerformanceMetricsTable pattern)
- [x] In MergedGroupTable detail rows: same negative handling for individual products

### AC-2: Over-Attribution Count Badge
- [x] Warning banner above the performance table: "⚠️ N товаров с over-attribution (переатрибуция рекламы)"
- [x] Shows count of data rows where organic_sales < 0
- [x] Hidden when count is 0 (no banner shown)

### AC-3: Filter Toggle
- [x] Toggle control in the banner: "Скрыть"
- [x] When activated, table rows with negative organicSales are filtered out
- [x] Both PerformanceMetricsTable and MergedGroupTable respect the filter
- [x] Filter state does NOT persist in URL (session-only)

### AC-4: Summary Recalculation
- [x] When filter is active, summary cards recalculate excluding negative organic rows
- [x] Summary card values reflect only the visible (non-filtered) data
- [x] When filter is deactivated, summary cards revert to original values
