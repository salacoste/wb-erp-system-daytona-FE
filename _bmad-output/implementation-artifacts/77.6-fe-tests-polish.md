### Previous Story Intelligence (77.5)

**Key learnings from 77.5 that impact this story:**

1. **ESLint hook runs on every edit**: Must add import + usage in single edit to avoid unused variable errors.
2. **CSV Blob interception pattern**: `globalThis.Blob = class MockBlob extends OrigBlob` captures CSV content from constructor args (jsdom limitation — `.text()` not available).
3. **Russian locale formatting**: `formatPercentage(5.5)` → `"5,5 %"`, `formatCurrency(1234)` → `"1 234 ₽"`. Use regex matchers like `/5[.,]5/` for locale-agnostic assertions.
4. **deliveryCoverageRatio is pre-wired**: Computed in page state, passed to health score, but NOT consumed by any UI component. Documented as "pre-wired for future use."
5. **`calculateHealthScore()` has zero UI callers**: The function exists but no component calls it directly. The health score is currently dead code — test the function but don't expect to find it rendered.
6. **Sort icon direction**: `getSortIcon` now returns `ArrowUp`/`ArrowDown` based on sort order (not just static `ArrowUpDown`). Added in 77.5 code review fix M1.
